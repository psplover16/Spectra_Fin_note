一相依性與函數相依

相依性（Dependency）描述關聯中「某些屬性決定另一些屬性」的限制關係；最重要的一種是函數相依（其餘如多值相依、合併相依，分別對應 4NF、5NF）。

函數相依（Functional Dependency, FD）完整定義

在關聯 R 中，給定屬性集合 X、Y。若 R 內任意兩列，只要在 X 上的值相等，則在 Y 上的值也必定相等，就稱「X 函數決定 Y」（或 Y 函數相依於 X），記作 X → Y。X 稱決定因素（determinant）、Y 稱相依因素。

白話：知道 X 的值，就能唯一決定 Y 的值。例：學號 → 姓名——同一個學號一定對到同一個姓名。能從已知 FD 推導出所有隱含 FD 的工具，就是後面的阿姆斯壯公理。

💡 為什麼重要正規化的每一步，本質都在問「哪個屬性被哪個屬性決定」。先能寫出函數相依，才能判斷關聯違反第幾正規化、該怎麼拆。

二函數相依的種類

以下四種對正規化最關鍵（X、Y 為屬性集合）：

種類定義與正規化的關聯
完全函數相依
Full FD		Y 相依於整個 X，且不相依於 X 的任何真子集2NF 的要求
部分函數相依
Partial FD		Y 只相依於複合鍵 X 的一部分（真子集）違反 2NF
遞移函數相依
Transitive FD		X→Y、Y→Z 且 Y 不→X，使得 X→Z（透過中介 Y）違反 3NF
顯然函數相依
Trivial FD		Y ⊆ X（右邊是左邊的子集）恆成立、可忽略
💡 一句話記憶部分相依＝「只用半把鑰匙就開門」（複合鍵的一部分就決定了某屬性）；遞移相依＝「繞了一手」（A 決定 B、B 再決定 C）。2NF 砍部分相依、3NF 砍遞移相依。

三三個基本公理

以下 X、Y、Z 皆代表屬性集合（⇒ 表示「可推出」）：

公理形式說明
反身律
Reflexivity		Y ⊆ X ⇒ X → Y一個集合可決定它的子集（顯然相依）
擴充律
Augmentation		X → Y ⇒ XZ → YZ兩邊同時加入屬性，相依仍成立
遞移律
Transitivity		X → Y, Y → Z ⇒ X → Z相依可串接

這三條公理即可推導出所有函數相依（健全且完備），其餘規則都由它們導出。

💡 理解（反身律最直覺）{學號, 姓名} → 姓名 一定成立——知道一組屬性，當然知道其中任一個。這種右邊是左邊子集的相依，稱為「顯然函數相依（trivial FD）」。

四三個導出律（由基本公理推出）

規則形式說明
聯合律
Union		X → Y, X → Z ⇒ X → YZ右邊可合併
分解律
Decomposition		X → YZ ⇒ X → Y, X → Z右邊可拆開
擬遞移律
Pseudotransitivity		X → Y, WY → Z ⇒ WX → Z帶條件的遞移

五屬性閉包 X⁺（最實用的工具）

屬性閉包（Attribute Closure）X⁺：是「由 X 能函數決定的所有屬性」之集合。

計算演算法

  1. 令 X⁺ = X。
  2. 反覆檢查每條 FD A → B：若 A ⊆ X⁺，就把 B 加入 X⁺。
  3. 直到 X⁺ 不再變大為止。

範例

每套用一條相依，閉包就長大一次，直到無法再加入新屬性

兩大用途

  • 判斷 X → Y 是否成立：看 Y 是否 ⊆ X⁺。
  • 判斷 X 是否為超鍵：若 X⁺ = 全部屬性，則 X 是超鍵；若再「拿掉任一屬性就不再涵蓋全部」，則為候選鍵。

上例 學號⁺ = 全部屬性，故學號是候選鍵。

六結論

阿姆斯壯公理（反身、擴充、遞移三基本 ＋ 聯合、分解、擬遞移三導出）讓我們能推導所有函數相依；搭配屬性閉包，即可判斷 FD、找出候選鍵，進而判斷正規化形式，是正規化的理論基礎。

⚠️ 考點提醒
  • 函數相依四類：完全（2NF 要求）、部分（破 2NF）、遞移（破 3NF）、顯然（恆成立）。
  • 三個基本公理：反身（Reflexivity）、擴充（Augmentation）、遞移（Transitivity）——必記。
  • 阿姆斯壯公理具健全（sound）且完備（complete）性。
  • 聯合、分解、擬遞移為導出律（由三基本公理推得）。
  • 屬性閉包 X⁺ 兩大用途：判斷 FD（Y⊆X⁺）、判斷超鍵／候選鍵（X⁺＝全部屬性）。
  • 右邊是左邊子集的相依 = 顯然函數相依（trivial FD）。
