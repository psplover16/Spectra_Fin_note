一SQL 概說與四大分類

SQL（Structured Query Language，結構化查詢語言）是操作關聯式資料庫的標準語言。依功能可分為四大類：

看「動到什麼」分類：動結構＝DDL、動資料＝DML、動權限＝DCL、控制交易＝TCL
類別全名功能代表指令
DDLData Definition Language
資料定義語言		定義／修改資料庫結構CREATE、ALTER、DROP、TRUNCATE
DMLData Manipulation Language
資料操作語言		對表中的資料進行存取INSERT、UPDATE、DELETE、SELECT
DCLData Control Language
資料控制語言		控制使用者權限GRANT、REVOKE

題目常問的「三大類」指 DDL／DML／DCL；TCL 為交易控制，部分教材另列。

二DDL 資料定義語言

作用對象：資料庫的結構（綱要）。

  • CREATE：建立物件（表、檢視表、索引等）。
  • ALTER：修改物件結構（如新增欄位）。
  • DROP：刪除整個物件（含結構與資料）。
  • TRUNCATE：清空表中所有資料，但保留表結構。

特性：DDL 指令通常會自動提交（auto-commit），執行後即生效。

💡 重點：TRUNCATE 是 DDL（常考）＋ rollback 細節TRUNCATE 整批釋放資料頁、速度快、不可加 WHERE。關於 rollback：考試上答「不能 rollback」（因視為 DDL、自動提交）；但實務上 SQL Server、PostgreSQL 在交易中「可」rollback，Oracle、MySQL「不可」。→ 記「考試答不能、實務看系統」。

三DML 資料操作語言

作用對象：資料表中的資料（列）。

  • INSERT：新增資料列。
  • UPDATE：修改資料列。
  • DELETE：刪除資料列（可加 WHERE、可 rollback）。
  • SELECT：查詢資料。
💡 SELECT 的歸類多數教材把 SELECT 歸於 DML；部分教材獨立為 DQL（Data Query Language，資料查詢語言）。兩種說法都要會，作答時可註明「SELECT 屬 DML（部分稱 DQL）」。

四DCL 資料控制 與 TCL 交易控制

DCL（Data Control Language）—— 控制存取權限

  • GRANT：授予權限。
  • REVOKE：收回權限。

TCL（Transaction Control Language）—— 管理交易

  • COMMIT：確認交易、永久寫入。
  • ROLLBACK：回復交易至先前狀態。
  • SAVEPOINT：設定交易內的存檔點，可部分回復。

💡 理解（本質差異）DELETE 逐列刪、留軌跡（可回復、會觸發 trigger）；TRUNCATE 像「整桶倒掉」、直接釋放空間（快但不留逐列軌跡）；DROP 連桶子（表結構）一起丟。

六結論

SQL 依功能分為 DDL（結構）、DML（資料）、DCL（權限）、TCL（交易）四類。常考辨析包括：TRUNCATE 屬 DDL、SELECT 多歸 DML，以及 DELETE／TRUNCATE／DROP 的差異。

⚠️ 考點提醒
  • TRUNCATE 屬 DDL（不是 DML）—— 最常考的陷阱。
  • DELETE 是 DML、可加 WHERE、可 rollback；TRUNCATE 是 DDL、清空全表、考試答不可 rollback。
  • DROP 連表結構一起刪除。
  • GRANT／REVOKE 屬 DCL；COMMIT／ROLLBACK 屬 TCL。
  • SELECT 多歸 DML，部分教材稱 DQL。
