一JOIN 連接（最重要）

為什麼需要 JOIN：正規化為了消除重複，把資料拆成多張表；查詢時要用 JOIN 依「關聯欄位（通常是外來鍵）」把它們接回來。

深色 ＝ 該 JOIN 保留的列。兩圓分別代表左表、右表，交疊處 ＝ 兩表對得上的列
JOIN 型別保留哪些列
INNER JOIN只保留兩表都對得上的列（交集）
LEFT (OUTER) JOIN左表全部 ＋ 右表對得上的；對不上補 NULL
RIGHT (OUTER) JOIN右表全部 ＋ 左表對得上的；對不上補 NULL
FULL (OUTER) JOIN兩表全部；對不上的一邊補 NULL
CROSS JOIN笛卡兒積：每列兩兩相配，無 ON 條件

語法與範例

SELECT emp.name, dept.name FROM emp INNER JOIN dept ON emp.dept_id = dept.id;
SELECT emp.name, dept.name FROM emp LEFT JOIN dept ON emp.dept_id = dept.id; -- 沒部門的員工也會列出，dept.name 顯示 NULL
💡 INNER 與 LEFT 差在哪同一筆查詢，INNER 會把「對不上的列」丟掉；LEFT 會保留左表那些對不上的列（右邊欄位補 NULL）。想「不漏掉左表任何一列」就用 LEFT。

二彙總函式與 GROUP BY / HAVING

彙總函式（Aggregate）

COUNT 計數、SUM 總和、AVG 平均、MAX 最大、MIN 最小。

GROUP BY（分組）與 HAVING（分組後篩選）

SELECT dept_id, COUNT(*) AS 人數, AVG(salary) AS 平均薪 FROM emp GROUP BY dept_id HAVING COUNT(*) >= 3;

語意：依 dept_id 分組，對每組算人數與平均薪，再只留「人數 ≥ 3」的組。

💡 WHERE 與 HAVING 的差別WHERE 在分組前逐列篩選（此時還算不出 COUNT/AVG，故 WHERE 不能放彙總函式）；HAVING 在分組後對「每一組」篩選，可用彙總函式。

三子查詢（Subquery）

把一個 SELECT 巢狀在另一個查詢裡，常放在 WHERE。常搭配 IN、EXISTS 或比較運算子。

SELECT name FROM emp WHERE dept_id IN ( SELECT id FROM dept WHERE name = '研發部' );

語意：先查出「研發部」的部門 id，再撈出屬於這些部門的員工。

四集合運算

運算意義
UNION合併兩查詢結果，去除重複
UNION ALL合併但保留重複（較快）
INTERSECT交集（兩邊都有的列）
EXCEPT（Oracle 為 MINUS）差集（左有右無的列）

條件：上下兩個查詢的欄位數量與型別需相容。

SELECT name FROM emp_taipei UNION SELECT name FROM emp_taichung;

五常用運算子與其他

運算子意義例
BETWEEN a AND b範圍（含端點）salary BETWEEN 30000 AND 50000
IN (…)屬於清單之一dept_id IN (1, 2, 3)
LIKE模糊比對name LIKE '王%'
IS NULL判斷空值addr IS NULL
DISTINCT去除重複列SELECT DISTINCT city

LIKE 萬用字元：% ＝ 任意多個字元、_ ＝ 剛好一個字元。別名用 AS（給欄位或表取簡名）。

SELECT name, salary FROM emp WHERE salary BETWEEN 30000 AND 50000 AND name LIKE '王%' AND dept_id IS NOT NULL;
💡 空值不能用 = 比判斷空值要用 IS NULL ／ IS NOT NULL，不能寫 = NULL（NULL 代表「未知」，和任何值比較都不成立）。

六結論

正規化把資料拆開，JOIN 再依關聯欄位接回來（INNER 取交集、LEFT／RIGHT／FULL 保留某邊或雙邊）。彙總函式搭 GROUP BY 分組統計、HAVING 於分組後篩選；子查詢巢狀求值；集合運算合併結果（UNION 去重）。這些與 CRUD（講義 08）合起來即涵蓋 SQL 基本查詢能力。

⚠️ 考點提醒
  • 五種 JOIN：INNER（交集）、LEFT／RIGHT（保留某一邊全部）、FULL（雙邊全部）、CROSS（笛卡兒積）。
  • WHERE 不能放彙總函式，要用 HAVING；WHERE 分組前、HAVING 分組後。
  • COUNT(*) 算列數；COUNT(欄位) 不計 NULL。
  • UNION 去重、UNION ALL 留重複；差集 EXCEPT（Oracle 為 MINUS）。
  • LIKE：% 任意多字元、_ 單一字元；判斷空值用 IS NULL（非 = NULL）。
