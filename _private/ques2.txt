- [會畫]：建議自己畫圖，例如 OSI、memory hierarchy、process state、deadlock、thrashing。
- [比較]：常以表格題、配對題或觀念題出現。
- [補充]：不是原文主軸，但近年或常見教材會搭配考。

- 準備自我介紹：學經歷、報考動機、資訊背景、與職缺相關經驗。
- 準備專業口試：
  - OSI 7 層、資安事件處理、資料庫交易、作業系統排程、雲端與備份。
  - 能用白話說明技術，不只背名詞。
- 準備情境題：
  - 若公司遭遇勒索軟體怎麼處理。
  - 若系統效能突然下降如何排查。
  - 若資料庫資料異常或備份失敗如何處理。
- 準備國營或公部門特性：
  - 穩定性、法遵、資安、服務不中斷、跨部門溝通。
- 建議練習：
  - 1 分鐘自我介紹。
  - 3 分鐘說明一個專案或學習經驗。
  - 以 STAR 法回答行為題：Situation、Task、Action、Result。


最後複習順序建議

第一輪：建立地圖
- 計概：馮紐曼、RISC/CISC、memory、cache、補數、浮點數。
- OS：process、scheduling、deadlock、virtual memory。
- DS：複雜度、tree、graph、sorting。
- DB：SQL、key、normalization、ACID。
- Network：OSI、TCP/IP、routing、TCP/UDP、資安。

第二輪：做計算題
- Pipeline。
- Clock / CPI / MIPS。
- 位址與容量。
- 補數、浮點數、CRC、漢明碼。
- CPU scheduling。
- Banker's algorithm。
- Page replacement。
- Disk scheduling。
- Array address。
- Subnet / CIDR。

第三輪：背比較表
- RISC vs CISC。
- SRAM vs DRAM。
- ROM / PROM / EPROM / EEPROM。
- Write Through vs Write Back。
- Process vs Program。
- Paging vs Segmentation。
- TCP vs UDP。
- IDS vs IPS。
- Symmetric vs Asymmetric Encryption。
- SDLC / Agile / Spiral / Prototype。

第四輪：歷屆題回補
- 把錯題依章節補回本清單。
- 每個錯題標記原因：不熟、算錯、看錯題目、觀念混淆。
- 考前一週優先看錯題與比較表。
