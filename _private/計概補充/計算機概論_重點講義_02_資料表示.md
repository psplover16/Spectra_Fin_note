## 一、數字系統與進位轉換（Number Systems）

> **一句話核心**：同一個「量」，可以用不同的「基底（base）」寫出來；轉換就是換一種寫法。

電腦用**二進位**，因為電路只有兩種穩定狀態（高／低電壓、開／關），用 0／1 表示最可靠。常見四種：

| 進位 | 基底 | 可用數字 |
|---|---|---|
| 二進位 Binary | 2 | 0、1 |
| 八進位 Octal | 8 | 0～7 |
| 十進位 Decimal | 10 | 0～9 |
| 十六進位 Hex | 16 | 0～9、A～F |

**四個轉換方法**

- **其他 → 十進位**：位值展開（每位數 × 基底的位置次方，再相加）。
- **十進位 → 其他**：**除基取餘，由下往上讀**。
- **二 ↔ 八**：每 **3** 位二進位 = 1 位八進位（因為 2³ = 8）。
- **二 ↔ 十六**：每 **4** 位二進位 = 1 位十六進位（因為 2⁴ = 16）。
- （小數部分：十進位小數 → 二進位用「**乘基取整，由上往下讀**」。）

**範例 1（二 → 十）**：110101₂ 是多少？

- = 1×2⁵ + 1×2⁴ + 0×2³ + 1×2² + 0×2¹ + 1×2⁰
- = 32 + 16 + 0 + 4 + 0 + 1 = **53**

**範例 2（十 → 二）**：把 45 轉成二進位。

```
45 ÷ 2 = 22 … 餘 1   ↑ 由下往上讀
22 ÷ 2 = 11 … 餘 0   |
11 ÷ 2 = 5  … 餘 1   |
 5 ÷ 2 = 2  … 餘 1   |
 2 ÷ 2 = 1  … 餘 0   |
 1 ÷ 2 = 0  … 餘 1   |
```
- 由下往上：**101101₂**（驗證：32 + 8 + 4 + 1 = 45 ✓）

**範例 3（二 → 十六）**：11010110₂ 轉十六進位。

- 從右每 4 位一組：`1101` `0110` = **D6₁₆**（1101 = 13 = D、0110 = 6）

> ⚠️ **國考考點**
> - 整數：除基取餘（往上讀）；小數：乘基取整（往下讀）。
> - 二↔八每 3 位、二↔十六每 4 位，別記反。
> - 位值展開算十進位。

## 二、整數表示：二補數與溢位（Two's Complement）

> **一句話核心**：電腦用「二補數」表示有號整數，因為它讓加減法統一處理，而且 0 只有一種。

表示負數有三種做法，重點是最後勝出的二補數：

- **帶符號大小**：最高位當符號（0 正 1 負）。缺點：有 +0 與 −0、運算麻煩。
- **一補數**：負數 = 正數每位反相。仍有 ±0 問題。
- **二補數**：**負數 = 一補數 + 1**。優點：**0 只有一種、加減可直接相加**。← 現代電腦採用

**求二補數（負數 −x，以 n bits）**：寫出 x 的二進位 → 每位反相 → 再 +1。

**範例 1**：求 −20 的 8-bit 二補數。

- 20 = `00010100`
- 反相（一補數）= `11101011`
- +1 = **`11101100`**

**範例 2**：8-bit 二補數 `11111011` 是多少？

- 最高位是 1 → 負數。把它「轉回正」看大小：反相 `00000100` → +1 = `00000101` = 5
- 所以是 **−5**。
- （也可直接展開：−128 + 64 + 32 + 16 + 8 + 2 + 1 = −128 + 123 = −5 ✓）

**表示範圍（n bits 二補數）**：−2ⁿ⁻¹ ～ 2ⁿ⁻¹ − 1。

- 例：8 bits → **−128 ～ +127**（負數比正數多一個）。

**溢位（Overflow）判斷**：二補數加法直接相加（最高進位丟棄）；當「**兩個同號數相加，結果卻變不同號**」就是溢位。

**範例 3（溢位）**：8-bit 計算 64 + 64。

- 64 = `01000000`，相加 = `10000000`
- 兩個正數相加，結果最高位卻變 1（負）→ **溢位**（`10000000` 在二補數是 −128，明顯算錯）。

> ⚠️ **國考考點**
> - **二補數 = 一補數 + 1**；現代電腦採二補數。
> - 範圍 −2ⁿ⁻¹ ～ 2ⁿ⁻¹ − 1（**負的比正的多一個**）。
> - 溢位＝**同號相加變異號**。
> - 二補數的 0 只有一種。

## 三、浮點數表示（Floating Point）

> **一句話核心**：要表示很大、很小或帶小數的數，就用「科學記號」的方式存——拆成符號、指數、尾數三段。

固定小數點不夠用，改成 **(−1)^符號 × 尾數 × 2^指數** 的形式。**IEEE 754 單精度（32 bits）**結構：

```
[ 符號 S ][   指數 E   ][        尾數 M        ]
   1 bit      8 bits            23 bits
```

- **符號 S**：0 正、1 負。
- **指數 E**：用**偏移表示法（bias）**，單精度 bias = 127，真正指數 = E − 127。
- **尾數 M**：規格化成 `1.xxxx` 後的小數部分（前面那個 1 固定省略，叫**隱藏位**）。

**值 = (−1)^S × 1.M × 2^(E − 127)**

**範例**：把十進位 6.5 表示成單精度浮點。

- 6.5 = `110.1₂`
- 規格化（小數點前留一個 1）：`1.101 × 2²`
- 符號 S = 0（正）
- 指數：真正指數 2 → E = 2 + 127 = 129 = `10000001`
- 尾數：取 `101`，後面補 0 到 23 位
- 合起來：`0 10000001 10100000000000000000000`

> ⚠️ **國考考點**
> - 浮點 = **符號 + 指數（bias 偏移）+ 尾數**三段。
> - 單精度 32 bits（1+8+23）、bias = 127；雙精度 64 bits（1+11+52）、bias = 1023。
> - 規格化有**隱藏位 1**。
> - 浮點數**有精度誤差**，某些十進位小數無法精確表示。

## 四、字元與資料編碼（Character Encoding）

> **一句話核心**：電腦只懂 0／1，文字要先用「編碼」對應到一個數字才能存。

- **ASCII**：用 **7 bits（128 個字元）**，常擴充為 8 bits。涵蓋英文字母、數字、符號、控制字元。
  - 必記值：**'A' = 65、'a' = 97、'0' = 48**（小寫比大寫大 32）。
- **Unicode**：為涵蓋**全世界文字（含中文）**而設計，碼位範圍很大。**UTF-8／UTF-16** 是它的編碼方式；UTF-8 為**可變長度（1～4 bytes）、相容 ASCII**。
- **BCD（二進化十進）**：每個十進位數字用 **4 bits** 表示（0000～1001）。直觀、無轉換誤差，但較浪費空間（4 bits 只用到 10 種）。

**範例 1（ASCII）**：已知 'A' = 65，求 'D'。

- D 比 A 多 3 個位置 → 65 + 3 = **68**。

**範例 2（BCD）**：用 BCD 表示十進位 39。

- 3 → `0011`、9 → `1001` → **`0011 1001`**

> ⚠️ **國考考點**
> - ASCII 為 **7 bits（128 字）**；'A'=65、'a'=97、'0'=48。
> - Unicode 涵蓋多國語言；**UTF-8 可變長、相容 ASCII**。
> - BCD 每位數字 **4 bits**，範圍 0000～1001。

## 五、錯誤偵測與更正（Error Detection & Correction）

> **一句話核心**：資料在傳輸或儲存時可能位元翻轉出錯，加上「檢查位」就能偵測、甚至更正錯誤。

**同位檢查（Parity Bit）**

- 加一個檢查位，讓 1 的總數變成偶數（**偶同位**）或奇數（**奇同位**）。
- 能力有限：**只能偵測「奇數個」位元錯誤，不能更正，也偵測不到偶數個錯**。

**漢明碼（Hamming Code）**

- 加入多個檢查位（放在第 1、2、4、8…即 **2 的次方位置**），不只能偵測，還能**更正單一位元錯誤**。
- 檢查位數量 r 必須滿足：**2ʳ ≥ m + r + 1**（m = 資料位元數）。
- 原理：每個檢查位負責一組位置，接收端用各檢查位算出「出錯位置的編號」，直接把該位翻回來。

**範例 1（偶同位）**：要傳資料 `1010101`（裡面有 4 個 1，偶數）。

- 偶同位要讓 1 的總數維持偶數，現在已是偶數 → 檢查位 = **0**。
- （若用奇同位，則檢查位 = 1，湊成奇數個 1。）

**範例 2（漢明碼檢查位數）**：資料有 4 bits，需要幾個檢查位？

- 代入 2ʳ ≥ m + r + 1，試 r = 3：2³ = 8 ≥ 4 + 3 + 1 = 8 ✓
- 所以需 **3 個檢查位**，總長 7 bits，即常見的 **(7, 4) 漢明碼**。

> ⚠️ **國考考點**
> - 同位檢查：**只偵測奇數個錯、不能更正、偵測不到偶數個錯**。
> - 漢明碼：能**偵測並更正單一位元錯**；檢查位放在 2 的次方位置。
> - 檢查位數公式：**2ʳ ≥ m + r + 1**。
