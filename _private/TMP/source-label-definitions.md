# 全域來源標記定義

generated_at: 2026-06-13 10:52:00 +08:00  
scope: `_private` 根目錄允許來源 txt/md 與本輪輔助來源  
purpose: 給 route source inventory、topic prompt、content writer、verifier 與 import readiness 共用，避免每個副代理自行猜測方括號標記的意思。

本文件是第 16 組全路由教材重做的全域契約。方括號標記不是視覺裝飾，而是決定教材草稿必須補出哪些內容。所有 route 在建立 topic prompt 前都必須先引用本文件；若來源出現本文件未定義、且看起來像教材標記的候選，topic 必須停在 `draft` 或 `blocked`，不得產生 `.verified.md`。

## 分類規則

| Classification | 定義 | 處理方式 |
| --- | --- | --- |
| valid source label | 來源檔用來指示教材寫法、考試定位或學習行動的標記。 | 必須寫入 topic prompt，並依本文件展開成教材內容。 |
| auxiliary label | 本輪輔助來源出現，但不一定屬於正式 route source 的標記。 | 使用前必須確認來源角色；若導入正式教材，仍要依本文件展開。 |
| non-label syntax/code token | 程式碼索引、陣列內容、任務 checkbox、泛型或其他非教材標記。 | 不得寫入 prompt 的 source label 清單，也不得影響教材結構。 |
| unknown label | 看起來像教材標記，但不在本文件定義內，也不是明確的非標記語法。 | 阻擋 verifier，直到補入定義與展開規則。 |

## [必背]

label: [必背]  
classification: valid source label

### 定義

國考核心記憶點。考生需要能在沒有提示時寫出定義、關鍵字與最小作答句。

### 教材展開規則

- 先給正式定義，再用新手語言改寫一次。
- 說明為什麼常考、會怎麼被考。
- 提供最小背誦句，讓讀者能直接背起來。
- 補出國考作答模板，避免只懂概念但不會寫答案。

### Draft 必備段落

- `## 國考重點`
- `## 國考速記`
- `## 名詞解釋`
- `## 易錯提醒`
- `## 國考作答模板`

### Verifier 檢查點

- 定義不可只有標題或一句話帶過。
- 必須有中文與英文專有名詞對照。
- 必須有可背的最小句，不可只寫「請熟記」。

### 範例

`[必背] 程式內儲概念` 必須展開為 Stored-Program Concept 的定義、重要性、最小背誦句與常見誤解。

## [比較]

label: [比較]  
classification: valid source label

### 定義

兩個以上概念、架構、方法或名詞容易一起考，必須能判斷差異與適用情境。

### 教材展開規則

- 建立比較表或結構化條列。
- 說明差異原因，而不是只列特徵。
- 補出考試問法與判斷關鍵字。
- 若有易混點，要明確指出錯誤說法。

### Draft 必備段落

- `## 比較表`
- `## 判斷關鍵字`
- `## 易錯提醒`

### Verifier 檢查點

- 至少比較兩個對象。
- 每個比較欄位都要有明確差異。
- 不可把兩者寫成幾乎相同的摘要。

### 範例

`[比較] 馮紐曼架構 vs 哈佛架構` 必須補出記憶體、匯流排、優點、限制與常見應用差異。

## [會算]

label: [會算]  
classification: valid source label

### 定義

需要公式、代入、步驟演算、複雜度推導或數值轉換的內容。

### 教材展開規則

- 寫出公式與每個變數的意思。
- 用具體數字完整代入。
- 說明單位、邊界條件與常見陷阱。
- 若是時間複雜度，需說明輸入規模如何影響操作次數。

### Draft 必備段落

- `## 公式或規則`
- `## 變數定義`
- `## 代入例題`
- `## 易錯提醒`

### Verifier 檢查點

- 必須有完整計算過程。
- 不可只給答案。
- 公式符號必須先定義再使用。

### 範例

`[會算] 平均存取時間` 必須寫出公式、變數意義與一題完整代入。

## [會畫]

label: [會畫]  
classification: valid source label

### 定義

需要能畫出架構圖、流程圖、樹狀圖、資料流、狀態圖或記憶體配置的內容。

### 教材展開規則

- 說明繪圖順序。
- 定義圖中每個節點、箭頭、方向或資料流意義。
- 提供 ASCII 圖、文字圖或可照抄的畫法。
- 補充考試時畫圖的最低要求。

### Draft 必備段落

- `## 繪圖順序`
- `## 圖中元素`
- `## 文字圖`
- `## 易錯提醒`

### Verifier 檢查點

- 讀者不看原文也能畫出圖。
- 圖中箭頭或階層不能只出現未解釋符號。
- 若圖有方向，必須說明方向代表什麼。

### 範例

`[會畫] OSI 七層模型` 必須有由上到下或由下到上的順序與每層功能。

## [補充]

label: [補充]  
classification: valid source label

### 定義

不是第一優先背誦點，但能幫助理解、補足教材落差或避免選擇題陷阱。

### 教材展開規則

- 明確標示它是補充，不可混成必背核心。
- 說明它補的是背景、例外、延伸或版本差異。
- 若會影響考題判斷，要給一個簡短例子。

### Draft 必備段落

- `## 補充說明`
- `## 何時需要知道`
- `## 易錯提醒`

### Verifier 檢查點

- 不可把補充內容寫得比核心定義還重。
- 必須說明和主題的關係。

### 範例

`[補充] Cache miss 種類` 可補出 cold、capacity、conflict miss 的差異，但要標示其優先度。

## [易混淆]

label: [易混淆]  
classification: valid source label

### 定義

來源提醒讀者容易把兩個名詞、步驟、條件或考法混在一起。

### 教材展開規則

- 列出錯誤說法與正確說法。
- 說明為什麼錯。
- 補出考試辨認方法與關鍵字。

### Draft 必備段落

- `## 常見混淆`
- `## 正確辨認`
- `## 易錯提醒`

### Verifier 檢查點

- 至少包含一個錯誤說法。
- 必須給出正確改法。
- 不可只寫「不要混淆」。

### 範例

`[易混淆] 程序與行程` 必須比較 Program 與 Process 的差異。

## [考點]

label: [考點]  
classification: valid source label

### 定義

考官偏好的出題核心，通常需要整理成問法與答題抓字。

### 教材展開規則

- 將來源內容改寫成「可能怎麼問」。
- 補出答案應抓的關鍵字。
- 若能延伸到選擇題陷阱，列出辨認方式。

### Draft 必備段落

- `## 國考考點`
- `## 常見問法`
- `## 答題關鍵字`

### Verifier 檢查點

- 必須能看出考試用途。
- 不可只是把來源原句重貼。

### 範例

`[考點] DMA` 必須說明 DMA 為何減少 CPU 介入與常見問法。

## [建議]

label: [建議]  
classification: valid source label

### 定義

讀書策略、練習順序、最低掌握標準或準備方向。

### 教材展開規則

- 把建議改寫成具體行動。
- 說明先後順序與最低通過線。
- 若有練習題型，指出要練到什麼程度。

### Draft 必備段落

- `## 讀書建議`
- `## 練習順序`
- `## 最低通過標準`

### Verifier 檢查點

- 建議必須可執行。
- 不可只寫「多練習」或「自行補充」。

### 範例

`[建議] 布林代數` 必須說明先背定律，再練化簡，再練卡諾圖。

## [原文提醒]

label: [原文提醒]  
classification: valid source label

### 定義

來源作者對本段範圍、暫略內容、考試優先序或補充限制的提醒。

### 教材展開規則

- 保留來源提醒的用意。
- 說明哪些是本輪最低要求，哪些可後續延伸。
- 若原文提醒某處暫略，要把暫略風險寫清楚。

### Draft 必備段落

- `## 原文提醒`
- `## 本章最低要求`
- `## 後續可補`

### Verifier 檢查點

- 不可刪掉來源提醒。
- 不可把暫略內容誤寫成已完整涵蓋。

### 範例

`[原文提醒] 本段只整理常考協定` 必須告訴讀者本章不等於完整 RFC 教材。

## [補充建議]

label: [補充建議]  
classification: valid source label

### 定義

來源以外但對學習或作答有幫助的延伸建議。

### 教材展開規則

- 明確標示為延伸建議。
- 說明它和主題的關聯。
- 不得混成必背核心或 verifier 必過條件，除非 route prompt 另有要求。

### Draft 必備段落

- `## 補充建議`
- `## 使用時機`

### Verifier 檢查點

- 必須和主題相關。
- 不可擴寫成超出本 change 範圍的題庫或外部考古題收集。

### 範例

`[補充建議] 可補一張流程圖` 代表 writer 可加入文字圖，但不能改變核心範圍。

## [會做]

label: [會做]  
classification: valid source label

### 定義

讀者不只要知道名詞，還要能完成一個操作、判斷、設計、轉換或步驟型任務。

### 教材展開規則

- 拆成可執行步驟。
- 給一題完整示範。
- 補出完成後自我檢查方式。

### Draft 必備段落

- `## 操作步驟`
- `## 示範題`
- `## 檢核點`

### Verifier 檢查點

- 必須能照步驟完成任務。
- 不可只寫概念摘要。

### 範例

`[會做] 正規化` 必須示範如何從欄位相依判斷需要拆表。

## [會寫]

label: [會寫]  
classification: valid source label

### 定義

需要能寫出語法、SQL、程式片段、條件式、步驟文字或簡短申論答案。

### 教材展開規則

- 先解釋要寫什麼。
- 給可照抄的基本格式。
- 補出常見錯誤寫法與修正。

### Draft 必備段落

- `## 寫法模板`
- `## 範例`
- `## 常見錯誤`

### Verifier 檢查點

- 必須有可直接參考的寫法。
- 若是程式或 SQL，語意必須正確。

### 範例

`[會寫] SQL JOIN` 必須給基本語法、欄位來源與 WHERE/JOIN 條件差異。

## [必練]

label: [必練]  
classification: valid source label

### 定義

考前必須親手練習的題型或流程，只看懂不夠。

### 教材展開規則

- 指出最低練習題型。
- 給一題示範與一題自我練習方向。
- 說明練到什麼程度才算過關。

### Draft 必備段落

- `## 必練題型`
- `## 示範題`
- `## 自我檢查`

### Verifier 檢查點

- 必須有練習目標。
- 不可只有讀書建議。

### 範例

`[必練] ERD 轉關聯表` 必須有實際轉換步驟與檢查欄位。

## [會寫虛擬碼]

label: [會寫虛擬碼]  
classification: valid source label

### 定義

需要用 pseudo code 表達演算法流程，重點是邏輯，不是特定程式語言語法。

### 教材展開規則

- 說明輸入、輸出與主要變數。
- 寫出縮排清楚的 pseudo code。
- 補出每個關鍵步驟的目的。
- 若另有 Java 範例，pseudo code 必須和 Java 邏輯一致。

### Draft 必備段落

- `## 輸入與輸出`
- `## 虛擬碼`
- `## 步驟解釋`

### Verifier 檢查點

- 虛擬碼不能缺少終止條件。
- 變數名稱與步驟意義必須說明。

### 範例

`[會寫虛擬碼] DFS` 必須有 visited 標記、遞迴或 stack 流程與終止條件。

## [原文考點]

label: [原文考點]  
classification: valid source label

### 定義

來源原文已明確標出考點，writer 不得忽略或改寫到失去考試重心。

### 教材展開規則

- 保留原文考點的主旨。
- 改寫成國考可讀的重點句。
- 補出答題關鍵字與常見問法。

### Draft 必備段落

- `## 原文考點`
- `## 國考重點`
- `## 答題關鍵字`

### Verifier 檢查點

- 不可將原文考點降級成普通補充。
- 必須能追溯到來源段落。

### 範例

`[原文考點] 資訊系統角色` 必須保留原文對考試重點的定位。

## [原文保留]

label: [原文保留]  
classification: auxiliary label

### 定義

本輪輔助來源中出現的保留標記，用來提醒某段文字有保留原始語意或原始清單的需求。它目前只在輔助來源中出現，不視為正式 route source 的 valid source label，除非後續 route source 也出現或使用者明確要求導入。

### 教材展開規則

- 先確認它是否來自正式 route source。
- 若只來自輔助來源，應保留用意但不能直接變成 route 必背內容。
- 若被導入正式教材，要改寫成可教學、可應考的內容。

### Draft 必備段落

- `## 原文保留說明`
- `## 使用限制`
- `## 改寫方式`

### Verifier 檢查點

- 不可把輔助來源文字未經判斷直接匯入正式 app data。
- 若導入正式教材，必須有來源角色說明。

### 範例

`[原文保留]` 出現在輔助整理檔時，prompt 應提醒 writer 保留原意，但仍要轉成教材語氣。

## Non-label syntax/code token 排除規則

下列類型不是教材標記，不得寫入 source label list：

- 陣列或數列：`[1, 2, 3, 4, 5]`、`[5, 1, 4, 2]`
- 程式碼索引：`[i]`、`[j]`、`[j + 1]`、`[mid]`、`[right]`
- 公式或範圍符號：`[n * k]`、`[k + n - 1]`、`[left, right]`
- Markdown task checkbox：`[ ]`、`[P]`

若同一候選在某段上下文中同時可能是標記與程式碼，verifier 必須回到來源行判斷；無法判斷時視為 unknown label 並阻擋 verified。
