### [會做] 實際例子與操作步驟
題目：如何分辨白箱與黑箱測試？

1. White-box Test 知道內部結構，常檢查路徑、條件與程式邏輯。
2. Black-box Test 不看內部，只用輸入與輸出驗證需求。
3. Unit、Integration、Regression、Acceptance 等測試則依測試層級或目的分類。

結果：測試題要先分目的、層級與是否知道內部結構。
