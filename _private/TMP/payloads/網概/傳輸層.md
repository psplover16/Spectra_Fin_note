九、傳輸層

[比較] Circuit Switching vs Packet Switching
- Circuit Switching：先建立固定通道，例如傳統電話。
- Packet Switching：資料切成封包分別傳送，例如 Internet。

[必背] Packet
- 封包包含 header 與 payload。
- Header 放位址、序號、控制資訊等。

[必背] TCP
- Connection-oriented。
- Reliable delivery。
- Flow control。
- Congestion control。
- Ordered delivery。

[會畫] TCP 三方交握
1. Client → Server：SYN。
2. Server → Client：SYN + ACK。
3. Client → Server：ACK。

[會畫] TCP 四方交握
1. FIN。
2. ACK。
3. FIN。
4. ACK。

[必背] SYN Flood Attack
- 攻擊者大量送 SYN 但不完成握手，使 server 半開連線耗盡。
- 防禦：SYN cookies、rate limiting、防火牆、調整 backlog。

[必背] TCP Flow Control
- 透過 sliding window 與 receiver window 避免接收端被塞爆。

[必背] TCP Congestion Control
- Slow Start、Congestion Avoidance、Fast Retransmit、Fast Recovery。

[比較] TCP vs UDP
- TCP：可靠、連線導向、較慢，適合 HTTP、FTP、SMTP。
- UDP：不保證可靠、無連線、開銷小，適合 DNS、VoIP、串流、遊戲。
