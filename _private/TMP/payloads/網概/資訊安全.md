十一、資訊安全

[必背] 安全目標
- Confidentiality：機密性。
- Integrity：完整性。
- Availability：可用性。
- Non-repudiation：不可否認性。
- Authentication / Authenticity：認證性或真實性。

[比較] 防禦設備
- Firewall：依規則允許或阻擋流量。
- NGFW：加入應用識別、IPS、威脅情報等。
- WAF：Web Application Firewall，防護 HTTP/HTTPS 應用攻擊。
- IDS：偵測入侵並告警。
- IPS：偵測並主動阻擋。

[比較] 加密
- 對稱式加密：同一把 key 加解密，速度快，key distribution 困難。
- 非對稱式加密：public/private key，解決 key distribution，但速度較慢。
- Hash：單向摘要，不是加密，常用於完整性檢查。

[必背] 電子商務安全需求
- 機密性、完整性、不可否認性、可驗證性、存取控制。

[必背]
- 數位簽章：用私鑰簽章，公鑰驗證，提供完整性、身分驗證與不可否認性。
- Proxy Server：代理 client 或 server，可快取、過濾、匿名化或控管。
- VPN：建立加密通道。
- PPTP：早期 VPN 協定，安全性較弱，了解即可。
- DMZ：隔離對外服務區，降低內網暴露。
- EDR：Endpoint Detection and Response，端點偵測與回應。
- MDR：Managed Detection and Response，委外或託管式偵測回應服務。
- PKI：Public Key Infrastructure，包含 CA、憑證、CRL/OCSP。
- NIST：美國國家標準與技術研究院，常見資安框架來源。
- ISO 27001：資訊安全管理系統 ISMS 要求，現行主軸為 ISO/IEC 27001:2022。

[必背] 常見網攻
- 電腦病毒：需宿主程式，會感染檔案。
- Worm：可自我複製並透過網路散播。
- Trojan：偽裝成正常程式。
- Ransomware：勒索軟體，加密資料要求贖金。
- Phishing：釣魚，誘騙帳密或敏感資料。
- XSS：跨站腳本攻擊。
- SQL Injection：注入 SQL 指令。
- CSRF：跨站請求偽造。
- DoS / DDoS：阻斷服務。
- Man-in-the-Middle：中間人攻擊。
- ARP Spoofing、DNS Spoofing。

[補充] 近年常見觀念
- Zero Trust：永不信任、持續驗證、最小權限。
- MFA：多因素認證。
- Least Privilege：最小權限原則。
- Defense in Depth：縱深防禦。
- Backup 3-2-1：至少 3 份資料、2 種媒介、1 份異地。
