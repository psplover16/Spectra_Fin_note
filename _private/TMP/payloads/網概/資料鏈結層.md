七、資料鏈結層

[必背] 5-4-3 Rule
- 傳統乙太網路中繼器規則：5 個 segment、4 個 repeater、最多 3 個 populated segment。
- 現代交換式網路較少直接使用，但仍可能作為歷史觀念題。

[必背]
- 訊框化（Framing）：將 bit stream 切成 frame。
- Error Detection：常見 CRC。
- Flow Control：控制傳送速率。

[比較] HDLC vs PPP
- HDLC：位元導向資料鏈結協定。
- PPP：點對點協定，常見於撥接、PPPoE，可支援認證。

[比較] 傳輸方向
- Simplex：單工，單向傳輸。
- Half-duplex：半雙工，雙向但不能同時。
- Full-duplex：全雙工，雙向可同時。

[比較] 多重存取
- 無競爭多重存取：Token Passing、輪詢。
- 競爭多重存取：ALOHA、CSMA、CSMA/CD、CSMA/CA。

[比較] CSMA / CSMA/CD / CSMA/CA
- CSMA：先聽再傳。
- CSMA/CD：偵測碰撞後停止並退避，傳統乙太網。
- CSMA/CA：避免碰撞，常見於 Wi-Fi。

[必背] ARQ
- Stop-and-Wait ARQ。
- Go-Back-N ARQ。
- Selective Repeat ARQ。

[比較] Bridge / Switch
- Bridge：較早期，連接 LAN segment。
- L2 Switch：多埠 bridge，依 MAC table 轉送。
- L3 Switch：具 routing 功能，可在 VLAN 間轉送。
