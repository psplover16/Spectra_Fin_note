二、網路概論

[比較] LAN / MAN / WAN
- LAN：區域網路，範圍小，例如公司、校園。
- MAN：都會網路，城市範圍。
- WAN：廣域網路，跨城市或跨國，例如 Internet。

[比較] Client-Server vs P2P
- Client-Server：集中管理，伺服器提供服務，容易控管但伺服器可能成瓶頸。
- P2P：節點彼此提供資源，擴充性高但管理與安全較難。

[比較] HTTP vs HTTPS
- HTTP：明文傳輸，預設 port 80。
- HTTPS：HTTP over TLS，提供加密與憑證驗證，預設 port 443。

[必背] Stateless
- 定義：伺服器不保存每次請求間的狀態。
- 優點：簡單、容易擴充。
- 缺點：需靠 cookie、session、token 保存登入或購物車等狀態。

[比較] Session vs Cookie
- Cookie：存於 client，由瀏覽器帶給 server。
- Session：狀態多存於 server，client 只保存 session id。
- Token：常見於 API，例如 JWT，但需注意過期、簽章與撤銷問題。

[比較] 網路拓樸
- Bus：成本低，但主幹故障影響大。
- Ring：資料依環傳遞，故障可能影響整環。
- Star：以中心設備連接，易管理，中心故障影響大。
- Mesh：可靠度高，成本高。
