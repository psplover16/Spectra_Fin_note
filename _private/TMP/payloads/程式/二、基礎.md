二、基礎

[比較] Assembler vs Compiler vs Interpreter
- Assembler：組合語言轉機器碼。
- Compiler：將高階語言整體或大段編譯成目標碼。
- Interpreter：逐行或逐步解讀執行。

[必背]
- 變數：儲存資料的命名空間，注意型別與作用域。
- 函式：封裝可重用邏輯。
- 陣列：同型別連續資料集合。
- 迴圈：for、while、do-while。
- 條件：if-else、switch。
- 例外處理：try、catch、finally、throw。

[比較] 參數傳遞
- Call by Value：傳值，函式內修改不影響原值。
- Call by Address：傳位址，常見於 C 指標。
- Call by Reference：傳參考，可影響原物件或變數。
- Call by Name：延遲求值概念，較少見但可能考名詞。

[必背] static
- C/C++ 區域 static 變數：生命週期延長至程式結束，但作用域仍在區塊內。
- C/C++ 檔案層級 static：限制 linkage。
- Java static：屬於 class，不屬於特定 object。
