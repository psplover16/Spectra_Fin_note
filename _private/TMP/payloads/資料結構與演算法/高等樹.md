十、高等樹

[必背] AVL Tree
- 自平衡 BST。
- 任一節點左右子樹高度差最多 1。
- 插入或刪除後透過旋轉維持平衡。
- 旋轉：LL、RR、LR、RL。
- 搜尋、插入、刪除平均與最差多為 O(log n)。

[必背] B Tree
- 多路平衡搜尋樹，常用於磁碟索引與資料庫。
- 節點可有多個 key 與 child。
- 所有 leaf 在同一層。
- 搜尋、插入、刪除 O(log n)。
- 考點：階數、key 數、child 數、分裂、合併、借 key。

[必背] Heap Tree
- Complete Binary Tree。
- Max Heap：parent >= children。
- Min Heap：parent <= children。
- 插入：放最後再向上調整。
- 刪除 root：最後節點補 root，再向下調整。
- 搜尋任意值：通常 O(n)。
- 取最大或最小：O(1)。
- 插入與刪除 root：O(log n)。

[必背] Red-Black Tree
- 自平衡 BST。
- 節點顏色為紅或黑。
- Root 為黑。
- 紅節點不能有紅 child。
- 從任一節點到其 NIL leaf 的黑節點數相同。
- 搜尋、插入、刪除 O(log n)。
