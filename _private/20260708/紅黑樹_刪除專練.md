# 刪除 SOP

---

## 前置作業:刪除與判斷

### 1. 照常刪除

| `D`(你要刪的節點)有幾個小孩 | 做什麼 |
|:---:|:---|
| **0 個** | 直接砍掉 |
| **1 個** | 那個小孩頂替它的位置 |
| **2 個** | 找「**右子樹最小值**」當替身,把替身的 key 抄進來,**然後刪除那個替身** |

**兩個代號**(後面 16 題都用它們)

| | 意思 |
|:---|:---|
| **`y`** | **真正被刪掉或移走的節點**(是 `D`,或是替身) |
| **`x`** | **頂替 `y` 位置的節點**(可能是 NIL) |

> `y` 永遠只有 0 或 1 個小孩(替身是「一路往左到底」找到的,不可能有左小孩)。

### 2. 看顏色

| | 條件 | 動作 |
|:---:|:---|:---|
| **出口①** | **`y` 是紅色** | **SOP 結束,不用做事** |
| **出口②** | `y` 黑,但 **`x` 是紅色** | **把 `x` 塗黑,SOP 結束** |
| — | `y` 黑,`x` 也黑(含 NIL) | **產生「雙黑」**,進入下方修復 SOP |

> **「雙黑」= `x` 多背一個黑。**
> `x` 本來是紅 → 紅 + 黑 = 黑 → 直接塗黑就還清了(出口②)。
> `x` 本來是黑 → 黑 + 黑 = **雙黑** → 賴帳,要進四大情境。

### `y` 只有三種長相(所以不用擔心漏掉組合)

| `y` 的顏色 | `y` 的小孩數 | `x` | 走哪 |
|:---:|:---:|:---|:---|
| **紅** | **必定 0 個**(葉) | NIL | 出口① |
| **黑** | **1 個(必定是紅葉)** | 那個紅葉 | 出口② |
| **黑** | 0 個 | NIL | **雙黑 → 四大情境** |

> 性質 5 鎖死了組合:**紅節點不可能只有一個小孩;黑節點若只有一個小孩,那個小孩必定是紅葉。**

---

## 必背 SOP:雙黑修復四大情境

**前提假設**:雙黑節點在「**左邊**」。(如果在右邊,把口訣裡的左 / 右互換即可)
**觀察重點**:只看「**兄弟**」和「**姪子**(兄弟的小孩)」的顏色。

**請按照順序,從上往下套用這張表:**

| 情境 | 看到這個盤面… | 請執行這個 SOP 動作 | 接下來… |
|:---|:---|:---|:---|
| **Case 1** | **兄弟是紅色** | 1. 兄弟變黑,爸爸變紅<br>2. 對爸爸做 **左旋轉** | 轉變成下方 Case 2, 3, 4 |
| **Case 2** | **兄弟是黑色**<br>且 **兩個姪子都黑色** | 1. 兄弟變紅<br>2. **雙黑推給爸爸** | 見下方「Case 2 的三個結局」 |
| **Case 3** | **兄弟是黑色**<br>且 **近姪子(左)是紅色**<br>且 **遠姪子(右)是黑色** | 1. 兄弟變紅,近姪子變黑<br>2. 對兄弟做 **右旋轉** | 必定轉變成 Case 4 |
| **Case 4** | **兄弟是黑色**<br>且 **遠姪子(右)是紅色** | 1. 兄弟塗成爸爸原來的顏色<br>2. 爸爸變黑,遠姪子變黑<br>3. 對爸爸做 **左旋轉** | **完美破關,SOP 結束!** |

---

### ⚠️ Case 3 的「遠姪子是黑色」不能省

若**兩個姪子都是紅色**,正解是**直接跳 Case 4**(只轉 1 次)。
漏掉這個條件會先撞到 Case 3 → 變成 `Case 3 → Case 4`,**多轉一次**。

> 記法:**先看遠姪子。遠姪子紅 → 直接 Case 4。遠姪子黑、近姪子紅 → 才是 Case 3。**

---

### Case 2 的三個結局

雙黑推給爸爸之後:

| 爸爸的顏色 | 動作 |
|:---:|:---|
| **紅** | **爸爸塗黑,SOP 結束** |
| **黑** | 爸爸變成新的雙黑 → **重新套用此表** |
| **是根** | **SOP 結束**(全樹黑高一起 −1,一視同仁) |

> **Case 2 是四個情境裡唯一會迴圈的,而且一次都不旋轉。**

---

> **💡 考試小提示(名詞解釋)**
> - **兄弟**:雙黑在**左** → 兄弟 = 爸爸的**右**小孩;雙黑在**右** → 兄弟 = 爸爸的**左**小孩
> - **近姪子**:靠近雙黑節點的那個姪子(雙黑在左,近姪子就是**左**邊的)
> - **遠姪子**:遠離雙黑節點的那個姪子(雙黑在左,遠姪子就是**右**邊的)

```
雙黑在左(標準)                    雙黑在右(鏡像)

        爸爸                              爸爸
       /    \                            /    \
    雙黑     兄弟                     兄弟      雙黑
            /    \                   /    \
        近姪子   遠姪子           遠姪子   近姪子
```

> **鏡像時所有「左 / 右」對調,判斷邏輯一字不改。**

| | |
|:---|:---|
| **旋轉 ≤ 3 次** | 最壞路徑:`Case 1 → Case 3 → Case 4` |
| **變色 O(log n) 次** | Case 2 沿路上移 |
| **時間 O(log n)** | 找節點 + 找替身 + 修復 |

# 附錄|(可跳過)為什麼

> **這一節不用背。** 但看懂之後,四個 Case 就不需要背了。

---

## 一、換個看法:紅色 = 餘額,黑色 = 本金

> ### 黑節點 = **本金**(計入黑高)
> ### 紅節點 = **餘額**(不計入黑高,是「額外的」)

| 性質 | 翻譯 |
|:---|:---|
| **性質 5**(黑高處處相同) | 每條路徑的**本金**必須一樣多 |
| **性質 4**(不能紅接紅) | **餘額不能疊** |

**紅色就是可動用的錢。看到紅色,就是看到錢。**

---

## 二、刪除的每一條規則,都是同一句話

| 規則 | 用「餘額 / 本金」翻譯 |
|:---|:---|
| **`y` 是紅 → 什麼都不用做** | 你拿走的是**餘額**,本金沒動 |
| **`x` 是紅 → 塗黑就結束** | `x` **自己有餘額** → 轉成本金,補上缺口 |
| **雙黑** | 這條路的**本金少一塊**,而且身邊沒餘額可以轉 |
| **Case 2 之後爸爸是紅 → 塗黑結束** | **爸爸有餘額** → 直接拿來抵 |
| **推到根 → 結束** | 全樹本金一起少一塊,**誰都沒吃虧** |

---

## 三、四個 Case,只是在問「錢在哪」

### 先問:兄弟家有錢嗎?

> ### **看兩個姪子。有紅的 = 兄弟家有餘額。**

因為紅小孩**不佔黑高** —— 它就是掛在兄弟身上的**額外**資產。

| 兄弟 | 姪子 | 意思 |
|:---:|:---|:---|
| 黑 | **有紅的** | 有餘額,**借得到** → Case 3 / 4 |
| 黑 | 兩個都黑 | 兄弟身上只有自己那塊**本金**,借了它自己就垮 → **借不到** → Case 2 |

---

### Case 2|兄弟家也窮 → 兩家一起減,虧空上報

沒錢可借,那就**大家一起少一塊本金**(兄弟塗紅 = 本金變餘額)。

兩邊一樣窮 → 對爸爸來說公平 → **把「少一塊」的帳報給爸爸**。

| 爸爸 | 結果 |
|:---:|:---|
| **紅**(有餘額) | 拿來抵 → **結清** |
| **黑** | 爸爸成了新的雙黑 → **繼續往上報** |
| **是根** | 全樹一起少一塊,誰都沒吃虧 → **結清** |

> **只有 Case 2 會往上傳:合併之後虧空還在,只是換人扛。**

---

### Case 4|錢在遠端 → 直接借,收工

旋轉時,兄弟 `w` 會從**遠姪子頭上走掉** → 遠姪子那條路少一塊本金。

> **只有遠姪子本身是紅的(有餘額),才能把它塗黑補回來。**
> 它本來就是黑的話,塗了等於沒塗。

**那近姪子呢?** 旋轉時它**換邊搬到爸爸底下**,而爸爸剛好塗黑 —— 一進一出打平,幫不上忙。

---

### Case 3|錢在近端 → 先挪到遠端

近端的紅色是有錢,但**位置不對,遞不過來**。

先對兄弟轉一次,**把紅色挪到遠端** → 變成 Case 4 → 借。

---

### Case 1|你認錯人了

**這是最容易誤解的一個。它根本不是解法。**

```
      P(B)                     x 的「binary 兄弟」是 w
     /    \                    但 w 是紅的 ——
   x(BB)   w(R)                它其實跟 P 是「同一個節點」的一部分
          /    \
        wl(B)  wr(B)           ⇒ x 真正的兄弟是 wl,不是 w
```

Case 1 旋轉之後:

```
      w(B)
     /    \
   P(R)   wr(B)                x 的兄弟終於變成 wl 了
   /  \
  x(BB) wl(B)
```

> ### **Case 1 只是把畫法翻了一面,好讓 `x` 的「真兄弟」站到兄弟的位置上。**
> 雙黑一點都沒解決 —— 但你現在看得到真正的兄弟了。

(為什麼 `w` 跟 `P` 是「同一個節點」?看第四節。)

---

## 四、再深一層:紅黑樹其實是 2-3-4 樹

### 對應規則

> **一個黑節點,加上它的紅小孩,合起來是 B 樹裡的「同一個節點」。**

| 黑節點的紅小孩數 | 合起來是 | 幾個 key |
|:---:|:---:|:---:|
| 0 | **2-node** | 1 |
| 1 | **3-node** | 2 |
| 2 | **4-node** | 3 |

**紅色不是顏色,是一根「我跟我爸是同一個節點」的標記。**

### 四個 Case 的 B 樹意義

| Case | RB 動作 | **在 2-3-4 樹裡** | 旋轉 |
|:---:|:---|:---|:---:|
| **1** | 兄弟紅 → 旋轉換色 | **換畫法**。B 樹一點都沒變,只是把 `x` 的真兄弟叫出來 | 1 |
| **2** | 兩姪子黑 → 兄弟塗紅,往上推 | 兄弟是 **2-node**,沒有多的 key 可借 → **合併** → 爸爸下溢 → 往上 | **0** |
| **3** | 近姪子紅 → 旋轉換色 | **換畫法**。B 樹沒變,只是把要借的 key 挪到能借的位置 | 1 |
| **4** | 遠姪子紅 → 旋轉換色 | 兄弟是 **3-node / 4-node**,有多的 key → **借一個 key** → 結束 | 1 |

> ### **只有 Case 2(合併)和 Case 4(借)在做真正的事。**
> ### **Case 1 和 Case 3 都只是「換畫法」。**

「兄弟家有沒有紅姪子」= **「兄弟這個 B 樹節點是不是 2-node」**。
2-node 借不出去(借了自己就垮)→ 只能合併。這跟 B 樹刪除的邏輯**一字不差**。

### 這樣「旋轉 ≤ 3」就是廢話了

```
換畫法(Case 1)  1 轉
換畫法(Case 3)  1 轉
借  (Case 4)    1 轉
合併(Case 2)    0 轉 —— 只是記帳,不動樹
                ─────
                最多 3 轉
```

**Case 1 不可能出現兩次**(換完畫法,真兄弟就站好了)。
**Case 3 不可能出現兩次**(挪完錢,直接就借)。

---

## 五、記憶結構:只有三個問題

```
① 兄弟是紅的?    → 你認錯人了,先把真兄弟叫出來      (Case 1)
② 遠端有紅?      → 借,收工                          (Case 4)
③ 近端有紅?      → 先把錢挪到遠端,再借              (Case 3 → 4)
   都沒有         → 兩家一起窮,虧空報給爸爸          (Case 2)
```

---

## 六、順帶把插入也解釋了

| RB 插入 | 在 2-3-4 樹裡 | 旋轉 |
|:---|:---|:---:|
| 父親是黑 → 結束 | key 塞進 **2-node** → 變 3-node | 0 |
| **情況三**(叔叔黑,直線) | key 塞進 **3-node** → 變 4-node | 1 |
| **情況二**(叔叔黑,折線) | **換畫法** | 1 |
| **情況一**(叔叔紅) | 節點是 **4-node,塞不下了** → **分裂**,中間的 key 往上推 → 爸爸可能又溢位 → 往上 | **0** |

**插入旋轉 ≤ 2** = 換畫法(1)+ 完成(1)。分裂不旋轉。

### 新節點為什麼一律塗紅?

> 紅是**餘額**,不動本金 → 黑高不變 → **性質 5 永遠安全**。
> 塗黑就是**憑空多印一塊本金** → 全樹的帳立刻對不上。

**先放餘額,不動本金。這是紅黑樹所有操作的第一原則。**

```
      20(B)
     /    \
   10(R)  30(R)
```
**刪除 `10`。**

<br>

### ▼ 詳解

| 步驟 | 判斷 |
|:---|:---|
| 化簡 | `D = 10`,0 個小孩 → `y = 10`,`x = NIL` |
| 出口 | **`y` 是紅** → **結束** |

```
   20(B)
      \
      30(R)
```

**驗證**:`20→NIL(左)` = 1 黑;`20→30(R)→NIL` = 1 黑 ✔

**旋轉 0 次,變色 0 次。**

> 拿掉紅節點,所有路徑的黑數完全沒變。

## Q4|情況 4 → 一刀結束

```
        30(B)
       /    \
    20(B)   40(B)
            /   \
         35(R)  50(R)
```
**刪除 `20`。**

<br>

### ▼ 詳解

**起始樹驗證**:三條路徑黑數都是 2 ✔

| 步驟 | 判斷 |
|:---|:---|
| 化簡 | `y = 20`(黑葉),`x = NIL` |
| 出口 | 都黑 → `x` 雙黑 |
| fixup | `x` 在左,`w = 40(B)`。**遠** = `w.right = 50(R)` **紅** → **情況 4** |

**情況 4**(`x` 在左 → 左旋 `P`):

1. 對 `P(30)` **左旋** → `40` 上去,`30` 變 `40` 的左子,`35` 換邊到 `30` 的右邊
2. `w(40)` 接手 `P` 的顏色 → **黑**
3. `P(30)` → **黑**
4. **遠**小孩 `50` → **黑**

```
        40(B)
       /    \
    30(B)   50(B)
       \
       35(R)
```

**驗證**:根黑 ✔;`35(R)` 父 `30(B)` ✔;三條路徑黑數都是 2 ✔

**旋轉 1 次。**

## Q5|情況 3 → 情況 4

```
        30(B)
       /    \
    20(B)   40(B)
            /
         35(R)
```
**刪除 `20`。**

<br>

### ▼ 詳解

**起始樹驗證**:三條路徑黑數都是 2 ✔

| 步驟 | 判斷 |
|:---|:---|
| 化簡 | `y = 20`(黑葉),`x = NIL` |
| fixup | `x` 在左,`w = 40(B)`。**遠** = `w.right = NIL(黑)`;**近** = `w.left = 35(R)` → **情況 3** |

**① 情況 3**(`x` 在左 → 右旋 `w`):對 `w(40)` **右旋**;`40` ↔ `35` 換色

```
        30(B)
       /    \
      x     35(B)
               \
               40(R)
```

新 `w = 35(B)`,**遠** = `w.right = 40(R)` 紅 → **情況 4**

**② 情況 4**:對 `P(30)` **左旋**;`w(35)` 接手 `30` 的顏色(黑);`30`→黑;`40`→黑

```
        35(B)
       /    \
```

## 五個必記結論

| # | |
|:---:|:---|
| 1 | **`y` 只有三種長相**:紅葉 / 黑帶一個紅葉小孩 / 黑葉 |
| 2 | **`y` 紅 → 直接結束;`x` 紅 → 染黑結束。** 大部分刪除都在這裡收工 |
| 3 | **只有情況 2 會迴圈,而且一次都不轉** |
| 4 | **情況 1 只能出現一次**(它把 `P` 染紅,後面走不回情況 1)|
| 5 | **旋轉最多 3 次**:`情況 1 → 3 → 4`。這是唯一能打滿的路徑 |

## 三個最常見的錯

| 錯 | 對 |
|:---|:---|
| 一開始就跳進四情況 | **先看 `y` 紅 / `x` 紅兩個出口** |
| 「兩個小孩」當成第三種刪除 | 它是**降級機**:抄 key → 改刪後繼 → 後繼只有 0 或 1 個小孩 |
| `x` 上移後沿用上一輪的判斷 | **兄弟換人了,顏色要重新看**(見 Q15) |
| `x` 在右時把左右搞混 | **`x` 在右 → 所有左右對調**(`w = P.left`、近 = `w.right`、遠 = `w.left`) |
