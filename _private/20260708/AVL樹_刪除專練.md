# AVL 樹　刪除專練

> **高度約定**:`h(null) = 0`、`h(葉) = 1`、`h(x) = 1 + max(h(左), h(右))`
> **平衡因子**:`BF(x) = h(左) − h(右)`
> `★` = 失衡點　`◆` = 較高子

---

## 刪除 SOP(先背這個)

### 第一步|找出「真正要刪的節點」

設 `D` = 你要刪的那個值所在的節點。

| `D` 的小孩數 | 做什麼 |
|:---:|:---|
| **0** | 移除 `D` |
| **1** | 把那個小孩接到 `D` 原本的位置 |
| **2** | 從 `D.right` 一路往**左**走到底,得到 `S`。把 `S` 的值抄進 `D`。**改成去刪 `S`**(`S` 一定只有 0 或 1 個小孩,套上面兩列) |

> **被移除節點的父親 = 你的起點。**

### 第二步|從起點往上,一路做到根

對路徑上的**每一個**節點,依序做四件事:

**① 重算高度**　`h = 1 + max( h(左小孩), h(右小孩) )`
　　左右小孩的高度**直接讀**,不用重算。空的算 `0`。

**② 算 BF**　`BF = h(左小孩) − h(右小孩)`

**③ 判斷**

- `|BF| ≤ 1` → **不動**,跳到 ④
- `|BF| = 2` → 看**較高的那個小孩**的 BF,查表旋轉:

| 這個節點 BF | 較高子 BF | 做什麼 |
|:---:|:---:|:---|
| **+2** | `+1` 或 `0` | 對這個節點**右旋** |
| **+2** | `−1` | 先對**左小孩左旋**,再對這個節點**右旋** |
| **−2** | `−1` 或 `0` | 對這個節點**左旋** |
| **−2** | `+1` | 先對**右小孩右旋**,再對這個節點**左旋** |

**④ 往上一層,回到 ①**　直到處理完根節點。

### 旋轉怎麼畫

**右旋 `P`**　`L = P.left`;`b = L.right` 搬到 `P.left`

```
   P                L
  / \              / \
 L   c    ──►     a   P
/ \                  / \
a   b               b   c
```

**左旋 `P`**　`R = P.right`;`b = R.left` 搬到 `P.right`

```
   P                R
  / \              / \
 a   R    ──►     P   c
    / \          / \
   b   c        a   b
```

**檢查**:唸一次中序,順序沒變就對了。

### (選配)提早停手

不做也不會錯,只是多算幾層。考卷問「連鎖到哪一層」時才需要:

| 這一層發生了什麼 | 子樹高度 | 可以停? |
|:---|:---:|:---:|
| 沒失衡,`h` 沒變 | 不變 | **停** |
| 沒失衡,`h` 少 1 | 矮 1 | 往上 |
| **單旋**,較高子 BF = `±1` | 矮 1 | 往上 |
| **單旋**,較高子 BF = **`0`** | **不變** | **停** |
| **雙旋**(LR / RL) | 矮 1 | 往上 |

# 範例 A|二 → 零　＋　LR 雙旋　＋　連鎖

**特徵**:後繼是葉節點、第一次是雙旋、旋轉後矮 1 層 → 連鎖到根。

## 起始樹(12 節點,高度 5)

這是**高度 5 的最少節點 AVL 樹**(`N(5) = 12`),每個節點都在臨界值,一碰就倒。

```
                 50
             /        \
           30           70
         /    \        /   \
       20      40    60     80
      /  \    /        \
    10    25 35         65
    /
   5
```

**合法性驗證**

| 節點 | `h` | BF | | 節點 | `h` | BF |
|:---:|:---:|:---:|:---|:---:|:---:|:---:|
| `5` `25` `35` `65` `80` | 1 | 0 | | `60` | 2 | **−1** |
| `10` | 2 | +1 | | `70` | 3 | +1 |
| `20` | 3 | +1 | | `30` | 4 | +1 |
| `40` | 2 | +1 | | `50` | 5 | +1 |

全部 `|BF| ≤ 1` ✔

## 目標:刪除 `D = 70`

---

### 階段一|化簡:二換牌 → 降級成「零」

`D = 70` 有兩個小孩(`60`、`80`)→ **二換牌**

**找 `S`**:從 `D.right = 80` 出發,一路往左 → `80.left == null` → **`S = 80`**(右小孩自己就是最左者)

1. 把 `80` 的 key 抄到 `70` 這顆節點 → 名牌變 `80`
2. 改成去刪 `S = 80` —— 它是**葉節點** → **零直接** → 直接移除

> ⚠️ 全程有「**兩個 80**」。以下把**換過名牌的那顆節點**寫成 **`[80]`**(它的本體是原本的 `70`),
> 跟**被移除的葉節點 `80`** 區分開。

```
                 50
             /        \
           30          [80]      ← 名牌 80,本體是原本的 70
         /    \        /    ✗    ← 葉節點 80 從這裡消失了
       20      40    60
      /  \    /        \
    10    25 35         65
    /
   5
```

---

### 階段二|回家:第一站 = `[80]`

**先確認路徑**:真正被移除的是**葉節點 `80`**,它的父親是 **`[80]`**。

> **回溯路徑 = `[80]` → `50`。只有兩站。**
> `60`、`30`、`20`… 都**不在路徑上**,高度沒被動過。

**站在 `[80]`,伸出兩隻手:**

```
        [80]  ← 你站在這裡
        /   \
      60     null
      ↑        ↑
   沒動過      剛被刪掉
   直接讀      這裡空了
```

| 手 | 拿什麼 | 怎麼得到 |
|:---|:---|:---|
| 左手 | `h(60) = 2` | `60` 沒動過 → **直接讀它存的 `height`** |
| 右手 | `h(null) = 0` | 葉節點 `80` 被刪了 |

```
h([80])  = 1 + max(2, 0) = 3
BF([80]) = 2 − 0 = +2        ← 失衡!★
```

**接著查表,需要較高子 `◆` 的 BF**

較高子是 `60`(左邊比較高)。**額外算一次**(這跟回溯無關,只是為了查表):

```
BF(60) = h(60.left) − h(60.right) = h(null) − h(65) = 0 − 1 = −1
```

> ### ⚠️ 全題最狠的地方
> 看到 `+2`(左邊太高)就直接右旋 → **錯**。
> 較高子 `◆60` 是**右重**(`−1`)→ `+2` / `−1` **異號 → 雙旋**
> 路徑走向:`★[80]` → **左**(到 `60`)→ **右**(到 `65`)→ **LR**

---

### 階段三|LR 雙旋

**步驟 1:對 `◆60` 左旋(橋直)**　`P = 60`、`R = 65`、`b = R.left = null`

```
   [80]            [80]
   /               /
  60      ──►     65
    \             /
     65         60
```

`65` 升上來、`60` 掉下去、`b`(空的)換邊到 `60` 的右邊。
現在 `★[80]` 的左子樹是**左左直線**。

**步驟 2:對 `★[80]` 右旋**　`P = [80]`、`L = 65`、`b = L.right = null`

```
   [80]              65
   /                 /  \
  65      ──►      60   [80]
  /
60
```

> 旋轉完之後,`[80]` 只是一顆值為 `80` 的普通節點了。以下恢復寫成 `80`。

---

### 階段四|矮了嗎?

| | 子樹的根 | `h` |
|:---|:---:|:---:|
| 旋轉**前** | `[80]` | **3** |
| 旋轉**後** | `65` | **2** |

**矮 1 層**(查表:雙旋一定矮 1)→ **必須往上,走到第 2 站 `50`**

```
                 50
             /        \
           30           65
         /    \        /   \
       20      40    60     80
      /  \    /
    10    25 35
    /
   5
```

---

### 階段五|回家:第二站 = `50`(連鎖)

**站在 `50`,伸出兩隻手:**

| 手 | 拿什麼 | 怎麼得到 |
|:---|:---|:---|
| 左手 | `h(30) = 4` | `30` **不在路徑上**,沒動過 → 直接讀 |
| 右手 | `h(65) = 2` | 剛剛旋轉完,現算的 |

```
BF(50) = 4 − 2 = +2        ← 失衡!★
```

**查表,需要較高子 `◆` 的 BF**

較高子是 `30`。額外算一次(它一樣不在路徑上,只是借用):

```
BF(30) = h(20) − h(40) = 3 − 2 = +1
```

`+2` / `+1` **同號 → 單旋 → LL** → 對 `★50` **右旋**

`P = 50`、`L = 30`、**`b = L.right = 40 那一整包`**(含 `35`)

- `30` 升上來當根
- `50` 掉下去當 `30` 的右小孩
- **`40` 那一包換邊 → `50` 的左邊**(因為 `30 < 40 < 50`)

`50` 是根 → **收工**。

# 範例 B|二 → 一　＋　RL 雙旋　＋　收工

| `10` | 2 | +1 | | `66` | 2 | +1 |

---

### 階段一|化簡:二換牌 → 降級成「一」

`D = 50` 有兩個小孩 → **二換牌**

| 步 | 目前 | `left` 存在? | 動作 |
|:---:|:---:|:---:|:---|
| ① | `60` | ✔ `55` | 往左 |
| ② | `55` | ✘ `null` | **停 → `S = 55`** |

中序驗證:`… 40, 50, 55, 57 …` → `55` 確實是 `50` 的下一個 ✔

1. 把 `55` 的 key 抄到根(根這顆節點沒動,只改名牌)
2. 改成去刪 `S = 55` —— 它有 **1 個小孩(右子 `57`)** → **一頂替** → `57` 接上來

```
                    55          ← 名牌 55(本體是原本的 50)
             /              \
           30                60
         /    \            /     \
       20      40        57       68     ← 57 頂替了 55
      /  \    /                  /  \
    10    25 35                66    75

```

### 階段二|回家:第一站 = `60`

**先確認路徑**:真正被移除的是節點 `55`,它的父親是 **`60`**。

> **回溯路徑 = `60` → `[55]`(根)。只有兩站。**
> (`57` 只是**頂替**上來的小孩,它自己的子樹沒變、高度還是 `1`,不需要重算。)

```
                    [55]        ← 第 2 站(名牌 55,本體是原本的 50)
             /              \
           30                60      ← 第 1 站
         /    \            /     \
       20      40        57       68
                          ↑
                    頂替上來的,h 仍是 1
```

**站在 `60`,伸出兩隻手:**

| 手 | 拿什麼 | 怎麼得到 |
|:---|:---|:---|
| 左手 | `h(57) = 1` | 剛剛頂替上來的那一邊 |
| 右手 | `h(68) = 3` | `68` **不在路徑上**,沒動過 → 直接讀 |

```
h(60)  = 1 + max(1, 3) = 4
BF(60) = 1 − 3 = −2        ← 失衡!★(右邊太高)
```

**查表,需要較高子 `◆` 的 BF**

較高子是 `68`(右邊比較高)。額外算一次:

```
BF(68) = h(66) − h(75) = 2 − 1 = +1
```

> ⚠️ 看到 `−2` 就直接左旋 → **錯**。
> `◆68` 是**左重**(`+1`)→ `−2` / `+1` **異號 → 雙旋**
> 路徑走向:`★60` → **右**(到 `68`)→ **左**(到 `66`)→ **RL**

> 左旋是鏡像:換邊的是 `R` 的**左**子樹(`R.left`),搬到 `P` 的**右**邊。

# 詳解

## Q1 詳解

### 化簡

`D = 25`,**沒有小孩** → **零直接** → 直接移除。

```
            30
        /        \
      20          50
     /           /   \
   10           40    65
   /            /    /  \
  5           35   60    80
```

### 回家:第一站

| 節點 | 左子 `h` | 右子 `h` | `h` | **BF** | 判斷 |
|:---:|:---:|:---:|:---:|:---:|:---|
| **`20`** | **2** (`10`) | **0** | 3 | **+2** | ✗ **失衡 ★** |

- `★20` = `+2`
- `◆10` = `h(5) − h(null)` = `1 − 0` = **`+1`** → **同號 → 單旋 → LL** → 對 `★20` **右旋**

`P = 20`、`L = 10`、`b = L.right = null`

```
     20              10
    /       ──►     /  \
  10                5    20
  /
 5
```

**高度檢查**:旋轉前 `h(20) = 3`,旋轉後 `h(10) = 2` → **矮 1 層**(單旋、`◆` 的 BF = `+1`)→ **往上**

### 回家:第二站

| 節點 | 左子 `h` | 右子 `h` | `h` | **BF** | 判斷 |
|:---:|:---:|:---:|:---:|:---:|:---|
| `30`(根) | 2 (`10`) | 3 (`50`) | **4** | **−1** | ✔ 沒失衡 |

刪除前 `h(30) = 4`,現在還是 **4** → **高度沒變 → 收工。**

### 答案

```
            30
        /        \
      10          50
     /  \        /   \
    5    20     40    65
                /    /  \
              35   60    80
```

| 項目 | 值 |
|:---|:---|
| 旋轉組數 | **1 組**(LL) |
| 基本旋轉次數 | **1 次** |
| 停在 | **根 `30`**(檢查後發現沒失衡、高度也沒變) |
| 樹高 | `4 → 4` |

**驗證**:`5`,`20` 的 BF = 0;`10` 的 BF = 0;`35` h1;`40` BF = +1;`60`,`80` h1;`65` BF = 0;`50` BF = 0;`30` BF = `2 − 3` = **−1** ✔

**中序**:`5, 10, 20, 30, 35, 40, 50, 60, 65, 80`(原本多一個 `25`)✔

> **這題的重點**:旋轉之後子樹**矮了 1 層,所以必須往上檢查** —— 但檢查結果是「沒失衡」。
> **「矮了往上」和「往上一定要轉」是兩回事。**

## Q2 詳解

### 起始樹合法性

| 節點 | `h` | BF | | 節點 | `h` | BF |
|:---:|:---:|:---:|:---|:---:|:---:|:---:|
| `10` `25` `35` `45` `60` `130` `190` `210` | 1 | 0 | | `70` | 2 | **+1** |
| `20` | 2 | 0 | | `50` | 4 | +1 |
| `40` | 2 | 0 | | `200` | 2 | 0 |
| `30` | 3 | **0** | | `150` | 3 | −1 |
| | | | | `100` | 5 | +1 |

✔ 全部合法

### 化簡

`D = 60`,**葉節點** → **零直接** → 直接移除。

### 回家:第一站

| 節點 | 左子 `h` | 右子 `h` | `h` | **BF** | 判斷 |
|:---:|:---:|:---:|:---:|:---:|:---|
| `70` | 0 | 0 | 1 | 0 | ✔ |
| **`50`** | **3** (`30`) | **1** (`70`) | 4 | **+2** | ✗ **失衡 ★** |

- `★50` = `+2`
- `◆30` = `h(20) − h(40)` = `2 − 2` = **`0`** ← **關鍵!**

> **較高子 BF = 0** → 查表 ③ 仍然歸 **單旋 → LL** → 對 `★50` **右旋**
> (這種情況**只會在刪除時出現**,插入永遠不會)

`P = 50`、`L = 30`、**`b = L.right = 40 那一整包`**(含 `35`、`45`)

```
        50                    30
      /    \                /    \
    30      70    ──►     20      50
   /  \                  / \     /   \
  20   40               10  25  40    70
 / \   / \                      / \
10 25 35  45                  35   45
```

`40` 那一包換邊,接到 `50` 的左邊(因為 `30 < 40 < 50`)。

### 回家:高度檢查 → **停!**

| | 子樹的根 | `h` |
|:---|:---:|:---:|
| 旋轉**前** | `50` | **4** |
| 旋轉**後** | `30` | **4** |

**高度不變!** 查停止條件表:

> **單旋 + 較高子 BF = `0` → 子樹高度不變 → 停。**

所以 **`100` 完全不用檢查**,直接收工。

### 答案

```
                 100
             /         \
           30           150
         /     \       /    \
       20       50   130     200
      /  \     /  \          /  \
    10    25  40    70    190    210
             /  \
           35    45
```

| 項目 | 值 |
|:---|:---|
| 旋轉組數 | **1 組**(LL) |
| 基本旋轉次數 | **1 次** |
| 停在 | **`50` 這一層**(高度沒變,不必往上) |
| 樹高 | `5 → 5` |

**驗證**:`20` BF=0;`40` BF=0;`70` h1;`50` = `2 − 1` = **+1** ✔;`30` = `2 − 3` = **−1** ✔;`150` = −1;`100` = `4 − 3` = **+1** ✔

**中序**:`10,20,25,30,35,40,45,50,70,100,130,150,190,200,210`(原本 `50` 後面多一個 `60`)✔

> **這題的重點**:`◆` 的 BF = `0` 是一個**強訊號**。
> 它不只告訴你「歸單旋」,還直接宣告「**旋轉後高度不變,連鎖到此為止**」。
> 不知道這條規則的人,會一路往上重算到根 —— 浪費時間,而且容易算錯。
