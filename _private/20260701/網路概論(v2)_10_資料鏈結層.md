# 資料鏈結層

> 科目：網路概論。資料鏈結層＝ OSI 第 2 層，負責「**同一個網段內**，把訊框從一張網卡送到另一張網卡」，並處理**誰能講話（多重存取）**與**傳錯了怎麼辦（錯誤控制）**。
>
> 學習方式：本篇**大多屬【理解】**（懂邏輯就記得）；只有 **543 Rule 的數字屬【硬背】**。皆為穩定標準。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「**有線乙太網路**用哪種多重存取方式？**無線 WiFi** 又用哪種？」
> 2. 「**對講機**屬於單工、半雙工還是全雙工？」
> 3. 「543 Rule（5-4-3 規則）中的 5、4、3 各代表什麼？」

先想想再看答案。

---

## 🤔 先想想

資料鏈結層的名詞多，但都圍繞同一個核心情境——**「一條線上很多人，要怎麼有秩序地講話、講錯了怎麼補」**。給你幾個提示：

- 想像一間**只有一支麥克風的會議室**：大家搶著講會「撞在一起」（碰撞），這就是多重存取要解決的問題。
- **有線**環境「撞了偵測得到」，**無線**環境「撞了很難察覺」——這個差別決定了 CSMA/CD 與 CSMA/CA 的分工。
- 「傳輸方向」（單工／半雙工／全雙工）跟日常裝置（廣播、對講機、電話）一一對應，用生活例子記最快。

帶著這幾點往下拆。

## 📖 觀念拆解

### 一、訊框化 Framing　【理解】

資料鏈結層把上層來的**位元流**包成一個個**訊框（frame）**：前面加 **header**（來源／目的 **MAC** 位址）、後面加 **trailer**（尾端，放錯誤偵測碼 **FCS**）。

> **FCS**（Frame Check Sequence，訊框檢查碼）＝ 放在訊框尾端的一小段檢查碼，常用你在基本計概學過的 **CRC** 計算法算出來。接收端重算一次比對，就知道傳輸中有沒有出錯。

- **目的**：讓接收端知道訊框**從哪開始、哪結束（定界）**，並能**偵測錯誤**。

💡 **白話比喻：** 訊框就像一個「**信封**」——信封正面寫寄／收件人（header 的來源／目的 MAC），封口貼一張「防拆封條」（trailer 的 FCS）。收信人一看封條有沒有被破壞，就知道內容有沒有被動過。

🔎 **MAC 位址**：共 **48 位元（6 bytes）**，以 16 進位表示（如 `00-1A-2B-3C-4D-5E`），**前 24 位為廠商碼（OUI）**；全為 1（`FF-FF-FF-FF-FF-FF`）是**廣播位址**。

### 二、單工 / 半雙工 / 全雙工　【理解】

描述「資料能往哪個方向流」的三種模式，用生活裝置記最好：

| 模式 | 方向 | 例子 |
|---|---|---|
| 單工 Simplex | 只能單向 | 廣播、鍵盤 → 電腦 |
| 半雙工 Half-duplex | 雙向但不能同時（輪流） | 對講機 |
| 全雙工 Full-duplex | 雙向可同時 | 電話、現代乙太網路（switch） |

📌 **記憶鉤子：**
- **單工**＝ 只能一個方向（收音機廣播：電台講、你只能聽）。
- **半雙工**＝ 雙向但要**輪流**（對講機：講的時候不能聽，要說「over」換手）。
- **全雙工**＝ 雙向**同時**（電話：兩人可同時講同時聽；接 switch 的現代乙太網路也是）。

### 三、多重存取：競爭 vs 無競爭 + CSMA　【理解】★

多個裝置共用一條媒介，要決定「**誰能傳**」。兩大策略：

| | 競爭式 Contention | 無競爭式 Contention-free |
|---|---|---|
| 怎麼傳 | 大家搶著傳，可能碰撞 | 有秩序輪流，不碰撞 |
| 例子 | CSMA/CD、CSMA/CA、ALOHA | Token Passing（權杖）、Polling、TDMA |
| 優缺 | 低負載效率高；高負載碰撞多 | 無碰撞、高負載穩；低負載有等待開銷 |

**CSMA 家族**（傳前先「**聽**」媒介有沒有人用）：

| | 全名 | 用在 | 做法 |
|---|---|---|---|
| CSMA | 載波偵聽多重存取 | — | 先聽、沒人用才傳（但仍可能同時傳 → 碰撞） |
| CSMA/CD | ＋碰撞偵測 | 有線乙太網路 | 邊傳邊測，撞到就停、等隨機時間重傳 |
| CSMA/CA | ＋碰撞避免 | 無線 WiFi（802.11） | 傳前先等、用 RTS／CTS 預約，事先避免碰撞 |

⭐ **超常考：CD 用於「有線」**（偵測得到碰撞）、**CA 用於「無線」**（難偵測 → 改成事先避免）。原因：無線裝置常「聽不到彼此」（隱藏節點問題），撞了也不知道，所以乾脆改成「傳之前先避開」。

🔎 **表裡幾個名詞：**
- **ALOHA** ＝ 最早的「想傳就傳、撞了再重傳」隨機法。
- **Polling（輪詢）** ＝ 主控端逐一問各裝置「要不要傳」。
- **TDMA（分時多工）** ＝ 每台分配固定時段、輪流使用。
- **RTS／CTS** ＝ 無線裡「先舉手請求（RTS）、獲准（CTS）再傳」的預約機制。

### 四、543 Rule（5-4-3 規則）　【硬背】

早期乙太網路（**10 Mbps**）一個**碰撞域**的限制：最多 **5 個網段、4 個中繼器（hub）**，其中只有 **3 個網段可接裝置**（另 2 個只作連接用）。

- **目的**：限制訊號延遲，確保 **CSMA/CD 的碰撞偵測**還能正常運作。（訊號跑太遠太久，撞了也來不及測到。）
- **記法**：**5 段、4 中繼器、3 段有裝置。**

💡 這條規則是**老式 Hub 時代**的產物；現代用 Switch（每埠獨立碰撞域）後就不受它限制了，但考試仍會考它的數字。

🔎 **碰撞域 vs 廣播域**：Hub 全埠共用一個碰撞域；**Switch 每埠一個碰撞域**（但仍屬同一廣播域）；要分割**廣播域**得靠 **Router／VLAN**。

### 五、ARQ（自動重傳請求）　【理解】

**ARQ**（Automatic Repeat reQuest）：錯誤控制機制——接收端收到錯的或沒收到，就要發送端**重傳**（靠 **ACK** 確認／**NAK** 否定 ＋ **timeout** 逾時）。三種：

| 方式 | 做法 |
|---|---|
| Stop-and-Wait 停止等待 | 傳一個、等一個 ACK 再傳下一個（簡單、慢） |
| Go-Back-N 回溯 N | 錯了 → 從出錯那個之後全部重傳 |
| Selective Repeat 選擇性重傳 | 只重傳錯的那個（效率高、較複雜） |

📌 **對比記：** 停等最單純但最慢（一次一個）；**Go-Back-N** 一錯就「**整批重來**」（從錯的那個往後全送）；**選擇性重傳**只補「**壞掉那一個**」，效率最高但實作最複雜。

### 六、HDLC vs PPP　【理解】

兩個都是**點對點的 L2（WAN 廣域網）協定**：

| | HDLC | PPP |
|---|---|---|
| 全名 | High-level Data Link Control | Point-to-Point Protocol |
| 特性 | 位元導向、同步 | 點對點直連（撥接、DSL） |
| 功能 | 較簡單 | 多：支援多協定、身分驗證（PAP／CHAP，驗證登入帳密的協定）、錯誤偵測 |
| 標準 | 偏 Cisco 私有 | 標準開放（跨廠商） |

📌 **一句話：** **HDLC 較簡單、偏 Cisco 私有；PPP 功能多**（支援多協定、能驗證帳密）、**標準開放**（跨廠商都能用，撥接／DSL 上網常見）。

### 七、L2 vs L3 Switch　【理解】

交換器也有「看 MAC」與「看 IP」兩種等級：

| | L2 交換器 | L3 交換器 |
|---|---|---|
| 依據 | MAC 位址 | IP 位址 |
| 能做 | 同網段／VLAN 內轉送訊框 | switch ＋ router：跨 VLAN／子網路路由（硬體路由，快） |
| 層 | L2 | L3 |

💡 **重點：** L2 Switch 只在**同一網段／VLAN 內**依 MAC 轉送；**L3 Switch ＝ Switch＋Router 合體**，能用 IP **跨 VLAN／子網路做路由**，而且是硬體路由、速度快。

🔎 **VLAN（虛擬區域網路）**＝在交換器上以軟體邏輯切出的獨立網段，可**分割廣播域**、隔離不同群組流量。

### 八、重點整理（背這張）

- **訊框化** ＝ 包成 frame（MAC header ＋ 錯誤碼 trailer）、**定界 ＋ 偵錯**。
- **單工**單向、**半雙工**輪流、**全雙工**同時雙向。
- **多重存取**：競爭（搶，會撞）vs 無競爭（輪流，不撞）。
- **CSMA/CD 有線（偵測）、CSMA/CA 無線（避免）** ← 必考。
- **543 Rule**：5 段、4 中繼器、3 段有裝置。
- **ARQ 三種**：停等、Go-Back-N、選擇性重傳。
- **HDLC 簡單偏私有；PPP 功能多（驗證）、標準開放。**
- **L2 看 MAC、L3 看 IP** 可跨網段路由。

---

## ✅ 回到題目：解答

1. **有線用哪種多重存取？無線呢？** → 有線乙太網路用 **CSMA/CD（碰撞偵測）**；無線 WiFi（802.11）用 **CSMA/CA（碰撞避免）**。口訣：**CD 有線、CA 無線**。
2. **對講機屬哪種？** → **半雙工 Half-duplex**（雙向，但一次只能一個方向，要輪流）。
3. **543 Rule 的 5、4、3？** → 最多 **5 個網段、4 個中繼器（hub）、3 個網段可接裝置**（另 2 段只作連接）。

---

## 📌 重點整理

- 資料鏈結層＝ **L2**，管**同網段內的訊框傳遞、多重存取、錯誤控制**。
- **訊框**＝ header（MAC）＋ 資料 ＋ trailer（FCS/CRC）；作用是**定界＋偵錯**。
- 三種傳輸方向對應：單工（廣播）／半雙工（對講機）／全雙工（電話、switch）。
- **CSMA/CD（有線、偵測）** vs **CSMA/CA（無線、避免）** 是全篇最常考點。
- 硬背 **543 Rule**（5 段／4 中繼器／3 段有裝置）；**ARQ** 三法（停等／Go-Back-N／選擇性重傳）。
- **PPP** 功能多（驗證、跨廠商）、**HDLC** 簡單偏私有；**L3 Switch** 能用 IP 跨 VLAN 路由。

---

## ⚠️ 常見陷阱

- **CD vs CA 別背反**：**CD ＝ 有線**（Collision Detection，撞了偵測得到）；**CA ＝ 無線**（Collision Avoidance，難偵測所以事先避免）。這是最愛考的坑。
- **半雙工 ≠ 全雙工**：半雙工雙向但**要輪流**（對講機）；全雙工才是**同時雙向**（電話）。
- **543 的「3」意思**：是「3 個網段**可接裝置**」，不是「3 個中繼器」。5 段、4 中繼器、3 段有裝置，別錯位。
- **Go-Back-N vs 選擇性重傳**：Go-Back-N 一錯「**從錯的往後全部重傳**」；選擇性重傳「**只補壞的那個**」，兩者效率差在這。
- **FCS/CRC 是「偵錯」不是「加密」**：它只確認資料有沒有傳壞，跟保密無關。

## 📝 練習題（含解答）

**Q1.** 資料鏈結層的訊框（frame）由哪三部分組成？trailer 裡放的 FCS 有什麼用？
<details><summary>看解答</summary>

**header（來源／目的 MAC）＋ 資料 ＋ trailer**。trailer 裡的 **FCS（訊框檢查碼，常用 CRC 計算）** 用來**偵測傳輸錯誤**；header／trailer 也讓接收端知道訊框的起訖（定界）。
</details>

**Q2.** 為什麼無線網路用 CSMA/CA 而不用 CSMA/CD？
<details><summary>看解答</summary>

因為無線環境**很難偵測到碰撞**（裝置常聽不到彼此），所以不採「邊傳邊偵測」的 CD，改用「**傳前先避免**」的 **CA**（先等、用 RTS／CTS 預約再傳）。有線則相反，撞了偵測得到，用 CSMA/CD。
</details>

**Q3.** 競爭式（Contention）與無競爭式（Contention-free）各舉兩個例子，並說明高負載時誰較穩。
<details><summary>看解答</summary>

**競爭式**：CSMA/CD、CSMA/CA、ALOHA（大家搶著傳，可能碰撞）。**無競爭式**：Token Passing（權杖）、Polling、TDMA（有秩序輪流）。**高負載時無競爭式較穩**（不會碰撞）；競爭式在低負載時效率高、高負載時碰撞多。
</details>

**Q4.** ARQ 三種方式中，「只重傳出錯的那一個訊框」是哪一種？它的優缺點？
<details><summary>看解答</summary>

**Selective Repeat（選擇性重傳）**。優點：**效率高**（只補壞的、不整批重送）；缺點：**較複雜**（要記住哪些收到、哪些沒收到）。
</details>

**Q5.** PPP 相較於 HDLC，多了哪些能力？兩者標準開放程度有何不同？
<details><summary>看解答</summary>

**PPP** 功能較多：**支援多協定、身分驗證（PAP／CHAP）、錯誤偵測**，且為**標準開放**（跨廠商，撥接／DSL 常用）；**HDLC** 較簡單、**偏 Cisco 私有**。
</details>
