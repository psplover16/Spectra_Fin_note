# 樹 Tree（基本）+ 前中後序走訪

> 科目：演算法｜樹是繼陣列、鏈結串列之後最重要的資料結構。考題分兩種：**名詞與公式**偏背誦（葉數公式、節點上限），**走訪**偏流程（給你一棵樹要你寫出三序）。
>
> 學習方式：術語與公式屬【硬背】，但走訪只要記住一句話——「前中後指的是**根**什麼時候被走到」，就能秒解流程題。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 一棵有 **n 個節點** 的樹，共有幾條 **邊（edge）**？
> 2. 二元樹裡「葉節點數 n0」與「分支度為 2 的節點數 n2」有什麼固定關係？
> 3. 給一棵樹：根 A、左子樹 B（下有 D、E），右子樹 C（只有右子 F）。它的 **中序（Inorder）** 走訪結果是什麼？

先別急著看答案，自己試著回答。

---

## 🤔 先想想

- 樹是**階層式**結構，像家族族譜或公司組織圖：一個老闆（根）往下分支。
- 每個節點**最多一個父親**、可以有很多小孩——這點和「圖」不同（圖可以有環、多對多）。
- 走訪的「前、中、後」不是指左右順序，而是指**根**被拜訪的時機；左子樹永遠排在右子樹前面。

帶著這三點往下拆解。

---

## 📖 觀念拆解

### 一、Tree 的定義（4 個必記特徵）

1. 樹是**階層式 hierarchical 的非線性結構**，由節點 node 與邊 edge 組成。
2. 有**唯一根**；除了根以外，每個節點**恰有一個父節點**。
3. **沒有環 acyclic**；**n 個節點有 n − 1 條邊**。
4. **任兩節點間只有一條路徑**。

📌 **白話：** 「恰有一個父節點」是樹和圖最大的差別；因為每加一個節點就多一條連到父親的邊，所以 n 個節點剛好 n − 1 條邊（根自己沒有父親，不算邊）。

### 二、基本術語（表）

| 術語 | 意思 |
|---|---|
| Root（根） | 最上層、沒有父節點。 |
| Leaf（葉） | 沒有子節點，也叫終端節點。 |
| Internal Node（內部節點） | 有子節點的非終端節點。 |
| Parent / Child（父 / 子） | 上下層直接相連的節點關係。 |
| Sibling（兄弟） | 同一個父節點底下的節點。 |
| Degree（分支度） | 節點的子節點數；**樹的分支度**是所有節點 degree 的最大值。 |
| Level / Height（層 / 高度） | 起算可能從 0 或 1，考題若有定義要**依題目**。 |
| Forest（森林） | 多棵樹的集合；把樹的根拿掉就會形成森林。 |

📌 **白話：** 「Degree」在樹裡是**小孩數**（別和圖的 degree＝連幾條邊搞混）；把一棵樹的根砍掉，原本根的每個子樹就各自變成一棵樹，合起來就是「森林」。

### 三、Binary Tree（二元樹）種類與公式

二元樹＝每個節點**最多 2 個**子節點。常考四種特殊型態：

| 種類 | 條件 |
|---|---|
| Full Binary Tree | 每個節點**不是葉，就是恰好有 2 個**子節點。 |
| Complete Binary Tree | 除最後一層外都填滿，最後一層**靠左**排。 |
| Perfect Binary Tree | **每一層都填滿**，所有葉在同一層。 |
| Skewed Tree（偏斜樹） | 每個節點只有一邊子節點，退化得像鏈結串列。 |

**必背公式：**

1. 第 **i** 層最多 **2^(i−1)** 個節點。
2. 高度 **h** 的二元樹最多 **2^h − 1** 個節點。
3. **葉節點數 n0 = 分支度為 2 的節點數 n2 + 1**（超常考）。
4. **n 個節點有 n + 1 個 null link**（空指標）。

📌 **公式帶數字驗證（n0 = n2 + 1）：** 用第五節那棵範例樹——葉子是 D、E、F 共 **3 個**（n0 = 3）；有 2 個小孩的節點是 A、B 共 **2 個**（n2 = 2）。代入：n0 = n2 + 1 → 3 = 2 + 1 ✓。

### 四、三種走訪 Preorder / Inorder / Postorder

| 走訪 | 順序 | 根的位置 |
|---|---|---|
| Preorder（前序） | 根 → 左 → 右 | 根**先**被 visit。 |
| Inorder（中序） | 左 → 根 → 右 | 根在**中間**被 visit。 |
| Postorder（後序） | 左 → 右 → 根 | 根**最後**被 visit。 |

> 記憶關鍵：「前中後」＝**根**出現的位置；左一定在右前面。

另外還有 **層序 Level-order**：一層一層走，使用 **Queue**，本質上就是 **BFS**；相對地，**前序／中序／後序都屬於 DFS（深度優先）**。

### 五、逐步範例（同一棵樹跑三種走訪）

範例樹：**根 A；左子樹 B（下有 D、E）；右子樹 C（只有右子 F）**。畫出來是：

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

**Preorder（根 → 左 → 右）逐步：**
1. 先 visit 根 **A**。
2. 進左子樹 B：visit **B** → 再進 B 的左 **D** → B 的右 **E**。
3. 進右子樹 C：visit **C** → C 沒有左子，進右子 **F**。
- 結果：**A B D E C F**

**Inorder（左 → 根 → 右）逐步：**
1. 先做左子樹 B 的中序：B 的左 **D** → 根 **B** → B 的右 **E**。
2. 回來 visit 根 **A**。
3. 做右子樹 C 的中序：C 沒有左子 → 根 **C** → C 的右 **F**。
- 結果：**D B E A C F**

**Postorder（左 → 右 → 根）逐步：**
1. 先做左子樹 B 的後序：B 的左 **D** → B 的右 **E** → 根 **B**。
2. 做右子樹 C 的後序：C 沒有左子 → C 的右 **F** → 根 **C**。
3. 最後 visit 根 **A**。
- 結果：**D E B F C A**

📌 **由走訪反推樹（常考）：** Preorder 的**第一個**、Postorder 的**最後一個**必是**根**；再用 Inorder 以根為界切出左、右子樹。已知〈前序＋中序〉或〈後序＋中序〉可**唯一重建**二元樹，但〈前序＋後序〉**不一定唯一**。

---

## ✅ 回到題目：解答

1. **n 個節點有幾條邊？** → **n − 1 條**（除了根，每個節點各有一條連到父親的邊）。
2. **n0 與 n2 的關係？** → **n0 = n2 + 1**（葉節點數 = 分支度為 2 的節點數 + 1）。
3. **該樹的中序走訪？** → **D B E A C F**（左 → 根 → 右）。

---

## 📌 重點整理

- 樹：唯一根、除根外每點**恰一父**、無環、**n 點 n − 1 邊**、任兩點一條路徑。
- 術語：Leaf＝無子；Internal＝有子；Degree＝子節點數；Forest＝拿掉根後的多棵樹集合。
- 二元樹型態：Full（0 或 2 子）、Complete（最後層靠左）、Perfect（全滿）、Skewed（退化成串列）。
- 公式：第 i 層 ≤ **2^(i−1)**；高 h ≤ **2^h − 1**；**n0 = n2 + 1**；n 節點有 **n + 1** 個 null link。
- 走訪：前中後＝**根的位置**；Preorder 根左右、Inorder 左根右、Postorder 左右根；Level-order 用 **Queue** 即 **BFS**。

---

## ⚠️ 常見陷阱

- **Level / Height 起算點**：有的教材從 0、有的從 1，公式（如 2^(i−1)）會跟著變，**一定要看題目定義**。
- **樹的 degree vs 圖的 degree**：樹的 degree＝子節點數；圖的 degree＝連幾條邊，別混。
- **中序 ≠ 一定由小到大**：只有在**二元搜尋樹（BST）** 中，中序走訪才會得到排序結果；普通二元樹不保證（下一篇高等樹會用到）。
- **走訪把左右顛倒**：三種走訪**左子樹永遠先於右子樹**，只有「根」的位置在變。
- **null link 數**：n 個節點的二元樹有 **n + 1** 個空指標，不是 n − 1。

## 📝 練習題（含解答）

**Q1.** 一棵二元樹高度 h = 4（根為第 1 層），最多可以有幾個節點？
<details><summary>看解答</summary>

用公式 2^h − 1 = 2^4 − 1 = **15 個**。（每層最多 2^(i−1)：1 + 2 + 4 + 8 = 15。）
</details>

**Q2.** 某二元樹葉節點有 10 個，請問分支度為 2 的節點有幾個？
<details><summary>看解答</summary>

由 n0 = n2 + 1 → 10 = n2 + 1 → **n2 = 9 個**。
</details>

**Q3.** 給樹：根 A、左子樹 B（下有 D、E）、右子樹 C（只有右子 F）。寫出 **Preorder** 與 **Postorder**。
<details><summary>看解答</summary>

Preorder（根 → 左 → 右）＝**A B D E C F**；Postorder（左 → 右 → 根）＝**D E B F C A**。
</details>

**Q4.** Level-order（層序）走訪用什麼資料結構？它等同哪一種圖走訪？
<details><summary>看解答</summary>

用 **Queue（佇列）**；本質上就是 **BFS（廣度優先搜尋）**，一層一層往下走。
</details>

**Q5.** 「Complete Binary Tree」與「Perfect Binary Tree」差在哪？
<details><summary>看解答</summary>

Perfect＝**每一層都填滿**、所有葉在同一層；Complete＝**除最後一層外都填滿**，且最後一層**靠左**排（可以不滿）。Perfect 一定是 Complete，反之不一定。
</details>
