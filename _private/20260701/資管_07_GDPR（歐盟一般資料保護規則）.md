# GDPR（歐盟一般資料保護規則）

> 科目：資管｜GDPR 是國際資料保護的指標法規，常考「適用範圍」「處理原則」「資料主體權利」與「高額罰則門檻」。
>
> 這張要建立的直覺是：**GDPR 管的是「歐盟境內的資料主體」，不只看企業設在哪**；只要你向歐盟境內的人提供商品服務或監測其行為，就可能被管到。招牌考點是罰則：**2,000 萬歐元或全球年營業額 4%，取較高者**。
>
> 學習方式：適用範圍的判斷邏輯屬【理解】；七大原則、八大權利與罰則數字屬【硬背】。

## 🤔 先想想

三個提示幫你抓住 GDPR 的重點：

- 適用範圍看的是「**歐盟境內的資料主體**（data subjects in the Union）」，不是只看企業設立地，也不是只保護「歐盟公民」。
- 罰則數字要背死：**20M 歐元 或 全球年營業額 4%，取較高者**。
- 資料主體權利裡的「刪除權」又叫「**被遺忘權**」。

帶著這三點，我們來拆解。

## 📖 觀念拆解

### 一、GDPR 是什麼？

**GDPR（General Data Protection Regulation，一般資料保護規則）** 是歐盟一般資料保護規則，用來規範組織如何蒐集、處理、保存、移轉與保護個人資料，於 **2018 年 5 月 25 日**正式施行。

它強調資料主體權利、透明告知、合法處理依據、資料最小化、安全保護與問責。

> 📌 名詞先分清：**資料控制者（Controller）** 決定「為什麼、怎麼處理資料」；**資料處理者（Processor）** 是替控制者處理資料的一方；**資料保護長（DPO）** 則是特定情形下組織須指派、負責監督個資保護遵循的人員。

### 二、適用範圍（Article 3，最愛考）

GDPR 的地域適用**不只看組織設立地**。即使組織不在歐盟，只要向歐盟境內自然人／資料主體提供商品或服務，或監測其在歐盟境內的行為，也可能適用。

| 情境 | 是否可能適用 GDPR |
|---|---|
| 歐盟境內組織處理個資 | 可能適用。 |
| 非歐盟企業向歐盟境內資料主體提供商品或服務 | 可能適用。 |
| 非歐盟企業監測歐盟境內資料主體行為 | 可能適用。 |
| 完全與歐盟境內資料主體無關 | 通常不是 GDPR Article 3 的核心適用情境。 |

📌 **白話：** 判斷關鍵不是「公司在不在歐盟」，而是「有沒有碰到**歐盟境內的人**」——向他們賣東西，或追蹤他們的行為，就可能被管到。

### 三、個資處理原則（七大原則）

| 原則 | 意思 |
|---|---|
| 合法、公平、透明 | 處理資料要有合法依據，並清楚告知資料主體。 |
| 目的限制 | 資料只能用於特定、明確且合法的目的。 |
| 資料最小化 | 只蒐集達成目的所必要的資料。 |
| 正確性 | 資料應保持正確並適時更新。 |
| 保存限制 | 保存期間不應超過必要時間。 |
| 完整性與機密性 | 用適當安全措施避免未授權或非法處理、遺失或毀損。 |
| 問責 | 控制者要能證明自己符合 GDPR 要求。 |

📌 **白話：** 「問責（Accountability）」是 GDPR 的特色——不只是「有沒有做到」，還要能**自己舉證證明有做到**。

📌 **合法處理依據（Article 6）：** 處理個資須至少符合六項合法依據之一——**同意、契約履行、法律義務、重大利益、公共任務、正當利益**。注意「同意」只是其中一種，不是唯一途徑（常見陷阱）。

### 四、資料主體權利（八大權利）

| 權利 | 說明 |
|---|---|
| 告知權 | 有權知道自己的資料被誰、為何、如何蒐集與處理。 |
| 近用權 | 有權向控制者取得自己個人資料的副本。 |
| 更正權 | 要求修正不正確資料。 |
| 刪除權 | 在特定情形下要求刪除，也常被稱為被遺忘權。 |
| 限制處理權 | 在特定情形下限制資料處理。 |
| 資料可攜權 | 以結構化、常用、機器可讀格式取得並轉移資料。 |
| 反對權 | 在特定情形下反對資料處理（如反對直效行銷）。 |
| 自動化決策相關權利 | 不受「純自動化處理（含剖析）」對其產生法律或重大影響的決定所拘束（Article 22）。 |

📌 **白話：** 「刪除權」＝「**被遺忘權**（Right to be forgotten）」；「資料可攜權」＝可以把自己的資料打包帶去別家（結構化、機器可讀格式）。

> 💡 **八大 vs 六大**：上表為 ICO 等權威的「八大權利」；有些教材把「告知＋近用」併為一項、且不列第 8 項，因而稱「**六大權利**」——兩種分法都常見，依考綱作答。

### 五、罰則（招牌數字，務必背）

GDPR 高額罰則可達 **2,000 萬歐元 或 全球年營業額 4%，取較高者**。較低級別違規也可能有 **1,000 萬歐元 或 全球年營業額 2%** 的門檻。

📌 **外洩通報（常一起考）：** 發生個資外洩時，控制者原則上須於**知悉後 72 小時內**通報監管機關；若對當事人權益有高風險，並應通知資料主體。

## ✅ 回到題目：解答

1. **美國電商賣給歐盟消費者，會被管到嗎？** → **會（可能適用）**。適用範圍看的是有沒有向歐盟境內資料主體提供商品服務，不是只看企業設在哪。
2. **最高罰則？** → **2,000 萬歐元 或 全球年營業額 4%，取較高者**。
3. **資料主體權利？被遺忘權是哪一項？** → 告知、近用、更正、刪除、限制處理、資料可攜、反對、自動化決策相關（Art 22）；**「刪除權」即被遺忘權**。

---

## 📌 重點整理

- GDPR 保護**歐盟境內自然人／資料主體**的個人資料（不要簡化成只保護「歐盟公民」）。
- 適用範圍（Article 3）：看**有沒有向歐盟境內資料主體提供商品服務或監測其行為**，不只看設立地。
- 七大原則：合法公平透明、目的限制、資料最小化、正確性、保存限制、完整性與機密性、**問責**。
- 八大權利：告知、近用、更正、**刪除（被遺忘權）**、限制處理、資料可攜、反對、自動化決策相關（Art 22）。
- 罰則：**20M 歐元 或 4%，取高者**（較低級別為 10M 或 2%）。

---

## ⚠️ 常見陷阱

- **不要只寫「保護歐盟公民」**：Article 3 的關鍵是 **data subjects in the Union（歐盟境內的資料主體）**，重點是「人在歐盟境內」，不是國籍。
- **罰則取「較高者」**：是「2,000 萬歐元 **或** 全球年營業額 4%，**取較高者**」，不是取低者，也別把單位記成美元。
- **Controller vs Processor**：控制者決定目的與方式；處理者替控制者處理。問責主要落在控制者。
- **刪除權＝被遺忘權**：兩個名稱是同一個權利，別當成兩項。
