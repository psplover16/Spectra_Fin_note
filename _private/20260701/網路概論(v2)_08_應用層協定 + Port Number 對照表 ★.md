## 🤔 先想想

如果背得零零落落，給你幾個提示：

- 一台機器只有**一個 IP**，卻同時跑很多服務（網頁、收信、遠端登入…）。要靠 **Port** 分辨「這包資料要給哪個服務」。
- Port 號其實**有規律**：由小到大排一次（20/21 → 22 → 23 → 25 → 53…），比亂背好記很多。
- 大多數協定走 **TCP**（要正確），少數走 **UDP**（要快）；**DNS 兩個都用**——記住這些「例外」，考題就贏一半。

## 📖 觀念拆解

### 一、Port Number 對照表（★ 必背）　【硬背】

🏠 **Port（埠）是什麼？** 一台機器只有一個 IP，卻同時跑很多服務（網頁、收信、SSH…）。**Port ＝ 一個編號（0–65535）**，用來分辨「這包資料要給哪個服務」——像**大樓只有一個地址（IP）、裡面很多房間，port 就是房間號**。

**Port 範圍**：
- **0–1023**：周知埠（well-known，常見服務固定用這段）
- **1024–49151**：註冊埠
- **49152–65535**：動態／臨時埠（client 連線時臨時用）

| 協定 | Port | TCP/UDP | 功能 |
|---|---|---|---|
| FTP | 20（資料）、21（控制） | TCP | 檔案傳輸 |
| SSH | 22 | TCP | 安全遠端登入 |
| Telnet | 23 | TCP | 遠端登入（明文，不安全） |
| SMTP | 25 | TCP | 寄信（送出、伺服器間轉送） |
| DNS | 53 | TCP ＋ UDP | 域名解析（查詢用 UDP、區域傳送用 TCP） |
| DHCP | 67（伺服器）、68（客戶端） | UDP | 自動分配 IP |
| TFTP | 69 | UDP | 簡易檔案傳輸 |
| HTTP | 80 | TCP | 網頁 |
| POP3 | 110 | TCP | 收信（下載到本機，常從伺服器刪） |
| IMAP | 143 | TCP | 收信（保留在伺服器、多裝置同步） |
| SNMP | 161（查詢）、162（trap） | UDP | 網路管理 |
| HTTPS | 443 | TCP | 加密網頁（HTTP ＋ TLS） |
| RTSP | 554 | TCP/UDP | 串流控制（播放／暫停） |

**RTP／RTCP**：傳即時媒體用，**沒有固定周知埠**——RTP 走動態 UDP 偶數埠、RTCP 走相鄰的奇數埠（RTP 埠＋1）。

> 🧠 **背誦小幫手（由小到大）**：20/21 → 22 → 23 → 25 → 53 → 67/68 → 69 → 80 → 110 → 143 → 161 → 443 → 554。

🔎 **兩個小詞**：**trap**（SNMP 162）＝設備主動送出的異常通知；**區域傳送**（DNS 用 TCP）＝DNS 伺服器之間整批同步資料。

### 二、常見應用層協定（做什麼）　【理解】

背完號碼，也要懂每個協定在幹嘛：

- **DNS（53）**：把域名（`www.example.com`）轉成 IP 位址。就像**電話簿**，你只記得名字、它幫你查號碼。
- **DHCP（67/68）**：自動分配 IP、遮罩、預設閘道、DNS 給客戶端。流程口訣 **DORA**：
  - **D**iscover 探索 → **O**ffer 提供 → **R**equest 請求 → **A**CK 確認。
  - 📌 客戶端此時**還沒有 IP**，故 **Discover／Request 以廣播（broadcast）**送出。
- **FTP（20/21）**：檔案傳輸，用**兩條通道**——**21 控制**（下指令）、**20 資料**（傳檔案本身）。
- **Email 三劍客**：
  - **SMTP（25）** ＝ 寄信（送出、伺服器間轉送）
  - **POP3（110）** ＝ 收信，**下載到本機後常從伺服器刪**（適合單一裝置）
  - **IMAP（143）** ＝ 收信，**郵件留在伺服器、多裝置同步**（適合多裝置）
  - 口訣：**SMTP 寄、POP3／IMAP 收；POP3 下載刪、IMAP 留伺服器。**
- **SNMP（161/162）**：監控、管理網路設備（路由器、交換器等）。

### 三、GET vs POST（HTTP 方法，常考）　【理解】＋【硬背】

瀏覽器向網站要資料／送資料，最常用這兩個方法：

| | GET | POST |
|---|---|---|
| 用途 | 取得資料 | 提交資料（表單、改資料） |
| 參數放哪 | 放在 URL（看得到） | 放在 body（看不到） |
| 長度限制 | 有（URL 長度限制） | 無 |
| 可否被快取／加書籤 | 可 | 不適合 |
| 安全性 | 較低（參數露在網址） | 較高（但仍需 HTTPS 才真的加密） |

> 一句話：**GET 拿資料（參數在網址）、POST 送資料（參數在 body）。** 例如搜尋關鍵字會出現在網址列（GET）；登入輸入的密碼則藏在 body 裡（POST）。

📌 **HTTP 狀態碼（常考分類）**：**2xx 成功**（200 OK）、**3xx 轉址**（301／302）、**4xx 用戶端錯誤**（403 禁止、404 找不到）、**5xx 伺服器錯誤**（500 內部錯誤）。

### 四、URL（統一資源定位符）　【理解】

**URL**（Uniform Resource Locator）就是「網址」，格式如下：

```
協定://主機名稱:埠/路徑?查詢
```

範例：`https://www.example.com:443/page?id=1`

拆解這個範例：
- **協定**：`https`
- **主機**：`www.example.com`
- **埠**：`443`（HTTPS 的預設埠，平常省略不寫）
- **路徑**：`/page`
- **查詢**：`id=1`

### 五、SDN / CDN / 即時串流　【理解】

- **SDN（軟體定義網路）**：把網路的**控制平面**（決定怎麼走）和**資料平面**（實際轉送）分離，用軟體集中控制器統一管理，讓網路可程式化、好調整。
- **CDN（內容傳遞網路）**：把內容快取到全球各地的**邊緣伺服器**，讓使用者**就近取得** → 加速、減輕原伺服器負載。就像**在各地開分店**，不用大家都跑去總店。
- **即時串流三兄弟**：
  - **RTSP（554）** ＝ 控制：下播放／暫停／停止指令（像**遙控器**）。
  - **RTP（動態 UDP）** ＝ 傳輸：實際送即時的影音資料。
  - **RTCP** ＝ 品質回報：監控 RTP 的傳輸品質（延遲、遺失）。

## ✅ 回到題目：解答

1. **HTTP、HTTPS、SSH、DNS 的 Port？** → **HTTP 80、HTTPS 443、SSH 22、DNS 53**。
2. **DNS 用 TCP 還是 UDP？** → **兩個都用**。一般**查詢用 UDP**（快）、**區域傳送（伺服器間整批同步）用 TCP**。
3. **email 三協定角色？POP3 vs IMAP？** → **SMTP（25）寄信**；**POP3（110）** 收信、下載到本機後常從伺服器刪（適合單一裝置）；**IMAP（143）** 收信、郵件留在伺服器、多裝置同步（適合多裝置）。

## 📌 重點整理

- **必背 port**：FTP 20/21、SSH 22、Telnet 23、SMTP 25、DNS 53、DHCP 67/68、TFTP 69、HTTP 80、POP3 110、IMAP 143、SNMP 161/162、HTTPS 443、RTSP 554。
- **TCP/UDP 歸屬**：**DNS 同時用 TCP ＋ UDP**；**SNMP、DHCP、TFTP 用 UDP**；其餘多為 TCP。
- **Email**：SMTP 寄、POP3／IMAP 收；**POP3 下載刪、IMAP 留伺服器**。
- **HTTP 方法**：GET 拿（參數在網址）、POST 送（參數在 body）。
- **DHCP 流程：DORA**（Discover→Offer→Request→ACK）。**SDN ＝ 控制／資料平面分離；CDN ＝ 就近快取加速。**

---

## ⚠️ 常見陷阱

- **相鄰號碼容易記混**：**SSH 22／Telnet 23**（Telnet 明文、不安全）、**POP3 110／IMAP 143**、**HTTP 80／HTTPS 443**。
- **DNS 不是只有 UDP**：它**同時用 TCP＋UDP**（查詢 UDP、區域傳送 TCP）。
- **哪些是 UDP 別搞錯**：**SNMP、DHCP、TFTP 走 UDP**，別誤記成 TCP。
- **FTP 有兩個 port**：**21 控制、20 資料**，別只記一個。
- **POP3 vs IMAP 方向別記反**：POP3 下載到本機後**常刪**、IMAP **留伺服器**多裝置同步。
- **RTP／RTCP 沒有固定周知埠**：走動態 UDP（RTP 偶數埠、RTCP ＝ RTP＋1）；有固定 554 的是 **RTSP（控制）**。

**Q1.** 寫出下列協定的 Port：HTTP、HTTPS、SSH、DNS、SMTP。

**HTTP 80、HTTPS 443、SSH 22、DNS 53、SMTP 25。**

**Q2.** DNS 使用 TCP 還是 UDP？分別在什麼情況下用？
<details><summary>看解答</summary>

**兩者都用。** 一般**查詢（query）用 UDP**（快）；**區域傳送（zone transfer，DNS 伺服器之間整批同步資料）用 TCP**。
</details>

**Q3.** email 三劍客 SMTP／POP3／IMAP 的角色、port 各是什麼？POP3 與 IMAP 最大差別？
<details><summary>看解答</summary>

**SMTP（25）＝寄信**（送出、伺服器間轉送）；**POP3（110）＝收信**，下載到本機後常從伺服器刪（適合單一裝置）；**IMAP（143）＝收信**，郵件留在伺服器、多裝置同步（適合多裝置）。差別：**POP3 下載刪、IMAP 留伺服器。**
</details>

**Q4.** DHCP 自動取得 IP 的流程口訣是什麼？各步驟代表什麼？
<details><summary>看解答</summary>

口訣 **DORA**：**D**iscover 探索 → **O**ffer 提供 → **R**equest 請求 → **A**CK 確認。DHCP 埠為 67（伺服器）、68（客戶端），走 UDP。
</details>

**Q5.** GET 與 POST 的參數分別放在哪裡？哪個較適合被加入書籤／快取？
<details><summary>看解答</summary>

**GET 參數放在 URL（看得到）**、**POST 放在 body（看不到）**。GET 可被快取／加書籤；POST 不適合。（GET 安全性較低，因為參數露在網址上。）
</details>
