# 陣列 + 字串函式 + 例外處理

> 科目：程式（專業 B）｜這張把三個常考小主題打包：**陣列**（補語法）、**字串函式**（跨語言對照、硬背）、**例外處理**（理解為主）。
>
> 學習方式：陣列重點在**語法**（索引從 0、length）；字串函式屬【硬背】（記 Java／Python／C 的對照）；例外處理屬【理解】（try/catch/finally 的流程與 checked/runtime 差別）。範例以 Java 為主。

## 🎯 開場題目

> 考題常這樣問：
>
> 1. Java 裡 `int[] arr = new int[5];`，合法的索引範圍是多少？`arr[5]` 會怎樣？
> 2. Java 要比較兩個字串「內容一不一樣」，該用 `==` 還是 `.equals()`？
> 3. 一段 try/catch/finally，如果 try 裡出錯被 catch 接住了，finally 還會執行嗎？

先想過再往下看。

## 🤔 先想想

- 陣列像一排**連號的置物櫃**：櫃號（索引）**從 0 開始**，第 5 格的櫃號是 4，不是 5。
- 字串在不同語言的函式名字不一樣，但要做的事就那幾件：取長度、取字元、取子字串、串接、搜尋、分割——用「操作」當索引去記最省力。
- 例外處理的精神是：**「錯就錯，但別讓整個程式當掉」**，把可能出錯的地方圍起來、接住它。

## 📖 觀念拆解

### 一、陣列 Array

陣列特性是**連續記憶體、索引存取 O(1)、大小固定**；**索引從 0 開始**。

- Java 宣告：`int[] arr = new int[5];` 或 `int[] arr2 = {1, 2, 3};`
- C 宣告：`int arr[5];` 或 `int arr2[] = {1, 2, 3};`
- Java 用 `arr.length` 取長度；多維陣列可寫 `int[][] m = new int[3][4];`

為什麼索引存取是 **O(1)**？因為陣列是**連續記憶體**，某格位址 =「起點 + 索引 × 元素大小」，一步就算出來，不用逐格找。

```java
int[] arr = {10, 20, 30, 40, 50};
System.out.println(arr.length);   // 5
System.out.println(arr[0]);       // 10（第一個，索引從 0）
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
// arr[5] → 越界，丟 ArrayIndexOutOfBoundsException
```

### 二、字串常用函式（Java／Python／C 對照）　【硬背】

| 操作 | Java | Python | C |
|---|---|---|---|
| 長度 | s.length() | len(s) | strlen(s) |
| 取第 i 字元 | s.charAt(i) | s[i] | s[i] |
| 取子字串 | s.substring(a, b) | s[a:b] | - |
| 串接 | s1 + s2 | s1 + s2 | strcat(s1, s2) |
| 搜尋位置 | s.indexOf("x") | s.find("x") | strstr(s, "x") |
| 分割 | s.split(",") | s.split(",") | - |

📌 **重點：** Java 比字串要用 **`.equals()`，不是 `==`**；`==` 比的是**參考位址**，`.equals()` 比**內容**。C 用 `strcmp`，Python 可用 `==` 比內容。

```java
String a = new String("hi");
String b = new String("hi");
System.out.println(a == b);        // false（比位址，兩個不同物件）
System.out.println(a.equals(b));   // true （比內容）
```

📌 **字串不可變（immutable）：** Java 的 `String` 一旦建立就**不能修改**，每次用 `+` 串接都會產生**新物件**；要頻繁修改字串請改用 **`StringBuilder`／`StringBuffer`**（可變、效率較佳）。

### 三、例外處理 Exception Handling　【理解】

例外是程式**執行時的非預期錯誤**，例如**除以 0、陣列越界或找不到檔案**。

| 關鍵字 | 作用 |
|---|---|
| try | 放可能出錯的程式碼 |
| catch | 捕捉並處理某種例外 |
| finally | 不管有沒有錯都一定執行 |
| throw | 主動拋出例外 |
| throws | Java 方法宣告可能拋出的例外 |

Java 例外分 **checked** 與 **unchecked/runtime**；checked（如檔案 IO）會被**編譯器強制處理**。

```java
try {
    int[] arr = {1, 2, 3};
    System.out.println(arr[5]);   // 越界，這裡拋出例外
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("陣列越界了！");   // 接住並處理
} finally {
    System.out.println("我一定會執行");   // 不管有沒有錯都跑
}
// 輸出：
// 陣列越界了！
// 我一定會執行
```

`throw` 與 `throws` 的差別：

```java
// throws：宣告這個方法「可能」拋出 checked 例外
void readFile(String path) throws IOException {
    if (path == null) throw new IOException("路徑不能為空"); // throw：主動拋
}
```

- **checked**（如 `IOException`）：編譯器**強制**你 try-catch 或用 throws 宣告，否則編譯不過。
- **unchecked/runtime**（如 `NullPointerException`、`ArrayIndexOutOfBoundsException`、除以 0 的 `ArithmeticException`）：編譯器不擋，但沒接住就會當掉。

---

## ✅ 回到題目：解答

1. `new int[5]` 的合法索引是 **0～4**（共 5 格，索引從 0 開始）；`arr[5]` **越界**，Java 會丟 `ArrayIndexOutOfBoundsException`。
2. 比「內容」要用 **`.equals()`**。`==` 比的是**參考位址**（是不是同一個物件），`.equals()` 才是比**內容**。
3. **會**。finally 的設計就是「**不管有沒有錯、有沒有被接住，都一定執行**」，常用來做關檔、釋放資源等收尾。

---

## 📌 重點整理

- 陣列：連續記憶體、索引 O(1)、大小固定、**索引從 0**；Java 取長度用 `arr.length`。
- Java `int[] arr = new int[5];` / C `int arr[5];`；多維 Java `int[][] m = new int[3][4];`。
- 字串函式對照要背：length／charAt／substring／串接／indexOf／split（各語言名字不同）。
- **Java 比字串內容用 `.equals()`，不是 `==`**（== 比位址）。
- 例外處理：try 放可能出錯的、catch 接住、finally 一定執行；throw 主動拋、throws 宣告可能拋。
- Java 例外分 checked（編譯器強制處理，如 IO）與 unchecked/runtime。

---

## ⚠️ 常見陷阱

- **索引從 0**：長度 5 的陣列，最後一格是 `arr[4]`；`arr[5]` 越界。
- **Java 用 == 比字串**：超經典 bug，`==` 常常「碰巧」對又「有時」錯（跟字串池有關），內容比較一律用 `.equals()`。
- **字串池（string pool）的差別**：字面值 `String a = "hi"; String b = "hi";` 會**共用池中同一物件**，`a == b` 得 **true**；而 `new String("hi")` 每次都**另建新物件**，`==` 才會是 false。
- **finally 一定執行**：即使 try/catch 裡有 return，finally 仍會先跑；而且若 **finally 裡也有 `return`，會覆蓋掉 try/catch 的回傳值**（愛考的陷阱）。
- **checked vs runtime**：checked（IOException 等）不處理**編譯就過不了**；runtime（NullPointer、越界、除以 0）編譯不擋，但沒接住會當掉。
- **C 沒有內建 substring/split**（表中標「-」），別把 Java/Python 的用法套到 C。

## 📝 練習題（含解答）

**Q1.** Java 中 `int[] a = new int[3];`，`a.length` 是多少？合法索引有哪些？
<details><summary>看解答</summary>

length 是 **3**；合法索引 **0、1、2**。存取 `a[3]` 會越界（`ArrayIndexOutOfBoundsException`）。
</details>

**Q2.** 下面 Java 印出什麼？為什麼？
```java
String x = new String("abc");
String y = new String("abc");
System.out.println(x == y);
System.out.println(x.equals(y));
```
<details><summary>看解答</summary>

印 **false** 再 **true**。`==` 比參考位址，x、y 是兩個不同物件所以 false；`.equals()` 比內容，內容都是 "abc" 所以 true。
</details>

**Q3.** try/catch/finally 三者的職責各是什麼？
<details><summary>看解答</summary>

try 放**可能出錯**的程式碼；catch **捕捉並處理**某種例外；finally **不管有沒有錯都一定執行**（常用來收尾／關資源）。
</details>

**Q4.** Java 的 checked exception 和 runtime exception 差在哪？各舉一例。
<details><summary>看解答</summary>

checked 會被**編譯器強制處理**（要 try-catch 或用 throws 宣告），例：`IOException`（檔案 IO）；runtime/unchecked 編譯器不強制，例：`NullPointerException`、`ArrayIndexOutOfBoundsException`、除以 0 的 `ArithmeticException`。
</details>

**Q5.** `throw` 和 `throws` 差在哪？
<details><summary>看解答</summary>

`throw` 是**主動拋出**一個例外（`throw new IOException(...)`）；`throws` 是在**方法簽章上宣告**這個方法可能拋出哪些（checked）例外，交給呼叫者處理。
</details>
