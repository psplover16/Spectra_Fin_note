# 網路設備對應層級（看得懂版）

> 科目：網路概論｜這篇用 **OSI 分層** 把所有網路設備串起來。只要理解「每一層的設備看得懂什麼」，就不用死背哪個設備在哪一層——設備會自動歸位。
>
> 學習方式：理解為主【理解】；最後的總表與「背這張」屬【硬背】（有分層邏輯撐著，背起來輕鬆）。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「**交換器（Switch）** 能切開**碰撞域（Collision Domain）** 還是**廣播域（Broadcast Domain）**？」
> 2. 「**Hub** 與 **Switch** 最大的差別是什麼？各運作在哪一層？」
> 3. 「要在**不重新佈線**的情況下，把一台交換器邏輯切成多個獨立廣播域，用什麼技術？」

先想想再看答案。

---

## 🤔 先想想

還沒把握的話，先抓住三個直覺：

- 每個設備差在「**看得懂多少**」：只看訊號？看 MAC？看 IP？還是看整個協定？
- 「看得懂越多」的設備，通常在**越上層、越聰明、也越貴**。
- **碰撞域**和**廣播域**是兩件不同的事，不是每個設備都能切——這點超常考。

帶著這三點，我們來拆解。

---

## 📖 觀念拆解

### 一、一句話心法：越往上層，設備越「聰明」

設備之間的差別，就在「看得懂多少」：

```text
OSI 層            設備                       看得懂 → 做什麼
┌────────────────────────────────────────────────────────────┐
│ L7 應用層  │ Gateway 閘道器             │ 整個協定 → 翻譯           │
│ L3 網路層  │ Router／L3 Switch         │ IP／封包 → 跨網路找路       │
│ L2 連結層  │ Switch／Bridge／NIC       │ MAC／訊框 → 挑該送的埠       │
│ L1 實體層  │ Hub／Repeater／NIC        │ 只看訊號 → 無腦複製         │
└────────────────────────────────────────────────────────────┘
↑ 越往上，設備越「聰明」
```

**推理法（不用硬背）**：看 bit → L1；看 MAC → L2；看 IP → L3；轉協定 → Gateway（可到 L7）。記住這條軸線，下面所有設備自動歸位。

### 二、帶你走一遍（從下層到上層）

從最笨（只看訊號）到最聰明（看整個協定），依序認識八個設備：

1. **網路卡 NIC（L1/L2）** — 裝置的「網路嘴巴」。每張卡有獨一無二的 **MAC 位址**（Media Access Control，燒在網卡上的實體位址），是裝置能連網的基本配備。
2. **中繼器 Repeater（L1）** — 訊號傳遠會衰減，它把訊號**放大／再生**、延長距離。不懂位址，單純還原訊號。
3. **集線器 Hub（L1）** — 「多埠的中繼器」。資料**無腦複製給所有埠**，大家共享頻寬、容易碰撞。已被 Switch 取代。
4. **橋接器 Bridge（L2）** — 連接兩網段，看 **MAC** 決定要不要轉過去，藉此**切開碰撞域**、過濾流量。
5. **交換器 Switch（L2）** — 「多埠的橋接器」，現代區網主角。內部有 **MAC 位址表**，資料**只送到目的埠**（不像 Hub 全送）。每個埠都是獨立碰撞域、可**全雙工**（可同時收發）。
6. **L3 交換器 L3 Switch（L3）** — 「Switch ＋ Router 合體」：用 **IP** 在 VLAN／子網路之間轉送，而且是**硬體做路由、速度快**。企業內跨 VLAN 時常用。
7. **路由器 Router（L3）** — 用 **IP** 連接不同網路、選最佳路徑轉送封包。會**切開廣播域**；連 LAN 到 Internet、可做 **NAT**（Network Address Translation，把內部私有 IP 轉成對外公有 IP）。家裡對外那台就是它。
8. **閘道器 Gateway（L4–L7，可跨全層）** — 不同協定／系統之間的「翻譯官」（異質網路互通）。最上層、最複雜。

> ⚠ **名詞陷阱**：口語的「**預設閘道（default gateway）**」其實多半指**路由器**；設備分類的「**Gateway**」是指**協定轉換器**。看語境判斷。
>
> 💡 **L3 Switch vs Router**：兩個都 L3、都看 IP。差別在 L3 Switch 偏「企業內部跨 VLAN、硬體路由、快、埠多」；Router 偏「連到外部不同網路、功能多（NAT／防火牆）、埠少」。

### 三、網路設備總表　【硬背】★

| 設備 | OSI 層 | 看得懂 | 功能（做什麼） | 切碰撞域 | 切廣播域 |
|---|---|---|---|---|---|
| 網路卡 NIC | L1／L2 | MAC | 讓裝置連網、提供 MAC | — | — |
| 中繼器 Repeater | L1 實體 | 訊號 | 放大／再生訊號、延長距離 | ✗ | ✗ |
| 集線器 Hub | L1 實體 | 訊號 | 多埠中繼器，送所有埠 | ✗（全部同一個） | ✗ |
| 橋接器 Bridge | L2 連結 | MAC | 連網段、依 MAC 過濾 | ✓（每段一個） | ✗ |
| 交換器 Switch | L2 連結 | MAC | 依 MAC 表精準轉送 | ✓（每埠一個） | ✗（VLAN 才切） |
| L3 交換器 | L3 網路 | IP | Switch＋Router，跨 VLAN 硬體路由 | ✓ | ✓ |
| 路由器 Router | L3 網路 | IP | 跨網路繞送、找路徑、NAT | ✓ | ✓ |
| 閘道器 Gateway | L4–L7 | 協定 | 不同協定／系統轉換 | ✓ | ✓ |

📌 **「七大設備」怎麼算？**——核心是 Repeater／Hub／Bridge／Switch／Router／Gateway，再加一個（NIC 或 L3 Switch），依教材而定。上表全列出，記得住就好。

### 四、碰撞域 vs 廣播域（超常考）　【硬背】★

先把定義抓清楚：

- **碰撞域 Collision Domain**：共享同一介質、同時送會「相撞」的範圍（撞到要重送）。
- **廣播域 Broadcast Domain**：一個廣播訊框能傳到的範圍。

誰切誰：

| 設備 | 切碰撞域？ | 切廣播域？ |
|---|---|---|
| 中繼器／集線器 Hub | ✗ | ✗ |
| 橋接器／交換器 Switch | ✓（每埠一個） | ✗（VLAN 例外） |
| 路由器 Router／L3 Switch | ✓ | ✓ |

用比喻記：

- **碰撞域** ＝ 一間會議室共用一支麥克風，兩人同時講就撞 → Switch 給每個埠一支獨立麥克風，不撞了。
- **廣播域** ＝ 你喊「大家集合！」傳得到的範圍 → Router 像一道隔音牆，喊聲過不去。

一句話：**Switch 切碰撞域、不切廣播域；Router 兩個都切。**
口訣：**Hub 都不切、Switch 切碰撞、Router 全切。**

舉個具體例子：一台 **8 埠 Switch** → 每個埠各自一個碰撞域，共 **8 個碰撞域**；但這 8 個埠仍屬**同一個廣播域**（除非設 VLAN）。換成一台 Hub，8 個埠通通擠在**同一個碰撞域**裡搶頻寬。

### 五、LAN vs VLAN　【理解】

| | LAN | VLAN（虛擬 LAN） |
|---|---|---|
| 怎麼分 | 實體連在一起 ＝ 一個廣播域 | 用軟體把交換器的埠邏輯切成多個獨立廣播域 |
| 佈線 | 換網段要實體重新佈線 | 不用重新佈線，軟體設定即可 |
| 隔離／安全 | 同網段廣播互通 | 不同 VLAN 預設不能互通（要靠 L3 路由），隔離廣播、較安全 |
| 分組依據 | 依實體位置 | 依邏輯（如部門），不受實體位置限制 |

💡 **記憶鉤子**：VLAN ＝ 用軟體把一台實體交換器「邏輯切成多個獨立 LAN／廣播域」。好處：免重新佈線、隔離廣播、較安全、依部門彈性分組。
呼應上一節：**VLAN 就是「在 Switch 上額外切廣播域」的方法。**

### 六、易混淆／常考

- **Hub vs Switch（超常考）**：Hub 送**所有埠**（L1、共享頻寬、會碰撞）；Switch **只送目的埠**（L2、每埠獨立碰撞域）。
- **Switch vs Router**：Switch 用 **MAC**（L2、同網路內）；Router 用 **IP**（L3、跨網路）。
- **Bridge vs Switch**：本質相同（都 L2、看 MAC）；Switch ＝ 多埠、硬體加速的 Bridge。
- **L3 Switch vs Router**：都 L3；L3 Switch 偏內部跨 VLAN、快、埠多；Router 偏對外、功能多、埠少。
- **「切碰撞域」≠「切廣播域」**：Switch 只做前者，別搞混。
- **Gateway**：設備分類指「協定轉換器」；「預設閘道」口語多指 Router。
- **防火牆 Firewall**：不綁單一層——**封包過濾**型看 IP／Port（L3／L4）、**應用層**型（如 WAF、代理）可到 L7；考題問「防火牆在哪層」多半答 **L3～L7、可跨層**。

📎 無線設備（AP、Modem、無線路由器、CSMA/CA）見：**網路概論(v2)_05｜無線與上網接取設備**。

---

## ✅ 回到題目：解答

1. **Switch 切碰撞域還是廣播域？** → **切碰撞域**（每個埠各一個獨立碰撞域），**不切廣播域**（除非搭配 VLAN）。
2. **Hub 與 Switch 的差別？各在哪層？** → **Hub＝L1**，資料無腦複製給所有埠、共享頻寬會碰撞；**Switch＝L2**，看 MAC 表只送目的埠、每埠獨立碰撞域、可全雙工。
3. **不重新佈線切多個廣播域用什麼？** → **VLAN（虛擬 LAN）**：用軟體把交換器的埠邏輯切成多個獨立廣播域。

## 📌 重點整理

- **推理軸線**：看 bit → L1；看 MAC → L2；看 IP → L3；轉協定 → Gateway（可到 L7）。
- **設備對層**：NIC（L1/L2）、Repeater／Hub（L1）、Bridge／Switch（L2）、L3 Switch／Router（L3）、Gateway（L4–L7）。
- **切碰撞域／廣播域**：Hub 都不切、Switch 切碰撞（不切廣播）、Router／L3 Switch 兩個都切。
- **Hub vs Switch**：Hub 送所有埠；Switch 只送目的埠（靠 MAC 表）。
- **VLAN** ＝ 在 Switch 上用軟體額外切廣播域，免佈線、較安全、依部門彈性分組。

---

## ⚠️ 常見陷阱

- **「切碰撞域」≠「切廣播域」**：Switch 只切碰撞域，不切廣播域（VLAN 才切廣播域）。這是最常被考倒的地方。
- **Gateway 有兩義**：設備分類指「協定轉換器」（L4–L7）；口語「預設閘道 default gateway」多半指路由器。
- **L3 Switch vs Router 都在 L3、都看 IP**：L3 Switch 偏企業內跨 VLAN、硬體路由、快、埠多；Router 偏對外、功能多（NAT／防火牆）、埠少。別以為 L3 Switch 不是 L3。
- **Bridge 與 Switch 別當成不同層**：本質相同（都 L2、看 MAC），Switch 只是多埠、硬體加速的 Bridge。
- **Hub 不「切」碰撞域**：整台 Hub 底下是「同一個」碰撞域，別以為多埠就會分隔。

## 📝 練習題（含解答）

**Q1.** 依 OSI 分層，Hub、Switch、Router 分別在第幾層？各自「看得懂」什麼？
<details><summary>看解答</summary>

Hub＝**L1**（只看訊號、無腦複製）；Switch＝**L2**（看 MAC 訊框、挑該送的埠）；Router＝**L3**（看 IP 封包、跨網路找路）。
</details>

**Q2.** 一台 8 埠的 Switch，有幾個碰撞域？會切開廣播域嗎？
<details><summary>看解答</summary>

每個埠各是一個獨立碰撞域 → **8 個碰撞域**；**不切廣播域**（8 個埠仍屬同一個廣播域，除非設定 VLAN）。
</details>

**Q3.** 「預設閘道（default gateway）」通常指哪一種設備？它和設備分類講的「Gateway」一樣嗎？
<details><summary>看解答</summary>

「預設閘道」口語上多半指**路由器 Router**（對外那台）；跟設備分類裡的「**Gateway（協定轉換器，L4–L7）**」不是同一個東西，要看語境判斷。
</details>

**Q4.** L3 Switch 和 Router 都在 L3、都看 IP，實務上怎麼區分用途？
<details><summary>看解答</summary>

**L3 Switch** 偏「企業內部跨 VLAN、硬體路由、速度快、埠多」；**Router** 偏「連到外部不同網路、功能多（NAT／防火牆）、埠少」。
</details>

**Q5.** 想把同一台實體交換器上的不同部門隔成互不干擾的獨立廣播域，又不想重新佈線，該用什麼？原理是什麼？
<details><summary>看解答</summary>

用 **VLAN（虛擬 LAN）**：用軟體把交換器的埠邏輯切成多個獨立廣播域，免重新佈線、隔離廣播、較安全、可依部門彈性分組；不同 VLAN 預設不能互通，要靠 L3 路由。
</details>
