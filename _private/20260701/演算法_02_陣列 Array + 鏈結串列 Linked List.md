# 陣列 Array + 鏈結串列 Linked List

> 科目：演算法｜這是線性資料結構最經典的**對照題**：陣列靠索引快取值，鏈結串列靠指標快插刪。位址計算幾乎年年考，指標操作順序則是選擇題陷阱大戶。
>
> 學習方式：位址公式要理解每個符號的意思（不是死背）；鏈結串列插入要記住口訣「**先接後面，再改前面**」。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「陣列的**隨機存取**是 O(1)，那**中間插入**一筆是 O(?)？」
> 2. 「一維陣列 A[i] 的位址公式是什麼？若 B=1000、L=0、d=4，A[5] 在哪裡？」
> 3. 「在鏈結串列中間插入新節點，先改 `p.next` 還是先設 `new.next`？」

先別急著看答案，試著自己回答看看。

---

## 🤔 先想想

給你三個提示，幫你建立直覺：

- 陣列像**連號的停車格**：知道格號就能直接開過去（O(1)），但要在中間硬插一台車，後面全部得往後挪（O(n)）。
- 鏈結串列像**尋寶圖**：每張紙條寫著「下一張在哪」，插入新紙條只要改指向，但要找第 k 張得從頭一張張翻。
- 插入指標時**順序錯了會斷鏈**——先把新節點接上後面，才敢改前面的指向。

帶著這三點，我們來拆解。

---

## 📖 觀念拆解

### 一、陣列 Array

1. 陣列用**連續記憶體**存放相同型別元素。
2. 給定索引就能直接定位，因此**隨機存取是 O(1)**。
3. 大小通常在宣告時決定，中間插入或刪除需要**搬移後方元素**，所以是 **O(n)**。

| 優點 | 缺點 |
|---|---|
| 隨機存取快 O(1)、不用額外指標、省空間 | 大小固定、插入與刪除慢，因為要搬移元素 |

📌 **白話：** 「連續記憶體」是陣列一切特性的根源——正因為連續，才能用公式直接算出任一格位址（快）；也正因為連續又固定，插刪才要挪動一堆元素（慢）。

### 二、陣列位址計算　【常考】

一維陣列位址公式：

> **A[i] 位址 = B + (i − L) × d**
>
> B 是**起始位址**，L 是**下界**（索引從幾開始），d 是**每個元素大小**（bytes）。

二維陣列有兩種存法：

| 二維儲存方式 | 公式概念 | 常見語境 |
|---|---|---|
| Row-major | 一列一列存，A[i][j] 位移常看成 **i × 欄數 + j**。 | C、Java 常用。 |
| Column-major | 一行一行存，A[i][j] 位移常看成 **j × 列數 + i**。 | Fortran 常用。 |

同一格在 Row-major 與 Column-major 可能算出**不同位址**；題目若沒說，通常先檢查語境是否預設 row-major。

📌 **二維完整公式（Row-major，下界皆從 0）：** A[i][j] 位址 = B + (i × 欄數 + j) × d，「欄數」＝每一列的元素個數；含下界時 i、j 各換成 (i − L₁)、(j − L₂)。Column-major 則改成 B + (j × 列數 + i) × d。

📌 **白話：** 公式裡最容易忽略的是 **L（下界）**。索引從 0 開始和從 1 開始，算出來會差一格。

### 三、逐步範例：算一維位址

**範例 A：** B = 1000、L = 0、d = 4，求 A[5]。
1. 代入公式：A[5] = 1000 + (5 − 0) × 4。
2. 算括號：5 − 0 = 5。
3. 乘上 d：5 × 4 = 20。
4. 加起始位址：1000 + 20 = **1020**。

**範例 B（下界從 1 開始）：** B = 1000、L = 1、d = 4，求 A[5]。
1. A[5] = 1000 + (5 − 1) × 4。
2. 5 − 1 = 4；4 × 4 = 16。
3. 1000 + 16 = **1016**。

> 同樣要找 A[5]，只因為下界 L 不同，答案就差了一格（4 bytes）——這就是為什麼 L 不能忽略。

### 四、鏈結串列 Linked List

1. 每個節點 node 通常包含 **data 與 next 指標**。
2. 節點在記憶體中**不必連續**，靠指標串起來。
3. 大小可**動態增減**，但不能直接用索引跳到第 k 個，查找通常要**從頭走 O(n)**。
4. **已知位置**時插入與刪除主要是改指標，可視為 **O(1)**。

中間插入新節點時，正確順序是 **`new.next = p.next`，再 `p.next = new`**；若先改 `p.next`，後面整串可能**斷鏈**。

📌 **白話：** 想像 p 後面原本接著一長串。若你先把 `p.next` 指向新節點，那條「通往後面整串」的線就斷了、再也找不回來。所以一定要先讓新節點記住後面（`new.next = p.next`），再讓 p 改指向新節點。

### 五、Array vs Linked List

| 比較 | Array | Linked List |
|---|---|---|
| 記憶體 | 連續 | 不連續，靠指標 |
| 大小 | 固定 | 動態 |
| 隨機存取 | O(1) | O(n) |
| 插入/刪除 | O(n)，需要搬移 | 已知位置時 O(1)，主要改指標 |
| 額外空間 | 少 | 每節點需額外指標 |

📌 **白話：** 一句話記——**要常取值選陣列，要常插刪選鏈結串列**。

### 六、鏈結串列種類

| 種類 | 結構 | 特點 |
|---|---|---|
| Singly Linked List | 每節點只有 next | 只能往一個方向走。 |
| Doubly Linked List | 每節點有 prev 與 next | 可往前往後走，但多一個指標空間。 |
| Circular Linked List | 最後一個 next 指回頭 | 形成環，可從任一點繞遍全部。 |

---

## ✅ 回到題目：解答

1. **陣列中間插入是 O(?)** → **O(n)**，因為要搬移後方所有元素。
2. **A[5] 在哪裡？** → A[5] = 1000 + (5 − 0) × 4 = **1020**。
3. **先改哪個指標？** → 先設 **`new.next = p.next`**，再 `p.next = new`；順序反了會斷鏈。

---

## 📌 重點整理

- 陣列：連續記憶體、**隨機存取 O(1)**、中間**插刪 O(n)**、大小固定。
- 一維位址公式：**A[i] = B + (i − L) × d**（B 起始、L 下界、d 元素大小）。
- 二維：**Row-major**（i × 欄數 + j，C/Java）、**Column-major**（j × 列數 + i，Fortran）。
- 鏈結串列：不連續靠指標、大小動態、**查找 O(n)**、**已知位置插刪 O(1)**。
- 插入口訣：**先 `new.next = p.next`，再 `p.next = new`**。
- 種類：Singly（單向）、Doubly（雙向多一指標）、Circular（成環）。

---

## ⚠️ 常見陷阱

- **下界 L 忘記減**：索引從 1 開始時，A[i] 要用 (i − 1)，不是直接 i。
- **Row/Column-major 搞混**：C、Java 是 row-major；Fortran 是 column-major，公式不同。
- **插入順序反了**：先改 `p.next` 會讓後面整串斷鏈，務必先接新節點的 next。
- **以為鏈結串列能索引跳查**：錯——它沒有連續記憶體，找第 k 個要從頭走 O(n)。
- **以為鏈結串列比較省空間**：不一定——每個節點都要多存指標，額外空間反而較多。

## 📝 練習題（含解答）

**Q1.** 一維陣列 B=2000、L=0、每個元素 8 bytes，A[10] 的位址是？
<details><summary>看解答</summary>

A[10] = 2000 + (10 − 0) × 8 = 2000 + 80 = **2080**。
</details>

**Q2.** 陣列與鏈結串列，哪一個「已知位置的插入/刪除」比較快？為什麼？
<details><summary>看解答</summary>

**鏈結串列**較快（O(1)）——只要改指標；陣列要搬移後方元素（O(n)）。
</details>

**Q3.** 要在鏈結串列節點 p 後面插入新節點 new，正確的兩步驟順序是？
<details><summary>看解答</summary>

先 `new.next = p.next`（新節點接上後面），再 `p.next = new`（p 改指向新節點）。反過來會斷鏈。
</details>

**Q4.** 哪一種鏈結串列可以「往前也往後走」？代價是什麼？
<details><summary>看解答</summary>

**Doubly Linked List（雙向）**。每個節點多存一個 prev 指標，代價是多一份指標空間。
</details>

**Q5.** 二維陣列以 row-major 儲存，A[i][j] 的位移常看成什麼？
<details><summary>看解答</summary>

**i × 欄數 + j**（一列一列存，先跳過前面 i 列，再往右數 j 格）。
</details>
