# 圖 Graph 基礎 + DFS／BFS ★

> 科目：演算法｜圖比樹更「一般」：**可以有環，也能表示多對多關係**（地圖、社群網路、捷運路線都是圖）。
>
> 學習方式：這一章先掌握**術語、兩種表示法、DFS/BFS 走訪**，再把 Spanning Tree 接到下一篇 MST。走訪題常要你「寫出訪問順序」，是必拿分。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 一個有 **n 個頂點的無向完全圖（Complete Graph）**，共有幾條邊？
> 2. **鄰接矩陣（Adjacency Matrix）** 與 **鄰接串列（Adjacency List）**，哪個省空間？哪個查「兩點是否相連」比較快？
> 3. **DFS** 用什麼資料結構？**BFS** 又用什麼？

先自己想想再往下。

---

## 🤔 先想想

- 圖 = **頂點 + 邊**；和樹最大的差別是：圖**可以有環**、沒有「唯一根」、關係是**多對多**。
- 要把圖存進電腦，有兩種常見方法：一張「**表格**」（矩陣）或一堆「**清單**」（串列），各有優缺點。
- 走訪就是「有系統地把每個頂點都拜訪一次」：**DFS 往深處鑽、BFS 一圈圈擴散**。

---

## 📖 觀念拆解

### 一、Graph 定義與術語

圖 **G = (V, E)**，由**頂點 Vertex** 與**邊 Edge** 組成，用來表示頂點間**多對多**關係。

| 術語 | 意思 |
|---|---|
| Directed Graph（有向圖） | 邊有方向，例如 A → B。 |
| Undirected Graph（無向圖） | 邊無方向，例如 A — B。 |
| Weighted Graph（加權圖） | 邊上有**權重或成本**，例如距離、花費。 |
| Degree（度數） | 一個頂點連幾條邊；**有向圖分入度與出度**。 |
| Path（路徑） | 一連串相連的頂點。 |
| Cycle（環） | 繞回起點的路徑。 |
| Connected（連通） | 任兩頂點都有路徑相連。 |
| Complete Graph（完全圖） | 每兩頂點都有邊；**n 頂點無向完全圖有 n(n−1)/2 條邊**。 |

📌 **公式帶數字：** n = 5 的無向完全圖 → 5 × 4 / 2 = **10 條邊**（每個頂點都和其餘 4 個相連，除以 2 是因為每條邊被兩端各數了一次）。

📌 **握手定理（常考）：** 無向圖**所有頂點度數總和 = 2 × 邊數**（每條邊替兩端各加 1 度）；有向圖則**入度總和 = 出度總和 = 邊數**。

### 二、圖的兩種表示法

| 比較 | Adjacency Matrix（鄰接矩陣） | Adjacency List（鄰接串列） |
|---|---|---|
| 做法 | n × n 矩陣，[i][j] = 1 或權重表示 i 到 j 有邊。 | 每個頂點存一份**鄰居清單**。 |
| 空間 | **O(n²)** | **O(V+E)** |
| 查兩點是否相連 | **O(1)**，很快。 | 要掃鄰居清單。 |
| 適合 | **稠密圖**（邊多）。 | **稀疏圖**（邊少）。 |

📌 **白話：** 矩陣像一張「全班座位對照表」，查「A、B 有沒有連」一格就知道（O(1)），但就算邊很少也要占滿 n×n 格（浪費空間）。串列像每個人「自己的好友名單」，邊少時很省空間，但查兩點是否相連要翻名單。

### 三、DFS vs BFS（兩大走訪）

| 比較 | DFS（深度優先） | BFS（廣度優先） |
|---|---|---|
| 策略 | 一條路**走到底**，走不通再回頭。 | **一層一層**擴散，先訪問所有鄰居。 |
| 使用工具 | **Stack 或遞迴**。 | **Queue**。 |
| 直覺 | 走迷宮先往深處鑽。 | 水波一圈圈擴散。 |
| 鄰接串列複雜度 | **O(V+E)** | **O(V+E)** |
| 鄰接矩陣複雜度 | **O(V²)** | **O(V²)** |

📌 **記憶方式：** DFS 的 **D** 想成 **Deep**（往深處鑽）；BFS 的 **B** 想成 **Breadth**（一層層展開）。

📌 **常考應用：** **BFS 可求無權圖的最短路徑**（走過的層數＝最少邊數）；**DFS 則常用來偵測環與找連通分量**。

### 四、逐步範例（同一張圖跑 DFS 與 BFS）

範例無向圖（邊：A–B、A–C、B–D、C–E、D–E，其中 A–B–D–E–C–A 構成一個環）：

```
    A
   / \
  B   C
  |   |
  D — E
```

鄰居清單（依字母排序，走訪時挑最小未訪的鄰居）：

```
A: B, C      B: A, D      C: A, E      D: B, E      E: C, D
```

**DFS（用堆疊／遞迴，往深處鑽）：**
1. 訪 **A** → 挑鄰居 B。
2. 訪 **B** → A 已訪，挑 D。
3. 訪 **D** → B 已訪，挑 E。
4. 訪 **E** → 挑 C（D 已訪）。
5. 訪 **C** → A、E 都已訪，回溯結束。
- DFS 順序：**A B D E C**

**BFS（用佇列 Queue，一圈圈擴散）：**
1. 訪 **A**，把鄰居 B、C 入列。佇列：[B, C]
2. 出列 **B**，把未訪鄰居 D 入列。佇列：[C, D]
3. 出列 **C**，把未訪鄰居 E 入列。佇列：[D, E]
4. 出列 **D**，鄰居 B、E 都已訪／已入列，無新增。佇列：[E]
5. 出列 **E**，鄰居都已訪，結束。
- BFS 順序：**A B C D E**

📌 對照：DFS 先一路衝到底（A→B→D→E 才回頭找 C）；BFS 先把 A 的鄰居 B、C 都訪完，再往下一圈 D、E。

### 五、Spanning Tree（生成樹）

1. 生成樹是**連通圖的子圖**，包含**全部頂點**。
2. 生成樹**剛好使用 n − 1 條邊**，且**沒有環**。
3. 一張圖**可以有多種**生成樹。
4. 在**權重圖**中，**總權重最小**的生成樹叫 **Minimum Spanning Tree（MST）**。

📌 **白話：** 生成樹就是「用最少的邊（n−1 條）把所有頂點連起來、又不繞圈」。MST 則是在有權重時挑「總花費最小」的那一種連法。MST 的經典演算法是 **Kruskal 與 Prim**，流程與比較放在下一篇《圖演算法》。

## ✅ 回到題目：解答

1. **n 頂點無向完全圖的邊數？** → **n(n−1)/2**（例如 n = 5 → 10 條）。
2. **矩陣 vs 串列？** → **鄰接串列較省空間（O(V+E)）**，適合稀疏圖；**鄰接矩陣查兩點相連 O(1) 較快**，適合稠密圖。
3. **DFS / BFS 用什麼？** → **DFS 用 Stack 或遞迴**；**BFS 用 Queue**。

---

## 📌 重點整理

- 圖 G = (V, E)：頂點 + 邊、可有環、多對多；有向圖 degree 分入度與出度。
- **完全圖邊數**：無向 **n(n−1)/2**。
- 表示法：矩陣 **O(n²)**、查相連 O(1)、宜稠密；串列 **O(V+E)**、宜稀疏。
- 走訪：**DFS = Stack/遞迴、往深鑽**；**BFS = Queue、一層層**；鄰接串列皆 **O(V+E)**、鄰接矩陣皆 **O(V²)**。
- 生成樹：含全部頂點、**n−1 條邊、無環**、可有多種；權重最小者為 **MST**。

---

## ⚠️ 常見陷阱

- **DFS / BFS 的工具別記反**：DFS 用 **Stack（或遞迴）**、BFS 用 **Queue**。這幾乎每年考。
- **複雜度看表示法**：用鄰接串列是 **O(V+E)**、用鄰接矩陣是 **O(V²)**；題目會指定用哪種。
- **走訪順序會受鄰居順序影響**：同一張圖，若鄰居挑選順序不同，DFS/BFS 序列也會不同；考試通常規定「依編號 / 字母由小到大」。
- **完全圖公式別漏除以 2**：無向是 n(n−1)/2；若是**有向**完全圖則為 n(n−1)（每對兩個方向）。
- **生成樹的邊數固定**：n 個頂點的生成樹**一定是 n−1 條邊**，多一條就會產生環。

## 📝 練習題（含解答）

**Q1.** 一個有 6 個頂點的無向完全圖，共有幾條邊？
<details><summary>看解答</summary>

n(n−1)/2 = 6 × 5 / 2 = **15 條**。
</details>

**Q2.** 邊很少的「稀疏圖」，用鄰接矩陣還是鄰接串列比較適合？為什麼？
<details><summary>看解答</summary>

用**鄰接串列**。矩陣不管邊多少都要 O(n²) 空間，稀疏圖會浪費一堆 0；串列只存實際存在的邊，空間 O(V+E) 較省。
</details>

**Q3.** 用第四節那張圖，從 A 出發的 **BFS** 訪問順序是什麼（鄰居依字母小到大）？
<details><summary>看解答</summary>

**A B C D E**。先訪 A，再把鄰居 B、C 依序訪完（第一圈），最後才到 D、E。
</details>

**Q4.** 同一張圖從 A 出發的 **DFS** 訪問順序是什麼？和 BFS 差在哪？
<details><summary>看解答</summary>

**A B D E C**。DFS 一路往深處鑽（A→B→D→E 才回頭訪 C）；BFS 則先訪完同一層鄰居再往下一層。
</details>

**Q5.** 一張連通圖有 8 個頂點，它的任何一棵生成樹有幾條邊？
<details><summary>看解答</summary>

生成樹固定是 **n − 1 = 8 − 1 = 7 條邊**，且無環。
</details>
