# 防禦設備與攻擊類型 ★

> 科目：網路概論｜★ 資安攻防今年特別重，要多花時間（並多看時事）。這一篇分兩半：**防禦端**（防火牆、IDS/IPS、Proxy/DMZ、VPN、EDR/MDR、資安標準）和**攻擊端**（惡意程式、各種攻擊手法）。把「每種設備看得多深、能不能主動擋」和「每種攻擊怎麼散播／怎麼打」抓住，考題就有畫面。
>
> 學習方式：大多屬【理解】（懂功能就記得）；只有標準名稱（ISO 27001、NIST）屬【硬背】。

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「**IDS**」和「**IPS**」最大的差別是什麼？哪個被動、哪個主動？
> 2. **傳統防火牆、NGFW、WAF** 分別看到 OSI 的哪一層？**WAF** 主要擋哪些攻擊？
> 3. 「**病毒**」「**蠕蟲**」「**木馬**」三者怎麼分？哪一個會**自我複製、不需宿主**？

先別急著往下看答案，試著自己回答看看。

## 🤔 先想想

給你三個判斷方向：

- **防禦設備差在「看得多深」**：只看 IP／port（L3/L4），還是看得懂應用層內容（L7）。看得越深、能擋的攻擊越細。
- **「偵測」跟「阻擋」是兩件事**：能看到可疑活動，不代表能把它擋下來（IDS vs IPS 的核心差別）。
- **惡意程式的分類重點在「怎麼散播」**：靠宿主？自我複製？還是偽裝誘騙你自己安裝？

帶著這三點往下拆解。

## 📖 觀念拆解

### 一、防火牆 / 次世代防火牆 / WAF　【理解】

三種「牆」，看的層級一層比一層深：

|  | 看哪層／看什麼 | 特點 |
|---|---|---|
| 傳統防火牆 Firewall | L3／L4（IP、port、協定） | 依規則過濾進出流量（封包過濾；狀態檢測 ＝ 記住連線狀態、只放行屬於正常連線的封包） |
| 次世代防火牆 NGFW | 到 L7 | 傳統防火牆 ＋ 應用辨識 ＋ 內建 IPS ＋ 深度封包檢測（DPI） |
| WAF（網頁應用防火牆） | L7、專護 web app | 過濾 HTTP/HTTPS，擋 SQL injection、XSS 等網頁攻擊 |

📌 **白話理解：**
- **封包過濾**＝像門口警衛按「名單（規則）」看每個封包的 IP／port／協定放不放行。
- **狀態檢測（Stateful）**＝警衛還會**記住誰進來過**，只放行「屬於正常已建立連線」的封包，比單純看單一封包更聰明。
- **DPI（深度封包檢測）**＝不只看信封（IP/port），還**拆開看內容**，所以能辨識「這是哪個應用程式的流量」。
- **WAF** 專門守在**網站前面**，看得懂 HTTP，能擋針對網頁的攻擊（SQLi、XSS）。

**一句話：防火牆看 IP/port、NGFW 加應用辨識與 IPS、WAF 專門保護網站。**

### 二、IDS vs IPS　【理解】★

兩個名字很像，關鍵差在「會不會動手擋」：

|  | IDS 入侵偵測系統 | IPS 入侵防禦系統 |
|---|---|---|
| 做什麼 | 偵測可疑活動並告警 | 偵測 ＋ 主動阻擋 |
| 主／被動 | 被動（旁路監看） | 主動（串接在線上） |
| 比喻 | 監視器／警報器 | 警衛（會把人擋下來） |

📌 **白話理解：**
- **IDS 像監視器**：架在**旁邊（旁路）**看，發現可疑就**響警報**，但不會出手——流量還是照過。
- **IPS 像警衛**：**站在必經之路上（串接在線上）**，發現壞人就**直接攔下**。

**記憶鉤子：IDS 只「偵測＋告警」、IPS 還會「阻擋」。**

### 三、Proxy Server / DMZ　【理解】

- **Proxy Server（代理伺服器）**：介於使用者與目標伺服器之間的**中間人**，代為轉發請求。用途：**隱藏內部 IP、快取加速、存取控制／過濾、記錄**。
- **DMZ（非軍事區）**：介於「內部網路」與「外部網際網路」之間的**隔離緩衝區**，放需要對外服務的伺服器（web、mail、DNS）。即使對外伺服器被攻破，也**不會直接危及內部網路**（多一層隔離）。

💡 **比喻**：DMZ 像大樓的「一樓大廳」——訪客（外部使用者）只能到大廳（DMZ）辦事，就算大廳出事，也進不了樓上的辦公室（內部網路）。

### 四、VPN / PPTP　【理解】

- **VPN（虛擬私人網路）**：在公開網路上建一條**加密的虛擬通道（tunnel）**，讓遠端使用者安全地連回內部網路，如同在本地。用途：**遠端辦公、加密保護、隱藏 IP**。
- **PPTP**：早期的 VPN 通道協定（微軟）。設定簡單、快，但**加密弱、已不安全**，現多改用 **L2TP/IPSec、OpenVPN、IPSec**。

💡 **比喻**：VPN 像在公開的高速公路上，為你**挖一條加密的專用隧道**——別人看得到你有車在跑，卻看不到隧道裡裝了什麼。

### 五、常見網路攻擊　【理解】★（今年重點）

**惡意程式 Malware：**

| 類型 | 特性 |
|---|---|
| 病毒 Virus | 附在正常程式／檔案上，需執行宿主才散播、感染其他檔案 |
| 蠕蟲 Worm | 能自我複製、不需宿主，透過網路自動散播（吃資源） |
| 木馬 Trojan | 偽裝成正常軟體誘騙安裝，暗中開後門／竊資料；不自我複製 |
| 勒索軟體 Ransomware | 加密受害者檔案、勒索贖金 |
| 間諜軟體 Spyware | 偷偷蒐集使用者資訊 |
| Rootkit | 取得系統最高權限並**隱藏自身**行蹤，讓惡意程式難以被偵測／移除 |

**病毒 vs 蠕蟲 vs 木馬（常考）：病毒要宿主、蠕蟲自我複製、木馬偽裝誘騙。**

**攻擊手法：**

| 手法 | 做什麼 |
|---|---|
| XSS（跨站腳本） | 把惡意 script 注入網頁，在其他使用者瀏覽器執行（竊 cookie／session） |
| CSRF（跨站請求偽造） | 誘騙已登入的使用者在不知情下送出惡意請求（如轉帳、改設定）；常與 XSS 一起考 |
| SQL Injection | 在輸入欄塞惡意 SQL，操控資料庫（竊取／竄改資料） |
| 釣魚 Phishing | 偽裝可信來源（假網站／假信）騙取帳密、個資 |
| DoS／DDoS | 大量流量灌爆目標使其無法服務；DDoS 用大量殭屍主機（botnet ＝ 被攻擊者偷偷控制的一堆電腦）一起灌 |
| 中間人 MITM | 攔在通訊雙方中間竊聽／竄改（如 ARP spoofing） |
| 社交工程 | 利用人性弱點騙取資訊（釣魚是其一） |
| 暴力破解／字典攻擊 | 反覆嘗試大量密碼組合猜出帳密（字典攻擊使用常見密碼清單）；防範用強密碼、登入鎖定、MFA |
| 零時差 Zero-day | 利用尚未修補的未知漏洞 |

💡 **具體例子：**
- **SQL Injection**：登入框輸入 `' OR '1'='1`，若程式沒防護，可能讓「密碼判斷永遠成立」而被繞過登入。
- **DDoS**：攻擊者操控上萬台**殭屍主機（botnet）**同時對某網站發請求，把頻寬／伺服器灌爆，正常使用者連不進去（破壞**可用性**）。
- **零時差（Zero-day）**：漏洞**還沒被官方修補**就被攻擊者搶先利用，防守方「零天」可反應，特別難防。

### 六、EDR / MDR　【理解】

- **EDR（端點偵測與回應）**：監控**端點**（電腦、伺服器、手機等設備）上的活動，偵測威脅並回應（隔離、調查）。是**裝在端點的工具／技術**。
- **MDR（託管式偵測與回應）**：把偵測與回應**外包**給專業資安服務商（由他們 24/7 監控處理）。是一種**服務**，適合資安人力不足的組織。

**一句話：EDR 是「工具」（在端點）、MDR 是「服務」（委外給專家）。**

### 七、資安標準：NIST / ISO 27001　【理解】＋【硬背】

- **NIST 資安框架（CSF）**：美國 NIST 出的資安框架。原本 **5 大核心功能**：Identify（識別）、Protect（保護）、Detect（偵測）、Respond（回應）、Recover（復原）（**IPDRR**）；**2.0 版（2024）新增 Govern（治理），變成 6 個**。
- **ISO 27001**：國際標準化組織的**資訊安全管理系統（ISMS）**標準，提供建立、維運資安制度的框架，**可申請驗證認證**。
- **對照**：NIST CSF 是**框架**（功能導向）；ISO 27001 是**國際 ISMS 標準**（可拿認證）。

💡 **記法**：NIST CSF 想成資安的「五個動作循環」——**先認識自己有什麼（Identify）→ 保護它（Protect）→ 偵測異常（Detect）→ 出事回應（Respond）→ 事後復原（Recover）**，2.0 再罩上一層「治理（Govern）」。

### 八、重點整理（背這張）

- **防火牆看 IP/port、NGFW 加應用＋IPS、WAF 護網站（擋 SQLi／XSS）。**
- **IDS 偵測告警（被動）、IPS 偵測＋阻擋（主動）。**
- DMZ ＝ 放對外伺服器的隔離區；Proxy ＝ 代理中間人；VPN ＝ 加密通道（PPTP 已不安全）。
- 惡意程式：**病毒要宿主、蠕蟲自我複製、木馬偽裝**、勒索加密勒贖。
- 攻擊：XSS 注入腳本、SQLi 操控資料庫、釣魚騙帳密、DDoS 灌爆、MITM 攔中間。
- EDR 工具（端點）、MDR 服務（委外）。
- **NIST CSF：IPDRR 五功能（2.0 加 Govern 成六）；ISO 27001 ＝ ISMS 國際標準。**

## ✅ 回到題目：解答

1. **IDS vs IPS？** → **IDS** 只**偵測＋告警**（**被動**、旁路監看，像監視器）；**IPS** 是**偵測＋主動阻擋**（**主動**、串接在線上，像警衛）。
2. **防火牆／NGFW／WAF 各看哪層？WAF 擋什麼？** → 傳統**防火牆** L3/L4（IP、port、協定）；**NGFW** 到 **L7**（加應用辨識、內建 IPS、DPI）；**WAF** L7 專護 web app，擋 **SQL injection、XSS** 等網頁攻擊。
3. **病毒／蠕蟲／木馬怎麼分？誰自我複製、不需宿主？** → **病毒**要宿主（附在檔案、需執行才散播）、**蠕蟲**能**自我複製、不需宿主**（透過網路自動散播）、**木馬**偽裝誘騙安裝、不自我複製。→ **蠕蟲**會自我複製、不需宿主。

---

## 📌 重點整理

- 防禦設備看的層級：防火牆 L3/L4 →（NGFW 到 L7）→ WAF 專守 L7 網站。
- IDS＝偵測告警（被動）；IPS＝偵測＋阻擋（主動）。
- Proxy＝代理中間人（隱藏 IP、快取、過濾）；DMZ＝內外之間的隔離緩衝區。
- VPN＝公網上的加密通道；PPTP 已不安全，改用 L2TP/IPSec、OpenVPN、IPSec。
- 惡意程式：病毒（要宿主）、蠕蟲（自我複製）、木馬（偽裝）、勒索（加密勒贖）、間諜（偷資訊）。
- 攻擊手法：XSS、SQLi、釣魚、DoS/DDoS（botnet）、MITM（ARP spoofing）、社交工程、零時差。
- EDR＝端點工具；MDR＝委外服務。
- NIST CSF：IPDRR（2.0 加 Govern 成六）；ISO 27001＝ISMS，可認證。

## ⚠️ 常見陷阱

- **把 IDS 當成能擋攻擊**：IDS **只告警不阻擋**；會主動擋的是 **IPS**。
- **以為傳統防火牆能擋網頁攻擊**：傳統防火牆看 L3/L4，**擋不了 SQLi／XSS 這種 L7 網頁攻擊**——那要 **WAF**。
- **病毒 vs 蠕蟲搞混**：**病毒要宿主、要被執行**；**蠕蟲自我複製、不需宿主、自動散播**。
- **以為木馬會自我複製**：**木馬不自我複製**，它靠「偽裝誘騙你自己安裝」。
- **DoS 與 DDoS 不分**：**DDoS 是「分散式」多來源**（用 botnet 殭屍主機一起灌）；DoS 通常單一來源。
- **NIST CSF 只記 5 個功能**：原本 IPDRR 共 5 個，**2.0 版（2024）新增 Govern 變 6 個**，別漏掉最新版。
- **PPTP 當安全方案**：PPTP **加密弱、已不安全**，正式用途改用 L2TP/IPSec、OpenVPN、IPSec。

## 📝 練習題（含解答）

**Q1.** 某設備「只在旁邊監看、發現可疑就告警，但不會擋下流量」，這是 IDS 還是 IPS？另一個又是什麼特性？
<details><summary>看解答</summary>

這是 **IDS**（入侵偵測系統，被動、旁路監看、只告警）。另一個 **IPS**（入侵防禦系統）是**主動、串接在線上，偵測＋阻擋**。
</details>

**Q2.** 一個電商網站最擔心 SQL Injection 與 XSS，最該部署哪種「牆」？為什麼傳統防火牆不夠？
<details><summary>看解答</summary>

該部署 **WAF（網頁應用防火牆）**，它在 **L7** 過濾 HTTP/HTTPS，專擋 SQLi、XSS。傳統防火牆只看 **L3/L4（IP、port、協定）**，看不懂網頁應用層內容，擋不了這類攻擊。
</details>

**Q3.** 「病毒、蠕蟲、木馬」三者的散播方式各有何不同？
<details><summary>看解答</summary>

**病毒**：附在正常程式／檔案上，**需執行宿主**才散播。**蠕蟲**：能**自我複製、不需宿主**，透過網路自動散播。**木馬**：**偽裝**成正常軟體誘騙安裝、暗中開後門，**不自我複製**。
</details>

**Q4.** DDoS 和 DoS 的差別是什麼？「botnet」在 DDoS 裡扮演什麼角色？
<details><summary>看解答</summary>

**DoS** 通常是**單一來源**灌爆目標；**DDoS** 是**分散式、多來源**版本。**botnet（殭屍網路）** ＝ 一堆被攻擊者偷偷控制的電腦，DDoS 就是驅動大量殭屍主機一起發流量，把目標灌到無法服務（破壞可用性）。
</details>

**Q5.** NIST 資安框架（CSF）原本的 5 大核心功能是哪些？2.0 版做了什麼改變？
<details><summary>看解答</summary>

原本 5 大功能為 **Identify（識別）、Protect（保護）、Detect（偵測）、Respond（回應）、Recover（復原）**，簡稱 **IPDRR**。**2.0 版（2024）新增 Govern（治理）**，變成 **6 個**功能。
</details>
