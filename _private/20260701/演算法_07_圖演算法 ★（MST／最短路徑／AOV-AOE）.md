# 圖演算法 ★（MST／最短路徑／AOV-AOE）

> 科目：演算法｜這章是「圖」的應用篇。上一篇把圖的長相（頂點、邊、鄰接表示法、DFS／BFS）建好之後，這裡要回答三個超常考的問題：**怎麼用最少成本把所有點連起來（MST）**、**兩點間最短要走多遠（最短路徑）**、**一堆有先後關係的工作該照什麼順序做（AOV／AOE）**。
>
> 學習方式：選擇題通常**不是背程式碼**，而是辨認「這個演算法用來解什麼問題」與「流程每一步怎麼選下一個」。把每個演算法的「一句話定位」記牢，再配複雜度，就能穩穩得分。

## 🤔 先想想

三個提示，幫你把這章的地圖建起來：

- **MST** 是「連通全部頂點、沒有環、總權重最小」的樹；重點在「怎麼一步步挑邊」。
- **最短路徑**分兩種問法：只問「一個起點到所有點」用 Dijkstra；問「每一對點之間」用 Floyd-Warshall。
- **AOV／AOE** 是把工作排程畫成圖：AOV 問「可行的先後順序」，AOE 問「最短要多久做完」。

## 📖 觀念拆解

### 一、MST：Kruskal vs Prim

**最小生成樹（Minimum Spanning Tree, MST）** 的共同目標是：**連通全部頂點、沒有環、總權重最小**。Kruskal 與 Prim 是兩個經典解法，選邊順序可能不同，但結果都應該是 MST。

| 比較 | Kruskal | Prim |
|---|---|---|
| 核心 | 從最小的邊開始挑。 | 從一個頂點集合往外長。 |
| 規則 | 邊由小到大選，不成環就加入，直到 n - 1 條。 | 每次選連到已選集合、權重最小的跨界邊。 |
| 導向 | 邊導向，常說適合稀疏圖。 | 頂點導向，常說適合稠密圖。 |
| 複雜度 | O(E log E) | O(E log V) 或 O(V²)。 |
| 資料結構 | 用 Union-Find（並查集）判斷成環。 | 用 min-heap（優先佇列）挑最小跨界邊。 |

📌 **白話：**
- **Kruskal 是「邊導向」**：把所有邊由小排到大，一條一條試，只要加進去不會形成環就收下，收滿 **n − 1 條**（n 個頂點的樹剛好 n − 1 條邊）就完成。因為主要在處理邊，**邊少（稀疏圖）**時特別划算。
- **Prim 是「頂點導向」**：先從任一個頂點出發，把它當成「已選集合」，每次挑一條「一端在集合裡、另一端在集合外」的**最小跨界邊**，把新頂點納入，慢慢把整團長大。頂點多、邊也多（**稠密圖**）時較合適。

**🔢 Kruskal 逐步範例**（4 個頂點 A、B、C、D，需選 n − 1 = 3 條邊）：

邊與權重：A-B=1、B-C=2、A-C=3、C-D=4、B-D=5。

1. 由小到大排序：**1(A-B) → 2(B-C) → 3(A-C) → 4(C-D) → 5(B-D)**。
2. 選 **A-B(1)**：不成環 → 加入。（已 1 條）
3. 選 **B-C(2)**：不成環 → 加入。（已 2 條）
4. 選 **A-C(3)**：A、C 已透過 A-B-C 相連，加了會**成環** → 跳過。
5. 選 **C-D(4)**：不成環 → 加入。（已 3 條 = n − 1，結束）
6. MST = {A-B, B-C, C-D}，**總權重 = 1 + 2 + 4 = 7**。

### 二、最短路徑：Dijkstra vs Floyd-Warshall

| 比較 | Dijkstra | Floyd-Warshall |
|---|---|---|
| 求什麼 | 單一起點到所有點的 single-source shortest path。 | 所有點對之間的 all-pairs shortest path。 |
| 做法 | 每次挑目前最短的未確定點，再更新鄰居。 | 用每個頂點當中繼站，檢查 i 到 j 繞過 k 是否更短。 |
| 負權邊 | 不可有負權邊。 | 可有負權邊，但不可有負環。 |
| 複雜度 | O((V+E) log V) 或 O(V²)。 | O(V³)。 |

📌 **白話：**
- **Dijkstra**：從一個起點出發，反覆「挑一個目前距離最短、還沒定案的點」把它定案，再用它去**更新（放鬆）**鄰居的距離。因為它假設「已定案的點不會再變短」，所以**碰到負權邊會出錯**。
- **Floyd-Warshall**：把每個頂點輪流當「中繼站 k」，檢查「i 直接到 j」與「i 先到 k 再到 j」哪個短，短的就更新。它可以處理**負權邊**，但**不能有負環**（否則繞圈可以讓距離無限變小）。

> **relaxation（鬆弛）** 是 Dijkstra 的關鍵動作：若 **A → B → C 比 A → C 更短**，就把 C 的目前距離更新成較小值。

### 三、AOV 與 AOE

把「一堆有先後關係的工作」畫成圖，有兩種畫法：

| 比較 | AOV Network | AOE Network |
|---|---|---|
| 全名 | Activity On Vertex | Activity On Edge |
| 頂點代表 | 活動 | 事件或里程碑 |
| 邊代表 | 先後順序或前置關係 | 活動與所需時間 |
| 對應演算法 | Topological Sort | Critical Path |
| 用途 | 排出可行先後順序，例如課程先修。 | 算專案最短完成時間，例如 CPM/PERT。 |

1. **Topological Sort（拓樸排序）** 反覆找**入度為 0** 的頂點輸出，並移除它連出去的邊。
2. **Critical Path（關鍵路徑）** 是從起點到終點**總時間最長**的路徑，決定整個專案最短完成時間。
3. 關鍵路徑上的活動**沒有寬裕時間（slack）**，只要延誤就會讓整個專案延誤。

📌 **白話：** AOV 的頂點是「要做的事」，邊是「A 要先於 B」，拓樸排序就是排出一個「不違反任何先後關係」的可行順序。AOE 的邊帶了「花多久」，所以能算出「最快什麼時候全部做完」——瓶頸就在最長的那條關鍵路徑上。

**🔢 Topological Sort 逐步範例**（課程先修：A→B、A→C、B→D、C→D）：

先算入度（有幾條箭頭指進來）：A=0、B=1、C=1、D=2。

1. 找入度 0 → **A**，輸出 A；移除 A→B、A→C，於是 B 入度變 0、C 入度變 0。
2. 入度 0 有 B、C，輸出 **B**；移除 B→D，D 入度 2→1。
3. 輸出 **C**；移除 C→D，D 入度 1→0。
4. 輸出 **D**。
5. 一組合法的拓樸順序：**A → B → C → D**。（B、C 誰先都可以，答案不唯一）

### 四、圖演算法複雜度速查

| 演算法 | 複雜度 | 用途 |
|---|---|---|
| DFS/BFS | O(V+E) | 走訪。 |
| Kruskal | O(E log E) | MST，挑邊。 |
| Prim | O(E log V) 或 O(V²) | MST，長頂點集合。 |
| Dijkstra | O((V+E) log V) 或 O(V²) | 單源最短路，不可負權。 |
| Floyd-Warshall | O(V³) | 全點對最短路。 |
| Topological Sort | O(V+E) | AOV 先後順序。 |

（V 是頂點數 Vertex，E 是邊數 Edge。）

## ✅ 回到題目：解答

1. **Kruskal vs Prim 以什麼為中心？** → **Kruskal 以「邊」為中心**（邊由小到大挑，不成環就收，適合稀疏圖）；**Prim 以「頂點」為中心**（從已選集合往外長最小跨界邊，適合稠密圖）。兩者結果都是 MST。
2. **Dijkstra vs Floyd-Warshall？** → Dijkstra 求**單源**最短路、**不能有負權邊**、O((V+E) log V) 或 O(V²)；Floyd-Warshall 求**全點對**最短路、可有負權但**不可負環**、O(V³)。
3. **決定專案最短完成時間的路徑？** → **關鍵路徑（Critical Path）**，也就是起點到終點總時間最長的那條。

---

## 📌 重點整理

- **MST 三性質**：連通所有頂點、無環、總權重最小；邊數固定為 **n − 1**。
- **Kruskal＝挑邊（稀疏）**、**Prim＝長頂點集合（稠密）**；結果相同。
- **最短路徑**：單源找 Dijkstra（不可負權）、全點對找 Floyd-Warshall（O(V³)，可負權不可負環）。
- **relaxation**：發現更短的繞路就更新距離，是 Dijkstra 的核心動作。
- **貪婪法（Greedy）家族**：Kruskal、Prim、Dijkstra 每一步都挑「當下最小的邊／最短的點」，都屬貪婪演算法。
- **AOV → Topological Sort（先後順序）**、**AOE → Critical Path（最短完成時間）**。
- 複雜度：DFS/BFS、Topological Sort 都是 **O(V+E)**；Kruskal O(E log E)；Floyd-Warshall O(V³)。

---

## ⚠️ 常見陷阱

- **Kruskal / Prim 導向別記反**：Kruskal 挑「邊」（稀疏圖），Prim 長「頂點集合」（稠密圖）。
- **Dijkstra 不能有負權邊**：這是最常考的雷點；要處理負權得換別的演算法（如 Floyd-Warshall 或 Bellman-Ford）。
- **Floyd-Warshall 可負權但不可負環**：有負環時最短路徑無意義（可以無限變小）。
- **single-source vs all-pairs**：問「一個起點到所有點」是 Dijkstra；問「每一對點」是 Floyd-Warshall，別選錯。
- **無權重圖的最短路徑用 BFS 就夠**：邊沒有權重（或每條權重都相同）時，BFS 從起點一層一層擴展就能得到最短路徑，不必動用 Dijkstra／Floyd-Warshall。
- **拓樸排序答案不唯一**：同時有多個入度 0 的頂點時，輸出順序可以不同，只要不違反先後關係都算對。
- **關鍵路徑是「最長」不是最短**：它取最長路徑，因為最慢的那條才決定整體何時完工。

## 📝 練習題（含解答）

**Q1.** n 個頂點的最小生成樹會用到幾條邊？為什麼？
<details><summary>看解答</summary>

**n − 1 條**。生成樹要連通所有 n 個頂點且不能有環，這樣的樹恰好 n − 1 條邊；多一條就會成環。
</details>

**Q2.** 有一張圖含負權邊（但無負環），要求某一點到其他所有點的最短路徑，Dijkstra 適用嗎？
<details><summary>看解答</summary>

**不適用**。Dijkstra 不能有負權邊。可改用能處理負權的演算法（例如 Floyd-Warshall 求全點對，或 Bellman-Ford 求單源）。
</details>

**Q3.** 對頂點 A→B、A→C、B→D、C→D 做拓樸排序，寫出一組合法順序。
<details><summary>看解答</summary>

先找入度 0 的 A 輸出並移除其出邊，B、C 入度歸 0，接著輸出 B、C（順序可互換），最後 D。合法順序例如 **A → B → C → D**（或 A → C → B → D）。
</details>

**Q4.** Kruskal 演算法在挑到一條邊時，用什麼條件決定「收下」還是「跳過」？
<details><summary>看解答</summary>

邊已由小到大排序，逐條檢查：**加入後不會形成環就收下，會成環就跳過**，直到收滿 n − 1 條為止。
</details>

**Q5.** AOE 網路中的「關鍵路徑（Critical Path）」代表什麼？路徑上的活動有沒有寬裕時間？
<details><summary>看解答</summary>

關鍵路徑是從起點到終點**總時間最長**的路徑，它決定整個專案的**最短完成時間**。路徑上的活動**沒有寬裕時間（slack）**，任何一個延誤都會讓整個專案延誤。
</details>
