# 函數相依與阿姆斯壯公理

> 科目：資料庫（正規化基礎）｜正規化的每一步都在問「哪個屬性被哪個屬性決定」，而「功能相依」就是描述這件事的語言。先把功能相依、阿姆斯壯公理、屬性閉包學會，判斷「違反第幾正規化、該怎麼拆」才有工具可用。
>
> 學習方式：功能相依的**定義與四種類型**屬【理解】；**三基本公理＋三導出律**屬【硬背】；**屬性閉包 X⁺ 的算法**屬【練習】——會算閉包，就能判斷 FD、找候選鍵。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「阿姆斯壯公理的**三個基本公理**是哪三個？」
> 2. 「`X → Y` 且 `Y → Z`，可推出什麼？這是哪一條律？」
> 3. 「R(學號, 系所, 系主任)，`學號→系所`、`系所→系主任`，求 `學號⁺`（屬性閉包）＝？由此判斷學號是不是候選鍵。」

先自己想想再往下看。

---

## 🤔 先想想

- 「功能相依 `X → Y`」白話就是：**知道 X 的值，就能唯一決定 Y 的值**。例：`學號 → 姓名`。
- 已知幾條相依，其實還「暗藏」很多能推出來的相依——推導工具就是**阿姆斯壯公理**。
- 想知道「X 能決定哪些屬性」，就把 X 的**屬性閉包 X⁺**算出來；X⁺＝全部屬性，X 就是超鍵。

---

## 📖 觀念拆解

### 一、相依性與功能相依（FD）

**相依性（Dependency）**描述關聯中「某些屬性決定另一些屬性」的限制關係；最重要的一種是**功能相依**（其餘如多值相依、合併相依，分別對應 4NF、5NF）。

**功能相依（Functional Dependency, FD）完整定義**：在關聯 R 中，給定屬性集合 X、Y。若 R 內**任意兩列，只要在 X 上的值相等，則在 Y 上的值也必定相等**，就稱「X 功能決定 Y」（或 Y 功能相依於 X），記作 `X → Y`。X 稱**決定因素（determinant）**、Y 稱**相依因素**。

白話：**知道 X 的值，就能唯一決定 Y 的值**。例：`學號 → 姓名`——同一個學號一定對到同一個姓名。

> 💡 為什麼重要：正規化的每一步，本質都在問「哪個屬性被哪個屬性決定」。先能寫出功能相依，才能判斷關聯違反第幾正規化、該怎麼拆。

### 二、功能相依的種類

以下四種對正規化最關鍵（X、Y 為屬性集合）：

| 種類 | 定義 | 與正規化的關聯 |
|---|---|---|
| **完全功能相依** Full FD | Y 相依於整個 X，且**不**相依於 X 的任何真子集 | 2NF 的要求 |
| **部分功能相依** Partial FD | Y 只相依於複合鍵 X 的**一部分**（真子集） | **違反 2NF** |
| **遞移功能相依** Transitive FD | X→Y、Y→Z 且 Y 不→X，使得 X→Z（透過中介 Y） | **違反 3NF** |
| **顯然功能相依** Trivial FD | Y ⊆ X（右邊是左邊的子集） | 恆成立、可忽略 |

> 💡 一句話記憶：**部分相依**＝「只用半把鑰匙就開門」（複合鍵的一部分就決定了某屬性）；**遞移相依**＝「繞了一手」（A 決定 B、B 再決定 C）。**2NF 砍部分相依、3NF 砍遞移相依。**

### 三、三個基本公理（阿姆斯壯公理）

以下 X、Y、Z 皆代表屬性集合（⇒ 表示「可推出」）：

| 公理 | 形式 | 說明 |
|---|---|---|
| **反身律** Reflexivity | `Y ⊆ X ⇒ X → Y` | 一個集合可決定它的子集（顯然相依） |
| **擴充律** Augmentation | `X → Y ⇒ XZ → YZ` | 兩邊同時加入屬性，相依仍成立 |
| **遞移律** Transitivity | `X → Y, Y → Z ⇒ X → Z` | 相依可串接 |

這三條公理即可推導出所有功能相依（**健全 sound 且完備 complete**），其餘規則都由它們導出。

> 💡 反身律最直覺：`{學號, 姓名} → 姓名` 一定成立——知道一組屬性，當然知道其中任一個。這種右邊是左邊子集的相依，稱為「**顯然功能相依（trivial FD）**」。

### 四、三個導出律（由基本公理推出）

| 規則 | 形式 | 說明 |
|---|---|---|
| **聯合律** Union | `X → Y, X → Z ⇒ X → YZ` | 右邊可合併 |
| **分解律** Decomposition | `X → YZ ⇒ X → Y, X → Z` | 右邊可拆開 |
| **擬遞移律** Pseudotransitivity | `X → Y, WY → Z ⇒ WX → Z` | 帶條件的遞移 |

### 五、屬性閉包 X⁺（最實用的工具）

**屬性閉包（Attribute Closure）`X⁺`**：是「由 X 能功能決定的**所有屬性**」之集合。

**計算演算法：**

1. 令 `X⁺ = X`。
2. 反覆檢查每條 FD `A → B`：若 A ⊆ X⁺，就把 B 加入 X⁺。
3. 直到 X⁺ 不再變大為止。

**範例**：R(學號, 系所, 系主任)，F = { `學號→系所`, `系所→系主任` }，求 `學號⁺`：

```
{學號}
  ── 套用 學號→系所 ──▶ {學號, 系所}
  ── 套用 系所→系主任 ──▶ {學號, 系所, 系主任}
＝ 全部屬性 → 學號 是候選鍵
```

每套用一條相依，閉包就長大一次，直到無法再加入新屬性。

**兩大用途：**

- **判斷 `X → Y` 是否成立**：看 Y 是否 ⊆ X⁺。
- **判斷 X 是否為超鍵**：若 X⁺ = 全部屬性，則 X 是超鍵；若再「拿掉任一屬性就不再涵蓋全部」，則為**候選鍵**。

上例 `學號⁺` = 全部屬性，故學號是候選鍵。

💡 **找候選鍵的快捷法則**：先看每個屬性在所有 FD 的出現位置——**只出現在左邊（或從未出現）的屬性，必屬於每個候選鍵**；**只出現在右邊的屬性，一定不在候選鍵內**。先把「必含屬性」湊出來算閉包，能大幅縮小試算範圍。

---

## ✅ 回到題目：解答

1. 三個基本公理：**反身律（Reflexivity）、擴充律（Augmentation）、遞移律（Transitivity）**。
2. `X → Y` 且 `Y → Z` ⇒ `X → Z`，這是**遞移律（Transitivity）**。
3. `學號⁺` = {學號} → {學號, 系所} → {學號, 系所, 系主任} = **全部屬性**，所以學號能決定所有屬性、是**超鍵**；且它是單一屬性、拿掉就空了，故也是**候選鍵**。

---

## 📌 重點整理

- **功能相依 `X → Y`**：知道 X 就能唯一決定 Y；X＝決定因素、Y＝相依因素。
- **四種 FD**：完全（2NF 要求）、部分（破 2NF）、遞移（破 3NF）、顯然（恆成立）。
- **三基本公理**：反身、擴充、遞移——具**健全且完備**性，能推出所有 FD。
- **三導出律**：聯合、分解、擬遞移（由三基本公理推得）。
- **屬性閉包 X⁺ 兩大用途**：判斷 FD（Y⊆X⁺）、判斷超鍵／候選鍵（X⁺＝全部屬性）。

---

## ⚠️ 常見陷阱

- **顯然功能相依**：右邊是左邊子集（Y ⊆ X）就恆成立，判斷正規化時可忽略。
- **聯合／分解／擬遞移是「導出律」**，不是基本公理；基本公理只有反身、擴充、遞移三條。
- **分解律方向**：`X → YZ` 可拆成 `X → Y`、`X → Z`；但 `X → Y`、`X → Z` 合併回 `X → YZ` 靠的是**聯合律**，兩者別搞反。
- **算閉包判超鍵 vs 候選鍵**：X⁺＝全部屬性只證明「超鍵」；還要「拿掉任一屬性就不再涵蓋全部」才是「候選鍵（最小超鍵）」。

---

## 📝 練習題（含解答）

**Q1.** 阿姆斯壯公理的三個**基本公理**與三個**導出律**分別是什麼？
<details><summary>看解答</summary>

基本公理：**反身律、擴充律、遞移律**。導出律：**聯合律、分解律、擬遞移律**（由三基本公理推得）。

</details>

**Q2.** 用一句話分辨「部分相依」與「遞移相依」，並說出各自破壞哪個正規化。
<details><summary>看解答</summary>

部分相依＝「只用半把鑰匙開門」（複合鍵的一部分就決定某屬性）→ **破壞 2NF**；遞移相依＝「繞了一手」（A→B、B→C）→ **破壞 3NF**。

</details>

**Q3.** R(A, B, C, D)，F = { `A→B`, `B→C`, `C→D` }，求 `A⁺`，並判斷 A 是否為候選鍵。
<details><summary>看解答</summary>

`A⁺` = {A} → {A,B} → {A,B,C} → {A,B,C,D} = 全部屬性 → A 是**超鍵**；A 為單一屬性、拿掉即空，故也是**候選鍵**。

</details>

**Q4.** 要判斷 `X → Y` 是否成立，用屬性閉包該怎麼做？
<details><summary>看解答</summary>

先算出 `X⁺`，再看 **Y 是否 ⊆ X⁺**：若 Y 的每個屬性都在 X⁺ 裡，則 `X → Y` 成立。

</details>

**Q5.** 「阿姆斯壯公理是健全且完備的」是什麼意思？
<details><summary>看解答</summary>

**健全（sound）**：由公理推出的相依一定是真的（不會推出錯的）；**完備（complete）**：所有成立的相依都能由這三條基本公理推出來（不會漏）。因此三基本公理足以推導全部功能相依。

</details>
