# 氣泡排序法(Bubble Sort)

> 科目：演算法｜氣泡排序是**最入門的排序法**，也是理解「相鄰比較 + 交換」的最佳起點。它的邏輯簡單到可以用手畫出來，但也因為慢，常被拿來當「反例」考你複雜度。
>
> 學習方式：**核心動作（相鄰比較、較大往右冒）**屬【理解】；**最壞 O(n²)、可提前結束的最佳 O(n)、穩定排序**這幾個結論屬【硬背】，但只要看懂它怎麼跑，就不必死背。

---

## 🎯 開場題目

> 考題常這樣問：
>
> 1. 「氣泡排序法的**最壞時間複雜度**是多少？」
> 2. 「為什麼氣泡排序**加上一個 `swapped` 旗標**後，遇到已排序資料可以更快？最佳情況會變成多少？」
> 3. 「氣泡排序是**穩定（stable）**還是不穩定排序？」

先別急著往下看答案，試著自己回答看看。

## 🤔 先想想

給你三個提示，幫你建立直覺：

- 氣泡排序每一輪都在做同一件事：**從左到右，相鄰兩個比大小，大的往右移**。
- 一輪跑完，**最大的值一定會「浮」到最右邊**——就像水裡的大氣泡浮到水面。
- 如果**某一輪從頭到尾都沒交換**，代表資料早就排好了，這時可以提前收工。

帶著這三點，我們來拆解。

## 📖 觀念拆解

### 一、演算法概念

氣泡排序會讓較大的值像氣泡一樣慢慢往右邊移動。它容易理解，但最壞情況下需要做大量相鄰比較與交換。

> 白話：把陣列想成一排高矮不一的人，你從左邊開始，每次比較「相鄰兩個人」，矮的留下、高的往右挪一格。走完一趟，最高的人一定被推到最右邊；再走一趟，第二高的被推到倒數第二……如此重複。

### 二、核心規則

1. 從左到右比較相鄰兩個元素。
2. 若左邊比右邊大，就交換兩者位置。
3. 每一輪會把目前未排序範圍中的最大值推到最右側。
4. 若某一輪完全沒有交換，代表資料已排序完成，可以提前結束。

> 新手重點：第 3 點是為什麼**每跑一輪，右邊就多固定一個元素**（所以非遞迴版內層寫 `n - i - 1`，右邊 `i` 個不用再比）；第 4 點就是「提前結束」的關鍵，也是最佳情況能到 O(n) 的原因。

### 三、帶數字的逐步範例（陣列 [5, 2, 4, 1]）

以非遞迴版為例，`n = 4`。粗體是本次比較的兩格，箭頭代表發生交換。

**第 1 輪（i = 0，內層 j 從 0 到 2）：**

| 步驟 | 比較 | 動作 | 結果 |
|---|---|---|---|
| j=0 | **5, 2** | 5 > 2 → 交換 | [**2, 5**, 4, 1] |
| j=1 | **5, 4** | 5 > 4 → 交換 | [2, **4, 5**, 1] |
| j=2 | **5, 1** | 5 > 1 → 交換 | [2, 4, **1, 5**] |

第 1 輪結束：`[2, 4, 1, 5]`，最大值 **5** 已浮到最右邊（定位）。

**第 2 輪（i = 1，內層 j 從 0 到 1）：**

| 步驟 | 比較 | 動作 | 結果 |
|---|---|---|---|
| j=0 | **2, 4** | 2 < 4 → 不交換 | [2, 4, 1, 5] |
| j=1 | **4, 1** | 4 > 1 → 交換 | [2, **1, 4**, 5] |

第 2 輪結束：`[2, 1, 4, 5]`，次大值 **4** 定位。

**第 3 輪（i = 2，內層 j 只有 0）：**

| 步驟 | 比較 | 動作 | 結果 |
|---|---|---|---|
| j=0 | **2, 1** | 2 > 1 → 交換 | [**1, 2**, 4, 5] |

第 3 輪結束：`[1, 2, 4, 5]`，排序完成。

**關於「提前結束」**：本例每一輪都有交換，所以沒有提前結束。但假設輸入本來就是 `[1, 2, 4, 5]`，第 1 輪跑完 `swapped` 仍是 `false`，程式會直接 `break`／`return`——這就是最佳情況只需掃一趟、達到 **O(n)** 的來源。

### 四、最壞時間複雜度

| 版本 | 最壞時間複雜度 | 推導重點 |
|---|---|---|
| 遞迴版本 | O(n²) | (n - 1) + (n - 2) + ... + 1，所以保留最高次項 n²。 |
| 非遞迴版本 | O(n²) | 反向排序時，每一輪都需要相鄰比較並可能交換。 |

> 白話：最壞情況是**完全反序**（例如 [4, 3, 2, 1]），每一輪都得比到底、每次都交換。比較次數是 (n-1)+(n-2)+…+1 = n(n-1)/2，取最高次項就是 **O(n²)**。

### 五、遞迴版 Java 程式

每次遞迴先完成一輪相鄰比較，把目前最大值推到右邊，再排序前 n - 1 個元素。

```java
private static void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

public static void bubbleSortRecursive(int[] arr) {
    bubbleSortRecursive(arr, arr.length);
}

private static void bubbleSortRecursive(int[] arr, int n) {
    // n <= 1 表示剩 0 或 1 個元素，不需要排序。
    if (n <= 1) {
        return;
    }

    boolean swapped = false;

    // 做一輪相鄰比較，把目前前 n 個元素中的最大值推到第 n - 1 個位置。
    for (int j = 0; j < n - 1; j++) {
        if (arr[j] > arr[j + 1]) {
            swap(arr, j, j + 1);
            swapped = true;
        }
    }

    // 若沒有交換，代表已排序完成，可以提前結束。
    if (!swapped) {
        return;
    }

    // 最大值已經在最右邊，接著只需要排序前 n - 1 個元素。
    bubbleSortRecursive(arr, n - 1);
}
```

> 新手解釋：遞迴版把「排序前 n 個」拆成「先做一輪把最大值推到底，再排序前 n-1 個」。參數 `n` 每次縮小 1，直到 `n <= 1` 停止；`swapped` 一樣負責提前結束。

### 六、非遞迴版 Java 程式

用雙層迴圈做相鄰比較，外層控制輪數，內層把目前最大值往右推。

```java
private static void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

public static void bubbleSortIterative(int[] arr) {
    int n = arr.length;

    // 外層控制「第幾輪」。每一輪會把目前範圍內最大的值推到右邊。
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false; // 用來判斷本輪有沒有交換；若沒有，代表已排序完成。

        // 內層負責相鄰比較。n - i - 1 是因為右邊 i 個元素已經排好。
        for (int j = 0; j < n - i - 1; j++) {
            // 若左邊比右邊大，就交換，讓大的值慢慢往右邊「浮上去」。
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
                swapped = true;
            }
        }

        // 若整輪都沒有交換，代表陣列已經由小到大排序完成。
        if (!swapped) {
            break;
        }
    }
}
```

> 新手解釋：外層 `i` 是輪數，內層 `j` 做相鄰比較。`n - i - 1` 是重點——右邊已定位的 `i` 個不用再比，能省下比較。`swapped` 為 `false` 就 `break`，對應「提前結束」。

## ✅ 回到題目：解答

1. **最壞時間複雜度？** → **O(n²)**（反序輸入時，每輪都比到底、每次都交換）。
2. **加 `swapped` 旗標後為何更快？最佳情況？** → 若某一輪完全沒交換，代表已排序，直接停止。對**已排序**輸入只需掃一趟，最佳情況為 **O(n)**。
3. **穩定嗎？** → **穩定（stable）**。因為只有在「左邊嚴格大於右邊」（`>`）時才交換，值相等時不動，相對順序不變。

---

## 📌 重點整理

- 核心動作：**相鄰比較，較大者往右冒**；一輪定位一個最大值。
- 複雜度：最壞／平均 **O(n²)**，最佳（加旗標且已排序）**O(n)**。
- **額外空間 O(1)**（原地排序），**穩定排序**。
- 內層邊界 `n - i - 1`：右邊已排好的部分不用重比。
- `swapped` 旗標是「提前結束」與最佳 O(n) 的關鍵。

---

## ⚠️ 常見陷阱

- **最佳 O(n) 有前提**：一定要有 `swapped` 提前結束機制，且輸入已（近乎）排序；沒有旗標的純雙層迴圈，最佳也是 O(n²)。
- **穩定性別答錯**：氣泡排序是**穩定**的，前提是用 `>`（嚴格大於）判斷交換；若寫成 `>=` 會把相等元素也交換，變成不穩定。
- **內層邊界寫錯**：內層若一直跑到 `n - 1`，雖然結果正確但白做已定位元素的比較，浪費效能。
- **「往右冒」冒的是大值**：一輪結束定位的是**最大值**在右邊，不是最小值在左邊，別記反。

## 📝 練習題（含解答）

**Q1.** 對 `[3, 1, 2]` 用非遞迴氣泡排序跑第 1 輪，結果是什麼？
<details><summary>看解答</summary>

j=0：比較 3,1 → 3>1 交換 → [1, 3, 2]；j=1：比較 3,2 → 3>2 交換 → [1, 2, 3]。第 1 輪結束為 **[1, 2, 3]**，最大值 3 已定位。
</details>

**Q2.** 氣泡排序的最壞與最佳時間複雜度各是多少？各發生在什麼輸入？
<details><summary>看解答</summary>

最壞 **O(n²)**，發生在**完全反序**時；最佳 **O(n)**，發生在**已排序**輸入且程式有 `swapped` 提前結束機制時。
</details>

**Q3.** 非遞迴版內層迴圈寫 `j < n - i - 1`，這個 `- i - 1` 的用意是什麼？
<details><summary>看解答</summary>

因為每跑完第 `i` 輪，右邊就已固定 `i` 個最大值，不需要再比較它們；`- 1` 則是因為相鄰比較會用到 `arr[j + 1]`，要留一格避免越界。
</details>

**Q4.** 氣泡排序是穩定排序嗎？若把交換條件從 `arr[j] > arr[j+1]` 改成 `arr[j] >= arr[j+1]` 會怎樣？
<details><summary>看解答</summary>

原本用 `>` 是**穩定**的（相等不交換）。改成 `>=` 後，值相等時也會交換，會破壞相等元素的原始相對順序，變成**不穩定**。
</details>

**Q5.** 遞迴版的參數 `n` 為什麼每次呼叫都減 1？終止條件是什麼？
<details><summary>看解答</summary>

因為每做完一輪，最大值已推到第 `n - 1` 格並定位，接下來只需排序**前 n - 1 個**元素，所以遞迴呼叫 `bubbleSortRecursive(arr, n - 1)`。終止條件是 `n <= 1`（剩 0 或 1 個元素不需排序），或某輪無交換提前 `return`。
</details>
