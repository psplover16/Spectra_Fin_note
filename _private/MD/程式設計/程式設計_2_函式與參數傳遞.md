# 程式設計 2：函式 + 參數傳遞 ★

> 科目：程式設計｜★ 參數傳遞超常考、很多人搞混。
> 核心問題：**在函式裡改參數，外面原本的變數會不會跟著變？**
> 範例用 C／Java，重點看「改了會不會影響本尊」。

---

## 一、函式 Function　【理解】

- **函式**：一段**有名字、可重複呼叫**的程式碼，接收**參數**、做事、可**回傳**結果。
- 好處：**重複使用、模組化、好維護**。
- **參數 vs 引數**（觀念題愛考）：
  - **參數 parameter（形式參數）**：函式**定義時**的變數。
  - **引數 argument（實際參數）**：**呼叫時**實際傳入的值。

```java
int add(int a, int b) {   // a、b 是「參數」
    return a + b;
}
add(3, 5);                // 3、5 是「引數」
```

---

## 二、參數傳遞方式（核心！）★　【理解】

把變數傳進函式，函式內改參數，**會不會影響外面的原變數**？看是哪種傳遞：

| 方式 | 傳進去的是 | 改參數會影響外面嗎？ |
|---|---|---|
| **傳值 Call by Value** | 值的**複製品** | ❌ **不影響** |
| **傳址 Call by Address**（傳指標） | 變數的**記憶體位址** | ✅ **影響** |
| **傳參考 Call by Reference** | 變數的**別名**（同一個本尊） | ✅ **影響** |
| **傳名 Call by Name** | **整個表達式**（用到才求值） | ✅ 影響（且每次重算） |

- **傳值**：最常見（C、Java 的基本型別都是）。函式拿到的是影本，改影本不動本尊。
- **傳址**：C／C++ 用**指標**，把位址給函式，透過位址改到本尊。
- **傳參考**：C++ 的 `&` 參考，參數就是本尊的另一個名字。
- **傳名**：較罕見（早期 Algol），把引數的表達式原封代入、延遲求值。

### 經典範例：交換兩數 swap
**傳值（失敗）**——只換到影本：
```c
void swap(int x, int y) {     // 傳值，x、y 是複製品
    int t = x; x = y; y = t;
}
int a = 1, b = 2;
swap(a, b);   // 外面 a、b 沒變，還是 1、2 ❌
```
**傳址（成功）**——透過位址換到本尊：
```c
void swap(int *x, int *y) {   // 傳址（指標）
    int t = *x; *x = *y; *y = t;
}
int a = 1, b = 2;
swap(&a, &b); // 外面 a、b 真的變成 2、1 ✅
```

### ⚠ Java 的常見誤解
**Java 全部都是「傳值」**（pass by value）！
- 基本型別：傳值的複製 → 改了不影響外面。
- 物件：傳的是「**參考的值**」（位址被複製一份）。所以**透過這個參考去改物件內容會影響外面**，但**把參數重新指向新物件不影響外面**。
- 這常被誤以為是 call by reference，但嚴格說 **Java 沒有 call by reference，只有 call by value**。

## 三、static 關鍵字　【理解】＋【硬背】

核心：**屬於「類別本身」而非個別物件；或生命週期持續整個程式**。

### ① 靜態變數
- **C：函式內的 `static` 區域變數** → **生命週期持續整個程式**，值**保留到下次呼叫**：
```c
void f() {
    static int n = 0;   // 只初始化一次
    n++;
    printf("%d\n", n);  // 第1次印 1、第2次印 2、第3次印 3
}
```
- **Java／C++：類別裡的 `static` 成員** → **所有物件共用同一份**（不是每個物件各一份）：
```java
class Counter {
    static int count = 0;   // 所有 Counter 物件共用
    Counter() { count++; }
}
// 每 new 一個，count 就 +1，大家看到同一個 count
```

### ② 靜態方法
- **`static` 方法屬於類別**，**不用建立物件就能呼叫**（如 `Math.sqrt()`）。
- static 方法內**不能用 `this`、不能直接存取非 static 成員**。

> 一句話：**static ＝ 類別層級（大家共用）；非 static ＝ 物件層級（各自一份）**。

---

## 四、重點整理（背這張）

- **參數 ＝ 定義時的變數；引數 ＝ 呼叫時傳入的值**。
- 參數傳遞會不會影響外面：**傳值 ❌**、**傳址 ✅**、**傳參考 ✅**、**傳名 ✅**。
- swap 要成功：**傳址／傳參考**（傳值只換到影本）。
- **Java 全是傳值**：物件傳的是「參考的值」，所以改內容會影響、重新指派不影響（不是 call by reference）。
- **static**：類別層級、大家共用；C 的函式內 static 區域變數會**保留值**；static 方法不用物件就能叫、不能用 this。
