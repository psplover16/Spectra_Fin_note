# 十六、浮點數轉換

定義
- 浮點數是電腦用來表示小數或很大、很小數字的方法。
- 「浮點」的意思是小數點位置可以移動。
- 國考常考二進位小數、正規化、IEEE 754 單精度與雙精度。

先背一句：

```text
浮點數轉換 = 轉二進位 -> 正規化 -> 填 Sign / Exponent / Fraction。
```

---

## [必背] IEEE 754 欄位

| 類型 | 總位元 | Sign | Exponent | Fraction | bias |
| --- | ---: | ---: | ---: | ---: | ---: |
| 單精度 | 32 bits | 1 bit | 8 bits | 23 bits | 127 |
| 雙精度 | 64 bits | 1 bit | 11 bits | 52 bits | 1023 |

公式：

```text
(-1)^S * 1.F * 2^(E - bias)
```

欄位意思：

| 欄位 | 中文 | 白話 |
| --- | --- | --- |
| S | 符號位 | 0 正、1 負 |
| E | 指數欄位 | 存的是實際指數 + bias |
| F | Fraction / 尾數欄位 | 只存小數點右邊，不存最前面的 1 |

---

## [理解] 正規化

正規化就是把二進位數寫成：

```text
1.xxxxx * 2^n
```

例子：

```text
1101.101(2) = 1.101101(2) * 2^3
```

小數點往左移 3 位，所以指數是 `+3`。

小於 1 的例子：

```text
0.0101(2) = 1.01(2) * 2^-2
```

小數點往右移 2 位，所以指數是 `-2`。

---

## [會算] 十進位小數轉二進位

整數部分：

```text
除以 2，記餘數，最後倒著讀。
```

小數部分：

```text
乘以 2，取整數，最後順著讀。
```

例子：`13.625(10)`

```text
13 = 1101
0.625 = 0.101
```

所以：

```text
13.625(10) = 1101.101(2)
```

正規化：

```text
1101.101(2) = 1.101101(2) * 2^3
```

---

## [會算] 10.25 轉 IEEE 754 單精度

題目：將 `10.25(10)` 轉成 IEEE 754 單精度。

單精度：

```text
Sign 1 bit | Exponent 8 bits | Fraction 23 bits
bias = 127
```

### 1. 決定符號位

`10.25` 是正數：

```text
S = 0
```

### 2. 轉成二進位

```text
10(10) = 1010(2)
0.25(10) = 0.01(2)
```

所以：

```text
10.25(10) = 1010.01(2)
```

### 3. 正規化

```text
1010.01(2) = 1.01001(2) * 2^3
```

實際指數：

```text
n = 3
```

### 4. 算 Exponent 欄位

```text
E = n + bias
E = 3 + 127
E = 130
130(10) = 10000010(2)
```

### 5. 填 Fraction

正規化結果：

```text
1.01001 * 2^3
```

Fraction 只填小數點右邊：

```text
01001
```

補滿 23 bits：

```text
01001000000000000000000
```

答案：

```text
0 10000010 01001000000000000000000
```

若轉成十六進位：

```text
0x41240000
```

## [會判斷] IEEE 754 反推

題目：

```text
1 10000001 10000000000000000000000
```

拆欄位：

```text
S = 1
E = 10000001(2) = 129
F = 10000000000000000000000
```

單精度 bias = 127：

```text
實際指數 n = E - bias = 129 - 127 = 2
```

Fraction 前面補回隱含的 1：

```text
1.F = 1.1(2) = 1.5(10)
```

代入公式：

```text
(-1)^1 * 1.5 * 2^2
= -1 * 1.5 * 4
= -6
```

答案：

```text
-6
```

## [常考] 為什麼 0.1 可能不精確？

十進位 `0.1` 轉二進位會變成循環小數：

```text
0.1(10) = 0.0001100110011...(2)
```

電腦欄位有限，不能存無限位，所以只能存近似值。

因此：

```text
不是所有十進位小數都能被二進位浮點數精確表示。
```

---

## [易錯] 常見陷阱

| 容易錯的地方 | 正確觀念 |
| --- | --- |
| Exponent 直接存實際指數 n | 錯，存的是 `n + bias` |
| Fraction 把最前面的 1 也存進去 | 錯，正規化的最前面 1 是隱含位元 |
| 小於 1 的數正規化後指數寫正數 | 通常錯，小數點往右移時指數是負數 |
| 十進位小數轉二進位用除以 2 | 錯，小數部分用乘以 2 |
| 負浮點數用二補數表示 | 錯，IEEE 754 用 Sign bit 表示正負 |

---

## [必背] 國考答題句

1. IEEE 754 正規化數的公式為 `(-1)^S * 1.F * 2^(E - bias)`。
2. 單精度共有 32 bits，欄位為 Sign 1 bit、Exponent 8 bits、Fraction 23 bits，bias 為 127。
3. 雙精度共有 64 bits，欄位為 Sign 1 bit、Exponent 11 bits、Fraction 52 bits，bias 為 1023。
4. Exponent 欄位儲存的是實際指數加上 bias，不是直接儲存實際指數。
5. Fraction 欄位只存正規化後小數點右側的位元，最前面的 `1` 為隱含位元。
6. 十進位小數轉二進位小數時，使用乘以 2 取整數的方法。
7. 有些十進位小數轉成二進位會循環，因此浮點數可能只能近似表示。

## [考前速記]

IEEE 754 單精度：

```text
1 / 8 / 23，bias = 127
```

IEEE 754 雙精度：

```text
1 / 11 / 52，bias = 1023
```

轉換流程：

```text
1. 看正負號，決定 S。
2. 把絕對值轉成二進位。
3. 正規化成 1.F * 2^n。
4. 算 E = n + bias。
5. Fraction 填 F，不填隱含的 1。
6. 合併 S、Exponent、Fraction。
```

反推流程：

```text
1. 拆 S、E、F。
2. 算 n = E - bias。
3. Fraction 前面補回隱含的 1。
4. 套 (-1)^S * 1.F * 2^n。
```
