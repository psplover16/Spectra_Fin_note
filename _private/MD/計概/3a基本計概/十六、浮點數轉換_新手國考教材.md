## 名詞解釋

### 浮點數

浮點數是電腦用來表示「可能有小數點」的數字，例如 `3.14`、`0.125`、`-10.5`。它叫「浮點」，是因為小數點的位置可以移動；同一個值可以寫成不同形式，例如十進位的 `123.4` 可以寫成 `1.234 * 10^2`。

在計算機概論考題中，浮點數常和「二進位小數」、「科學記號」、「IEEE 754 格式」一起出現。

### 位元

位元是電腦儲存資料的最小單位，只能是 `0` 或 `1`。IEEE 754 單精度用 32 個位元表示一個浮點數，雙精度用 64 個位元表示一個浮點數。

### 基底

基底是數字系統使用幾個符號來表示數字。十進位的基底是 10，二進位的基底是 2，十六進位的基底是 16。

轉換浮點數時要特別注意：十進位小數點右邊是 `10^-1`、`10^-2`；二進位小數點右邊則是 `2^-1`、`2^-2`、`2^-3`。

### 二進位小數

二進位小數是用 2 為基底的小數。例如：

```text
0.101(2) = 1 * 2^-1 + 0 * 2^-2 + 1 * 2^-3
         = 0.5 + 0 + 0.125
         = 0.625(10)
```

所以 `0.101(2)` 不是十進位的零點一零一，而是十進位的 `0.625`。

### 科學記號

科學記號是把數字寫成「一個有效數字乘上基底的次方」。十進位常見例子是：

```text
123.4 = 1.234 * 10^2
```

二進位也可以使用同樣概念：

```text
1010.01(2) = 1.01001(2) * 2^3
```

國考看到浮點數轉換時，通常就是要把數字整理成這種二進位科學記號。

### 正規化

正規化是把二進位數字調整成：

```text
1.xxxxx * 2^n
```

也就是小數點左邊只保留一個 `1`。例如：

```text
1101.101(2) = 1.101101(2) * 2^3
```

小數點往左移 3 位，所以指數是 `3`。如果原本是很小的小數，例如 `0.0101(2)`，要把小數點往右移到第一個 `1` 後面：

```text
0.0101(2) = 1.01(2) * 2^-2
```

小數點往右移 2 位，所以指數是 `-2`。

### 符號位

符號位用來表示正負號。IEEE 754 中通常記為 `S`：

```text
S = 0 表示正數
S = 1 表示負數
```

例如 `+10.25` 的符號位是 `0`，`-10.25` 的符號位是 `1`。

### 指數與偏移值

指數是正規化之後的 `2^n` 裡面的 `n`。但 IEEE 754 不會直接把 `n` 存進指數欄位，而是先加上一個固定值，這個固定值叫 bias，也常翻成偏移值。

```text
儲存的指數 E = 實際指數 n + bias
實際指數 n = 儲存的指數 E - bias
```

單精度的 bias 是 `127`，雙精度的 bias 是 `1023`。

### 尾數與 Fraction 欄位

尾數是正規化後 `1.F` 裡的小數部分。IEEE 754 的 Fraction 欄位只存 `F`，不存最前面的 `1`。

例如：

```text
1.01001(2) * 2^3
```

這裡的 `1` 是隱含的，Fraction 欄位從 `01001` 開始填，不是從 `101001` 開始填。

### 單精度與雙精度

單精度是 32 bits，雙精度是 64 bits。國考最常考它們的欄位配置：

```text
單精度：Sign 1 bit、Exponent 8 bits、Fraction 23 bits、bias = 127
雙精度：Sign 1 bit、Exponent 11 bits、Fraction 52 bits、bias = 1023
```

一般正規化數值的公式是：

```text
(-1)^S * 1.F * 2^(E - bias)
```

## 核心想法

浮點數轉換可以拆成四件事：先決定正負號，再把數值大小轉成二進位，接著正規化，最後依照 IEEE 754 欄位填入符號位、指數欄位與尾數欄位。

第一步是看正負號。正數的 `S` 是 `0`，負數的 `S` 是 `1`。正負號只影響符號位，不改變後面二進位大小的轉換方法。

第二步是把十進位轉成二進位。整數部分用「除以 2 取餘數，餘數倒著讀」；小數部分用「乘以 2 取整數，整數順著讀」。這兩個方法很常考，不能只背結果。

第三步是正規化。把二進位數字的小數點移到第一個 `1` 的後面，整理成 `1.F * 2^n`。小數點往左移，指數變正；小數點往右移，指數變負。

第四步是填 IEEE 754 欄位。指數欄位不是直接填 `n`，而是填 `n + bias`。Fraction 欄位只填 `1.F` 裡小數點右邊的 `F`，最前面的 `1` 不填，因為它是正規化數的隱含位元。

## 具體範例

### 範例一：將 13.625 轉成二進位並正規化

題目要轉換 `13.625(10)`。先分成整數部分 `13` 與小數部分 `0.625`。

整數部分用除以 2 取餘數：

```text
13 / 2 = 6 ... 1
 6 / 2 = 3 ... 0
 3 / 2 = 1 ... 1
 1 / 2 = 0 ... 1
```

餘數要由下往上讀，所以：

```text
13(10) = 1101(2)
```

小數部分用乘以 2 取整數：

```text
0.625 * 2 = 1.25  取整數 1，留下 0.25
0.25  * 2 = 0.5   取整數 0，留下 0.5
0.5   * 2 = 1.0   取整數 1，留下 0
```

整數要由上往下讀，所以：

```text
0.625(10) = 0.101(2)
```

合起來：

```text
13.625(10) = 1101.101(2)
```

接著正規化。把小數點移到第一個 `1` 後面：

```text
1101.101(2) = 1.101101(2) * 2^3
```

小數點從 `1101.101` 移到 `1.101101`，往左移 3 位，所以指數是 `3`。

### 範例二：將 0.3125 轉成二進位並正規化

題目要轉換 `0.3125(10)`。這個數沒有整數部分，所以直接做小數部分。

```text
0.3125 * 2 = 0.625  取整數 0，留下 0.625
0.625  * 2 = 1.25   取整數 1，留下 0.25
0.25   * 2 = 0.5    取整數 0，留下 0.5
0.5    * 2 = 1.0    取整數 1，留下 0
```

由上往下讀整數：

```text
0.3125(10) = 0.0101(2)
```

接著正規化：

```text
0.0101(2) = 1.01(2) * 2^-2
```

這次小數點是往右移 2 位才到第一個 `1` 後面，所以指數是 `-2`。新手最容易在這裡把負號漏掉。

### 範例三：將 10.25 轉成 IEEE 754 單精度

題目要把 `10.25(10)` 轉成 IEEE 754 單精度。單精度格式是：

```text
Sign 1 bit | Exponent 8 bits | Fraction 23 bits
bias = 127
```

第一步，決定符號位。`10.25` 是正數，所以：

```text
S = 0
```

第二步，轉二進位。整數 `10`：

```text
10 / 2 = 5 ... 0
 5 / 2 = 2 ... 1
 2 / 2 = 1 ... 0
 1 / 2 = 0 ... 1
```

餘數由下往上讀：

```text
10(10) = 1010(2)
```

小數 `0.25`：

```text
0.25 * 2 = 0.5  取整數 0，留下 0.5
0.5  * 2 = 1.0  取整數 1，留下 0
```

所以：

```text
0.25(10) = 0.01(2)
```

合起來：

```text
10.25(10) = 1010.01(2)
```

第三步，正規化：

```text
1010.01(2) = 1.01001(2) * 2^3
```

所以實際指數 `n = 3`。

第四步，計算儲存的指數欄位：

```text
E = n + bias
E = 3 + 127
E = 130
```

把 `130` 轉成 8 位元二進位：

```text
130(10) = 10000010(2)
```

第五步，填 Fraction 欄位。正規化結果是：

```text
1.01001(2) * 2^3
```

Fraction 只取小數點右邊的 `01001`，再補 0 到 23 bits：

```text
Fraction = 01001000000000000000000
```

最後合併三個欄位：

```text
S        Exponent   Fraction
0        10000010   01001000000000000000000
```

所以 IEEE 754 單精度表示為：

```text
0 10000010 01001000000000000000000
```

若題目要求寫成十六進位，可以每 4 個 bits 分一組：

```text
0100 0001 0010 0100 0000 0000 0000 0000
= 0x41240000
```

### 範例四：由 IEEE 754 單精度反推十進位

題目給：

```text
1 10000001 10000000000000000000000
```

第一步，拆欄位：

```text
S = 1
E = 10000001(2)
F = 10000000000000000000000
```

第二步，看符號。`S = 1` 表示負數。

第三步，把指數欄位轉成十進位：

```text
10000001(2) = 129(10)
```

單精度 bias 是 `127`，所以實際指數：

```text
n = E - bias
n = 129 - 127
n = 2
```

第四步，還原尾數。正規化數有隱含的 `1`，所以：

```text
1.F = 1.10000000000000000000000(2)
```

這其實就是：

```text
1.1(2) = 1 + 1 * 2^-1 = 1.5(10)
```

第五步，代入公式：

```text
(-1)^S * 1.F * 2^(E - bias)
= (-1)^1 * 1.5 * 2^2
= -1 * 1.5 * 4
= -6
```

答案是：

```text
-6(10)
```

### 範例五：將 -5.5 轉成 IEEE 754 雙精度欄位

雙精度格式是：

```text
Sign 1 bit | Exponent 11 bits | Fraction 52 bits
bias = 1023
```

第一步，決定符號位。`-5.5` 是負數：

```text
S = 1
```

第二步，轉二進位：

```text
5(10) = 101(2)
0.5(10) = 0.1(2)
```

所以：

```text
5.5(10) = 101.1(2)
```

第三步，正規化：

```text
101.1(2) = 1.011(2) * 2^2
```

實際指數是：

```text
n = 2
```

第四步，計算雙精度指數欄位：

```text
E = n + bias
E = 2 + 1023
E = 1025
```

把 `1025` 轉成 11 位元二進位：

```text
1025(10) = 10000000001(2)
```

第五步，填 Fraction 欄位。`1.011` 的小數部分是 `011`，後面補 0 到 52 bits：

```text
Fraction = 0110000000000000000000000000000000000000000000000000
```

所以欄位表示為：

```text
S        Exponent      Fraction
1        10000000001   0110000000000000000000000000000000000000000000000000
```

若寫成十六進位：

```text
1100 0000 0001 0110 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000
= 0xC016000000000000
```

### 範例六：為什麼 0.1 不一定能被二進位精確表示

十進位的 `0.1` 轉二進位時，用小數乘以 2：

```text
0.1 * 2 = 0.2  取整數 0，留下 0.2
0.2 * 2 = 0.4  取整數 0，留下 0.4
0.4 * 2 = 0.8  取整數 0，留下 0.8
0.8 * 2 = 1.6  取整數 1，留下 0.6
0.6 * 2 = 1.2  取整數 1，留下 0.2
```

留下的 `0.2` 又出現了，代表接下來會重複。因此：

```text
0.1(10) = 0.0001100110011...(2)
```

這是一個無限循環二進位小數。電腦欄位有限，只能取近似值，所以有些十進位小數在浮點數中無法被精確表示。

## 國考常見考法

### 考法一：十進位小數轉二進位小數

這類題目通常會給 `0.625`、`0.3125`、`10.25` 之類的數字。解題重點是整數部分與小數部分要分開處理。整數部分用除以 2 取餘數，小數部分用乘以 2 取整數。

如果小數部分最後變成 0，表示可以有限位數表示；如果某個小數餘值重複出現，表示二進位小數會循環。

### 考法二：二進位數正規化

題目常問：

```text
1101.01(2) 要寫成 1.F * 2^n 是多少？
```

做法是把小數點移到第一個 `1` 後方。若小數點往左移，`n` 是正數；若小數點往右移，`n` 是負數。

### 考法三：計算 bias exponent

國考很常設陷阱，把「實際指數」和「儲存指數」混在一起。記住：

```text
儲存指數 E = 實際指數 n + bias
```

單精度用 `127`，雙精度用 `1023`。例如單精度實際指數是 `3`，欄位要存的是 `130`，也就是 `10000010(2)`。

### 考法四：填 IEEE 754 欄位

題目可能要求把一個十進位數轉成：

```text
S Exponent Fraction
```

流程是先轉二進位，再正規化，最後填欄位。Fraction 欄位只填正規化後小數點右邊的部分，不填最前面的隱含 `1`。

### 考法五：由 IEEE 754 位元反推數值

反推時要先拆欄位，再套公式：

```text
(-1)^S * 1.F * 2^(E - bias)
```

這類題目常考單精度，因為欄位比較短，適合筆算。解題時先把 Exponent 欄位轉十進位，再扣掉 bias。

## 必要比較表與易混淆整理

### 單精度與雙精度比較

| 類型 | 總位元數 | Sign | Exponent | Fraction | bias |
|---|---:|---:|---:|---:|---:|
| 單精度 | 32 bits | 1 bit | 8 bits | 23 bits | 127 |
| 雙精度 | 64 bits | 1 bit | 11 bits | 52 bits | 1023 |

單精度與雙精度的公式形式相同，差別在欄位長度與 bias。考題若沒有特別說雙精度，常見預設會考單精度，但仍要以題目敘述為準。

### 欄位意義比較

| 欄位 | 白話意思 | 常見錯誤 |
|---|---|---|
| Sign | 表示正負號 | 把負數直接做二補數，這不是 IEEE 754 浮點數正規化題目的做法 |
| Exponent | 儲存加過 bias 的指數 | 把實際指數 `n` 直接填入欄位 |
| Fraction | 儲存 `1.F` 的小數部分 | 把隱含的最前面 `1` 也填進去 |

### 易混淆一：實際指數與儲存指數

正規化後的 `2^n` 裡，`n` 叫實際指數。IEEE 754 指數欄位存的是 `n + bias`，不是 `n`。所以看到 Exponent 欄位時，要用 `E - bias` 才能還原真正的指數。

### 易混淆二：尾數不等於整段 `1.F`

在很多教材中，「尾數」有時泛指 `1.F`，但 IEEE 754 的 Fraction 欄位實際只存 `F`。考試填欄位時要以欄位名稱為準：Fraction 欄位不存隱含的 `1`。

### 易混淆三：小於 1 的數，正規化指數常是負數

例如：

```text
0.0101(2) = 1.01(2) * 2^-2
```

因為小數點要往右移，代表原本的數比較小，所以指數是負數。新手常把它誤寫成 `2^2`。

### 易混淆四：小數乘 2 是順著讀，不是倒著讀

整數除以 2 的餘數要倒著讀；小數乘以 2 取出的整數要順著讀。兩者剛好相反，這是筆算題最常見的失分點之一。

## 國考答題句

1. 浮點數轉 IEEE 754 時，應先將數值轉成二進位，再正規化為 `1.F * 2^n`。
2. IEEE 754 正規化數的數值公式為 `(-1)^S * 1.F * 2^(E - bias)`。
3. 單精度共有 32 bits，欄位為 Sign 1 bit、Exponent 8 bits、Fraction 23 bits，bias 為 127。
4. 雙精度共有 64 bits，欄位為 Sign 1 bit、Exponent 11 bits、Fraction 52 bits，bias 為 1023。
5. Exponent 欄位儲存的是實際指數加上 bias，不是直接儲存實際指數。
6. Fraction 欄位只存正規化後小數點右側的位元，最前面的 `1` 為隱含位元。
7. 十進位小數轉二進位小數時，使用乘以 2 取整數的方法；若小數部分重複，表示二進位表示會循環。

## 容易考的判斷題

### 1. IEEE 754 單精度浮點數共有 32 bits。

答案：對。

單精度格式是 Sign 1 bit、Exponent 8 bits、Fraction 23 bits，合計 `1 + 8 + 23 = 32` bits。

### 2. IEEE 754 雙精度的 bias 是 127。

答案：錯。

`127` 是單精度的 bias；雙精度的 bias 是 `1023`。

### 3. 正規化數的 Fraction 欄位會存入最前面的 `1`。

答案：錯。

正規化數寫成 `1.F * 2^n`，最前面的 `1` 是隱含位元，Fraction 欄位只存 `F`。

### 4. 若單精度正規化後的實際指數為 3，Exponent 欄位的十進位值是 130。

答案：對。

單精度 bias 是 `127`，所以 `E = 3 + 127 = 130`。

### 5. `0.101(2)` 等於 `0.625(10)`。

答案：對。

`0.101(2) = 1 * 2^-1 + 0 * 2^-2 + 1 * 2^-3 = 0.5 + 0.125 = 0.625`。

### 6. 二進位 `1010.01(2)` 正規化後是 `1.01001(2) * 2^3`。

答案：對。

小數點從 `1010.01` 移到第一個 `1` 後面，需要往左移 3 位，所以指數是 `3`。

### 7. 十進位小數轉二進位小數時，小數部分使用除以 2 取餘數。

答案：錯。

小數部分要用乘以 2 取整數。除以 2 取餘數是整數部分的做法。

### 8. 所有十進位小數都可以用有限位數的二進位小數精確表示。

答案：錯。

有些十進位小數轉成二進位會無限循環，例如 `0.1(10) = 0.0001100110011...(2)`，所以在有限位元中只能近似表示。

### 9. IEEE 754 的符號位 `S = 1` 表示負數。

答案：對。

IEEE 754 使用 `S = 0` 表示正數，`S = 1` 表示負數。

### 10. 若 Exponent 欄位越長，通常可表示的指數範圍越大。

答案：對。

Exponent 欄位用來表示指數大小。雙精度有 11 bits 的 Exponent，比單精度 8 bits 更長，因此通常能表示更大的指數範圍。

## 考前速記小抄

### 十進位轉二進位

整數部分：

```text
除以 2，記餘數，最後倒著讀。
```

小數部分：

```text
乘以 2，取整數，最後順著讀。
```

### 正規化

```text
把二進位數寫成 1.F * 2^n
```

小數點往左移，`n` 是正數；小數點往右移，`n` 是負數。

### IEEE 754 欄位

```text
單精度：1 / 8 / 23，bias = 127
雙精度：1 / 11 / 52，bias = 1023
```

這裡的 `1 / 8 / 23` 代表 Sign、Exponent、Fraction 的位元數，不是數值大小。

### IEEE 754 轉換流程

```text
1. 看正負號，決定 S。
2. 把絕對值轉成二進位。
3. 正規化為 1.F * 2^n。
4. 算 E = n + bias。
5. Fraction 填 F，不填隱含的 1。
6. 合併 S、Exponent、Fraction。
```

### IEEE 754 反推流程

```text
1. 拆出 S、E、F。
2. 用 E - bias 得到實際指數。
3. 把 Fraction 前面補回隱含的 1，形成 1.F。
4. 套用 (-1)^S * 1.F * 2^(E - bias)。
```

### 最容易忘的三句

```text
Exponent 存的是 n + bias。
Fraction 不存最前面的 1。
小數轉二進位是乘以 2，整數順著讀。
```
