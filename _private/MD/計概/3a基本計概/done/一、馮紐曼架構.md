馮紐曼架構
1. 定義
**馮紐曼架構**是一種電腦設計方式。核心定義是程式和資料都放在同一個記憶體中，通常也共用同一組匯流排，CPU 依照順序一個一個讀取指令並執行。
計算機系統基本組成項目: 輸入單元、輸出單元、運算器、控制器、記憶體。
**匯流排**是電腦內部傳輸資料的通道。可以把匯流排想成馬路。CPU、記憶體、輸入輸出設備之間，要靠匯流排傳送資料。

# 2. 特色
# 2-1. 程式內儲概念(stored-program concept)  程式與資料皆存放於記憶體中，CPU 可從記憶體依序讀取指令並執行。
# 2-2. CPU 依照「取指令、解碼、執行」的步驟循序處理記憶體中的指令，除非遇到跳躍指令或中斷事件，才會改變原本的執行順序。


3. 差異
哈佛架構
1. 定義: 程式記憶體和資料記憶體分開，程式和資料可以分別存取。
2. 與馮紐曼架構相異之處: 馮紐曼架構中，程式與資料共用記憶體與匯流排，設計簡單，但 CPU 取指令與存取資料可能互相競爭傳輸通道，造成效能瓶頸。哈佛架構則將程式記憶體與資料記憶體分離，可同時取指令與取資料，效能較佳，但設計較複雜。



4. 馮紐曼瓶頸

### 馮紐曼瓶頸
4-1.
**馮紐曼瓶頸**：馮紐曼瓶頸是指在馮紐曼架構中，CPU 與記憶體之間的資料傳輸速度有限，當 CPU 需要頻繁讀取指令與資料時，會因等待記憶體傳輸而降低整體效能。
4-2. 改善方法(共同目標都是 減少 CPU 等待記憶體的時間，提高資料供應速度，讓 CPU 更有效率地執行):
1. 快取 Cache，是一種速度很快、容量較小的記憶體，通常放在 CPU 附近或 CPU 內部，用來存放 CPU 最近常用或可能會再用到的資料。
CPU 如果每次都去較慢的主記憶體拿資料，會浪費時間。如果資料已經在快取中，CPU 就可以更快取得。
2. **預取**是指電腦預先猜測 CPU 接下來可能需要哪些指令或資料，先把它們拿到較快的位置。
3. **增加匯流排寬度**提高一次可以傳送多少位元資料。
4. **記憶體頻寬**是指單位時間內，記憶體可以傳輸多少資料。
5. **管線化**是把一個工作切成多個階段，讓不同指令可以重疊執行。
6. **平行處理**是指同時處理多個工作。
7. **記憶體階層**是指電腦把不同速度、容量、成本的記憶體安排成層級。 (暫存器 → 快取 → 主記憶體 RAM → SSD / 硬碟)
