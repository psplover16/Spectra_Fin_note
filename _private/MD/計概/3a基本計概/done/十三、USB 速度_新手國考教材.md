# 十三、USB 速度

| --- | --- | --- |
| USB 1.0 / 1.1 | Low Speed | 1.5 Mbps |
| USB 1.0 / 1.1 | Full Speed | 12 Mbps |
| USB 2.0 | High Speed | 480 Mbps |
| USB 3.0 / USB 3.1 Gen 1 / USB 3.2 Gen 1x1 | SuperSpeed | 5 Gbps |
| USB 3.1 Gen 2 / USB 3.2 Gen 2x1 | SuperSpeed+ | 10 Gbps |

最常考優先背(對應上面的表格，那一行，幫我標示成 紅色文字顏色)：
USB 2.0 = 480 Mbps
USB 3.0 = 5 Gbps
USB 3.1 Gen 2 = 10 Gbps
USB 3.2 Gen 2x2 = 20 Gbps
USB4 = 常見 40 Gbps
USB4 Version 2.0 = 80 Gbps



## Mbps 與 MB/s 不一樣

1. USB 規格常寫的是：Mbps / Gbps，這裡的小寫 `b` 是 bit（位元）。
2. 1 Byte = 8bits
3. MB/s 約等於 Mbps ÷ 8；GB/s 約等於 Gbps ÷ 8


## 備註
1. 實際速度會受線材、控制器、協定開銷與裝置限制影響。
2. Type-C 是接頭形狀。不保證一定是高速 USB。
