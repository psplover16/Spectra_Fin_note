## 名詞解釋

**進制**就是「逢幾進一」的數字表示法。例如十進制是逢 10 進 1，二進制是逢 2 進 1，八進制是逢 8 進 1，十六進制是逢 16 進 1。進制也常稱為「基底」或「基數」。

**基底**是進制的大小，通常用英文 base 或 radix 表示。十進制的基底是 10，二進制的基底是 2，八進制的基底是 8，十六進制的基底是 16。題目寫成 `(1011)2`，右下角的 2 就代表這個數字是二進制。

**位數**是數字中每一個位置的符號。例如 `(374)8` 有三個位數，分別是 3、7、4。每一位的意義不只是它本身的數字，還要看它站在哪個位置。

**位值**或**權重**是每個位置代表的大小。以十進制 `374` 為例，3 在百位，代表 `3 * 10^2`；7 在十位，代表 `7 * 10^1`；4 在個位，代表 `4 * 10^0`。其他進制也一樣，只是把 10 換成該進制的基底。

**整數部分**是小數點左邊的部分，例如 `45.625` 的整數部分是 45。十進制整數轉成 n 進制時，常用「連除法」。

**小數部分**是小數點右邊的部分，例如 `45.625` 的小數部分是 0.625。十進制小數轉成 n 進制時，常用「連乘法」。

**bit**是二進制的一位，也稱為位元。因為電腦底層用 0 和 1 表示資料，所以二進制、八進制、十六進制在計算機概論中很常一起考。

**十六進制的 A 到 F**代表十進制的 10 到 15。也就是 `A=10`、`B=11`、`C=12`、`D=13`、`E=14`、`F=15`。因為十六進制每一位最多要表示到 15，所以需要用英文字母補足。

## 核心想法

進制轉換最重要的觀念是：每一位數字的真正大小，等於「該位數字」乘上「基底的次方」。因此，n 進制轉十進制時，就是把每一位拆開，乘上對應的基底次方後加總。

十進制轉 n 進制時，整數部分和小數部分的處理方式不同。整數部分用連除法：一直除以目標基底，記下餘數，最後把餘數由下往上讀。小數部分用連乘法：一直乘以目標基底，記下每次乘積的整數部分，最後把整數部分由上往下讀。

二進制、八進制、十六進制之間可以快速轉換，因為 8 和 16 都是 2 的冪次方。`8 = 2^3`，所以二進制每 3 bits 可以對應八進制 1 位；`16 = 2^4`，所以二進制每 4 bits 可以對應十六進制 1 位。

記憶體容量常用 2 的冪次方來考。國考常見速記是 `2^10` 約等於 `1K`，`2^20` 約等於 `1M`，`2^30` 約等於 `1G`，`2^40` 約等於 `1T`。嚴格來說，`2^10 = 1024`，不是剛好 1000。

## 具體範例

### 範例一：十進制整數轉二進制

題目：將十進制 `45` 轉成二進制。

十進制整數轉二進制時，用 2 做連除，並記下每次的餘數。

| 除法 | 商 | 餘數 |
|---|---:|---:|
| 45 ÷ 2 | 22 | 1 |
| 22 ÷ 2 | 11 | 0 |
| 11 ÷ 2 | 5 | 1 |
| 5 ÷ 2 | 2 | 1 |
| 2 ÷ 2 | 1 | 0 |
| 1 ÷ 2 | 0 | 1 |

連除法的答案要把餘數「由下往上」讀，所以得到：

```text
(45)10 = (101101)2
```

檢查方式是把 `(101101)2` 轉回十進制：

```text
1 * 2^5 + 0 * 2^4 + 1 * 2^3 + 1 * 2^2 + 0 * 2^1 + 1 * 2^0
= 32 + 0 + 8 + 4 + 0 + 1
= 45
```

### 範例二：十進制整數轉八進制

題目：將十進制 `156` 轉成八進制。

目標是八進制，所以用 8 做連除。

| 除法 | 商 | 餘數 |
|---|---:|---:|
| 156 ÷ 8 | 19 | 4 |
| 19 ÷ 8 | 2 | 3 |
| 2 ÷ 8 | 0 | 2 |

把餘數由下往上讀：

```text
(156)10 = (234)8
```

檢查：

```text
2 * 8^2 + 3 * 8^1 + 4 * 8^0
= 2 * 64 + 3 * 8 + 4 * 1
= 128 + 24 + 4
= 156
```

### 範例三：十進制小數轉二進制

題目：將十進制 `0.625` 轉成二進制。

十進制小數轉二進制時，用 2 做連乘。每次乘出來的「整數部分」就是下一個二進制小數位。

| 連乘 | 乘積 | 取整數部分 | 留下小數部分 |
|---|---:|---:|---:|
| 0.625 × 2 | 1.25 | 1 | 0.25 |
| 0.25 × 2 | 0.5 | 0 | 0.5 |
| 0.5 × 2 | 1.0 | 1 | 0.0 |

小數部分變成 0 就可以停止。把取出的整數部分由上往下讀：

```text
(0.625)10 = (0.101)2
```

檢查：

```text
1 * 2^-1 + 0 * 2^-2 + 1 * 2^-3
= 1/2 + 0 + 1/8
= 0.5 + 0.125
= 0.625
```

### 範例四：含整數與小數的十進制轉二進制

題目：將十進制 `13.625` 轉成二進制。

先分成整數部分 `13` 和小數部分 `0.625`。

整數部分 `13` 用連除法：

| 除法 | 商 | 餘數 |
|---|---:|---:|
| 13 ÷ 2 | 6 | 1 |
| 6 ÷ 2 | 3 | 0 |
| 3 ÷ 2 | 1 | 1 |
| 1 ÷ 2 | 0 | 1 |

餘數由下往上讀，所以：

```text
(13)10 = (1101)2
```

小數部分 `0.625` 用連乘法，從範例三可知：

```text
(0.625)10 = (0.101)2
```

最後把整數部分和小數部分合併：

```text
(13.625)10 = (1101.101)2
```

### 範例五：二進制轉十進制

題目：將二進制 `(101101)2` 轉成十進制。

n 進制轉十進制時，要把每一位乘上基底的次方。二進制的基底是 2，最右邊整數位是 `2^0`，往左依序是 `2^1`、`2^2`、`2^3`。

```text
(101101)2
= 1 * 2^5 + 0 * 2^4 + 1 * 2^3 + 1 * 2^2 + 0 * 2^1 + 1 * 2^0
= 32 + 0 + 8 + 4 + 0 + 1
= (45)10
```

所以：

```text
(101101)2 = (45)10
```

### 範例六：十六進制轉十進制

題目：將十六進制 `(2F)16` 轉成十進制。

十六進制的 `F` 代表十進制 15。基底是 16，所以左邊那位乘 `16^1`，右邊那位乘 `16^0`。

```text
(2F)16
= 2 * 16^1 + F * 16^0
= 2 * 16 + 15 * 1
= 32 + 15
= (47)10
```

所以：

```text
(2F)16 = (47)10
```

### 範例七：八進制小數轉十進制

題目：將八進制 `(17.4)8` 轉成十進制。

小數點左邊從右到左是 `8^0`、`8^1`，小數點右邊第一位是 `8^-1`。

```text
(17.4)8
= 1 * 8^1 + 7 * 8^0 + 4 * 8^-1
= 8 + 7 + 4/8
= 15 + 0.5
= (15.5)10
```

所以：

```text
(17.4)8 = (15.5)10
```

### 範例八：二進制轉八進制

題目：將二進制 `(110101011.101)2` 轉成八進制。

二進制轉八進制時，每 3 bits 分成一組。整數部分從小數點往左分組，不足 3 位時在最左邊補 0；小數部分從小數點往右分組，不足 3 位時在最右邊補 0。

```text
整數部分：110 101 011
小數部分：101
```

把每組二進制轉成一位八進制：

| 二進制 3 bits | 八進制 |
|---|---:|
| 110 | 6 |
| 101 | 5 |
| 011 | 3 |
| 101 | 5 |

因此：

```text
(110101011.101)2 = (653.5)8
```

### 範例九：二進制轉十六進制

題目：將二進制 `(1011110010.11)2` 轉成十六進制。

二進制轉十六進制時，每 4 bits 分成一組。整數部分從小數點往左分組，不足 4 位在最左邊補 0；小數部分從小數點往右分組，不足 4 位在最右邊補 0。

```text
整數部分：10 1111 0010 → 補成 0010 1111 0010
小數部分：11 → 補成 1100
```

逐組轉換：

| 二進制 4 bits | 十六進制 |
|---|---:|
| 0010 | 2 |
| 1111 | F |
| 0010 | 2 |
| 1100 | C |

因此：

```text
(1011110010.11)2 = (2F2.C)16
```

### 範例十：十六進制轉二進制

題目：將十六進制 `(3A)16` 轉成二進制。

十六進制每 1 位對應二進制 4 bits。`3` 要寫成 4 位二進制是 `0011`，`A` 代表十進制 10，寫成 4 位二進制是 `1010`。

```text
3 → 0011
A → 1010
```

合併後：

```text
(3A)16 = (00111010)2
```

若題目不要求保留前導 0，也可以寫成：

```text
(3A)16 = (111010)2
```

## 國考常見考法

第一種常見考法是「十進制轉其他進制」。這類題目通常要求把十進制整數轉成二進制、八進制或十六進制。解題時先看目標進制是幾，就用幾去做連除，最後把餘數由下往上讀。

第二種常見考法是「其他進制轉十進制」。這類題目重點不是連除，而是位值展開。每一位都要乘上基底的次方，整數部分從右邊開始是 0 次方，小數部分從小數點右邊開始是 -1 次方。

第三種常見考法是「二進制、八進制、十六進制快速互轉」。因為 `8 = 2^3`，所以二進制和八進制互轉時以 3 bits 為一組；因為 `16 = 2^4`，所以二進制和十六進制互轉時以 4 bits 為一組。這類題目比用十進制作中介更快，也比較不容易算錯。

第四種常見考法是「容量單位與 2 的冪次方」。題目可能問 `2^10`、`2^20`、`2^30`、`2^40` 約等於多少。要記得國考常用速記是 K、M、G、T，但精確值與十進制的 1000 倍不完全相同。

第五種常見考法是「小數轉換」。看到小數不要和整數混在一起算，應該把整數部分和小數部分拆開。整數用連除，小數用連乘，最後再用小數點合併答案。

## 必要比較表與易混淆整理

### 各種轉換方法比較

| 題型 | 方法 | 讀取方向 | 重點 |
|---|---|---|---|
| 十進制整數轉 n 進制 | 連除法 | 餘數由下往上讀 | 除到商為 0 停止 |
| 十進制小數轉 n 進制 | 連乘法 | 整數部分由上往下讀 | 小數變 0 或達到題目要求位數時停止 |
| n 進制轉十進制 | 位值展開後加總 | 依照次方計算 | 每位乘上基底的次方 |
| 二進制轉八進制 | 每 3 bits 分組 | 整數向左，小數向右 | 不足位數補 0 |
| 二進制轉十六進制 | 每 4 bits 分組 | 整數向左，小數向右 | 10 到 15 寫成 A 到 F |

### 易混淆整理

「十進制轉 n 進制」和「n 進制轉十進制」方法相反。十進制轉出去時，整數用連除法；其他進制轉回十進制時，用位值展開加總。

「整數部分」和「小數部分」的方向不同。整數轉換時，連除法的餘數要由下往上讀；小數轉換時，連乘法取出的整數部分要由上往下讀。

「二進制轉八進制」不是每 4 bits 一組，而是每 3 bits 一組。因為八進制的基底 8 等於 `2^3`。

「二進制轉十六進制」不是每 3 bits 一組，而是每 4 bits 一組。因為十六進制的基底 16 等於 `2^4`。

「前導 0」通常不影響數值。例如 `(001101)2` 和 `(1101)2` 數值相同。但是在分組轉換時，補 0 可以幫助湊滿 3 位或 4 位。

「2^10 約 1K」是考試速記，不代表 `2^10 = 1000`。精確來說 `2^10 = 1024`。在計概與電腦容量脈絡中，常把 1024 視為約 1K。

## 國考答題句

十進制整數轉 n 進制時，將整數連續除以 n，記錄每次餘數，最後把餘數由下往上排列。

十進制小數轉 n 進制時，將小數連續乘以 n，記錄每次乘積的整數部分，最後把整數部分由上往下排列。

n 進制轉十進制時，將每一位乘上基底的對應次方，再全部加總。

二進制轉八進制時，每 3 bits 分成一組，整數部分由小數點往左分，小數部分由小數點往右分。

二進制轉十六進制時，每 4 bits 分成一組，整數部分由小數點往左分，小數部分由小數點往右分。

`2^10` 約為 `1K`，`2^20` 約為 `1M`，`2^30` 約為 `1G`，`2^40` 約為 `1T`。

## 容易考的判斷題

1. 十進制整數轉二進制時，可以用連除以 2 的方式求出答案。  
   答：正確。整數部分用連除法，餘數由下往上讀。

2. 十進制小數轉二進制時，可以用連除以 2 的方式求出答案。  
   答：錯誤。小數部分要用連乘法，不是連除法。

3. n 進制轉十進制時，每一位要乘上基底的次方後加總。  
   答：正確。這就是位值展開法。

4. 二進制轉八進制時，每 4 bits 對應八進制 1 位。  
   答：錯誤。每 3 bits 才對應八進制 1 位，因為 `8 = 2^3`。

5. 二進制轉十六進制時，每 4 bits 對應十六進制 1 位。  
   答：正確。因為 `16 = 2^4`。

6. 十六進制的 `F` 代表十進制的 16。  
   答：錯誤。`F` 代表十進制的 15，十六進制逢 16 才進位。

7. `(1010)2` 等於 `(10)10`。  
   答：正確。計算為 `1 * 2^3 + 0 * 2^2 + 1 * 2^1 + 0 * 2^0 = 8 + 2 = 10`。

8. `2^10` 精確等於 1000。  
   答：錯誤。`2^10 = 1024`，只是常被近似記成 1K。

9. 二進制分組轉換成八進制或十六進制時，不足位數可以補 0。  
   答：正確。整數部分在最左邊補 0，小數部分在最右邊補 0，不會改變原數值。

10. `(17)8` 等於 `(17)10`。  
    答：錯誤。`(17)8 = 1 * 8^1 + 7 * 8^0 = 15`，所以它等於 `(15)10`。

## 考前速記小抄

十進制整數轉 n 進制：連除 n，餘數由下往上讀。

十進制小數轉 n 進制：連乘 n，整數部分由上往下讀。

n 進制轉十進制：每位數字乘上基底次方後加總。

二進制轉八進制：3 bits 一組，因為 `8 = 2^3`。

二進制轉十六進制：4 bits 一組，因為 `16 = 2^4`。

八進制每位只能用 `0` 到 `7`，不會出現 `8` 或 `9`。

十六進制每位可用 `0` 到 `9` 和 `A` 到 `F`，其中 `A=10`、`B=11`、`C=12`、`D=13`、`E=14`、`F=15`。

小數點左邊次方是 `0、1、2、3...` 往左增加；小數點右邊次方是 `-1、-2、-3...` 往右減少。

容量速記：`2^10 ≈ 1K`，`2^20 ≈ 1M`，`2^30 ≈ 1G`，`2^40 ≈ 1T`。

考場檢查技巧：如果是把十進制轉成其他進制，算完可以用位值展開轉回十進制，確認答案是否等於原題數字。
