## 名詞解釋

**卡諾圖**：卡諾圖是一種把真值表重新排成方格圖的方法。它的目的不是改變邏輯函數，而是讓相鄰的 `1` 比較容易被看見，進而把布林式化簡。

**布林函數**：布林函數是輸入只有 `0` 或 `1`，輸出也只有 `0` 或 `1` 的邏輯函數。例如 `F(A, B)` 代表輸入變數是 `A`、`B`，輸出是 `F`。

**變數**：變數就是會影響輸出的輸入符號，例如 `A`、`B`、`C`、`D`。2 變數卡諾圖有 `2^2 = 4` 格，3 變數有 `2^3 = 8` 格，4 變數有 `2^4 = 16` 格。

**最小項**：最小項可以先理解成「真值表中的某一列」。若某一列輸出為 `1`，那一列對應的格子就要在卡諾圖上填 `1`。國考常用 `Σm(...)` 表示哪些最小項為 `1`。

**Don't care**：Don't care 常寫成 `X` 或 `d`，意思是該輸入組合的輸出不重要，可以當 `1` 用，也可以不使用。使用原則很簡單：如果把它當 `1` 可以圈更大的群，就使用；如果不能幫助化簡，就不要勉強使用。

**相鄰格**：相鄰格是指卡諾圖中左右或上下緊貼的格子。因為卡諾圖的排列使用格雷碼，所以相鄰格只會差一個變數，這正是能化簡的原因。

**格雷碼順序**：格雷碼順序是卡諾圖欄列標籤的排列方式，常見順序是 `00, 01, 11, 10`。注意不是一般二進位的 `00, 01, 10, 11`，因為卡諾圖要求相鄰欄或列只能差一個位元。

**圈選**：圈選就是把卡諾圖上的 `1` 圈成一組。每一圈的格數必須是 `1, 2, 4, 8, 16...`，也就是 `2` 的冪次方。圈越大，化簡後留下的變數越少。

**可重疊**：可重疊表示同一個 `1` 可以被不只一個圈使用。只要這樣能讓其他圈變大或讓整體式子更簡，就可以重疊。

**可跨邊**：可跨邊表示卡諾圖的最左欄和最右欄相鄰，最上列和最下列也相鄰。卡諾圖可以想成左右相接、上下相接的圖，不要只把它當普通表格。

**乘積項**：乘積項是用 AND 連起來的一項，例如 `A'B`、`BC`、`A'C'D`。卡諾圖圈完後，每一圈通常會轉成一個乘積項。

**和項式**：和項式在這裡可先理解為「多個乘積項用 OR 加起來」，例如 `F = A'B + BC`。國考最常考的是由卡諾圖化簡成這種 SOP 形式。

## 核心想法

卡諾圖化簡的核心只有一句話：**把相鄰的 `1` 盡量圈成最大的 `2` 的冪次方群組，圈完後只留下每一圈中沒有變化的變數。**

為什麼可以這樣做？因為相鄰格只差一個變數。假設有兩格分別代表 `A'B` 和 `AB`，兩格唯一不同的是 `A`，而 `B` 都是 `1`。這兩項相加：

```text
A'B + AB = B(A' + A) = B
```

`A' + A` 一定等於 `1`，所以 `A` 被消掉，只剩 `B`。卡諾圖就是用圖形方式幫你看出這種可以消掉的變數。

基本規則如下。

1. 只圈 `1`，Don't care 可視需要加入圈選。
2. 每圈格數必須是 `1, 2, 4, 8, 16...`。
3. 每圈必須形成長方形或正方形，不能斜著圈，也不能圈成 L 形。
4. 可以重疊，因為重疊常常能得到更大的圈。
5. 可以跨邊，因為卡諾圖左右邊、上下邊視為相鄰。
6. 要盡量圈大，因為圈越大，消掉的變數越多。
7. 每一個 `1` 至少要被圈到一次。
8. Don't care 不是一定要圈；只有能讓結果更簡時才圈。

化簡時可以用這個口訣思考：**先填圖，再找最大圈；圈可重疊也可跨邊；圈完看不變，變的消失不寫。**

## 具體範例

### 例一：2 變數卡諾圖

題目：化簡 `F(A, B) = Σm(1, 3)`。

2 變數共有 `4` 格，最小項編號如下。

```text
      B
      0   1
A 0  m0  m1
  1  m2  m3
```

`Σm(1, 3)` 表示 `m1` 和 `m3` 填 `1`。

```text
      B
      0   1
A 0   0  [1]
  1   0  [1]
```

圈選說明：右邊同一欄有兩個相鄰的 `1`，可以圈成 `2` 格。

這一圈中，`A` 從 `0` 變成 `1`，所以 `A` 消掉；`B` 都是 `1`，所以留下 `B`。

答案：

```text
F = B
```

新手常犯錯是把兩格分別寫成 `A'B + AB` 就停住。卡諾圖要繼續看出它們可以合併成 `B`。

### 例二：3 變數卡諾圖

題目：化簡 `F(A, B, C) = Σm(0, 1, 2, 3)`。

3 變數卡諾圖常把 `A` 放在列，`BC` 放在欄。欄位要用格雷碼順序 `00, 01, 11, 10`。

最小項位置如下。

```text
          BC
          00  01  11  10
A = 0     m0  m1  m3  m2
A = 1     m4  m5  m7  m6
```

填入 `Σm(0, 1, 2, 3)`：

```text
          BC
          00  01  11  10
A = 0    [1] [1] [1] [1]
A = 1     0   0   0   0
```

圈選說明：上排四個 `1` 可以圈成 `4` 格。這比圈成兩個 `2` 格更好，因為圈越大，化簡越多。

看這一圈中哪些變數不變：

- `A` 都是 `0`，所以留下 `A'`。
- `B` 在欄位中有 `0` 也有 `1`，所以消掉。
- `C` 在欄位中有 `0` 也有 `1`，所以消掉。

答案：

```text
F = A'
```

這題在國考常用來測驗「要盡量圈大」。若寫成 `A'B' + A'B`，雖然邏輯上可再化簡，但不是最簡答案。

### 例三：3 變數跨邊圈選

題目：化簡 `F(A, B, C) = Σm(0, 2, 4, 6)`。

先填卡諾圖：

```text
          BC
          00  01  11  10
A = 0    [1]  0   0  [1]
A = 1    [1]  0   0  [1]
```

注意最左欄 `BC = 00` 和最右欄 `BC = 10` 是相鄰，因為 `00` 與 `10` 只差 `B`。所以四個角落狀的 `1` 可以跨左右邊圈成一個 `4` 格群組。

用文字表示圈選：

```text
          BC
          00  01  11  10
A = 0    (1)  0   0  (1)
A = 1    (1)  0   0  (1)

圈選：左欄兩格 + 右欄兩格，左右跨邊視為相鄰。
```

看不變的變數：

- `A` 有 `0` 也有 `1`，消掉。
- `B` 在 `00` 與 `10` 中有 `0` 也有 `1`，消掉。
- `C` 都是 `0`，留下 `C'`。

答案：

```text
F = C'
```

這題的關鍵是知道「卡諾圖可以跨邊」。如果忘記跨邊，就會把它錯誤拆成兩圈，答案會變得不夠簡。

### 例四：4 變數卡諾圖與重疊圈選

題目：化簡 `F(A, B, C, D) = Σm(0, 1, 2, 3, 8, 9, 10, 11, 6, 7, 14, 15)`。

4 變數卡諾圖常把 `AB` 放在列，`CD` 放在欄，兩邊都用格雷碼順序 `00, 01, 11, 10`。

最小項位置如下。

```text
             CD
             00  01  11  10
AB = 00      m0  m1  m3  m2
AB = 01      m4  m5  m7  m6
AB = 11      m12 m13 m15 m14
AB = 10      m8  m9  m11 m10
```

填入題目的 `1`：

```text
             CD
             00  01  11  10
AB = 00     [1] [1] [1] [1]
AB = 01      0   0  [1] [1]
AB = 11      0   0  [1] [1]
AB = 10     [1] [1] [1] [1]
```

先找最大圈。

第一圈：最上列與最下列可以跨上下邊圈成 `8` 格。

```text
             CD
             00  01  11  10
AB = 00     (1) (1) (1) (1)
AB = 01      0   0   1   1
AB = 11      0   0   1   1
AB = 10     (1) (1) (1) (1)

圈選一：AB = 00 與 AB = 10 兩列跨邊相鄰，共 8 格。
```

這一圈中：

- `A` 在 `00` 與 `10` 中有變化，消掉。
- `B` 都是 `0`，留下 `B'`。
- `C`、`D` 在四欄都有變化，消掉。

所以第一圈得到 `B'`。

第二圈：右邊兩欄 `CD = 11` 和 `CD = 10`，四列都是 `1`，可以圈成 `8` 格。

```text
             CD
             00  01  11  10
AB = 00      1   1  (1) (1)
AB = 01      0   0  (1) (1)
AB = 11      0   0  (1) (1)
AB = 10      1   1  (1) (1)

圈選二：CD = 11 與 CD = 10 兩欄相鄰，共 8 格。
```

這一圈中：

- `A`、`B` 在四列都有變化，消掉。
- `C` 都是 `1`，留下 `C`。
- `D` 在 `11` 與 `10` 中有變化，消掉。

所以第二圈得到 `C`。

答案：

```text
F = B' + C
```

這題同時考「跨邊」與「重疊」。最上列、最下列右邊的 `1` 也被第二圈使用，這是允許的。卡諾圖不是要求每個 `1` 只能用一次，而是要求每個 `1` 至少被覆蓋一次，並讓整體式子最簡。

### 例五：Don't care 的使用

題目：化簡 `F(A, B, C) = Σm(1, 3, 5) + d(7)`。

其中 `d(7)` 表示 `m7` 是 Don't care。

先填圖：

```text
          BC
          00  01  11  10
A = 0     0  [1] [1]  0
A = 1     0  [1]  X   0
```

如果不使用 `X`，只能把 `m1`、`m3` 圈一組，再把 `m1`、`m5` 圈一組，結果會有兩項。若把 `m7` 當成 `1`，右中四格可以圈成一個 `4` 格：

```text
          BC
          00  01  11  10
A = 0     0  (1) (1)  0
A = 1     0  (1) (X)  0

圈選：m1、m3、m5 加上 Don't care m7，形成 4 格。
```

看不變的變數：

- `A` 有 `0` 也有 `1`，消掉。
- `B` 有 `0` 也有 `1`，消掉。
- `C` 都是 `1`，留下 `C`。

答案：

```text
F = C
```

這題的重點是：Don't care 可以拿來幫忙變大圈，但不是輸出一定為 `1` 的格子。它是「可用可不用」。

## 國考常見考法

國考最常先給你真值表或 `Σm(...)`，要求畫出 2、3、4 變數卡諾圖並化簡。這類題目要先把最小項編號放到正確位置，尤其 3 變數與 4 變數的欄列順序必須使用格雷碼。只要欄位順序排錯，後面圈選就會全部跟著錯。

另一種常見考法是考圈選規則，例如「可否圈 3 格」、「可否圈 L 形」、「可否跨邊」、「可否重疊」。答案要記得：不能圈 3 格，不能圈 L 形，可以跨邊，可以重疊。

也常考 Don't care。題目會把某些格標成 `X`，問最簡式為何。作答時不要把所有 `X` 都硬圈進去；應先看它能不能讓 `1` 形成更大的 `2` 的冪次方群組。能變大就用，不能變大就不用。

4 變數題目常考「最大圈」與「跨邊」。例如四個角落都是 `1` 時，它們不是四個孤立格，而是可以上下左右跨邊形成一個 `4` 格圈。考試時若看到角落、最外列、最外欄有 `1`，要立刻檢查跨邊。

判斷化簡結果時，國考也會要求從圈選推出乘積項。方法是看每一圈中不變的變數；值固定為 `1` 就寫原變數，值固定為 `0` 就寫反變數，有變化就不寫。

## 必要比較表或易混淆整理

### 2、3、4 變數卡諾圖比較

| 變數數量 | 格數 | 常見列欄安排 | 必背重點 |
|---|---:|---|---|
| 2 變數 | 4 格 | `A` 為列，`B` 為欄 | 看懂相鄰兩格如何消去一個變數 |
| 3 變數 | 8 格 | `A` 為列，`BC` 為欄 | 欄順序是 `00, 01, 11, 10`，可跨左右邊 |
| 4 變數 | 16 格 | `AB` 為列，`CD` 為欄 | 列與欄都用 `00, 01, 11, 10`，可上下左右跨邊 |

### 圈選規則整理

| 規則 | 正確觀念 | 常見錯誤 |
|---|---|---|
| 圈選數量 | 只能圈 `1, 2, 4, 8, 16...` 格 | 圈 3 格、6 格或 12 格 |
| 圈選形狀 | 必須是長方形或正方形 | 圈成 L 形、斜線形 |
| 圈選大小 | 優先圈最大群組 | 明明可圈 8 格卻只圈 4 格 |
| 圈選重疊 | 可以重疊 | 誤以為每個 `1` 只能圈一次 |
| 邊界關係 | 可以跨左右邊、上下邊 | 誤以為表格邊界不能相鄰 |
| Don't care | 可用可不用，以最簡為準 | 把所有 `X` 都硬圈，或完全不考慮 `X` |

### 從圈選寫出項目的判斷表

| 圈內變數狀態 | 寫法 |
|---|---|
| 變數固定為 `1` | 寫原變數，例如 `A` |
| 變數固定為 `0` | 寫反變數，例如 `A'` |
| 變數有 `0` 也有 `1` | 不寫，表示被消去 |

### 容易混淆：卡諾圖欄列順序

很多新手會把 4 變數欄位排成 `00, 01, 10, 11`，這是錯的。卡諾圖使用格雷碼，正確順序是：

```text
00, 01, 11, 10
```

原因是相鄰兩欄只能差一個位元。`01` 到 `11` 只差第一個位元，但 `01` 到 `10` 差兩個位元，所以不能在卡諾圖中直接相鄰。

## 國考答題句

遇到卡諾圖化簡題，可以用下面句型作答。

「先依最小項將 `1` 填入卡諾圖，欄列採格雷碼順序。將相鄰的 `1` 以 `2` 的冪次方數量圈選，且盡量形成最大圈；圈選可重疊、可跨邊，Don't care 視是否能幫助化簡而使用。每一圈只保留不變的變數，變動的變數消去，最後將各圈所得乘積項相加。」

若題目問 Don't care，可寫：

「Don't care 可視為 `1` 參與圈選，也可不使用；是否使用以能否形成更大圈、得到更簡化結果為判斷標準。」

若題目問為何可跨邊，可寫：

「卡諾圖採格雷碼排列，最左與最右、最上與最下也只差一個變數，因此視為相鄰，可跨邊圈選。」

## 容易考的判斷題

1. 卡諾圖中可以圈 3 個相鄰的 `1`。  
   錯。圈選數量必須是 `2` 的冪次方，所以可圈 `1, 2, 4, 8...` 格，不能圈 3 格。

2. 卡諾圖圈選時可以跨越邊界。  
   對。最左欄與最右欄相鄰，最上列與最下列也相鄰。

3. 卡諾圖圈選時每個 `1` 只能被圈一次。  
   錯。圈選可以重疊，只要有助於形成更大的圈或更簡的式子即可。

4. Don't care 一定要全部圈進去。  
   錯。Don't care 可用可不用，使用標準是能否讓化簡結果更簡。

5. 4 變數卡諾圖的欄位可以排成 `00, 01, 10, 11`。  
   錯。卡諾圖欄列要用格雷碼順序，應為 `00, 01, 11, 10`。

6. 若一圈內某變數有時為 `0`、有時為 `1`，該變數在化簡項中要消去。  
   對。只有在整個圈內固定不變的變數才保留。

7. 圈越大，通常化簡後的項越簡。  
   對。圈越大，能消去的變數越多。

8. 斜對角的兩格若都是 `1`，就可以直接圈成一組。  
   錯。卡諾圖的相鄰是上下左右，不包含斜對角。

## 考前速記小抄

卡諾圖的本質是把真值表排成方便合併的圖。看到題目先確認變數數量：2 變數 `4` 格、3 變數 `8` 格、4 變數 `16` 格。

欄列順序要背：有兩個變數放在同一邊時，順序一定是：

```text
00, 01, 11, 10
```

圈選口訣：

```text
圈 1 要全蓋，
數量 2 次方；
可重疊、可跨邊，
能圈大就圈大；
X 可用可不用，
變的消去，不變留下。
```

由圈寫式子的口訣：

```text
固定 1：寫原變數
固定 0：寫反變數
有變化：不寫
```

最常見錯誤要避開：

```text
不能圈 3 格
不能圈 L 形
不能斜著圈
不要忘記跨邊
不要把格雷碼排成一般二進位
Don't care 不必全部使用
```

考試最後檢查三件事：第一，每個 `1` 是否至少被圈到一次；第二，有沒有更大的圈可用；第三，圈內變數是否只留下不變者。這三點檢查完，卡諾圖題通常就能穩定拿分。
