# 卡諾圖化簡

## 先抓重點

卡諾圖是把真值表重新排成方格，幫你快速看出哪些項可以合併。

核心口訣：

```text
把相鄰的 1 盡量圈大。
圈完只留下不變的變數。
有變化的變數消掉。
```

國考最常考：

1. 格雷碼順序。
2. 圈選數量必須是 `2` 的冪次方。
3. 可以跨邊、可以重疊。
4. Don't care 可用可不用。
5. 從圈選寫出最簡 SOP。

## 必懂名詞

| 名詞 | 新手理解 |
|---|---|
| 卡諾圖 | 把真值表排成方便合併的方格圖 |
| 最小項 | 真值表中的某一列，常用 `m0`、`m1` 表示 |
| `Σm(...)` | 括號內列號要在卡諾圖填 `1` |
| Don't care | 可當 `1` 幫忙圈，也可不用，常寫 `X` 或 `d` |
| 相鄰格 | 上下左右相鄰，不含斜角 |
| 格雷碼 | 相鄰標籤只差一個位元的排序 |
| 跨邊 | 最左和最右相鄰，最上和最下相鄰 |
| 重疊 | 同一個 `1` 可以被多個圈使用 |

## 格數與排列

| 變數數量 | 格數 | 常見安排 | 必背 |
|---:|---:|---|---|
| 2 | 4 | `A` 當列，`B` 當欄 | 基本相鄰合併 |
| 3 | 8 | `A` 當列，`BC` 當欄 | 欄位用 `00, 01, 11, 10` |
| 4 | 16 | `AB` 當列，`CD` 當欄 | 列與欄都用 `00, 01, 11, 10` |

格雷碼順序一定要背：

```text
00, 01, 11, 10
```

不能排成：

```text
00, 01, 10, 11
```

原因是卡諾圖要求相鄰格只差一個變數。

## 圈選規則

| 規則 | 說明 |
|---|---|
| 只圈 `1` | Don't care 可視需要一起圈 |
| 圈數量 | 只能圈 `1, 2, 4, 8, 16...` 格 |
| 圈形狀 | 必須是長方形或正方形 |
| 盡量圈大 | 圈越大，化簡後變數越少 |
| 可重疊 | 有助於更大圈時可以重複使用同一格 |
| 可跨邊 | 左右邊、上下邊視為相鄰 |
| 全部覆蓋 | 每個 `1` 至少要被圈到一次 |
| Don't care | 能讓圈變大才用，不必全部使用 |

不能做：

```text
圈 3 格
圈 6 格
圈 L 形
斜角相鄰
忘記跨邊
```

## 從圈寫出布林式

每一圈會變成一個積項。判斷方式如下：

| 圈內某變數狀態 | 寫法 |
|---|---|
| 全部固定為 `1` | 寫原變數，例如 `A` |
| 全部固定為 `0` | 寫反變數，例如 `A'` |
| 有 `0` 也有 `1` | 不寫，代表被消掉 |

最後把每一圈得到的積項用 `+` 加起來。

## 例題 1：2 變數

題目：

```text
F(A,B) = Σm(1,3)
```

2 變數卡諾圖：

```text
      B
      0   1
A 0   0  [1]
  1   0  [1]
```

右邊兩格可以圈成一組。

這一圈中：

- `A` 有 `0` 也有 `1`，消掉。
- `B` 都是 `1`，留下 `B`。

答案：

```text
F = B
```

## 例題 2：3 變數，圈成 4 格

題目：

```text
F(A,B,C) = Σm(0,1,2,3)
```

3 變數卡諾圖，欄位要用格雷碼：

```text
          BC
          00  01  11  10
A = 0    [1] [1] [1] [1]
A = 1     0   0   0   0
```

上排四格圈成一組。

這一圈中：

- `A` 都是 `0`，留下 `A'`。
- `B` 有變化，消掉。
- `C` 有變化，消掉。

答案：

```text
F = A'
```

## 例題 3：跨邊圈選

題目：

```text
F(A,B,C) = Σm(0,2,4,6)
```

```text
          BC
          00  01  11  10
A = 0    [1]  0   0  [1]
A = 1    [1]  0   0  [1]
```

最左欄 `00` 和最右欄 `10` 可以跨邊相鄰，所以四個 `1` 可圈成一組。

這一圈中：

- `A` 有變化，消掉。
- `B` 有變化，消掉。
- `C` 都是 `0`，留下 `C'`。

答案：

```text
F = C'
```

## 例題 4：Don't care

題目：

```text
F(A,B,C) = Σm(1,3,5) + d(7)
```

`d(7)` 是 Don't care，可用可不用。

```text
          BC
          00  01  11  10
A = 0     0  [1] [1]  0
A = 1     0  [1]  X   0
```

如果把 `X` 當 `1`，中間四格可圈成一組。

這一圈中：

- `A` 有變化，消掉。
- `B` 有變化，消掉。
- `C` 都是 `1`，留下 `C`。

答案：

```text
F = C
```

重點：Don't care 不是一定要用。只有能讓圈更大、式子更簡時才用。

## 例題 5：4 變數重點圖

4 變數常用：

```text
             CD
             00  01  11  10
AB = 00      m0  m1  m3  m2
AB = 01      m4  m5  m7  m6
AB = 11      m12 m13 m15 m14
AB = 10      m8  m9  m11 m10
```

注意：

- 列也是格雷碼。
- 欄也是格雷碼。
- 四個角落可以一起跨邊形成一圈。
- 最上列和最下列相鄰。
- 最左欄和最右欄相鄰。

## 國考常考

| 題型 | 解法 |
|---|---|
| 給 `Σm(...)` | 把指定最小項填 `1` |
| 給 Don't care | 把 `d(...)` 填 `X`，看能否幫忙圈大 |
| 問可否圈 3 格 | 不行，必須是 `2` 的冪次方 |
| 問可否跨邊 | 可以 |
| 問可否重疊 | 可以 |
| 從圈寫式子 | 只留下固定不變的變數 |
| 4 變數位置 | 用 `00, 01, 11, 10` 排列 |

## 易錯整理

### 1. 不要把格雷碼排錯

正確：

```text
00, 01, 11, 10
```

錯誤：

```text
00, 01, 10, 11
```

### 2. 圈越大通常越好

能圈 `8` 格，就不要只圈 `4` 格。
能圈 `4` 格，就不要只圈 `2` 格。

圈越大，代表消掉的變數越多。

### 3. Don't care 不必全部圈

使用標準只有一個：

```text
能不能讓結果更簡
```

能幫忙就用，不能幫忙就不管。

### 4. 每個 `1` 至少要被圈到一次

Don't care 可以沒被圈。
但真正的 `1` 不能漏掉。

## 考前速記

```text
2 變數 -> 4 格
3 變數 -> 8 格
4 變數 -> 16 格
```

```text
格雷碼：00, 01, 11, 10
```

```text
圈選：
1, 2, 4, 8, 16 格
可重疊
可跨邊
不能 L 形
不能斜角
```

```text
固定 1 -> 寫原變數
固定 0 -> 寫反變數
有變化 -> 消掉不寫
```

最後檢查：

1. 每個 `1` 是否都被圈到。
2. 是否有更大的圈可以用。
3. 是否忘記跨邊。
4. Don't care 是否只在有幫助時使用。
5. 圈內變數是否只留下不變者。
