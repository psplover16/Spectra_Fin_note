# 萬用閘

## 先抓重點

萬用閘的意思是：

```text
只用同一種邏輯閘，就能做出 NOT、AND、OR。
```

只要能做出 `NOT`、`AND`、`OR`，就能組合出其他布林邏輯。

國考要直接記：

```text
NAND 是萬用閘。
NOR 也是萬用閘。
```

AND、OR、NOT 單獨通常不稱為萬用閘。

## 必懂名詞

| 名詞 | 新手理解 |
|---|---|
| NAND | AND 後反相，`A NAND B = (AB)'` |
| NOR | OR 後反相，`A NOR B = (A+B)'` |
| 萬用閘 | 只靠同一種閘，可做出所有基本邏輯 |
| 輸入短接 | 把同一訊號接到同一閘的兩個輸入 |
| 德摩根定理 | 把 AND/OR 互換並反相，是轉換 OR/AND 的關鍵 |

## NAND 與 NOR 比較

| 項目 | NAND | NOR |
|---|---|---|
| 公式 | `(AB)'` | `(A+B)'` |
| 直覺 | AND 後反相 | OR 後反相 |
| 何時輸出 `0` | A、B 都是 `1` | A 或 B 至少一個是 `1` |
| 何時輸出 `1` | 不是全 `1` | A、B 都是 `0` |
| 是否萬用 | 是 | 是 |
| 做 NOT | `A NAND A` | `A NOR A` |

## 最重要：同輸入做 NOT

NAND 做 NOT：

```text
A NAND A = (A · A)' = A'
```

NOR 做 NOT：

```text
A NOR A = (A + A)' = A'
```

新手記法：

```text
同一個輸入接兩端，就是反相。
```

## 只用 NAND 做基本邏輯

NAND 的基本式：

```text
A NAND B = (AB)'
```

| 要做的邏輯 | NAND 組法 | 常見需要幾個 |
|---|---|---:|
| NOT A | `A NAND A` | 1 |
| A AND B | `(A NAND B) NAND (A NAND B)` | 2 |
| A OR B | `(A NAND A) NAND (B NAND B)` | 3 |
| A XOR B | 4 個 NAND 的標準組合 | 4 |

### NAND 做 AND

先 NAND 得到 AND 的反相，再反相一次：

```text
X = A NAND B = (AB)'
Y = X NAND X = AB
```

合在一起：

```text
Y = (A NAND B) NAND (A NAND B)
```

### NAND 做 OR

用德摩根：

```text
A + B = (A'B')'
```

先把 A、B 各自反相，再送進 NAND：

```text
Y = (A NAND A) NAND (B NAND B)
```

### NAND 做 XOR

常見 4 個 NAND：

```text
N1 = A NAND B
N2 = A NAND N1
N3 = B NAND N1
Y  = N2 NAND N3
```

國考若只問能不能做，答案是可以。若問常見組法，可記 4 個 NAND。

## 只用 NOR 做基本邏輯

NOR 的基本式：

```text
A NOR B = (A+B)'
```

| 要做的邏輯 | NOR 組法 | 常見需要幾個 |
|---|---|---:|
| NOT A | `A NOR A` | 1 |
| A OR B | `(A NOR B) NOR (A NOR B)` | 2 |
| A AND B | `(A NOR A) NOR (B NOR B)` | 3 |
| A XOR B | 可先做 XNOR 再反相 | 常見 5 |

### NOR 做 OR

先 NOR 得到 OR 的反相，再反相一次：

```text
X = A NOR B = (A+B)'
Y = X NOR X = A+B
```

合在一起：

```text
Y = (A NOR B) NOR (A NOR B)
```

### NOR 做 AND

用德摩根：

```text
AB = (A' + B')'
```

先把 A、B 各自反相，再送進 NOR：

```text
Y = (A NOR A) NOR (B NOR B)
```

### NOR 做 XOR

NOR 也能做 XOR，因為 NOR 是萬用閘。
常見理解是先做出 XNOR，再反相成 XOR。

一組常見寫法：

```text
N1 = A NOR B
N2 = A NOR N1
N3 = B NOR N1
N4 = N2 NOR N3
Y  = N4 NOR N4
```

## 為什麼 NAND/NOR 是萬用閘

只要能做出下面三個，就能完成一般布林邏輯：

```text
NOT
AND
OR
```

NAND 可以做：

- NOT：`A NAND A`
- AND：NAND 後再反相
- OR：先反相 A、B，再 NAND

NOR 可以做：

- NOT：`A NOR A`
- OR：NOR 後再反相
- AND：先反相 A、B，再 NOR

所以兩者都是萬用閘。

## 國考常考

| 題型 | 答案方向 |
|---|---|
| 哪些是萬用閘 | NAND、NOR |
| NAND 做 NOT | `A NAND A` |
| NOR 做 NOT | `A NOR A` |
| NAND 做 AND | `(A NAND B) NAND (A NAND B)` |
| NOR 做 OR | `(A NOR B) NOR (A NOR B)` |
| NAND 做 OR | `(A NAND A) NAND (B NAND B)` |
| NOR 做 AND | `(A NOR A) NOR (B NOR B)` |
| XOR 能不能用 NAND/NOR 做 | 可以，因為它們是萬用閘 |

## 易錯整理

### 1. NAND 比較接近 AND

NAND 本來就是：

```text
(AB)'
```

所以 NAND 做 AND 只要再反相一次，需要 2 個 NAND。

### 2. NOR 比較接近 OR

NOR 本來就是：

```text
(A+B)'
```

所以 NOR 做 OR 只要再反相一次，需要 2 個 NOR。

### 3. 比較遠的邏輯要靠德摩根

NAND 做 OR：

```text
A+B = (A'B')'
```

NOR 做 AND：

```text
AB = (A'+B')'
```

### 4. NOT 只要 1 個閘

不要誤以為反相一定要另外找 NOT 閘。
在 NAND/NOR 系統裡，同輸入就能做反相。

## 考前速記

```text
萬用閘：NAND、NOR
```

```text
NAND:
NOT = A NAND A
AND = (A NAND B) NAND (A NAND B)
OR  = (A NAND A) NAND (B NAND B)
```

```text
NOR:
NOT = A NOR A
OR  = (A NOR B) NOR (A NOR B)
AND = (A NOR A) NOR (B NOR B)
```

口訣：

```text
同腳相接變 NOT。
NAND 近 AND。
NOR 近 OR。
遠的那個靠德摩根。
```

最後檢查：

1. 題目要求只用 NAND 還是只用 NOR。
2. 有沒有把 NAND/NOR 的反相忘掉。
3. 做 NOT 時是不是把同一個輸入接到兩端。
4. NAND 做 OR、NOR 做 AND 是否套到德摩根。
