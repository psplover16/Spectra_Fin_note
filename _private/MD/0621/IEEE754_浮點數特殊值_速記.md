# IEEE 754 浮點數特殊值・速記版

> 判斷只看兩件事:**① 指數欄位是不是全 0 / 全 1 ② 尾數是不是 0**

---

## ★ 核心判讀表(背這張就夠)

| 指數欄位 | 尾數(mantissa) | 代表 | 隱藏位元 |
|---|---|---|---|
| **全 0** | 全 0 | **±0** | — |
| **全 0** | ≠ 0 | **非正規化數**(denormal/subnormal) | **0** |
| 介於兩者之間 | 任意 | **正規化數**(一般的數) | **1** |
| **全 1** | 全 0 | **±∞ 無限大** | — |
| **全 1** | ≠ 0 | **NaN**(不是數) | — |

> 「介於兩者之間」= 單精度 1~254、雙精度 1~2046。

---

## ★ 記憶法(兩端 × 尾數)

- **指數全 0 → 最小那一端**:尾數 0 → **±0**;尾數 ≠ 0 → **denormal**
- **指數全 1 → 壞掉/超出那一端**:尾數 0 → **±∞**;尾數 ≠ 0 → **NaN**

---

## ★ 各特殊值重點

- **±0**:有符號位 → 有 +0 與 −0。兩者相等,但 1÷(+0)=+∞、1÷(−0)=−∞。
- **±∞**:溢位或除以 0 時出現(例:1.0 ÷ 0.0 = +∞)。
- **NaN**:無意義運算的結果(0÷0、∞−∞、∞÷∞、√(−1))。性質:**NaN ≠ 任何值,連自己都不等於**(NaN == NaN 為 false)。
- **非正規化數**:隱藏位元變 **0**,值 = `0.尾數 × 2^(−126)`(單精度)。用途:填補 0 與最小正規化數之間的縫隙(gradual underflow)。
- **正規化數**:隱藏位元固定為 **1**,值 = `1.尾數 × 2^(指數−bias)`。

---

## ★ 位元範例(單精度 32 位元)

```
+0  :  0 00000000 00000000000000000000000
−0  :  1 00000000 00000000000000000000000
+∞  :  0 11111111 00000000000000000000000
−∞  :  1 11111111 00000000000000000000000
NaN :  x 11111111 (尾數任一位為 1)
```

---

## ★ 單精度 vs 雙精度(規則相同,只是欄位寬度不同)

| | 符號 | 指數 | 尾數 | bias | 「指數全 1」= |
|---|---|---|---|---|---|
| 單精度 (32-bit) | 1 | 8 | 23 | 127 | 255 |
| 雙精度 (64-bit) | 1 | 11 | 52 | 1023 | 2047 |

> 特殊值的判斷規則完全一樣,差別只在「全 0 / 全 1」的位數。

---

## ★ 考試最愛考的對比(易混點)

1. **∞ vs NaN**:都「指數全 1」,差在尾數 → 尾數 0 是 **∞**、尾數 ≠ 0 是 **NaN**。
2. **±0 vs denormal**:都「指數全 0」,差在尾數 → 尾數 0 是 **±0**、尾數 ≠ 0 是 **denormal**。
3. **NaN ≠ NaN**(連自己都不相等)。
4. **隱藏位元**:正規化 = **1**、非正規化 = **0**。
