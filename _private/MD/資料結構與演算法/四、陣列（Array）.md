## 陣列是什麼

陣列（Array）是一種把多個相同型別資料放在一起的資料結構。你可以把它想成一排連續編號的置物格，每一格放一個元素（Element），而每一格的位置用索引（Index）表示。

元素（Element）是陣列中實際存放的資料，例如整數、字元或物件。索引（Index）是用來指出元素位置的編號，例如 `A[0]`、`A[1]`、`A[2]`。在很多程式語言中，陣列索引從 `0` 開始，但在考題中也可能指定從 `1` 或其他數字開始，所以一定要看清楚題目給的下界（Lower Bound）。

下界（Lower Bound）是陣列第一個合法索引值。若題目說 `A[1..10]`，代表下界是 `1`；若題目說 `A[0..9]`，代表下界是 `0`。國考很喜歡利用下界設陷阱，因為位址計算時不能直接把索引乘上元素大小，必須先扣掉下界。

## 陣列的重要組成

陣列通常可以從四個角度理解。

1. 基底位址（Base Address）

   基底位址（Base Address）是陣列第一個元素在記憶體中的起始位置。若陣列 `A` 的第一個元素從記憶體位址 `1000` 開始，則 `Base(A)` 可以理解為 `1000`。

2. 索引（Index）

   索引（Index）是用來指定元素位置的編號。陣列透過索引找到特定元素，例如 `A[i]` 代表陣列 `A` 中索引為 `i` 的元素。

3. 元素大小（Element Size）

   元素大小（Element Size）是每個元素占用的記憶體空間。例如整數可能占 `4` bytes，字元可能占 `1` byte。因為陣列元素型別相同，所以每個元素大小通常固定。

4. 連續記憶體（Contiguous Memory）

   連續記憶體（Contiguous Memory）是指陣列元素在記憶體中一個接一個排列，中間沒有被其他資料打斷。這是陣列能快速存取資料的關鍵。

## 陣列的核心特色

陣列最重要的特色是支援隨機存取（Random Access）。隨機存取（Random Access）是指不必從第一個元素一路找過去，而是可以直接用索引算出某個元素的位置。

例如你想存取 `A[5]`，電腦不需要先看 `A[0]`、`A[1]`、`A[2]`，而是直接利用基底位址、索引、下界與元素大小算出 `A[5]` 的記憶體位置。因為這個計算步驟固定，所以陣列存取任一元素的時間複雜度（Time Complexity）是 `O(1)`。

時間複雜度（Time Complexity）是用來描述演算法執行時間隨資料量增加而成長的程度。`O(1)` 稱為常數時間（Constant Time），意思是不管陣列有 `10` 個元素或 `100000` 個元素，只要索引合法，直接存取某一格所需時間都可以視為固定。

不過，陣列的快是快在「已知索引時的存取」。如果題目問的是「尋找某個值」，而陣列沒有排序，也沒有其他輔助資訊，就可能必須從頭掃到尾，這時搜尋（Search）的時間複雜度通常是 `O(n)`。

## 陣列的插入與刪除

插入（Insertion）是把新元素放進資料結構中。刪除（Deletion）是把既有元素從資料結構中移除。陣列在插入與刪除時常常需要搬移元素，這是國考很常考的觀念。

假設陣列目前是：

```text
索引： 0   1   2   3
內容： 10  20  30  40
```

如果要在索引 `1` 插入 `15`，原本的 `20`、`30`、`40` 都要往右移，才能空出位置：

```text
插入後：
索引： 0   1   2   3   4
內容： 10  15  20  30  40
```

如果要刪除索引 `1` 的 `20`，原本後面的 `30`、`40` 要往左移，避免中間留下空洞：

```text
刪除後：
索引： 0   1   2
內容： 10  30  40
```

因此，陣列在中間插入或刪除元素時，最壞情況可能要搬移很多元素，時間複雜度通常是 `O(n)`。這裡的 `n` 代表陣列中的元素數量。

要特別注意，若是在陣列最後方新增元素，而且陣列仍有空間，可能可以做到 `O(1)`；但國考若問「一般陣列插入或刪除」通常要回答可能需要搬移元素，因此是 `O(n)`。

## 陣列的位址計算

位址計算是陣列最常見的計算題。重點不是死背符號，而是理解「先算出距離第一格有幾格，再乘上每格大小，最後加上基底位址」。

### 一維陣列（One-dimensional Array）

一維陣列（One-dimensional Array）是只有一個索引方向的陣列，例如 `A[i]`。

一維陣列的位址公式是：

```text
LOC(A[i]) = Base(A) + (i - lower_bound) * element_size
```

其中，`LOC(A[i])` 是 `A[i]` 的記憶體位址，`Base(A)` 是基底位址，`i` 是要存取的索引，`lower_bound` 是下界，`element_size` 是每個元素大小。

例題：假設陣列 `A[1..10]` 的基底位址是 `1000`，每個元素占 `4` bytes，求 `A[6]` 的位址。

```text
LOC(A[6]) = 1000 + (6 - 1) * 4
          = 1000 + 5 * 4
          = 1020
```

這題不能算成 `1000 + 6 * 4`，因為下界是 `1`，`A[6]` 距離第一格 `A[1]` 其實只有 `5` 格。

### 二維陣列（Two-dimensional Array）

二維陣列（Two-dimensional Array）是有列與欄兩個索引方向的陣列，例如 `A[i][j]`。列（Row）通常代表橫向一排資料，欄（Column）通常代表直向一排資料。

二維陣列雖然看起來像表格，但記憶體本質上仍是一條線，所以必須決定要用哪一種順序攤平成一維來存放。常見方式有列優先順序（Row-major Order）與欄優先順序（Column-major Order）。

列優先順序（Row-major Order）是先放完同一列的所有欄，再放下一列。常見於 C、C++、Java 等語言的二維陣列概念。

欄優先順序（Column-major Order）是先放完同一欄的所有列，再放下一欄。常見於 Fortran 或部分數學運算環境。

### 二維陣列列優先順序（Row-major Order）

列優先順序的位址公式是：

```text
LOC(A[i][j]) =
Base + [(i - row_lower) * number_of_columns + (j - column_lower)] * element_size
```

這個公式可以拆成兩步看：

1. `(i - row_lower) * number_of_columns`：先算前面已經跳過幾列，每列有幾欄。
2. `(j - column_lower)`：再算同一列內往右移幾格。

例題：假設二維陣列 `A[1..3][1..4]` 採列優先順序，基底位址是 `2000`，每個元素占 `2` bytes，求 `A[3][2]` 的位址。

```text
row_lower = 1
column_lower = 1
number_of_columns = 4

LOC(A[3][2]) = 2000 + [(3 - 1) * 4 + (2 - 1)] * 2
             = 2000 + [2 * 4 + 1] * 2
             = 2000 + 9 * 2
             = 2018
```

列優先順序的核心是：先看前面有幾整列，再看目前這列內偏移幾格。

### 二維陣列欄優先順序（Column-major Order）

欄優先順序的位址公式是：

```text
LOC(A[i][j]) =
Base + [(j - column_lower) * number_of_rows + (i - row_lower)] * element_size
```

這個公式也可以拆成兩步看：

1. `(j - column_lower) * number_of_rows`：先算前面已經跳過幾欄，每欄有幾列。
2. `(i - row_lower)`：再算同一欄內往下移幾格。

例題：同樣假設二維陣列 `A[1..3][1..4]` 採欄優先順序，基底位址是 `2000`，每個元素占 `2` bytes，求 `A[3][2]` 的位址。

```text
row_lower = 1
column_lower = 1
number_of_rows = 3

LOC(A[3][2]) = 2000 + [(2 - 1) * 3 + (3 - 1)] * 2
             = 2000 + [1 * 3 + 2] * 2
             = 2000 + 5 * 2
             = 2010
```

同一個 `A[3][2]`，在列優先與欄優先下可能得到不同位址，原因是記憶體排列順序不同。

## 國考常見考法

國考考陣列時，通常不是只問定義，而是把觀念藏在題目敘述中。

1. 考陣列存取時間

   題目可能問「陣列存取第 `i` 個元素的時間複雜度為何？」答案通常是 `O(1)`，因為陣列支援隨機存取。

2. 考插入與刪除時間

   題目可能問「在陣列中間插入一筆資料，最壞情況時間複雜度為何？」答案通常是 `O(n)`，因為需要搬移後面的元素。

3. 考一維陣列位址

   題目會給基底位址、索引範圍、元素大小，要求算 `LOC(A[i])`。這類題最容易錯在忘記扣下界。

4. 考二維陣列位址

   題目會指定列優先或欄優先，再給列數、欄數、上下界與元素大小。這類題最容易錯在把列數與欄數放錯位置。

5. 考列優先與欄優先差異

   題目可能問哪一種排列方式會先儲存同一列，或哪一種公式要乘上欄數。列優先乘欄數，欄優先乘列數，這是必背重點。

## 易混淆比較表

| 概念 | 定義 | 常見考點 |
|---|---|---|
| 隨機存取（Random Access） | 用索引直接算出元素位置 | 已知索引存取是 `O(1)` |
| 循序搜尋（Sequential Search） | 從頭到尾逐一檢查元素 | 未排序陣列找特定值通常是 `O(n)` |
| 插入（Insertion） | 加入新元素 | 中間插入通常要搬移，為 `O(n)` |
| 刪除（Deletion） | 移除既有元素 | 中間刪除通常要搬移，為 `O(n)` |
| 列優先順序（Row-major Order） | 同一列先連續存放 | 位址公式中先乘欄數 |
| 欄優先順序（Column-major Order） | 同一欄先連續存放 | 位址公式中先乘列數 |

## 國考必背整理

- 陣列（Array）使用連續記憶體（Contiguous Memory）配置。
- 陣列用索引（Index）存取元素，已知索引時支援 `O(1)` 隨機存取（Random Access）。
- 陣列在中間插入（Insertion）或刪除（Deletion）元素時，通常需要搬移元素，時間複雜度為 `O(n)`。
- 一維陣列（One-dimensional Array）位址公式：

```text
LOC(A[i]) = Base(A) + (i - lower_bound) * element_size
```

- 二維陣列（Two-dimensional Array）列優先順序（Row-major Order）位址公式：

```text
LOC(A[i][j]) =
Base + [(i - row_lower) * number_of_columns + (j - column_lower)] * element_size
```

- 二維陣列（Two-dimensional Array）欄優先順序（Column-major Order）位址公式：

```text
LOC(A[i][j]) =
Base + [(j - column_lower) * number_of_rows + (i - row_lower)] * element_size
```

## 容易考的判斷題

1. 陣列中的元素通常存放在連續記憶體中。

   正確。這也是陣列能用索引快速計算位址的原因。

2. 陣列存取任意索引元素一定是 `O(n)`。

   錯誤。若索引合法且已知，陣列支援 `O(1)` 隨機存取。

3. 在陣列中間插入元素，最壞情況可能需要搬移許多元素。

   正確。因為後方元素可能都要往後移一格。

4. 一維陣列位址計算時，只要用索引乘上元素大小即可。

   錯誤。還要考慮下界（Lower Bound），正確偏移量是 `i - lower_bound`。

5. 列優先順序的二維陣列位址公式會用到欄數。

   正確。列優先是先跳過前面的整列，因此要乘上每列的欄數。

6. 欄優先順序的二維陣列位址公式會用到列數。

   正確。欄優先是先跳過前面的整欄，因此要乘上每欄的列數。

## 考前速記小抄

陣列（Array）的三個核心關鍵是連續記憶體（Contiguous Memory）、索引（Index）、隨機存取（Random Access）。看到「已知第幾個位置」就想到 `O(1)`；看到「中間插入或刪除」就想到搬移元素與 `O(n)`。

位址計算先記一個原則：先算偏移幾格，再乘每格大小，最後加上基底位址。

一維陣列要扣下界：

```text
(i - lower_bound)
```

二維陣列要先判斷排列方式：

```text
列優先：先列後欄，乘欄數
欄優先：先欄後列，乘列數
```

最後記住一句話：列優先順序（Row-major Order）看「前面有幾列」，欄優先順序（Column-major Order）看「前面有幾欄」。這句話通常可以幫你把公式放對位置。
