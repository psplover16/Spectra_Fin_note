# 資料結構與演算法 8：雜湊 Hashing

> 科目：資料結構與演算法（最後一篇）
> 學習方式：概念屬【理解】；**碰撞處理的位置計算**屬【練流程】。

---

## 一、雜湊是什麼 + 核心想法　【理解】

- **雜湊法**：用一個**雜湊函數（hash function）**把**鍵值 key** 直接**算出**一個存放位置（索引），存進**雜湊表（hash table）**。
- **核心想法**：不用一個個比對找，而是**「算」出位置** → 理想情況下查找／插入／刪除都是 **O(1)**！
- **例**：表大小 10、函數 `h(key) = key % 10`。
  - 存 25 → `h(25)=5` → 放索引 5。
  - 找 25 → 直接算 `h(25)=5` → 看索引 5，一步到位。

---

## 二、常見雜湊函數　【理解】

| 方法 | 做法 |
|---|---|
| **除法 Division** | `h(k) = k % m`（m 常取**質數**，分布較均勻）← 最常見 |
| **中間平方 Mid-square** | 把 key 平方，取**中間幾位** |
| **折疊 Folding** | 把 key **切段相加** |

> 好的雜湊函數：**算得快 ＋ 分布均勻**（碰撞少）。

---

## 三、碰撞 Collision 與 溢位 Overflow（核心）　【理解】

- **碰撞 Collision**：兩個**不同的鍵**算出**相同位置**（例：`h(17)` 和 `h(24)` 都等於 3）。
- **溢位 Overflow**：要存的位置**已經滿了**，放不下。
- 怎麼處理 → 兩大類：

### A. 開放定址法 Open Addressing（在表內找別的空位）
| 方法 | 找空位的方式 |
|---|---|
| **線性探測 Linear Probing** | 往後**一格一格**找：h, h+1, h+2 …（mod m）。缺點：容易**群聚 clustering** |
| **二次探測 Quadratic Probing** | 間隔用平方：h+1², h+2², h+3² …（減少群聚） |
| **雙重雜湊 Double Hashing** | 用**第二個雜湊函數**決定間隔 |

### B. 鏈結法 Chaining（每格接一條串列）
每個位置接一個**鏈結串列**，碰撞的鍵都**掛在同一格的串列上**。
- 優：**不會溢位**（串列可一直接）、刪除簡單。
- 缺：需額外指標空間；最差查找 O(n)（全擠同一條）。

---

## 四、手把手：兩種處理法對照　【練流程】

表大小 **m = 7**，`h(k) = k % 7`，依序插入 **10、17、24、3**（這四個都 % 7 ＝ 3，狂碰撞）：

**線性探測**（往後找空位）：
```
索引:  0   1   2   3    4    5    6
      [ ] [ ] [ ] [10] [17] [24] [3]
                   ↑    ↑    ↑    ↑
                  原位  +1   +2   +3   ← 後三個被擠到後面
```

**鏈結法**（同一格串起來）：
```
索引3： → 10 → 17 → 24 → 3      （其他索引皆空）
```

> 算式：10%7=3、17%7=3、24%7=3、3%7=3，全部撞在索引 3。

---

## 五、補充：載入因子 + 複雜度　【理解】

- **載入因子 Load Factor `α = n / m`**（已存數 ÷ 表大小）。**α 越大、碰撞越多、越慢**；開放定址法 α 必須 ≤ 1。
- **時間複雜度**：理想（無碰撞）**O(1)**；最差（全碰撞）**O(n)**。

---

## 六、重點整理（背這張）

- 雜湊：用**函數算出位置**，理想 **O(1)**；最常用 `h(k)=k%m`（m 取質數）。
- **碰撞**＝不同鍵算到同位置；**溢位**＝位置滿了。
- 處理兩大類：
  - **開放定址**（表內找空位）：**線性探測**（往後一格，易群聚）、二次探測、雙重雜湊。
  - **鏈結法**（每格接串列）：不溢位、刪除易，最差 O(n)。
- **載入因子 α＝n/m**，越大越慢；理想 O(1)、最差 O(n)。
