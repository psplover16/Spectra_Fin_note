## 一、圖 Graph 定義與術語　【理解】＋【硬背】

- **圖 G ＝ (V, E)**：由**頂點 Vertex（V）**和**邊 Edge（E）**組成，表示頂點間「**多對多**」的關係（比樹更一般，**可以有環**）。

| 術語 | 意思 |
|---|---|
| **有向圖 Directed** | 邊**有方向**（箭頭，A→B） |
| **無向圖 Undirected** | 邊**無方向**（A—B 雙向） |
| **權重圖 Weighted** | 邊上有**權重／成本**（如距離、花費） |
| **度數 Degree** | 一個頂點**連幾條邊**；有向圖分**入度／出度** |
| **路徑 Path** | 一連串相連的頂點 |
| **環／迴路 Cycle** | 繞回起點的路徑 |
| **連通 Connected** | 任兩頂點都有路徑相連 |
| **完全圖 Complete** | 每兩頂點都有邊；n 頂點無向完全圖有 **n(n−1)/2** 條邊 |

## 二、圖的兩種表示法　【理解】

| | 鄰接矩陣 Adjacency Matrix | 鄰接串列 Adjacency List |
|---|---|---|
| 做法 | n×n 矩陣，`[i][j]=1`（或權重）表示 i→j 有邊 | 每個頂點存一個「鄰居清單」 |
| 空間 | **O(n²)** | **O(V+E)** |
| 查「兩點是否相連」 | **O(1)** 快 | 要掃清單 |
| 適合 | **稠密圖**（邊多） | **稀疏圖**（邊少） |

## 三、DFS vs BFS（走遍圖的兩種方式）　【練流程】★

兩種都是「把圖的頂點走一遍」，差別在**走的順序**：

| | DFS 深度優先 | BFS 廣度優先 |
|---|---|---|
| 策略 | **一條路走到底**，走不通再回頭 | **一層一層擴散**，先訪問所有鄰居 |
| 用的工具 | **堆疊 Stack**（或遞迴） | **佇列 Queue** |
| 像什麼 | 走迷宮硬走到撞牆才回頭 | 水波一圈圈擴散 |

**示範圖**（無向，鄰居按字母順序處理）：
```
    A
   / \
  B   C
 / \   \
D   E───F
```
鄰居表：A:{B,C}　B:{A,D,E}　C:{A,F}　D:{B}　E:{B,F}　F:{C,E}

**DFS 從 A**（一路走到底、回頭）：
- A → B → D（D 走不通，回頭）→ E → F → C
- **DFS 順序：A, B, D, E, F, C**

**BFS 從 A**（用佇列，一層層）：

| 步驟 | 取出（訪問） | 佇列狀態 |
|---|---|---|
| 1 | A | [B, C] |
| 2 | B | [C, D, E] |
| 3 | C | [D, E, F] |
| 4 | D | [E, F] |
| 5 | E | [F] |
| 6 | F | [ ] |

- **BFS 順序：A, B, C, D, E, F**

> 記憶：**DFS 用 Stack（深，往深處鑽）、BFS 用 Queue（廣，一層層）**。

## 四、生成樹 Spanning Tree　【理解】

- **生成樹**：一個**連通圖**的子圖，**包含全部頂點**，但只用**剛好 n−1 條邊**把它們連起來、**且無環**（n ＝ 頂點數）。
- 一張圖可以有很多種生成樹。
- **最小生成樹 MST（Minimum Spanning Tree）**：在**權重圖**中，**總權重最小**的生成樹。

## 五、重點整理（背這張）

- 圖 ＝ (頂點 V, 邊 E)，多對多、可有環；有向／無向、有權／無權。
- 表示法：**鄰接矩陣 O(n²)（稠密、查相連 O(1)）**；**鄰接串列 O(V+E)（稀疏）**。
- **DFS 用 Stack（一路鑽到底再回頭）；BFS 用 Queue（一層層擴散）**。
- DFS／BFS 複雜度：鄰接串列 **O(V+E)**、鄰接矩陣 O(V²)。
- 生成樹：含全部頂點、**n−1 條邊**、無環；權重最小的叫 **MST**。
