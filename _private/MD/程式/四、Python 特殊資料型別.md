## Python 特殊資料型別是什麼

Python 的特殊資料型別，通常是指用來存放「一組資料」的容器型別（Container Type）。容器型別（Container Type）就是可以把多個值集中放在一起管理的資料型別。

在國考中，最常考的四種是：

1. 串列（List）
2. 元組（Tuple）
3. 字典（Dictionary）
4. 集合（Set）

這四種型別最重要的差異，不是語法背起來而已，而是要看懂三個核心判斷：

1. 是否有順序（Ordered）
2. 是否可以修改（Mutable）
3. 是否允許重複資料（Duplicate）

有順序（Ordered）表示資料放進去後，Python 會保留它們的排列位置，可以用索引（Index）取得指定位置的資料。索引（Index）是用來表示資料位置的編號，Python 通常從 `0` 開始算。

可變（Mutable）表示資料建立後，內容還可以被修改，例如新增、刪除或改變元素。不可變（Immutable）則表示建立後不能直接改動內容。

可重複（Duplicate Allowed）表示同一個值可以出現多次；不可重複則表示相同值只會保留一份。

## 串列（List）

串列（List）是 Python 中最常用的資料容器，用來存放一組有順序、可以修改、可以重複的資料。

串列（List）的核心想法是：「我想用一個變數，依照順序存放很多資料，而且之後可能還會修改它。」

例如：

```python
scores = [80, 90, 90, 75]
```

這裡的 `scores` 是一個串列（List），裡面有四個分數。因為串列（List）有順序，所以 `scores[0]` 是 `80`，`scores[1]` 是 `90`。因為串列（List）可重複，所以兩個 `90` 可以同時存在。因為串列（List）可變，所以之後可以修改內容。

例如：

```python
scores[0] = 100
scores.append(60)
```

第一行把第 0 個元素改成 `100`，第二行在串列（List）後面新增 `60`。

國考考串列（List）時，常問它是否有順序、是否可修改、是否可以有重複值。答案是：有序、可變、可重複。

## 元組（Tuple）

元組（Tuple）是有順序、不可修改、可以重複的資料容器。

元組（Tuple）的核心想法是：「我想存放一組有固定順序的資料，而且建立後不希望它被改動。」

例如：

```python
point = (10, 20)
```

這裡的 `point` 是一個元組（Tuple），可以代表一個座標。因為元組（Tuple）有順序，所以 `point[0]` 是 `10`，`point[1]` 是 `20`。

但是元組（Tuple）不可變（Immutable），所以不能像串列（List）那樣直接修改其中某個元素。

例如：

```python
point[0] = 30
```

這種寫法會發生錯誤，因為元組（Tuple）的內容建立後不能直接修改。

要注意，元組（Tuple）雖然不可修改，但它仍然允許重複資料。

例如：

```python
numbers = (1, 1, 2, 3)
```

這是合法的，因為元組（Tuple）可重複。

國考考元組（Tuple）時，最常把它拿來和串列（List）比較。兩者都「有序、可重複」，最大差異是串列（List）可變，元組（Tuple）不可變。

## 字典（Dictionary）

字典（Dictionary）是以鍵值配對（Key-Value Pair）存放資料的容器。鍵值配對（Key-Value Pair）表示每一筆資料都有一個鍵（Key）和一個值（Value）。

鍵（Key）是用來查找資料的名稱或代號；值（Value）是鍵（Key）對應到的實際資料。

例如：

```python
student = {
    "name": "Amy",
    "score": 90
}
```

這裡的 `"name"` 和 `"score"` 是鍵（Key），`"Amy"` 和 `90` 是值（Value）。如果要取得學生姓名，可以用：

```python
student["name"]
```

字典（Dictionary）的核心想法是：「我不想靠第幾個位置找資料，而是想用名稱或代號快速找到對應的值。」

字典（Dictionary）最重要的考點是：鍵（Key）不可重複。如果同一個鍵（Key）出現多次，後面的值通常會覆蓋前面的值。

例如：

```python
data = {
    "score": 80,
    "score": 90
}
```

這時 `"score"` 這個鍵（Key）只會保留一份，最後對應到的值會是 `90`。

不過，字典（Dictionary）的值（Value）可以重複。

例如：

```python
scores = {
    "Amy": 90,
    "Bob": 90
}
```

這是合法的，因為重複的是值（Value），不是鍵（Key）。

國考考字典（Dictionary）時，常見陷阱是問「Dictionary 是否可以重複？」這句話不夠精確。正確說法是：鍵（Key）不可重複，但值（Value）可以重複。

## 集合（Set）

集合（Set）是無順序、不允許重複資料的容器。

集合（Set）的核心想法是：「我只在乎有哪些不同的資料，不在乎排列順序，也不想保留重複值。」

例如：

```python
numbers = {1, 2, 2, 3}
```

集合（Set）會自動去除重複值，所以實際上只會留下 `1`、`2`、`3` 這三個不同元素。

集合（Set）無序（Unordered），表示不能依賴元素的排列位置來取資料。因此，不應該把集合（Set）當成可以用索引（Index）讀取的資料結構。

例如：

```python
numbers[0]
```

這種想法不適合用在集合（Set），因為集合（Set）不保證元素順序。

集合（Set）常用在去除重複資料或判斷某個資料是否存在。

例如：

```python
names = {"Amy", "Bob", "Amy"}
```

最後集合（Set）中只會保留 `"Amy"` 和 `"Bob"`。

國考考集合（Set）時，最常問兩件事：第一，集合（Set）是否有順序；第二，集合（Set）是否允許重複。答案是：無序、不重複。

## 四種資料型別比較表

| 資料型別 | 英文 | 是否有順序 | 是否可修改 | 是否可重複 | 核心特色 |
|---|---|---|---|---|---|
| 串列 | List | 有序 | 可變 | 可重複 | 最常用的一般資料清單 |
| 元組 | Tuple | 有序 | 不可變 | 可重複 | 固定不想被改動的資料組 |
| 字典 | Dictionary | 以鍵查值 | 可變 | 鍵不可重複 | 使用鍵值配對存資料 |
| 集合 | Set | 無序 | 可變 | 不重複 | 自動去除重複元素 |

字典（Dictionary）比較特別，它的重點不是用索引（Index）看第幾個資料，而是用鍵（Key）找值（Value）。所以國考若問字典（Dictionary）的特色，最穩的回答是：鍵值配對（Key-Value Pair），且鍵（Key）不可重複。

## 國考常見考法

國考通常不會只問你語法，更多時候會考「性質判斷」與「資料型別選擇」。

### 考法一：問哪個型別可修改

如果題目問「下列何者建立後不可修改？」通常要想到元組（Tuple）。

串列（List）、字典（Dictionary）、集合（Set）一般都屬於可變（Mutable）容器；元組（Tuple）是不可變（Immutable）容器。

### 考法二：問哪個型別不允許重複

如果題目問「下列何者不允許重複元素？」通常答案是集合（Set）。

但若題目問的是字典（Dictionary），要看清楚它問的是鍵（Key）還是值（Value）。字典（Dictionary）的鍵（Key）不可重複，值（Value）可以重複。

### 考法三：問哪個型別適合用名稱查資料

如果題目出現「姓名對應分數」、「帳號對應密碼」、「代號對應名稱」這種情境，通常適合使用字典（Dictionary）。

例如：

```python
score = {
    "Amy": 95,
    "Bob": 88
}
```

這種資料不是重點在第幾筆，而是重點在用 `"Amy"` 找到 `95`。

### 考法四：問 List 和 Tuple 的差異

串列（List）和元組（Tuple）都可以有順序，也都可以放重複值。最大的差別是：

| 比較項目 | 串列（List） | 元組（Tuple） |
|---|---|---|
| 建立後能否修改 | 可以 | 不可以 |
| 常見符號 | `[]` | `()` |
| 適合情境 | 之後會變動的清單 | 固定不變的資料 |

## 國考必背整理

1. 串列（List）：有序、可變、可重複。
2. 元組（Tuple）：有序、不可變、可重複。
3. 字典（Dictionary）：用鍵值配對（Key-Value Pair）存放資料，鍵（Key）不可重複。
4. 集合（Set）：無序、不重複。
5. 索引（Index）適合用在有序資料，例如串列（List）與元組（Tuple）。
6. 鍵（Key）查找適合用在字典（Dictionary）。
7. 去除重複資料常想到集合（Set）。

## 容易考的判斷題

1. 串列（List）中的元素可以重複。  
   正確。串列（List）有序、可變、可重複。

2. 元組（Tuple）建立後可以直接修改元素。  
   錯誤。元組（Tuple）是不可變（Immutable）。

3. 字典（Dictionary）的鍵（Key）可以重複。  
   錯誤。字典（Dictionary）的鍵（Key）不可重複。

4. 字典（Dictionary）的值（Value）可以重複。  
   正確。限制不可重複的是鍵（Key），不是值（Value）。

5. 集合（Set）會保留重複元素。  
   錯誤。集合（Set）不允許重複元素。

6. 集合（Set）適合用索引（Index）取得第 0 個元素。  
   錯誤。集合（Set）無序，不適合用索引（Index）取第幾個元素。

7. 串列（List）和元組（Tuple）都屬於有序資料型別。  
   正確。兩者都保留資料順序。

## 考前速記小抄

看到 Python 四大特殊資料型別時，可以用這句話記：

> List 會變，Tuple 不變；Dictionary 用 Key 找 Value；Set 不重複也不看順序。

再濃縮成表格：

| 型別 | 一句話記法 |
|---|---|
| 串列（List） | 有順序、可修改、可重複 |
| 元組（Tuple） | 有順序、不可修改、可重複 |
| 字典（Dictionary） | 鍵值配對，鍵不可重複 |
| 集合（Set） | 無順序、不重複 |

考試時遇到選項，先抓關鍵字：

1. 題目說「可修改的清單」：選串列（List）。
2. 題目說「固定不變的一組資料」：選元組（Tuple）。
3. 題目說「用名稱查對應資料」：選字典（Dictionary）。
4. 題目說「去除重複」：選集合（Set）。
