## 指標（Pointer）

指標（Pointer）是一種用來「存放記憶體位址」的變數。一般變數存的是資料本身，例如整數 `10`；指標變數存的不是 `10`，而是某個資料在記憶體中的位置。

在 C 或 C++ 中，指標常和兩個符號一起考：

1. 取址運算子（Address-of Operator）`&`：取得變數的記憶體位址。
2. 解參考運算子（Dereference Operator）`*`：透過指標所存的位址，取出該位址中的資料。

例如：

```c
int x = 10;
int *p = &x;
```

這段程式的意思是：`x` 是一個整數變數，值為 `10`；`p` 是一個指向整數的指標，裡面存放 `x` 的位址。若寫 `*p`，就是沿著 `p` 裡面的位址去看那格記憶體，因此會得到 `10`。

### 指標與陣列（Array）的關係

陣列（Array）是一組連續存放在記憶體中的同型別資料。指標與陣列常一起出題，因為陣列名稱在很多情況下會被視為陣列第一個元素的位址。

例如：

```c
int a[3] = {10, 20, 30};
```

在常見考法中，`a` 可代表 `&a[0]`，也就是第一個元素的位址；`*(a + 1)` 代表往後移一個整數元素的位置，所以值是 `20`。

這裡要注意，指標加一不是單純位址數字加 `1`，而是依照資料型別大小移動。例如 `int *p` 的 `p + 1`，會移到下一個整數的位置。

### 空指標、懸空指標與記憶體洩漏

空指標（Null Pointer）是沒有指向任何有效記憶體位置的指標。它常用來表示「目前沒有指向任何物件」。若對空指標做解參考，通常會造成程式錯誤。

懸空指標（Dangling Pointer）是指向已經失效記憶體的指標。例如某塊動態配置的記憶體已經被釋放，但指標仍然保留原本位址，這時再使用它就很危險。

記憶體洩漏（Memory Leak）是指程式向系統取得記憶體後，使用完卻沒有釋放，導致那塊記憶體無法再被正常回收。長時間執行的程式若持續發生記憶體洩漏，可能會越跑越慢，甚至耗盡記憶體。

### 國考常見考法

國考通常不會只問「指標是什麼」，而會用程式片段測驗你是否看得懂位址、取址與解參考。常見題型包括：判斷 `&x`、`p`、`*p` 的意義；判斷指標與陣列運算後取到哪個元素；判斷空指標、懸空指標與記憶體洩漏的風險。

## 字串相關函式（String Functions）

字串（String）是由多個字元組成的資料。在不同程式語言中，字串的處理方式不完全相同。C 語言常把字串視為字元陣列，C++、Java、Python 則提供較高階的字串類別或內建操作。

### C 語言常見字串函式

C 字串（C String）通常是以空字元（Null Character）`\0` 結尾的字元陣列。國考常考以下函式：

| 函式 | 中文意義 | 重點 |
|---|---|---|
| `strlen` | 計算字串長度 | 不包含結尾的 `\0` |
| `strcpy` | 複製字串 | 目的端空間不足會有風險 |
| `strncpy` | 限制長度的字串複製 | 較能控制複製長度，但仍要注意結尾 |
| `strcmp` | 比較字串 | 相同通常回傳 `0` |
| `strcat` | 串接字串 | 目的端需有足夠空間 |

國考很喜歡考 `strlen` 不計算 `\0`。例如 `"abc"` 實際上會以 `a`、`b`、`c`、`\0` 存放，但 `strlen("abc")` 的結果是 `3`，不是 `4`。

### C++ 的 `std::string`

`std::string` 是 C++ 標準函式庫提供的字串類別，比 C 字串更方便也較安全。常見操作如下：

| 操作 | 意義 |
|---|---|
| `length()` | 取得字串長度 |
| `substr()` | 取出子字串 |
| `find()` | 尋找某段文字的位置 |

例如 `s.substr(1, 3)` 通常表示從索引 `1` 開始取 `3` 個字元。考試看到這類題目時，要先確認語言與函式定義，尤其是「第二個參數」代表長度還是結束位置。

### Java 的 `String`

Java 的 `String` 是字串類別，常見操作如下：

| 操作 | 意義 |
|---|---|
| `length()` | 取得字串長度 |
| `substring()` | 取出子字串 |
| `equals()` | 比較字串內容是否相同 |
| `charAt()` | 取得指定位置字元 |

Java 常考 `equals()` 與 `==` 的差異。`equals()` 比較字串內容；`==` 比較兩個參考是否指向同一個物件。國考若問「比較字串內容」，通常要選 `equals()`。

### Python 的字串操作

Python 的字串（String）是常用內建型別，常見操作如下：

| 操作 | 意義 |
|---|---|
| `len()` | 取得字串長度 |
| `split()` | 分割字串 |
| `join()` | 合併多個字串 |
| `find()` | 尋找子字串位置 |
| `replace()` | 取代文字 |

例如 `"a,b,c".split(",")` 會得到三個部分：`a`、`b`、`c`。而 `",".join(["a", "b", "c"])` 會把清單中的字串用逗號接起來。

### 國考常見考法

字串題通常考函式用途、回傳值與容易混淆的細節。C 語言偏重 `\0`、陣列空間與複製風險；Java 偏重 `equals()`；Python 偏重 `split()` 與 `join()` 的方向；C++ 偏重 `std::string` 的常用方法。

## 物件導向程式設計（Object-Oriented Programming, OOP）

物件導向程式設計（Object-Oriented Programming, OOP）是一種把程式設計成「物件」互動的方式。物件（Object）可以想成同時包含資料與行為的單位；類別（Class）則像是物件的設計圖。

例如「學生」可以是一個類別，裡面有姓名、學號等資料，也有選課、查成績等操作。真正建立出來的某一位學生，才是物件。

### 封裝（Encapsulation）

封裝（Encapsulation）是把資料與操作資料的方法包在同一個類別中，並透過存取控制保護內部資料。核心想法是：外部不應任意直接改動物件內部狀態，而是透過設計好的方法操作。

例如銀行帳戶物件不應讓外部直接把餘額改成任意數字，而應透過存款、提款等方法改變餘額。這樣可以避免不合法操作。

國考常把封裝描述成「資料隱藏」、「提高安全性」、「降低外部依賴」。

### 繼承（Inheritance）

繼承（Inheritance）是讓新的類別取得既有類別的屬性與方法。被繼承的類別稱為父類別（Superclass）或基底類別（Base Class），繼承者稱為子類別（Subclass）或衍生類別（Derived Class）。

例如「交通工具」可以是父類別，「汽車」與「機車」可以是子類別。子類別可以沿用交通工具的共同特性，也可以加入自己的特性。

國考常考繼承的好處：程式碼重用、建立類別階層、表達「是一種」的關係。

### 多型（Polymorphism）

多型（Polymorphism）是指同一個介面或方法呼叫，在不同物件上可以產生不同實作結果。白話說，就是「同樣的指令，交給不同物件做，會用各自的方式完成」。

例如父類別 `Animal` 有 `speak()` 方法，子類別 `Dog` 的 `speak()` 可能輸出狗叫聲，子類別 `Cat` 的 `speak()` 可能輸出貓叫聲。呼叫同一個 `speak()`，結果依物件型態不同而不同。

國考常把多型和「同一介面、不同實作」連在一起考。

### 多載與覆寫

多載（Overloading）是同一個類別中，方法名稱相同，但參數個數或參數型別不同。它強調的是「同名方法，用參數差異區分」。

覆寫（Overriding）是子類別重新定義父類別已經有的方法。它強調的是「子類別改寫父類別行為」。

例如 `print(int x)` 與 `print(String s)` 是多載；子類別把父類別的 `speak()` 改成自己的版本，是覆寫。

### 抽象類別與介面

抽象類別（Abstract Class）是不能直接建立物件、通常用來作為共同父類別的類別。它可以包含狀態，也可以包含已實作的方法與尚未實作的抽象方法。

介面（Interface）偏向規格契約，用來規定某個類別應該提供哪些方法。類別實作介面後，就代表它承諾提供介面要求的行為。

國考常考抽象類別與介面的差異：抽象類別比較像「有部分共同實作的父類別」；介面比較像「行為規格」。

## 遞迴（Recursion）

遞迴（Recursion）是指函式在執行過程中呼叫自己。它常用來處理可以分解成相似小問題的題目，例如階乘、費氏數列、河內塔、樹走訪與深度優先搜尋。

遞迴一定要有兩個重要部分：

1. 終止條件（Base Case）：問題小到可以直接回答，不再繼續呼叫自己。
2. 遞迴情況（Recursive Case）：把原問題拆成較小的同類問題，再呼叫自己處理。

例如階乘（Factorial）可寫成：

```text
n! = n * (n - 1)!
0! = 1
```

其中 `0! = 1` 是終止條件，`n! = n * (n - 1)!` 是遞迴情況。若沒有終止條件，函式會一直呼叫自己，最後可能造成堆疊溢位（Stack Overflow）。

### 常見遞迴題型

階乘（Factorial）是最基本的遞迴題，重點是知道終止條件通常是 `0!` 或 `1!`。

費氏數列（Fibonacci Sequence）也是常考題，定義通常是 `F(0)=0`、`F(1)=1`、`F(n)=F(n-1)+F(n-2)`。它很適合考遞迴，但單純遞迴會重複計算很多次。

河內塔（Tower of Hanoi）是典型遞迴問題，核心想法是先把上面的小盤移開，再移最大盤，最後把小盤移回目標柱。

樹走訪（Tree Traversal）與深度優先搜尋（Depth-First Search, DFS）也常用遞迴描述，因為樹或圖的結構常能拆成更小的子問題。

### 記憶化

記憶化（Memoization）是一種把已經算過的結果存起來，避免重複計算的技巧。它常用在費氏數列這類有大量重複子問題的遞迴。

例如計算 `F(5)` 會用到 `F(4)` 與 `F(3)`，而 `F(4)` 又會用到 `F(3)`。如果不把 `F(3)` 的結果記住，就會重複計算。記憶化能讓程式更有效率。

## 國考常見比較與易混淆整理

| 易混淆觀念 | 正確理解 | 常見陷阱 |
|---|---|---|
| `&x` 與 `*p` | `&x` 是取出 `x` 的位址；`*p` 是取出 `p` 指到的值 | 把位址和值混在一起 |
| 空指標與懸空指標 | 空指標是不指向有效物件；懸空指標是指向已失效記憶體 | 以為只要不是空指標就安全 |
| `strlen` 與實際儲存長度 | `strlen` 不計算字串結尾的 `\0` | `"abc"` 需要 4 格儲存，但長度是 3 |
| Java `equals()` 與 `==` | `equals()` 比內容；`==` 比參考 | 用 `==` 判斷字串內容 |
| 多載與覆寫 | 多載看參數差異；覆寫看子類別改寫父類別方法 | 只看到同名方法就誤判 |
| 抽象類別與介面 | 抽象類別可有狀態與部分實作；介面偏規格契約 | 把介面當成一般類別 |
| 遞迴終止條件與遞迴情況 | 終止條件讓遞迴停下來；遞迴情況負責縮小問題 | 忘記終止條件造成無限遞迴 |

## 國考必背整理

1. 指標（Pointer）存放的是記憶體位址，不是一般資料值。
2. `&` 是取址，`*` 是解參考。
3. 陣列（Array）名稱常可視為第一個元素的位址。
4. 空指標（Null Pointer）不能隨便解參考。
5. 懸空指標（Dangling Pointer）指向已失效記憶體。
6. 記憶體洩漏（Memory Leak）是配置後未釋放記憶體。
7. C 語言 `strlen` 不包含字串結尾的 `\0`。
8. C 語言 `strcpy`、`strcat` 要注意目的端空間是否足夠。
9. Java 比較字串內容常用 `equals()`。
10. 物件導向程式設計（OOP）三大特性是封裝、繼承、多型。
11. 多載（Overloading）是同名方法搭配不同參數。
12. 覆寫（Overriding）是子類別改寫父類別方法。
13. 遞迴（Recursion）必須有終止條件與遞迴情況。
14. 記憶化（Memoization）可避免遞迴重複計算。

## 容易考的判斷題

1. 指標變數存放的是資料的記憶體位址。正確。
2. `&` 可以取得變數位址。正確。
3. `*p` 一定表示宣告指標，不可能表示解參考。錯誤。`*` 在宣告與運算時意義不同。
4. C 字串的 `strlen` 會把結尾的 `\0` 算進長度。錯誤。
5. `strcpy` 複製字串時完全不需要注意目的端大小。錯誤。
6. 封裝（Encapsulation）有助於保護物件內部資料。正確。
7. 繼承（Inheritance）可以讓子類別重用父類別的屬性與方法。正確。
8. 多型（Polymorphism）表示同一介面可以有不同實作。正確。
9. 多載（Overloading）與覆寫（Overriding）是完全相同的概念。錯誤。
10. 遞迴函式不需要終止條件也能正常結束。錯誤。
11. 遞迴可能造成堆疊溢位（Stack Overflow）。正確。
12. 記憶化（Memoization）可用來減少重複計算。正確。

## 考前速記小抄

指標（Pointer）看到題目先分清楚三件事：變數的值、變數的位址、指標指到的值。`&` 取位址，`*` 取指到的內容。

字串（String）看到 C 語言題目，要立刻想到字元陣列與 `\0`。看到 Java 字串比較，要想到 `equals()`。看到 Python 題目，要分清楚 `split()` 是切開，`join()` 是接起來。

物件導向程式設計（OOP）三大特性要背熟：封裝（Encapsulation）保護資料，繼承（Inheritance）重用與擴充，多型（Polymorphism）同一介面不同實作。

多載（Overloading）看「參數不同」，覆寫（Overriding）看「子類別改父類別方法」。抽象類別（Abstract Class）可有狀態與部分實作，介面（Interface）偏向規格契約。

遞迴（Recursion）一定要找終止條件（Base Case）與遞迴情況（Recursive Case）。若題目提到重複計算，就聯想到記憶化（Memoization）。
