## 名詞解釋

**if-else** 是「條件判斷」的基本寫法。程式會先檢查條件是否成立，成立就執行 if 區塊，不成立就改走 else 或其他分支。白話來說，就是讓程式依照情況選路走。

**switch** 也是條件判斷，但通常適合用在「同一個變數有多種固定值」的情況。例如選單輸入 1、2、3 時，各自執行不同功能。它和 if-else 很像，但可讀性常比一長串 if-else 好。

**迴圈** 是讓程式重複執行某段指令的結構。常見有 for、while、do-while。白話來說，就是把「重複做某件事」交給程式，不用一行一行手寫很多次。

**物件導向** 是把資料與操作資料的方法包在一起的程式設計方式。常見觀念包含類別、物件、封裝、繼承與多型。白話來說，類別像設計圖，物件像照著設計圖做出來的實體。

**字串函式** 是處理文字資料的常用工具，例如取得長度、擷取部分文字、搜尋某個字、取代文字、大小寫轉換等。國考常用來測驗考生是否理解索引、長度與函式回傳值。

**指標** 是 C / C++ 的重要特色，代表「存放記憶體位址的變數」。一般變數放的是值，指標放的是某個資料所在的位置。因為它直接碰到記憶體，所以常與陣列、函式參數、動態配置一起出題。

**垃圾回收** 是 Java 的記憶體管理機制。程式不再使用的物件，會由 JVM 的垃圾回收器自動回收記憶體。考試常問它的觀念：Java 不需要像 C/C++ 一樣手動釋放大多數物件記憶體。

**G1GC** 是 Java 的一種垃圾回收器，全名常理解為 Garbage First Garbage Collector。它把堆積記憶體切成多個區域，優先回收效益較高的區域，目標是兼顧吞吐量與停頓時間。

**List、Tuple、Dictionary、Set** 是 Python 常見資料結構。List 是可變且有順序的串列，Tuple 是不可變且有順序的資料組，Dictionary 用鍵值對存資料，Set 則是不重複元素的集合。

## 核心想法

準備程式題時，不必一開始就追求背完所有語法細節。國考更常測的是「看得懂程式怎麼跑」與「知道某個語言的關鍵特色」。因此準備方向可以分成兩層：第一層是所有語言都常見的基本能力，第二層是各語言容易被拿來出題的特色。

第一層基本能力包含條件判斷、分支選擇、迴圈、字串處理與物件導向。這些能力在 C、C++、Java、Python 都會出現，只是語法長得不太一樣。若能先掌握「條件決定路線、迴圈負責重複、函式負責重用、物件導向負責組織程式」這幾個觀念，看到不同語言時就不會只被符號嚇到。

第二層是語言獨有特色。C / C++ 常考指標，因為指標牽涉記憶體位址與資料存取。Java 常考垃圾回收，因為它代表 Java 記憶體管理的核心觀念。Python 常考四種內建容器，因為 List、Tuple、Dictionary、Set 的差異很適合出選擇題與判斷題。

## 具體範例

### if-else 與 switch

if-else 適合判斷條件範圍，例如分數是否及格：

```c
if (score >= 60) {
    printf("pass");
} else {
    printf("fail");
}
```

這段程式的重點不是 printf，而是 `score >= 60` 這個條件。條件成立時輸出 pass，不成立時輸出 fail。

switch 適合判斷固定選項，例如使用者輸入功能代號：

```c
switch (choice) {
    case 1:
        printf("新增");
        break;
    case 2:
        printf("刪除");
        break;
    default:
        printf("錯誤選項");
}
```

這裡的 `break` 很重要。若少了 break，在某些語言或語法情境下，程式可能繼續往下一個 case 執行，這是常見考點。

### 迴圈

for 迴圈常用在「次數已知」的情況：

```c
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}
```

執行後 sum 會是 1 + 2 + 3 + 4 + 5，也就是 15。考題常要求追蹤每一輪 i 與 sum 的變化。

while 迴圈常用在「條件成立就繼續」的情況：

```c
while (passwordWrong) {
    retry();
}
```

這種寫法表示只要密碼仍然錯誤，就一直重新嘗試。考試要特別注意條件是否可能永遠成立，若永遠成立就會形成無窮迴圈。

### C / C++ 指標

```c
int x = 10;
int *p = &x;
```

`x` 是一般整數變數，值是 10。`&x` 表示 x 的記憶體位址，`p` 則是存放這個位址的指標變數。若看到 `*p`，通常表示透過 p 找到該位址上的值，也就是 x 的值。

### Java 垃圾回收

```java
Student s = new Student();
s = null;
```

第一行建立一個 Student 物件，第二行讓 s 不再指向該物件。若沒有其他變數參照這個物件，它就可能成為垃圾回收的對象。要注意的是，垃圾回收由 JVM 管理，程式設計者通常無法保證它在某一個精確時間點立刻執行。

### Python 容器

```python
names = ["Amy", "Bob"]
point = (3, 5)
score = {"Amy": 90, "Bob": 80}
tags = {"passed", "reviewed", "passed"}
```

`names` 是 List，可新增、刪除或修改元素。`point` 是 Tuple，建立後通常不能修改。`score` 是 Dictionary，可用姓名這個 key 找到分數這個 value。`tags` 是 Set，重複的 `"passed"` 只會保留一份。

## 國考常見考法

國考的程式題通常不會只問「語法長什麼樣子」，而是會問執行結果、觀念差異或哪個敘述正確。遇到程式碼題時，先不要急著看答案，應該逐行追蹤變數如何改變，尤其是迴圈次數、條件判斷與字串索引。

if-else 常考條件是否互斥，以及 else 到底對應哪一個 if。switch 常考 case、default 與 break 的效果。迴圈常考執行幾次、最後變數值是多少、是否形成無窮迴圈。字串函式常考長度與索引，尤其要注意很多語言的索引從 0 開始。

C / C++ 常考指標與位址，例如 `&` 代表取址、`*` 代表宣告指標或解參考。Java 常考垃圾回收的自動化特性，以及「無參照物件才可能被回收」。Python 則常考四種容器的可變性、是否有順序、是否允許重複，以及查找資料的方式。

## 比較表與易混淆整理

### 基本控制結構比較

| 項目 | 主要用途 | 新手記法 | 常見考點 |
| --- | --- | --- | --- |
| if-else | 判斷條件成立與否 | 條件選路 | 條件範圍、巢狀 if、else 對應 |
| switch | 判斷固定值的多分支 | 選單分流 | case、break、default |
| for | 重複固定次數 | 次數明確的迴圈 | 起始值、終止條件、遞增遞減 |
| while | 條件成立就重複 | 先判斷再執行 | 是否進入迴圈、是否無窮迴圈 |
| do-while | 至少執行一次 | 先執行再判斷 | 與 while 的差異 |

### 語言特色比較

| 語言 | 容易考的特色 | 白話重點 | 常見陷阱 |
| --- | --- | --- | --- |
| C | 指標、陣列、記憶體位址 | 可以直接操作記憶體位置 | `&` 與 `*` 意義混淆 |
| C++ | 指標、物件導向、類別 | 兼具 C 的底層能力與物件導向 | 指標與物件生命週期 |
| Java | JVM、垃圾回收、物件導向 | 記憶體回收多由 JVM 管理 | 以為可精準控制 GC 時間 |
| Python | List、Tuple、Dictionary、Set | 內建容器強大且常用 | 可變性、順序、重複性混淆 |

### Python 容器易混淆整理

| 容器 | 是否有順序 | 是否可修改 | 是否允許重複 | 適合用途 |
| --- | --- | --- | --- | --- |
| List | 有 | 可修改 | 可重複 | 存一串會變動的資料 |
| Tuple | 有 | 不可修改 | 可重複 | 存固定不變的一組資料 |
| Dictionary | 依語言版本與實作有定義順序，但重點是鍵值對 | 可修改 | key 不可重複 | 用 key 查 value |
| Set | 通常不靠順序使用 | 可修改 | 不可重複 | 去除重複、集合運算 |

## 國考答題句

條件判斷題可以寫：「if-else 依條件真假決定執行分支，switch 則常用於同一變數對多個固定值進行分支選擇。」

迴圈題可以寫：「for 通常用於已知重複次數的情況，while 則用於條件成立時持續重複，判斷時應注意初始值、終止條件與每次迭代的更新。」

指標題可以寫：「指標變數儲存的是記憶體位址，`&` 可取得變數位址，`*` 可用來宣告指標或取得指標所指向位置的內容。」

Java 記憶體管理題可以寫：「Java 透過 JVM 的垃圾回收機制回收不再被參照的物件，但垃圾回收的執行時機通常不由程式設計者精準控制。」

Python 容器題可以寫：「List 可變且有順序，Tuple 有順序但不可變，Dictionary 以鍵值對存取資料，Set 則用於不重複元素的集合。」

## 容易考的判斷題

1. if-else 可以讓程式依照條件真假執行不同區塊。  
   答：對。這正是條件判斷的基本功能。

2. switch 一定比 if-else 更強，因此所有條件都應改用 switch。  
   答：錯。switch 適合固定值分支，若是範圍判斷或複雜條件，if-else 通常更適合。

3. for 迴圈通常適合用在已知重複次數的情況。  
   答：對。例如從 1 加到 100，次數明確，就很適合使用 for。

4. while 迴圈若條件一直成立，可能造成無窮迴圈。  
   答：對。因此要檢查迴圈內是否有更新條件相關變數。

5. C / C++ 的指標變數存放的是一般數值本身，與記憶體位址無關。  
   答：錯。指標存放的是記憶體位址，不是一般資料值本身。

6. Java 的垃圾回收可以回收不再被參照的物件。  
   答：對。這是 Java 自動記憶體管理的重要觀念。

7. Java 程式設計者通常可以保證垃圾回收在指定的某一毫秒立刻完成。  
   答：錯。垃圾回收由 JVM 管理，通常不能保證精準執行時間。

8. Python 的 Tuple 建立後通常不可修改。  
   答：對。這是 Tuple 與 List 最常見的差異之一。

9. Python 的 Set 允許保留多個完全相同的元素。  
   答：錯。Set 的重點是不重複。

10. Dictionary 適合用 key 查找對應的 value。  
    答：對。例如用學生姓名查分數，就是典型鍵值對使用情境。

## 考前速記小抄

基本語法先抓四件事：條件、分支、迴圈、資料處理。條件用 if-else，固定選項多分支常用 switch，重複執行用迴圈，文字處理常靠字串函式。

看迴圈題時，依序檢查「初始值、條件、每輪更新、最後一次是否執行」。很多錯誤答案都藏在少算一次或多算一次。

看 switch 題時，特別注意 `break` 與 `default`。少了 break 可能繼續往下跑，default 則通常處理沒有符合任何 case 的情況。

C / C++ 記指標：指標放位址，`&` 取位址，`*` 看指到哪裡的值。只要題目出現位址、陣列、函式參數，就要提高警覺。

Java 記垃圾回收：不用手動釋放大多數物件，沒有參照的物件才可能被回收，但不能保證精準回收時間。G1GC 是一種垃圾回收器，重點是分區回收與降低停頓影響。

Python 記四容器：List 可變有序，Tuple 不可變有序，Dictionary 是 key-value，Set 不重複。選擇題最愛考可不可變、重不重複、是不是用 key 查資料。
