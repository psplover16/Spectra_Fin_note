# 程式設計 6：遞迴 Recursion ★

> 科目：程式設計｜★ 你說很少用，這篇把它講透。
> 核心：**函式呼叫自己**，把大問題拆成「同形式的小問題」。範例用 Java。

---

## 一、遞迴是什麼？　【理解】

- **遞迴 Recursion**：一個函式**呼叫自己**，把大問題拆成**同樣形式的小問題**，直到小到能直接回答。
- 比喻：**俄羅斯娃娃**——打開一個，裡面還有一個更小的，直到最小那個（不能再打開）。

---

## 二、兩個必要元素（關鍵！）　【理解】

| 元素 | 意思 |
|---|---|
| **① 終止條件 Base Case** | 小到**不用再遞迴、可直接回答**的情況。**少了它會無限遞迴 → 堆疊溢位 stack overflow 崩潰** |
| **② 遞迴呼叫 Recursive Case** | 把問題**縮小一點**，呼叫自己處理更小的子問題 |

> 口訣：**遞迴一定要有「停下來的條件」＋「往下縮小的呼叫」。**

---

## 三、範例 1：階乘 Factorial　【練流程】

`n! = n × (n−1) × … × 1`。遞迴定義：**終止 `0! = 1`**、**遞迴 `n! = n × (n−1)!`**
```java
int factorial(int n) {
    if (n == 0) return 1;            // ① 終止條件
    return n * factorial(n - 1);     // ② 遞迴呼叫
}
```
**展開 `factorial(4)`**（先一路往下到終止，再一路乘回來）：
```
factorial(4) = 4 × factorial(3)
             = 4 × (3 × factorial(2))
             = 4 × (3 × (2 × factorial(1)))
             = 4 × (3 × (2 × (1 × factorial(0))))   ← factorial(0)=1 觸發終止
             = 4 × 3 × 2 × 1 × 1
             = 24
```

---

## 四、範例 2：費氏數列 Fibonacci　【練流程】

`0, 1, 1, 2, 3, 5, 8…`，每個是**前兩個的和**。終止 `F(0)=0, F(1)=1`、遞迴 `F(n)=F(n−1)+F(n−2)`
```java
int fib(int n) {
    if (n <= 1) return n;            // 終止：F(0)=0, F(1)=1
    return fib(n - 1) + fib(n - 2);  // 遞迴
}
```
**展開 `fib(4)`**：
```
fib(2) = fib(1) + fib(0) = 1 + 0 = 1
fib(3) = fib(2) + fib(1) = 1 + 1 = 2
fib(4) = fib(3) + fib(2) = 2 + 1 = 3
```
> ⚠ 考點：這種**直接遞迴的費氏是 O(2ⁿ)**（指數，因為 fib(2) 之類被重複算很多次），效率差；實務會改用迴圈或記憶化（memoization）。

---

## 五、遞迴 vs 迴圈　【理解】

| | 遞迴 Recursion | 迴圈 Iteration |
|---|---|---|
| 寫法 | 函式呼叫自己 | for／while |
| 可讀性 | **某些問題更簡潔**（樹、分治） | 一般運算更直接 |
| 記憶體 | 每次呼叫佔**呼叫堆疊**，較耗、可能 stack overflow | **省記憶體** |
| 速度 | 有函式呼叫開銷，通常較慢 | 較快 |

> 任何遞迴都能改寫成迴圈（反之亦然），取捨看**可讀性 vs 效能**。

---

## 六、遞迴與堆疊（重要關聯）　【理解】

- 每次遞迴呼叫，系統把「目前狀態（區域變數、回傳位址）」**壓進呼叫堆疊（call stack，LIFO）**。
- 到**終止條件**後，開始**一層層彈出（return）**、回填結果。
- 所以：**沒有終止條件 → 一直壓 → 堆疊爆掉（stack overflow）**；遞迴太深也會爆。
- （呼應前面 Stack 那篇：函式呼叫就是靠 call stack。）

---

## 七、重點整理（背這張）

- 遞迴 ＝ **函式呼叫自己**；必須有 **① 終止條件 ② 遞迴呼叫**，少了終止會 **stack overflow**。
- 階乘：`0!=1`、`n!=n×(n−1)!`；費氏：`F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2)`。
- **直接遞迴費氏是 O(2ⁿ)**（會重複計算）。
- 遞迴 vs 迴圈：遞迴簡潔但**耗呼叫堆疊**、迴圈省記憶體較快；可互相改寫。
- 遞迴靠**呼叫堆疊（LIFO）**運作：往下壓、到終止再一層層 return。
