## 一、陣列 Array（複習 + 程式語法）　【理解】

> 特性（連續記憶體、索引存取 O(1)、大小固定）在資料結構已講，這裡補「怎麼寫」。

**宣告與初始化**：
```java
// Java
int[] arr  = new int[5];          // 5 個元素（預設 0）
int[] arr2 = {1, 2, 3, 4, 5};     // 直接給值
```
```c
// C
int arr[5];
int arr2[] = {1, 2, 3, 4, 5};
```
- **索引從 0 開始**：`arr[0]` 是第一個；Java 用 `arr.length` 取長度。

**多維陣列**：
```java
int[][] m = new int[3][4];   // 3 列 4 行
m[1][2] = 7;
```

**走訪（兩種迴圈）**：
```java
for (int i = 0; i < arr.length; i++) { ... }   // 一般 for
for (int x : arr) { ... }                       // for-each（直接拿值）
```

## 二、字串常用函式（跨語言對照）　【硬背】

| 操作 | Java | Python | C |
|---|---|---|---|
| **長度** | `s.length()` | `len(s)` | `strlen(s)` |
| **取第 i 字元** | `s.charAt(i)` | `s[i]` | `s[i]` |
| **取子字串** | `s.substring(a, b)` | `s[a:b]` | — |
| **串接** | `s1 + s2` | `s1 + s2` | `strcat(s1, s2)` |
| **搜尋位置** | `s.indexOf("x")` | `s.find("x")` | `strstr(s, "x")` |
| **轉大小寫** | `toUpperCase()`／`toLowerCase()` | `upper()`／`lower()` | — |
| **分割** | `s.split(",")` | `s.split(",")` | — |
| **替換** | `s.replace("a","b")` | `s.replace("a","b")` | — |

### ⚠ 超常考陷阱：Java 比字串要用 `.equals()`，不是 `==`
```java
String a = "hi", b = "hi";
a == b          // 比的是「參考（位址）」→ 不可靠！
a.equals(b)     // 比的是「內容」→ 正確 ✅
```
> C 比字串用 `strcmp(s1, s2)`（回傳 0 代表相等）；Python 可直接用 `==`（比內容）。

## 三、例外處理 Exception Handling　【理解】

- **例外 Exception**：程式執行時的**非預期錯誤**（除以 0、陣列越界、找不到檔案…）。
- **例外處理**：把例外**捕捉起來處理**，不讓程式直接崩潰。

**結構：try / catch / finally**
```java
int a = 10, b = 0;
try {
    int x = a / b;                    // 執行時除以零 → 丟例外
} catch (ArithmeticException e) {      // 捕捉並處理特定例外
    System.out.println("除以零錯誤");
} finally {
    System.out.println("一定會執行");   // 不管有沒有錯都會跑
}
```

| 關鍵字 | 作用 |
|---|---|
| **try** | 放**可能出錯**的程式碼 |
| **catch** | **捕捉**並處理某種例外 |
| **finally** | **不管有沒有出錯都一定執行**（常用來關檔／釋放資源） |
| **throw** | **主動拋出**一個例外 |
| **throws**（Java） | 在方法宣告它**可能拋出**哪些例外 |

- **例外分兩種（Java）**：
  - **編譯時期 checked**：編譯器強制你處理（如檔案 IO）。
  - **執行時期 unchecked／runtime**：執行才爆（如 `NullPointerException`、`ArrayIndexOutOfBoundsException`）。

## 四、重點整理（背這張）

- 陣列：**索引從 0**、`arr.length` 取長度、多維 `m[i][j]`、可用 for-each 走訪。
- 字串函式記常用：長度、取子字串、串接、搜尋、大小寫、split、replace。
- **Java 比字串用 `.equals()` 不是 `==`**（== 比位址）；C 用 `strcmp`。
- 例外處理：**try（可能錯）→ catch（接住）→ finally（一定執行）**；throw 主動拋、throws 宣告；checked（編譯強制）vs runtime（執行才爆）。
