# 程式設計 5：物件導向 OOP 三大特性 ★

> 科目：程式設計｜★ 必考。
> 用「動物 → 狗／貓」的例子把三大特性具體化。範例用 Java。

---

## 一、類別與物件　【理解】

- **類別 Class**：一個**藍圖／模板**，定義一類東西有哪些**屬性（資料）**和**方法（行為）**。
- **物件 Object（實例 Instance）**：根據類別**造出來的具體東西**。
- 比喻：**類別 ＝ 餅乾模具**，**物件 ＝ 用模具做出的一塊塊餅乾**。

```java
class Dog {
    String name;             // 屬性（資料）
    void bark() { ... }      // 方法（行為）
}
Dog d = new Dog();           // d 是一個「物件」（實例）
```

---

## 二、三大特性（核心）★　【理解】

### ① 封裝 Encapsulation —— 包起來、藏細節
把**資料和操作資料的方法包在類別裡**，並**隱藏內部細節**，只透過公開方法存取。
- 做法：屬性設 **`private`（私有）**，提供 **`public` 的 getter／setter** 來存取。
- 好處：**保護資料、外部不用知道內部怎麼實作**。

```java
class Account {
    private int balance;                          // 餘額藏起來，外部不能直接亂改
    public void deposit(int n) { balance += n; }  // 只能透過方法改
    public int  getBalance()   { return balance; }
}
```

### ② 繼承 Inheritance —— 子承父、可重用
子類別**繼承**父類別的屬性和方法，可**重用並擴充**。表達 **"is-a"** 關係（狗 is-a 動物）。
```java
class Animal {
    void eat() { ... }            // 父類別的共同行為
}
class Dog extends Animal {        // Dog 繼承 Animal（自動就有 eat()）
    void bark() { ... }           // 自己新增的
}
```
- 子類別可**新增**成員，或**覆寫（override）**父類別的方法。

### ③ 多型 Polymorphism —— 同操作、不同表現
**同一個操作，不同物件有不同表現**。
```java
Animal a = new Dog();   a.sound();   // 執行 Dog 的 sound() → 汪汪
Animal b = new Cat();   b.sound();   // 執行 Cat 的 sound() → 喵喵
```
同一行 `物件.sound()`，因實際物件不同而行為不同，就是多型。兩種：

| 種類 | 說明 | 時機 |
|---|---|---|
| **覆寫 Override** | 子類別**重新定義**父類別的同名方法 | **執行期**多型 |
| **重載 Overload** | **同名、但參數不同**（數量／型別） | **編譯期**多型 |

> 重載例：`add(int,int)` 和 `add(double,double)`，同名、不同參數。

> 口訣：**封裝＝包起來藏細節、繼承＝子承父可重用、多型＝同操作不同表現。**
> （有些書把**抽象 Abstraction** 也算進去稱「四大特性」，但你朋友講的三大就是封裝／繼承／多型。）

## 三、補充：抽象類別 vs 介面（常一起考）　【理解】

| | 抽象類別 Abstract Class | 介面 Interface |
|---|---|---|
| 能否 new | **不能**（只當父類別模板） | 不能 |
| 內容 | 可含**已實作方法 ＋ 抽象方法 ＋ 欄位** | 傳統上**只有方法宣告**（規格） |
| 關係 | **is-a** | **can-do**（能力） |
| 繼承／實作 | 一個類別**只能繼承一個**（單一繼承） | 一個類別**可實作多個**（解決單一繼承限制） |
| Java 關鍵字 | `extends` | `implements` |

> 你之前說懂的 **implement** 概念，就是「實作介面」——類別承諾提供介面規定的那些方法。

---

## 四、重點整理（背這張）

- **類別 ＝ 藍圖、物件 ＝ 實例**（模具與餅乾）。
- **三大特性**：
  - **封裝**：資料 private、藏細節，只透過方法存取。
  - **繼承**：子承父（`extends`）、is-a、可覆寫。
  - **多型**：同操作不同表現；**覆寫 Override（執行期）**、**重載 Overload（編譯期）**。
- **抽象類別**（is-a、單一繼承、可有實作）vs **介面**（can-do、可多重實作、只有規格，`implements`）。
