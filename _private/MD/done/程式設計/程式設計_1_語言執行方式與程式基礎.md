## 一、Assembler vs Compiler vs Interpreter　【硬背】

程式語言層級：**高階語言**（人看得懂）→ **組合語言 assembly**（低階）→ **機器碼**（0／1，機器看得懂）。

| | 翻譯什麼 → 成什麼 | 特點 | 例子 |
|---|---|---|---|
| **組譯器 Assembler** | 組合語言 → 機器碼 | 一對一翻譯 | — |
| **編譯器 Compiler** | 高階語言**整個一次**翻成機器碼，**產生執行檔** | **執行快**；要先編譯 | **C、C++** |
| **直譯器 Interpreter** | 高階語言**一行一行**邊翻邊執行，**不產生執行檔** | 較慢；**跨平台、好除錯** | **Python、JavaScript** |

> **Java 是混合型**：先**編譯**成 **bytecode（位元組碼）**，再由 **JVM** 直譯／JIT 執行 → 達成**跨平台**（write once, run anywhere）。

## 二、變數與資料型別　【理解】

- **變數**：一個**有名字的記憶體空間**，用來存放資料。
- **常見型別**：整數 `int`、浮點 `float`／`double`、字元 `char`、布林 `boolean`、字串 `string`。
- **靜態型別 vs 動態型別**（常考觀念）：

| | 靜態型別 Static | 動態型別 Dynamic |
|---|---|---|
| 何時定型別 | **宣告時就定死**（要寫型別） | **執行時才決定**（不用寫型別） |
| 例子 | **C、C++、Java** | **Python、JavaScript** |

```java
// Java（靜態）：要宣告型別
int    age  = 25;
String name = "Tom";
```
```python
# Python（動態）：不用寫型別
age  = 25
name = "Tom"
```
- **常數**（值不能改的變數）：C／C++ 用 `const`、Java 用 `final`。

## 三、流程控制（你已會，重點在語法與陷阱）　【理解】

程式三大結構：**循序、選擇、重複**。

### 選擇：if-else / switch
```java
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```
- **switch**：對**單一變數的多個值**做多分支。
- ⚠ **每個 case 後面要 `break`，否則會「貫穿（fall-through）」繼續執行下面的 case**（超常考陷阱）：
```java
switch (day) {
    case 1: ...; break;   // 少了 break 就會繼續掉進 case 2！
    case 2: ...; break;
    default: ...;
}
```

### 重複：迴圈
| 迴圈 | 用途 | 判斷時機 |
|---|---|---|
| **for** | **計次**（知道跑幾次） | 先判斷 |
| **while** | **條件**成立就一直跑 | **先判斷**（可能一次都不跑） |
| **do-while** | — | **後判斷**（**至少執行一次**） |

- `break`：**跳出整個迴圈**；`continue`：**跳過這一輪**、繼續下一輪。

---

## 四、重點整理（背這張）

- **編譯器**整個翻、產生執行檔、快（C／C++）；**直譯器**一行行翻、跨平台（Python／JS）；**Java 混合**（編成 bytecode 給 JVM 跑，跨平台）。
- **靜態型別**宣告時定（C／Java）、**動態型別**執行時定（Python／JS）。
- **switch 的 case 沒 `break` 會貫穿（fall-through）** ← 易考陷阱。
- 迴圈：**for 計次、while 先判斷、do-while 至少跑一次**；break 跳出、continue 跳過這輪。
