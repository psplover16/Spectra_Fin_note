# 程式設計 4：指標 Pointer ★（C／C++）

> 科目：程式設計｜★ 很多人最頭痛，但核心只有一句：**指標存的是「位址」，不是值本身**。
> 用「房間號碼」的比喻 + 圖示，把它講清楚。Java／Python 沒有明確指標（見最後對照）。

---

## 一、指標是什麼？（核心比喻）　【理解】

記憶體像**一排有編號的房間**，每個編號就是**位址（address）**。
- **一般變數** ＝ 房間裡**放的東西**（值）。
- **指標 Pointer** ＝ 一張**寫著某房間號碼的紙條**（存的是**位址**，不是東西本身）。
- 拿著紙條上的號碼，就能**找到那個房間、拿或換裡面的東西**。

```
記憶體（房間）：
 位址 0x100： [ x = 10 ]      ← 變數 x 住在這，裡面是值 10
 位址 0x200： [ p = 0x100 ]   ← 指標 p 住在這，裡面放的是「x 的房號」
                  │
                  └──指向──► x
```

---

## 二、兩個關鍵符號：`&` 和 `*`　【理解】

| 符號 | 名稱 | 意思 |
|---|---|---|
| **`&`** | 取址（address-of） | 放變數前，取出它的**位址**：`&x` ＝ x 的房號 |
| **`*`**（宣告時） | — | `int *p;` 宣告 p 是「**指向 int 的指標**」 |
| **`*`**（使用時） | 解參考（dereference） | `*p` ＝ **順著 p 的位址，去拿那個房間裡的值** |

> 口訣：**`&` 拿地址、`*` 順著地址拿值。**

---

## 三、手把手範例　【練流程】

```c
int x = 10;        // x 值為 10
int *p = &x;       // p 存「x 的位址」（紙條寫上 x 的房號）

printf("%d", x);    // 10  → 直接看 x
printf("%d", *p);   // 10  → 順著 p 去拿 x 的值
printf("%p", p);    // x 的位址（紙條上的號碼）

*p = 20;           // 順著 p 去「改」x → x 變成 20！
printf("%d", x);    // 20  ← x 真的被改了
```
改之後：
```
 位址 0x100： [ x = 20 ]   ← 透過 *p = 20 改掉了
```
> 這就是為什麼前一篇的 **swap 用指標（傳址）能改到外面的變數**。

---

## 四、指標與陣列　【理解】＋【練流程】

- **陣列名稱本身就是「第一個元素的位址」**（`arr` ＝ `&arr[0]`）。
- 所以指標可以指向陣列、用指標走訪：

```c
int arr[3] = {10, 20, 30};
int *p = arr;          // p 指向 arr[0]（陣列名就是首位址）

printf("%d", *p);       // 10  → arr[0]
printf("%d", *(p + 1)); // 20  → arr[1]
printf("%d", p[2]);     // 30  → 指標也能用 []
```
- ⚠ **指標算術**：`p + 1` **不是位址 +1 byte，而是 +1 個元素的大小**（int 就 +4 bytes），自動跳到下一個元素。

---

## 五、用途 & 常見陷阱　【理解】

**用途**：
- **傳址**讓函式改到外面的變數（swap）。
- **動態記憶體配置**：C 用 `malloc`／`free`、C++ 用 `new`／`delete`。
- 高效處理大資料（傳位址、不用複製整份）。
- 建**鏈結串列、樹**等結構（節點靠指標串連）。

**常見陷阱（考點）**：
| 問題 | 意思 |
|---|---|
| **空指標 NULL** | 不指向任何東西；**解參考 NULL 會崩潰**（segmentation fault） |
| **迷途指標 dangling** | 指向**已釋放／無效**的記憶體 |
| **記憶體洩漏 leak** | `malloc` 後**忘了 `free`**，記憶體拿不回來 |

---

## 六、C/C++ vs Java/Python　【理解】

| | C／C++ | Java／Python |
|---|---|---|
| 指標 | **有**，可直接操作位址 | **沒有明確指標**（用「參考」概念，不能直接碰位址） |
| 記憶體管理 | **手動**（malloc/free、new/delete） | **自動**（GC 垃圾回收） |
| 取捨 | 強大、底層、易出錯 | 安全、但較不底層 |

---

## 七、重點整理（背這張）

- 指標存的是**位址**（紙條寫房號），不是值。
- **`&` 拿地址、`*` 順著地址拿值**；`*p = 20` 會改到 p 指向的那個變數。
- **陣列名 ＝ 首元素位址**；`*(p+i)` ＝ `arr[i]`；指標 +1 跳「一個元素大小」。
- 用途：傳址、動態配置（malloc/free）、串接資料結構。
- 陷阱：**NULL 解參考崩潰、迷途指標、記憶體洩漏（忘了 free）**。
- **Java／Python 沒有明確指標、記憶體由 GC 自動回收**。
