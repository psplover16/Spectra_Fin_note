# 資料結構與演算法 3：堆疊 Stack + 佇列 Queue

> 科目：資料結構與演算法
> 學習方式：特色／應用／比較屬【理解】；**環狀佇列的索引與滿／空判斷**屬【練流程】。
> 一樣用程式碼＋圖幫你快速理解。

---

## 一、堆疊 Stack　【理解】

- **核心：LIFO（Last In First Out，後進先出）**。只能從**同一端（頂端 top）**進出。
- 像一疊盤子：最後放上去的，最先拿下來。
  ```
  push →  ┌───┐  → pop
          │ 30│   top（頂端，進出都在這）
          ├───┤
          │ 20│
          ├───┤
          │ 10│
          └───┘
  ```
- **主要操作**：
  - `push(x)`：壓入（放到頂端）
  - `pop()`：彈出（從頂端拿走）
  - `peek()／top()`：看頂端但不拿走
  - `isEmpty()`：是否空

```
push(x):  top++;  arr[top] = x;             // 放到頂端
pop():    x = arr[top];  top--;  return x;  // 從頂端拿走
```

- **實際應用**：
  - 函式呼叫的**呼叫堆疊（call stack）**、**遞迴**
  - **括號配對檢查**、運算式求值（中序 → 後序）
  - **上一步 Undo**、瀏覽器「上一頁」

---

## 二、佇列 Queue　【理解】

- **核心：FIFO（First In First Out，先進先出）**。**後端（rear）進、前端（front）出**。
- 像排隊：先來的先被服務。
  ```
  （出）front → [10][20][30] ← rear（進）
                 ↑dequeue        ↑enqueue
  ```
- **主要操作**：
  - `enqueue(x)`：加入（從 rear）
  - `dequeue()`：取出（從 front）
  - `front()`：看前端

```
enqueue(x):  rear++;   arr[rear] = x;             // 從尾端加入
dequeue():   x = arr[front];  front++;  return x; // 從前端取出
```

- **實際應用**：
  - **排程**（CPU 排程、列印佇列）
  - **廣度優先搜尋 BFS**
  - **緩衝區 buffer**、訊息佇列

## 三、四者比較：Array / Linked List / Stack / Queue　【理解】

> 重要觀念：**Stack 和 Queue 是「限制存取方式」的抽象資料型別（ADT）**，底層其實可用**陣列或鏈結串列**實作。陣列／鏈結串列講的是「**怎麼存**」，堆疊／佇列講的是「**怎麼進出**」。

| | 進出方式 | 特性 |
|---|---|---|
| **Array 陣列** | 用**索引**隨機存取任一格 | 連續、存取 O(1)、大小固定 |
| **Linked List** | **從頭循序**走 | 不連續、動態、插刪改指標 |
| **Stack 堆疊** | 只在**頂端**進出 | **LIFO** 後進先出 |
| **Queue 佇列** | **後端進、前端出** | **FIFO** 先進先出 |

## 四、環狀佇列 Circular Queue　【理解】＋【練流程】

### 為什麼要環狀？（解決「假性溢位」）
用陣列做的普通佇列，front 和 rear 一直往後移。即使前面 dequeue 後空出格子，rear 一旦到底就被當成「滿了」，**前面空間白白浪費** → 稱為**假性溢位（false overflow）**。

**解法**：把陣列**頭尾相接成環**，rear 到底就**繞回開頭**，重複利用空間。
```
        [0]
     [4]   [1]
        [3][2]      ← rear 到 4 後，下一步繞回 0
```

### 怎麼繞回？（取餘數）
> 移動時用 **`(index + 1) % size`** 繞回開頭。
> 例：size = 5，rear 在 4，下一步 `(4 + 1) % 5 = 0` → 回到索引 0。

### 滿 / 空怎麼分？（「犧牲一格」的巧思）
問題：**空**和**滿**時都會是 `front == rear`，無法區分！
常見解法 —— **故意留一格不用**：

| 狀態 | 判斷 |
|---|---|
| **空** | `front == rear` |
| **滿** | `(rear + 1) % size == front`（rear 的下一格剛好是 front，視為滿） |

> 所以容量 size 的環狀佇列，**實際只能放 size − 1 個**（犧牲一格來區分滿與空）。
> （另有用「計數器 count」的版本可放滿 size 個，但考試最常考「留一格」這種。）

---

## 五、重點整理（背這張）

- **Stack ＝ LIFO（後進先出）**，push／pop 都在**頂端**；應用：遞迴、call stack、括號配對、Undo。
- **Queue ＝ FIFO（先進先出）**，**後進前出**；應用：排程、BFS、buffer。
- Stack／Queue 是**存取規則（ADT）**，底層可用陣列或鏈結串列實作。
- **環狀佇列**：解決假性溢位，用 **`(i + 1) % size`** 繞回；
  - 空 `front == rear`、滿 `(rear + 1) % size == front`，**實際可放 size − 1 個**。
