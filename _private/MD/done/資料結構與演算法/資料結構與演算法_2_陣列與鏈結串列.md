# 資料結構與演算法 2：陣列 Array + 鏈結串列 Linked List

> 科目：資料結構與演算法
> 學習方式：特色／比較屬【理解】；**位址計算**與**插入／刪除指標操作**屬【練流程】。
> 用程式碼＋圖來理解最快（你本來就會 code）。

---

## 一、陣列 Array

### 特色　【理解】
- **連續**記憶體存放**相同型別**的元素，用**索引（index）**直接定位。
- **隨機存取 O(1)**（給索引就能直接算出位址、直接取）。
- **大小固定**（宣告時決定）。
- 在中間**插入／刪除要搬移**後面所有元素 → **O(n)**。

| 優點 | 缺點 |
|---|---|
| 隨機存取快（O(1)）、不用額外指標、省空間 | 大小固定、插入／刪除慢（要搬移） |

### 一維陣列位址計算　【練流程】

公式（起始位址 B、每個元素 d bytes、索引從 L 開始）：
> **A[i] 位址 ＝ B ＋ (i − L) × d**

**範例**：`int A[10]`，起始位址 1000，每個 int 4 bytes，索引從 0。求 A[5]？
→ 1000 ＋ (5 − 0) × 4 ＝ 1000 ＋ 20 ＝ **1020**

### 二維陣列位址計算　【練流程】

二維 `A[m][n]`（m 列 rows、n 行 columns），兩種儲存方式（索引都從 0 起）：

- **Row-major（列優先，一列一列存；C／Java 用這個）**
  > **A[i][j] ＝ B ＋ (i × n ＋ j) × d**
- **Column-major（行優先，一行一行存；Fortran 用）**
  > **A[i][j] ＝ B ＋ (j × m ＋ i) × d**

**範例**：`A[3][4]`（3 列 4 行），起始位址 1000，每元素 4 bytes，求 **A[1][2]**：
- Row-major：1000 ＋ (1 × 4 ＋ 2) × 4 ＝ 1000 ＋ 6 × 4 ＝ **1024**
- Column-major：1000 ＋ (2 × 3 ＋ 1) × 4 ＝ 1000 ＋ 7 × 4 ＝ **1028**

> 看出差別了嗎？同一格 A[1][2]，**列優先用「行數 n」當乘數、行優先用「列數 m」當乘數**。考試會明講是哪一種（沒講通常預設 row-major）。

## 二、鏈結串列 Linked List

### 特色與運作　【理解】
- 由**節點（node）**串成，每個節點 ＝ **資料 data ＋ 指向下一個節點的指標 next**。
- 節點在記憶體中**不連續**，靠指標串起來：
  ```
  head → [10|•] → [20|•] → [30|null]
  ```
- **大小可動態增減**；但**不能隨機存取**，要找第 k 個得**從頭走** → O(n)。

節點長這樣（類 Java）：
```
class Node {
    int  data;
    Node next;   // 指向下一個節點（最後一個指向 null）
}
```

### Array vs Linked List　【理解】

| | 陣列 Array | 鏈結串列 Linked List |
|---|---|---|
| 記憶體 | **連續** | **不連續**（靠指標） |
| 大小 | 固定 | **動態** |
| 隨機存取（用索引） | **O(1)** 快 | O(n) 慢（從頭走） |
| 插入／刪除 | O(n)（要搬移） | **O(1)**（已知位置，只改指標） |
| 額外空間 | 無 | 每節點多存一個指標 |

### 插入／刪除（重點：改指標）　【練流程】

**① 在 head 前插入（頭插）**
```
newNode.next = head;   // 新節點指向原本的頭
head = newNode;        // 頭換成新節點
```
```
new → [舊head] → ...
```

**② 在節點 p 之後插入**
```
newNode.next = p.next;  // 先讓新節點接住 p 的下一個
p.next = newNode;       // 再讓 p 指向新節點
```
> 順序很重要：**先接後面、再改 p**。反過來先改 p，後面整串就弄丟了（斷鏈）。

**③ 刪除 p 的下一個節點**
```
p.next = p.next.next;   // p 直接跳過下一個，指向「下下個」
```
```
刪除前： [p] → [X] → [下下個] → ...
刪除後： [p] ───────→ [下下個] → ...   （X 沒人指向 → 移除）
```

### 單向 / 雙向 / 環狀　【理解】

| 種類 | 結構 | 特點 |
|---|---|---|
| **單向 Singly** | 每節點只有 **next** | 只能往一個方向走 |
| **雙向 Doubly** | 每節點有 **prev ＋ next** | 可往前往後走；多一個指標的空間 |
| **環狀 Circular** | 最後一個 next **指回頭** | 形成環，可從任一點繞遍全部 |

---

## 三、重點整理（背這張）

- 陣列：**連續、隨機存取 O(1)、大小固定、插刪要搬移 O(n)**。
- 一維位址：**B ＋ (i − L) × d**。
- 二維：**row-major 用行數 n**（`B+(i·n+j)·d`）、**column-major 用列數 m**（`B+(j·m+i)·d`）。
- 鏈結串列：**不連續、靠指標、動態、隨機存取 O(n)、插刪改指標 O(1)**。
- 中間插入：**先接後面、再改前面**（否則斷鏈）。
- 三種：單向（next）、雙向（prev＋next）、環狀（尾接頭）。
