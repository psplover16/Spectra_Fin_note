## 一、演算法是什麼（定義 + 5 個必要條件）　【理解】

- **演算法 Algorithm**：解決問題的一組「**明確、有限**步驟」的方法。
- **5 個必要條件（Knuth）**：

| 條件 | 意思 |
|---|---|
| **輸入 Input** | 可有 **0 或多個**輸入 |
| **輸出 Output** | **至少 1 個**輸出（結果） |
| **明確性 Definiteness** | 每個步驟都清楚、不含糊 |
| **有限性 Finiteness** | 執行**有限步驟後一定會停**（不能無限跑） |
| **有效性 Effectiveness** | 每個步驟都**基本、可實際執行** |

> 口訣：**輸入、輸出、明確、有限、有效。**（注意：輸入可以 0 個，但輸出至少 1 個。）

---

## 二、複雜度：用途與核心想法　【理解】

- **用途**：衡量演算法「跑多快（時間）、用多少記憶體（空間）」**隨資料量 n 成長的趨勢**，用來比較效率，而且**不受機器快慢影響**（看成長趨勢、不是絕對秒數）。
- **核心想法**：Big-O 描述「**執行次數隨 n 成長的數量級**」，只看**成長最快的那一項**，**丟掉常數與低次項**。
  - 例：`3n² + 5n + 100` → **O(n²)**（只留最高次、丟係數與低項）。

---

## 三、怎麼判斷（看程式碼）　【練流程】

| 程式長相 | 複雜度 |
|---|---|
| 固定次數、沒迴圈（一次加法、陣列索引存取） | **O(1)** 常數 |
| 一層迴圈跑 n 次 | **O(n)** 線性 |
| 兩層巢狀迴圈（各跑 n） | **O(n²)** 平方 |
| 每次把問題**減半**（如二分搜尋） | **O(log n)** 對數 |
| 分治 ＋ 每層處理 n（如合併排序） | **O(n log n)** |

**常見複雜度由快到慢（必背比較圖）：**
> **O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)**

---

## 四、手把手範例（看程式碼判複雜度）

**範例 1：一層迴圈**
```
for (i = 0; i < n; i++) {
    print(i);          // 執行 n 次
}
```
→ 一層跑 n 次 → **O(n)**

**範例 2：兩層巢狀**
```
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        print(i, j);   // 執行 n × n 次
    }
}
```
→ n × n → **O(n²)**

**範例 3：每次減半**
```
i = n;
while (i > 1) {
    i = i / 2;         // 每次砍一半
}
```
→ 從 n 一直減半到 1，要 **log₂ n** 次 → **O(log n)**

**範例 4：兩段相加，取最高次**
```
for (i=0; i<n; i++) { ... }          // 這段 O(n)
for (i=0; i<n; i++)                  // 這段 O(n²)
    for (j=0; j<n; j++) { ... }
```
→ O(n) ＋ O(n²)，**取最大** → **O(n²)**

> 規則：**相加取最高次、丟係數；巢狀迴圈是「相乘」。**

## 五、最佳／平均／最壞 + 時間／空間　【理解】

- **三種情況**：最佳（Best）、平均（Average）、**最壞（Worst）**。Big-O 通常指「**最壞情況的上界**」。
  - （另有 Ω 下界、Θ 緊界，但考試最常用 **Big-O 上界**。）
- **時間複雜度**：執行「次數／時間」隨 n 的成長。
- **空間複雜度**：用的「**額外記憶體**」隨 n 的成長。
- 兩者常有**取捨（time–space tradeoff）**：想更快常要用更多空間，反之亦然。

---

## 六、對照表（背這張）

| 複雜度 | 名稱 | 典型例子 |
|---|---|---|
| **O(1)** | 常數 | 陣列用索引取值、加法 |
| **O(log n)** | 對數 | 二分搜尋 |
| **O(n)** | 線性 | 一層迴圈、線性搜尋 |
| **O(n log n)** | 線性對數 | 合併排序、快速排序（平均） |
| **O(n²)** | 平方 | 兩層巢狀、氣泡／選擇／插入排序 |
| **O(2ⁿ)** | 指數 | 窮舉所有子集 |
| **O(n!)** | 階乘 | 全排列 |

**口訣：**
- **演算法 5 條件：輸入、輸出、明確、有限、有效。**
- **看迴圈層數估次方（一層 n、兩層 n²）；減半就是 log；分治＋每層 n 就是 n log n。**
- **只留最高次、丟係數；相加取最高次、巢狀相乘。**
