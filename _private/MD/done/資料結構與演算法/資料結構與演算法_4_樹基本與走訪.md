# 資料結構與演算法 4：樹 Tree（基本）+ 前中後序走訪

> 科目：資料結構與演算法
> 學習方式：**術語、二元樹特性公式**屬【硬背】（你朋友說 Tree 名詞多）；**走訪**屬【練流程】。
> 走訪用同一棵樹畫圖＋逐步跑，看懂三種差在哪。

---

## 一、樹 Tree 定義　【理解】

- **樹**：一種**階層式（hierarchical）**的非線性結構，由**節點 node**和**邊 edge**組成，從一個**根**往下分支。
- 特性：
  - 有**唯一的根**；除了根，**每個節點恰有一個父節點**。
  - **沒有環（acyclic）**；n 個節點有 **n − 1 條邊**。
  - 任兩節點間**只有一條路徑**。

---

## 二、基本術語（名詞多，要記）　【硬背】

```
            A           ← 根 Root（第 1 層）
          /   \
         B     C        ← 第 2 層
        / \     \
       D   E     F      ← 第 3 層（D、E、F 是葉 Leaf）
```

| 術語 | 意思 |
|---|---|
| **根 Root** | 最上層、**沒有父節點**的節點（上圖 A） |
| **葉 Leaf／終端節點** | **沒有子節點**的節點（D、E、F） |
| **內部節點／非終端** | 有子節點的節點（A、B、C） |
| **父 Parent／子 Child** | 上下層直接相連：A 是 B 的父、B 是 A 的子 |
| **兄弟 Sibling** | 同一個父的節點（B、C 互為兄弟） |
| **祖先／子孫 Ancestor／Descendant** | 往上／往下整條線上的節點 |
| **分支度 Degree（節點的）** | 這個節點**有幾個子節點**（A 的 degree＝2） |
| **樹的分支度** | 所有節點中**最大的 degree** |
| **層 Level** | 根為第 1 層，往下 +1 |
| **高度 Height／深度** | 從根到最深葉的層數（上圖高度＝3） |
| **子樹 Subtree** | 某節點和它所有子孫構成的樹 |
| **森林 Forest** | 多棵樹的集合（把樹的根拿掉就成森林） |

> ⚠ 注意：**Level（層）和 Height（高度）的起算，不同教材有從 0 或從 1 兩種**。本篇用「**根＝第 1 層**」。考題若有定義就依題目。

## 三、二元樹 Binary Tree　【理解】＋【硬背】

### 定義
每個節點**最多 2 個子節點**（左子 left、右子 right），而且**分左右**（左、右不一樣，有順序）。

### 常見種類（名稱中英對照，概念為準）
| 種類 | 條件 |
|---|---|
| **Full（嚴格）二元樹** | 每個節點**不是葉、就是恰好有 2 個子** |
| **Complete 完全二元樹** | 除最後一層外**都填滿**，最後一層節點**靠左排** |
| **Perfect 完美二元樹** | **每一層都填滿**（所有葉在同一層） |
| **Skewed 偏斜樹** | 每個節點只有一邊子（退化成像鏈結串列） |

> 中文書「滿二元樹」有時指 Full、有時指 Perfect，**以英文／概念為準**。

### 重要特性公式　【硬背】
（根為第 1 層）
- 第 **i** 層最多 **2^(i−1)** 個節點。
- 高度 **h** 的二元樹最多 **2^h − 1** 個節點。
- **葉節點數 ＝ 分支度為 2 的節點數 ＋ 1**，即 **n₀ ＝ n₂ ＋ 1**（超常考！）
- n 個節點 → 有 **n + 1 個空連結（null link）**。

> n₀ ＝ n₂ ＋ 1 怎麼來：總節點 n ＝ n₀＋n₁＋n₂，總邊 ＝ n − 1 ＝ n₁＋2n₂，兩式相減即得。

### Binary Tree vs Tree
| | 一般樹 Tree | 二元樹 Binary Tree |
|---|---|---|
| 子節點數 | 不限 | **最多 2** |
| 左右順序 | 不分 | **分左右**（左 ≠ 右） |
| 可否為空 | 通常至少 1 節點 | **可以是空樹** |

## 四、前 / 中 / 後序走訪　【練流程】★

三種都是**深度優先**走訪，差別只在「**根**什麼時候訪問」（左永遠在右前面）：

| 走訪 | 順序 | 「根」的位置 |
|---|---|---|
| **前序 Preorder** | **根 → 左 → 右** | 根**先** |
| **中序 Inorder** | **左 → 根 → 右** | 根**中間** |
| **後序 Postorder** | **左 → 右 → 根** | 根**最後** |

> 口訣：「前／中／後」指的是**根**的位置；左恆在右之前。
> （另有**層序 Level-order**：一層一層走，用 **Queue**，就是 BFS。）

### 程式碼：三種只差「visit() 放哪一行」
```
preorder(node):
    if node == null: return
    visit(node)           // 根 ← 前序：根在最前
    preorder(node.left)   // 左
    preorder(node.right)  // 右
```
中序把 `visit()` 移到左、右中間；後序把 `visit()` 移到最後。**邏輯一模一樣，只是 visit 的位置不同**。

### 手把手：同一棵樹跑三種
```
        A
       / \
      B   C
     / \   \
    D   E   F
```
- **前序（根左右）**：`A B D E C F`
- **中序（左根右）**：`D B E A C F`
- **後序（左右根）**：`D E B F C A`

拆解（用 B 的子樹示範）：B 子樹是 `D—B—E`
- 前序＝根先：`B D E`；中序＝根中：`D B E`；後序＝根後：`D E B`。
整棵就是把各子樹照規則拼起來。

## 五、重點整理（背這張）

- 樹：階層式、唯一根、n 節點 n−1 邊、無環。
- 術語重點：葉（無子）、分支度（子數）、層、高度；**Level／Height 起算有 0 與 1 兩種**。
- 二元樹：最多 2 子、分左右、可空。
- 公式：第 i 層最多 **2^(i−1)**；高 h 最多 **2^h − 1**；**n₀ ＝ n₂ ＋ 1**；n 節點 n+1 空連結。
- 走訪看「根」位置：**前＝根左右、中＝左根右、後＝左右根**；程式只差 visit() 放哪。
