## 一、最小生成樹 MST：Kruskal vs Prim　【練流程】★

兩個都在求 MST（總權重最小、連通、含全部頂點、n−1 條邊），策略不同：

| | Kruskal | Prim |
|---|---|---|
| 核心 | **從最小的「邊」開始挑** | **從一個「頂點」長出去** |
| 規則 | 邊由小到大選，**不成環**就加，選到 n−1 條 | 每次選「連到已選集合、最小、不成環」的邊 |
| 導向 | 邊導向（適合稀疏圖） | 頂點導向（適合稠密圖） |

**示範帶權圖**（無向，5 頂點）。邊與權重：
> A-B=1、B-C=2、A-C=3、C-D=4、B-D=5、D-E=6、C-E=7
```
        A
      1/ \3
      B───C
      |\ /|
      | X |          B-C=2；交叉的是 B-D=5、C-D=4
      |/ \|
      D   E
       \ /
       6,7            D-E=6、C-E=7
```

### Kruskal（把邊由小到大挑）
邊排序：**AB(1) → BC(2) → AC(3) → CD(4) → BD(5) → DE(6) → CE(7)**

| 看這條邊 | 動作 | 已選邊 |
|---|---|---|
| AB(1) | 加入 | AB |
| BC(2) | 加入 | AB, BC |
| AC(3) | A、C 已連通 → **跳過（會成環）** | AB, BC |
| CD(4) | 加入 | AB, BC, CD |
| BD(5) | B、D 已連通 → **跳過** | AB, BC, CD |
| DE(6) | 加入（第 4 條，完成） | AB, BC, CD, DE |

→ **MST：AB, BC, CD, DE，總權重 ＝ 1+2+4+6 ＝ 13**

### Prim（從 A 開始長）

| 步 | 已納入頂點 | 可選的「跨界邊」 | 選最小 | 新增頂點 |
|---|---|---|---|---|
| 1 | {A} | AB(1), AC(3) | **AB(1)** | B |
| 2 | {A,B} | AC(3), BC(2), BD(5) | **BC(2)** | C |
| 3 | {A,B,C} | CD(4), CE(7), BD(5) | **CD(4)** | D |
| 4 | {A,B,C,D} | DE(6), CE(7) | **DE(6)** | E |

→ **MST：AB, BC, CD, DE，總權重 ＝ 13**（和 Kruskal 結果相同）

## 二、最短路徑：Dijkstra vs Floyd-Warshall　【練流程】★

| | Dijkstra | Floyd-Warshall |
|---|---|---|
| 求什麼 | **單一起點**到所有點（single-source） | **所有點對之間**（all-pairs） |
| 做法 | 每次挑「目前最短的未確定點」，更新其鄰居 | 三層迴圈，用每個頂點當「中繼站」更新 |
| 負權邊 | **不可**有負權邊 | 可（但不可有負環） |
| 複雜度 | O((V+E) log V) 或 O(V²) | **O(V³)** |

### Dijkstra（從 A 跑）
**示範有向圖**：A→B(1)、A→C(4)、B→C(2)、B→D(5)、C→D(1)
```
   A
 1↓ ↘3... （A→C=4）
   B─2→C
 5↓   ↓1
   D ←─┘
```

每步挑「最短的未確定點」，鬆弛（更新）它的鄰居：

| 動作 | A | B | C | D |
|---|---|---|---|---|
| 初始 | 0 | ∞ | ∞ | ∞ |
| 挑 **A(0)**，更新 B、C | 0 | 1 | 4 | ∞ |
| 挑 **B(1)**，更新 C、D | 0 | 1 | **3** | 6 |
| 挑 **C(3)**，更新 D | 0 | 1 | 3 | **4** |
| 挑 **D(4)** | 0 | 1 | 3 | 4 |

→ 從 A 的最短距離：**B=1、C=3、D=4**；到 D 的路徑 **A→B→C→D（1+2+1=4）**

> 注意 C：A→C 直接是 4，但 **A→B→C ＝ 1+2 ＝ 3 更短**，所以更新成 3。這個「繞一下反而更短」就是鬆弛（relaxation）的精神。

### Floyd-Warshall（概念）
- 對每個「中繼點 k」，檢查所有 i→j：**繞過 k 會不會更短**：
  > **dist[i][j] ＝ min( dist[i][j], dist[i][k] ＋ dist[k][j] )**
- 三層迴圈（**k 在最外層**），把所有點對都算出來 → **O(V³)**。

## 三、AOV / AOE 網路　【理解】★

| | AOV 網路 | AOE 網路 |
|---|---|---|
| 全名 | Activity **On Vertex** | Activity **On Edge** |
| 頂點代表 | **活動** | **事件（里程碑）** |
| 邊代表 | **先後順序**（前置關係） | **活動**（含所需時間） |
| 對應演算法 | **拓樸排序 Topological Sort** | **關鍵路徑 Critical Path** |
| 用途 | 排出可行先後順序（課程先修、工序） | 算專案最短完成時間（CPM／PERT） |

### 拓樸排序（AOV 用）
把**有向無環圖（DAG）**的頂點排成線性順序，使每條邊都**由前指向後**。
- **做法**：反覆找**入度為 0** 的頂點輸出、移除（連同它的邊），直到全部輸出。
- 範例 DAG：A→B、A→C、B→D、C→D
  - 入度 0 的是 A → 輸出 A → B、C 入度變 0
  - 輸出 B → D 入度剩 1；輸出 C → D 入度 0；輸出 D
  - **拓樸排序：A, B, C, D**（合法順序之一）

### 關鍵路徑（AOE 用）
- **關鍵路徑 ＝ 從起點到終點「最長」的路徑**，它決定**整個專案的最短完成時間**。
- 關鍵路徑上的活動**不能延誤**（沒有寬裕時間 slack），一誤整個專案就 delay。

## 四、圖演算法複雜度總表（背這張）　【硬背】

| 演算法 | 複雜度 | 用途 |
|---|---|---|
| **DFS／BFS** | O(V+E) | 走訪 |
| **Kruskal** | O(E log E) | MST（挑邊） |
| **Prim** | O(E log V) 或 O(V²) | MST（長頂點） |
| **Dijkstra** | O((V+E) log V) 或 O(V²) | 單源最短路（**不可負權**） |
| **Floyd-Warshall** | **O(V³)** | 全點對最短路 |
| **拓樸排序** | O(V+E) | AOV 先後順序 |

---

## 五、重點整理（背這張）

- **MST**：Kruskal＝**挑最小邊、不成環**；Prim＝**從頂點長出去、挑最小跨界邊**；兩者結果同為最小生成樹。
- **最短路徑**：Dijkstra＝**單源、不可負權**、挑最短點再鬆弛；Floyd-Warshall＝**全點對、O(V³)**、用中繼點更新。
- **AOV**（頂點＝活動）→ **拓樸排序**（找入度 0 輸出）；**AOE**（邊＝活動）→ **關鍵路徑**（最長路徑＝最短完工時間）。
- 複雜度：DFS／BFS、拓樸 O(V+E)；Kruskal O(E log E)；Dijkstra O(V²)／O((V+E)log V)；Floyd O(V³)。
