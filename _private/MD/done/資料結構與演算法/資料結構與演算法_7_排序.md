> 最重要的是最後那張**比較表（幾乎必考）**；幾個重點排序用例子一步步演（朋友建議「把每步畫出來」）。

---

## 一、排序定義 + 穩定性　【理解】

- **排序**：把一堆資料**按大小（或某鍵值）排成順序**。
- **穩定性 Stability（重要！）**：排序後，**值相等**的元素**相對順序不變**，就叫**穩定**。
  - 例：兩個都是 3 → 排序前 `3ᵃ` 在 `3ᵇ` 前，排序後 `3ᵃ` 仍在 `3ᵇ` 前 → **穩定**。
  - 為什麼重要：**多欄位排序**時（先按部門排、再按薪水排），穩定排序能**保留前一次的順序**。

---

## 二、簡單排序（都是 O(n²)）

### 氣泡排序 Bubble Sort（穩定）
相鄰兩兩比，**大的往後換**，每輪把最大的「冒泡」到最後。

逐步跑 `[5, 3, 8, 1]`：
```
第1輪： [5,3,8,1] →(5>3換) [3,5,8,1] →(5<8不換) [3,5,8,1] →(8>1換) [3,5,1,8]   8到底
第2輪： [3,5,1,8] →(3<5不換) [3,5,1,8] →(5>1換) [3,1,5,8]                       5到位
第3輪： [3,1,5,8] →(3>1換) [1,3,5,8]                                            完成
```
- 時間：最好 **O(n)**（已排序＋旗標判斷）、平均／最差 **O(n²)**。

### 選擇排序 Selection Sort（不穩定）
每輪從**未排序中找最小**，放到前面。
- 時間：最好／平均／最差**都 O(n²)**（不管怎樣都得找最小）。

### 插入排序 Insertion Sort（穩定）
像整理撲克牌：把每個元素**插入到前面已排序部分的正確位置**。
- 時間：最好 **O(n)**（已排序）、平均／最差 **O(n²)**。
- 資料量小或接近排序好時很快。

---

## 三、進階排序（都是 O(n log n)）

### 合併排序 Merge Sort（穩定）
**分治**：對半分到不能再分，再兩兩**合併**成有序。

`[5,3,8,1]`：
```
分： [5,3,8,1] → [5,3] [8,1] → [5][3] [8][1]
合： [5][3]→[3,5]   [8][1]→[1,8]   →   [3,5]+[1,8] → [1,3,5,8]
```
- 時間：最好／平均／最差**都 O(n log n)**（穩定的 n log n）。
- 空間：**O(n)**（需額外陣列合併）。

### 快速排序 Quick Sort（不穩定）
**分治**：選一個**樞紐 pivot**，把**比它小的放左、大的放右**（partition），再對左右遞迴。

`[5,3,8,1,4]`，pivot＝4：
```
分割後： [3,1] 4 [5,8]      （比4小的在左、大的在右，4 歸位）
遞迴左 [3,1]→[1,3]、右 [5,8]→[5,8]
結果： [1,3,4,5,8]
```
- 時間：最好／平均 **O(n log n)**、**最差 O(n²)**（pivot 每次都挑到最大／最小，例如資料已排序）。
- 實務上**最快的通用排序**（常數因子小）。

### 堆積排序 Heap Sort（不穩定）
先**建最大堆**，再反覆**取出根（最大）放到尾端**、調整堆。（用前面 Heap 那套）
- 時間：最好／平均／最差**都 O(n log n)**；空間 **O(1)**。

---

## 四、特殊：基數排序 Radix Sort（穩定）

**非比較式**排序：按**位數**從個位 → 高位，用**桶子（0~9）**分配再收集。
- 時間：**O(d×(n+k))** ≈ **O(n)** 線性！（d＝位數、k＝基數如 10）
- 限制：只適合**整數或固定長度的鍵**。

---

## 五、★ 七大排序比較表（必背！）　【硬背】

| 排序法 | 最好 | 平均 | 最差 | 穩定性 | 額外空間 |
|---|---|---|---|---|---|
| **氣泡 Bubble** | O(n) | O(n²) | O(n²) | **穩定** | O(1) |
| **選擇 Selection** | O(n²) | O(n²) | O(n²) | 不穩定 | O(1) |
| **插入 Insertion** | O(n) | O(n²) | O(n²) | **穩定** | O(1) |
| **合併 Merge** | O(n log n) | O(n log n) | O(n log n) | **穩定** | **O(n)** |
| **快速 Quick** | O(n log n) | O(n log n) | **O(n²)** | 不穩定 | O(log n) |
| **堆積 Heap** | O(n log n) | O(n log n) | O(n log n) | 不穩定 | O(1) |
| **基數 Radix** | O(n) | O(n) | O(n) | **穩定** | O(n+k) |

> （希爾排序 Shell：插入排序的改良，用間隔分組，平均約 O(n^1.5)、不穩定，視間隔序列而定。）

---

## 六、重點整理（背這張）

- **穩定排序**：氣泡、插入、合併、基數（值相等者順序不變）。**不穩定**：選擇、快速、堆積、希爾。
- **保證 O(n log n)**（不管最好最差）：**合併、堆積**。
- **快速排序**平均最快，但**最差會掉到 O(n²)**（資料已排序時）。
- **合併排序**穩定、又是穩定的 n log n，但**要 O(n) 額外空間**。
- **基數排序** O(n) 線性，但只適用整數／固定長度鍵。
- 記憶鉤子：**簡單三兄弟（氣泡／選擇／插入）＝ O(n²)**；**分治雙雄（合併／快速）＋ 堆積 ＝ O(n log n)**；**基數 ＝ 非比較、O(n)**。
