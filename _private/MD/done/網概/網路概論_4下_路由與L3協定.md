## 一、靜態路由 vs 動態路由　【理解】

| | 靜態路由 Static | 動態路由 Dynamic |
|---|---|---|
| 怎麼來 | 管理員**手動**設路由表 | 路由器間用協定**自動**交換、更新 |
| 優點 | 簡單、安全、無額外開銷、可控 | **自動適應變化**（線路斷了會繞路）、適合大網路 |
| 缺點 | 不會自動繞路、大網路難維護 | 較複雜、耗 CPU／頻寬 |
| 適合 | 小型／穩定網路 | 大型／常變動網路 |

## 二、路由協定 + Distance Vector vs Link State　【理解】＋【硬背】

| 協定 | 演算法類型 | 度量（metric） | 範圍 | 重點 |
|---|---|---|---|---|
| **RIP** | Distance Vector | **跳數 hop**（最多 15，16＝不可達） | 內部（IGP） | 簡單、收斂慢、不適合大網 |
| **OSPF** | Link State | **成本 cost**（看頻寬） | 內部（IGP） | Dijkstra 算最短路、收斂快、大網適用 |
| **BGP** | Path Vector | 路徑屬性 | **自治系統間（EGP）** | **網際網路骨幹**用的就是它 |

**Distance Vector vs Link State：**

| | Distance Vector（如 RIP） | Link State（如 OSPF） |
|---|---|---|
| 知道什麼 | 只知「到各目的地的距離＋下一跳」 | 知道**整個網路拓樸地圖** |
| 怎麼運作 | 把路由表**定期告訴鄰居** | 各自用 **Dijkstra** 算最短路 |
| 比喻 | 只看路標跳數問路 | 每個人手上都有完整地圖 |
| 缺點 | 收斂慢、可能 routing loop | 較耗資源 |

## 三、NAT（網路位址轉換）　【理解】

- **定義**：把**私有 IP ↔ 公有 IP** 互轉，讓內部多台私有 IP 裝置**共用少數公有 IP** 上網。
- **好處**：節省公有 IP、隱藏內部結構（較安全）。
- **類型**：靜態 NAT（一對一）、動態 NAT（從池中取）、**PAT／NAPT（多對一，用 port 區分，最常見）**——就是家用分享器「一個對外 IP、全家共用」的原理。

## 四、L3 常見協定（ARP 家族 / ICMP / IGMP / IPSec）　【理解】＋【硬背】

| 協定 | 做什麼 | 記憶 |
|---|---|---|
| **ARP** | 由 **IP 查 MAC**（知道對方 IP，要找 MAC 才能在區網內傳） | 「IP → MAC」 |
| **RARP** | 反過來，由 **MAC 查 IP**（早期無磁碟工作站用，後被 DHCP 取代） | 「MAC → IP」 |
| **ICMP** | 傳**錯誤訊息與診斷**（不可達、逾時 Time Exceeded）；**ping 用它**；**traceroute 靠它的「TTL 逾時」回應**找每一跳（探測封包：Windows 用 ICMP、Linux 預設 UDP） | 診斷用 |
| **IGMP** | 管理**多播（multicast）群組**成員 | 多播群組 |
| **IPSec** | 在 IP 層提供**加密與驗證**（VPN 常用） | IP 層安全 |

> **ARP Spoofing（ARP 毒化）**：攻擊者偽造 ARP 回應，把自己的 MAC 對應到別人的 IP（常是閘道），讓流量被導到攻擊者 → **中間人攻擊（MITM）**。防範：靜態 ARP、DAI（動態 ARP 檢測）。（資安會再考，見網路 8。）

## 五、網路指令　【硬背】

| 指令 | 功能 |
|---|---|
| **ping** | 測與目標是否連通、測延遲（用 ICMP） |
| **traceroute／tracert** | 顯示封包到目標經過的**每一跳路由器路徑** |
| **netstat** | 顯示本機的網路連線、埠、路由表狀態 |
| **ipconfig（Win）／ifconfig（Linux）** | 顯示／設定本機 IP 設定 |
| **nslookup** | 查 **DNS**（域名查 IP 或反查） |

## 六、IPv4 vs IPv6　【理解】＋【硬背】

| | IPv4 | IPv6 |
|---|---|---|
| 長度 | **32 bits** | **128 bits** |
| 表示 | 點分十進位（192.168.1.1） | 冒號十六進位（2001:db8::1） |
| 位址數 | 約 43 億（已枯竭） | 海量（幾乎無限） |
| 安全 | 需外加 | **內建 IPSec** |
| NAT | 常需要 | 位址夠多、**不需 NAT** |
| Header | 有 checksum、可變長度、分段欄位 | **精簡**：拿掉 checksum、固定長度、分段改由端點處理 → 處理更快 |

> 友人提示的重點：**IPv6 的 header 欄位和 IPv4 不同**——IPv6 把 checksum、IHL、分段等欄位拿掉／簡化，所以路由器處理更快。

## 七、重點整理（背這張）

- 路由：**靜態（手動、穩）vs 動態（自動、適應變化）**。
- **RIP ＝ 距離向量／跳數（≤15）、OSPF ＝ 鏈結狀態／Dijkstra、BGP ＝ AS 間／網際網路骨幹。**
- 距離向量「告訴鄰居我的表」、鏈結狀態「人人有完整地圖」。
- NAT ＝ 私有 ↔ 公有，**PAT 多對一最常見**。
- **ARP：IP→MAC；RARP：MAC→IP；ICMP：ping／診斷；IGMP：多播；IPSec：IP 層加密。**
- IPv6 ＝ 128 位元、海量位址、header 精簡、內建 IPSec。
