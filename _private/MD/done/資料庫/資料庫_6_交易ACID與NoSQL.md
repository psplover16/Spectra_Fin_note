# 資料庫 6：交易 ACID + NoSQL

> 科目：資料庫（最後一篇）
> 學習方式：**ACID 四特性**屬【硬背】＋【理解】（必考）；NoSQL 概念與種類屬【理解】＋【硬背】。

---

## 一、交易 Transaction　【理解】

- **交易 Transaction**：一組**「要嘛全部成功、要嘛全部失敗」**的資料庫操作，視為**一個不可分割的工作單位**。
- **例**：**轉帳** ＝ A 扣 1000 ＋ B 加 1000，這**兩步必須同時成功或同時失敗**（不能只扣不加）。
- **控制指令**：`COMMIT`（提交，永久生效）、`ROLLBACK`（回復，撤銷整筆交易）、`SAVEPOINT`（設儲存點）。

---

## 二、ACID 四特性（必考）★　【硬背】＋【理解】

交易必須滿足的四個特性（用「轉帳」貫穿理解）：

| 特性 | 意思 | 轉帳例子 |
|---|---|---|
| **原子性 Atomicity** | 全部成功或全部失敗，**不會只做一半** | 扣款＋加款要嘛都成、要嘛都不做 |
| **一致性 Consistency** | 交易前後，資料庫都維持**合法／一致的狀態** | 轉帳前後**總金額不變** |
| **隔離性 Isolation** | 多個交易同時進行時，**彼此不互相干擾**（像各自獨立執行） | 兩筆轉帳同時跑，不會讀到對方的中間狀態 |
| **持久性 Durability** | 一旦 `COMMIT`，結果**永久保存**，**當機也不遺失** | 轉帳成功後，斷電重開資料還在 |

> 口訣：**ACID ＝ 原子、一致、隔離、持久。**

**補充（隔離性相關，常一起考）**——多交易並行若沒隔離好，會有：
- **髒讀 Dirty Read**：讀到別的交易**還沒 commit** 的資料。
- **不可重複讀 Non-repeatable Read**：同一筆資料前後讀到不一樣。
- **幻讀 Phantom Read**：同一查詢前後**筆數**不一樣。

---

## 三、NoSQL（非關聯式資料庫）　【理解】＋【硬背】

- **NoSQL（Not Only SQL）**：**非關聯式**資料庫，**不用固定 schema、不一定用 SQL**，適合**大量、非結構化、高擴展**的資料（大數據、Web 應用）。
- **特點**：
  - **沒有固定 schema**（結構彈性）。
  - **水平擴展容易**（scale out，加機器）。
  - 適合**大數據、高並發**。
  - 常採 **BASE** 取向（**最終一致**），而非嚴格 ACID。

### 四種類型
| 類型 | 怎麼存 | 代表 |
|---|---|---|
| **鍵值 Key-Value** | key → value（像字典） | Redis、DynamoDB |
| **文件 Document** | JSON／BSON 文件 | MongoDB |
| **欄位族 Column-family** | 按欄位族存 | Cassandra、HBase |
| **圖形 Graph** | 節點 ＋ 關係 | Neo4j |

### SQL（關聯式）vs NoSQL
| | SQL 關聯式 | NoSQL |
|---|---|---|
| 結構 | **固定 schema**、表格 | **彈性**、無固定 schema |
| 擴展 | **垂直**（scale up，升級單機） | **水平**（scale out，加機器） |
| 一致性 | **強（ACID）** | **最終一致（BASE）** |
| 適合 | 結構化、交易嚴謹（**金融**） | 大數據、高並發、非結構化 |

> **ACID vs BASE**：BASE ＝ **B**asically **A**vailable、**S**oft state、**E**ventually consistent（基本可用、軟狀態、最終一致）——用「最終會一致」換取**高可用與擴展性**。

---

## 四、重點整理（背這張）

- **交易**：一組全成或全敗的操作；`COMMIT` 提交、`ROLLBACK` 撤銷。
- **ACID**：**原子性**（全成全敗）、**一致性**（前後合法）、**隔離性**（並行不干擾）、**持久性**（commit 後不遺失）。
- 並行問題：髒讀、不可重複讀、幻讀。
- **NoSQL**：非關聯、彈性 schema、**水平擴展**、**最終一致（BASE）**；四型 **Key-Value／Document／Column-family／Graph**。
- SQL **強一致、垂直擴展、結構化**；NoSQL **最終一致、水平擴展、大數據**。
