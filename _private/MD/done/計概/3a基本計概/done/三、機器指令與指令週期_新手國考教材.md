# 機器指令與指令週期

機器指令是「工作單」，指令週期是「處理工作單的步驟」。

## 1. 考前小抄

1. 機器指令：CPU 直接看得懂的二進位命令。
2. Opcode：做什麼。
3. Operand：對誰做，或表示資料／位置資訊。
4. 位址欄位：指令中用來指出資料位置的欄位。
5. Effective Address：真正要存取資料的位址。
6. PC：下一個指令位址。
7. IR：目前取出的指令。
8. Fetch：取指令。
9. Operand Fetch：取資料。
10. Execute：真的做動作。

## 2. 機器指令範例

### 2.1 `ADD R1, R2`

| 部分 | 意義 |
|---|---|
| ADD | Opcode，表示加法 |
| R1、R2 | Operand，表示要被操作的暫存器 |

### 2.2 `LOAD R1, 1000`

| 部分 | 意義 |
|---|---|
| LOAD | Opcode，表示載入 |
| R1 | Operand，表示目的暫存器 |
| 1000 | 位址欄位或位址資訊，表示資料位置可能和 1000 有關 |

## 3. 指令週期怎麼理解

機器指令會透過指令週期的流程，去執行機器指令希望的動作。

1. **Fetch 取指令**：先把工作單拿來。
2. **Decode 解碼**：看懂工作單要做什麼。
3. **Operand Fetch / Address Calculation 取運算元或算位址**：準備要用的資料，或算出資料真正在哪裡。
4. **Execute 執行**：真的做加法、比較、跳躍、I/O 等動作。
5. **Write Back / Store 寫回**：把結果放回暫存器或記憶體。

### 3.1 指令週期階段表

| 階段 | 英文 | 核心問題 | 常考關鍵字 |
|---|---|---|---|
| 1. 取指令 | Fetch | 取得接下來要執行的那一條機器指令所在位置 | PC、Memory、IR |
| 2. 解碼 | Decode | 這條指令要做什麼？ | Opcode、Control Unit、Addressing Mode |
| 3. 取運算元或算位址 | Operand Fetch / Address Calculation | 資料在哪裡？要拿什麼資料？ | Operand、Effective Address |
| 4. 執行 | Execute | 實際做什麼動作？ | ALU、Branch、I/O |
| 5. 寫回 | Write Back / Store | 結果放去哪裡？ | Register、Memory、Interrupt |

### 3.2 指令週期關鍵字

| 名詞 | 中文 | 白話意思 | 例子 |
|---|---|---|---|
| I/O | 輸入與輸出 | Input / Output，也就是輸入與輸出 | 讀檔、寫檔、鍵盤輸入、螢幕輸出 |
| ALU | 算術邏輯單元 | CPU 裡面負責「計算與邏輯判斷」的部件 | 加減乘除、AND、OR、比較大小 |
| Branch | 分支 | 改變程式接下來要執行哪一條指令 | if 判斷、跳到另一個位址 |

## 4. 易混淆比較

### 4.1 Fetch vs Operand Fetch

| 比較點 | Fetch | Operand Fetch |
|---|---|---|
| 取什麼 | 指令本身 | 指令要用的資料 |
| 依據 | PC 指出的指令位址 | Operand、位址欄位、定址模式 |
| 常見錯誤 | 以為 Fetch 是取資料 | 以為 Operand Fetch 是取下一條指令 |

### 4.2 PC vs IR

| 項目 | PC | IR |
|---|---|---|
| 中文 | 程式計數器 | 指令暫存器 |
| 存放內容 | 下一個要取出的指令位址 | 目前已取出的指令 |
| 白話 | 下一步去哪裡拿指令 | 剛拿到的指令先放這裡 |

### 4.3 Decode vs Execute

| 比較點 | Decode | Execute |
|---|---|---|
| 重點 | 看懂指令 | 做出動作 |
| 內容 | 判斷 Opcode、格式、定址模式 | 運算、比較、跳躍、I/O |
| 記法 | 看題目 | 寫答案 |

## 5. 國考怎麼判斷

看到題目時可以照這樣判斷：

1. 題目問「CPU 可直接執行、二進位形式」：選機器指令。
2. 題目問「指出要執行的操作」：選 Opcode。
3. 題目問「被操作的資料、暫存器或位置」：選 Operand。
4. 題目問「真正要存取的記憶體位置」：選 Effective Address。
5. 題目問「下一個指令位址」：選 PC。
6. 題目問「目前取出的指令」：選 IR。
7. 題目問「取指令」：選 Fetch。
8. 題目問「實際運算或跳躍」：選 Execute。
