# 基本計概 10：浮點數轉換（IEEE 754）

> 數值與編碼（計算題）。

## 16. 浮點數轉換

> 浮點數是電腦用來表示小數或很大、很小數字的方法。

### IEEE 754 欄位
| 類型 | 總位元 | Sign | Exponent | Fraction | bias |
| --- | ---: | ---: | ---: | ---: | ---: |
| 單精度 | 32 bits | 1 bit | 8 bits | 23 bits | 127 |
| 雙精度 | 64 bits | 1 bit | 11 bits | 52 bits | 1023 |

公式：
```text
(-1)^S × 1.F × 2^(E − bias)
```

| 欄位 | 中文 | 白話 |
| --- | --- | --- |
| S | 符號位 | 0 正、1 負 |
| E | 指數欄位 | 存的是「實際指數 + bias」 |
| F | Fraction / 尾數欄位 | 只存小數點右邊，不存最前面的 1 |

### 完整流程（發送端：算出要傳什麼）
1. 判斷正負數：正數 S = 0；負數 S = 1。
2. 計算數值的二進位。
3. 正規化成 `1.xxxxx × 2^n`。
4. 算 `E = n + bias`。
5. 把 `(n + bias)₁₀` 轉成二進位（記為 Y）。
6. 把 `1.xxxxx` 去掉最高位的 1（記為 Z）。
7. 把 S、Y、Z 組合，注意 Fraction 的 bits 數。

### 正規化
把二進位數寫成 `1.xxxxx × 2^n`：
```text
1101.101(2) = 1.101101(2) × 2^3   （小數點往左移 3 位 → 指數 +3）
0.0101(2)   = 1.01(2)    × 2^-2   （小數點往右移 2 位 → 指數 −2）
```

### 十進位小數轉二進位
- 整數部分：除以 2，記餘數，最後**倒著讀**。
- 小數部分：乘以 2，取整數，最後**順著讀**。

例：`13.625(10)`
```text
13    = 1101
0.625 = 0.101
→ 13.625(10) = 1101.101(2) = 1.101101(2) × 2^3
```

### 範例：`10.25(10)` 轉 IEEE 754 單精度
1. 符號：10.25 是正數 → **S = 0**。
2. 轉二進位：`10 = 1010`、`0.25 = 0.01` → `10.25 = 1010.01(2)`。
3. 正規化：`1010.01 = 1.01001 × 2^3` → n = 3。
4. Exponent：`E = n + bias = 3 + 127 = 130 = 10000010(2)`。
5. Fraction：`1.01001` 取小數點右邊 `01001`，補滿 23 bits → `01001000000000000000000`。

**答案**：
```text
0 10000010 01001000000000000000000   →   0x41240000
```

### 範例：IEEE 754 反推
```text
1 10000001 10000000000000000000000
```
拆欄位：
```text
S = 1
E = 10000001(2) = 129
F = 1000000000000000000000
n = E − bias = 129 − 127 = 2
1.F = 1.1(2) = 1.5(10)
→ (-1)^1 × 1.5 × 2^2 = −1 × 1.5 × 4 = −6
```
**答案**：`−6`

### 為什麼 0.1 可能不精確？
```text
0.1(10) = 0.0001100110011…(2)   （循環小數）
```
電腦欄位有限，不能存無限位，只能存近似值 → **不是所有十進位小數都能被二進位浮點數精確表示**。

### 易錯陷阱
| 容易錯的地方 | 正確觀念 |
| --- | --- |
| Exponent 直接存實際指數 n | 錯，存的是 `n + bias` |
| Fraction 把最前面的 1 也存進去 | 錯，正規化的最前面 1 是隱含位元 |
| 小於 1 的數正規化後指數寫正數 | 通常錯，小數點往右移時指數是負數 |
| 十進位小數轉二進位用除以 2 | 錯，小數部分用乘以 2 |
| 負浮點數用二補數表示 | 錯，IEEE 754 用 Sign bit 表示正負 |

### 國考答題句
1. IEEE 754 正規化數的公式為 `(-1)^S × 1.F × 2^(E − bias)`。
2. 單精度共 32 bits：Sign 1、Exponent 8、Fraction 23，bias = 127。
3. 雙精度共 64 bits：Sign 1、Exponent 11、Fraction 52，bias = 1023。
4. Exponent 欄位存的是「實際指數 + bias」，不是直接存實際指數。
5. Fraction 只存正規化後小數點右側的位元，最前面的 1 為隱含位元。
6. 十進位小數轉二進位小數時，使用乘以 2 取整數的方法。
7. 有些十進位小數轉成二進位會循環，因此浮點數可能只能近似表示。

### 考前速記
```text
單精度：1 / 8 / 23，bias = 127
雙精度：1 / 11 / 52，bias = 1023

轉換流程：
1. 看正負號，決定 S。
2. 把絕對值轉成二進位。
3. 正規化成 1.F × 2^n。
4. 算 E = n + bias。
5. Fraction 填 F，不填隱含的 1。
6. 合併 S、Exponent、Fraction。

反推流程：
1. 拆 S、E、F。
2. 算 n = E − bias。
3. Fraction 前面補回隱含的 1。
4. 套 (-1)^S × 1.F × 2^n。
```
