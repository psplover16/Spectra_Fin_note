# 基本計概 13：檢查碼（二）漢明碼與漢明距

> 數值與編碼（計算題）。文末的「常見陷阱／國考答題句／考前速記」是整個數碼+檢查碼大區的總整理。

### Hamming Code（漢明碼）
1. 用多個「校驗位（檢查位）」來定位錯誤。
2. 校驗位 = 額外加的檢查位元；要先決定是奇校驗還是偶校驗。
3. 編碼步驟（發送端）：
   - **3-1. 算需要幾個校驗位 r**：`2^r ≥ m + r + 1`（m = 資料位數）。
   - **3-2. 排位置**（編號從左到右、從 1 開始）：第 1, 2, 4, 8…（2 的次方）位放校驗位 P1, P2, P4…；其餘位置依序填原始資料。
     - Hamming(7,4)：7 個總位元、4 個資料位元、3 個檢查位元。例：原始 `1011`
       ```text
       位置:      1   2   3   4   5   6   7
       位置2進制: 001 010 011 100 101 110 111
       內容:      P1  P2  1   P4  0   1   1
       （資料 1-0-1-1 填進位置 3,5,6,7）
       ```
   - **3-3. 算每個校驗位**：
     - P1 檢查「位置編號二進位**最右邊（個位）是 1**」的位置 → 1/3/5/7。
     - P2 檢查「位置編號二進位**最中間是 1**」的位置 → 2/3/6/7。
     - P4 檢查「位置編號二進位**最左邊是 1**」的位置 → 4/5/6/7。
       > 【修正】原筆記此行寫「最右邊是 1」，與其後的範例位置 4/5/6/7 矛盾（4/5/6/7 對應的是最左邊那一位 = 1）。P4 應為**最左邊**，已更正。
   - **3-4. 驗證**：把漢明碼重新檢查 P1、P2、P4 負責的範圍是否符合校驗。當資料位元出錯時，可透過校驗位找出錯誤位置，把那一個 bit 反轉回來，即可恢復原資料。

**Syndrome（症候值／校驗子）**：
```text
收到漢明碼 → 重新檢查 P1、P2、P4 的範圍
→ 檢查通過記 0，失敗記 1 → 得到 S1、S2、S4
→ 組成 S4 S2 S1 → 轉成十進位，就是錯誤位置
```

### 手把手例題（Hamming(7,4)，偶校驗）　【練流程】
**編碼**：把資料 `1011` 編成漢明碼。
```text
位置：  1   2   3   4   5   6   7
內容：  P1  P2  1   P4  0   1   1     （資料 1,0,1,1 填入位置 3,5,6,7）
P1(1,3,5,7)：1 ⊕ 0 ⊕ 1 = 0 → P1 = 0
P2(2,3,6,7)：1 ⊕ 1 ⊕ 1 = 1 → P2 = 1
P4(4,5,6,7)：0 ⊕ 1 ⊕ 1 = 0 → P4 = 0
→ 漢明碼 = 0110011
```
**解碼除錯**：收到 `0110111`（第 5 位被改了）。
```text
S1(1,3,5,7)：0 ⊕ 1 ⊕ 1 ⊕ 1 = 1
S2(2,3,6,7)：1 ⊕ 1 ⊕ 1 ⊕ 1 = 0
S4(4,5,6,7)：0 ⊕ 1 ⊕ 1 ⊕ 1 = 1
Syndrome = S4 S2 S1 = 101 = 5 → 第 5 位錯
把第 5 位反轉回來 → 0110011（還原成功）
```

### 漢明距（必背）
**漢明距（Hamming Distance）**：兩個碼字不同 bit 的數量（兩組資料中不一樣的位置有幾個）。

| 需求 | 最小漢明距 |
| --- | --- |
| 偵測 d 個錯誤 | `Dmin ≥ d + 1` |
| 更正 t 個錯誤 | `Dmin ≥ 2t + 1` |
| 已知 Dmin，最多偵測 | `Dmin − 1` |
| 已知 Dmin，最多更正 | `floor((Dmin − 1) / 2)` |

**手把手例題**：碼字 `10110` 與 `11100` 的漢明距？
```text
10110
11100
位置 2、4 不同 → 漢明距 = 2
```
> 應用：若某碼集 Dmin = 3 → 可偵測 `3 − 1 = 2` 個錯、更正 `floor((3−1)/2) = 1` 個錯。

### 常見陷阱
| 容易錯的地方 | 正確觀念 |
| --- | --- |
| BCD 是把整個十進位數轉二進位 | 錯，BCD 是每個十進位數字分開編 |
| `1010` 是有效 BCD | 錯，單一 BCD 只允許 0000 到 1001 |
| Binary 轉 Gray 和 Gray 轉 Binary 用同一規則 | 錯，兩個方向規則不同 |
| Unicode 和 UTF-8 是同一件事 | 錯，Unicode 是碼位，UTF-8 是編碼方式 |
| Parity 可以更正錯誤 | 通常錯，Parity 多半只能偵測 |
| CRC 是錯誤更正碼 | 國考通常視為錯誤偵測碼 |
| 偵測 d 個錯誤需要 `2d + 1` | 錯，那是更正常見公式的型態 |

### 國考答題句
1. BCD 是用 4 bits 表示一個十進位數字；8421 BCD 的權重為 8、4、2、1。
2. Gray Code 的特色是相鄰碼只差 1 bit，可減少狀態轉換時的讀取錯誤。
3. 二進位轉 Gray 時最高位不變，其餘位元為相鄰二進位位元 XOR。
4. Gray 轉二進位時最高位不變，其餘位元為前一個二進位位元 XOR 目前 Gray 位元。
5. 標準 ASCII 為 7 bits，可表示 128 種編號；延伸 ASCII 常為 8 bits。
6. EBCDIC 是 IBM 系統常見的字元編碼。
7. Unicode 用於統一表示多語言字元；UTF-8 是 Unicode 的常見可變長度編碼方式。
8. 同位元檢查可偵測奇數個 bit 錯誤，但通常不能定位或更正錯誤。
9. CRC 透過產生多項式做模 2 除法取得餘數，常用於錯誤偵測。
10. 漢明碼的檢查位通常放在 1、2、4、8 等 2 的冪次位置。
11. 偵測 d 個錯誤需要最小漢明距至少 `d + 1`；更正 t 個錯誤需要最小漢明距至少 `2t + 1`。

### 考前速記
```text
BCD：一個十進位數字用 4 bits。
Gray：相鄰只差 1 bit。
ASCII：標準 7 bits。
EBCDIC：IBM、大型主機。
Unicode：統一多語言碼位。
UTF-8：Unicode 的可變長度編碼。
Parity：奇偶檢查，能偵測奇數個 bit 錯。
CRC：模 2 除法，餘數當檢查碼。
Hamming：檢查位在 1、2、4、8。
漢明距：偵測 d 要 d+1，更正 t 要 2t+1。
```

## 加強練習　【練流程】
**練習 1（編碼）**：資料 `1100`
> 解：位置 3,5,6,7 = 1,1,0,0
> P1(1,3,5,7) = 1⊕1⊕0 = 0；P2(2,3,6,7) = 1⊕0⊕0 = 1；P4(4,5,6,7) = 1⊕0⊕0 = 1
> → 漢明碼 = **0111100**

**練習 2（解碼）**：收到 `0010011`，找錯誤位置
> 解：S1(1,3,5,7) = 0⊕1⊕0⊕1 = 0；S2(2,3,6,7) = 0⊕1⊕1⊕1 = 1；S4(4,5,6,7) = 0⊕0⊕1⊕1 = 0
> Syndrome = S4S2S1 = `010` = **第 2 位錯** → 反轉回 `0110011`

**練習 3**：碼集 `{000, 011, 101, 110}` 的 Dmin？能偵測／更正幾個錯？
> 解：兩兩距離都是 2 → Dmin = **2**；可偵測 `2−1 = 1` 個、更正 `floor((2−1)/2) = 0` 個

**練習 4**：`1011001` 與 `1110100` 的漢明距？
> 解：位置 2、4、5、7 不同 → **4**
