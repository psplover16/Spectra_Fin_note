# 基本計概 01：架構與計算理論

> 馮紐曼架構、圖靈機與圖靈測試。

## 1. 馮紐曼架構

### 定義
馮紐曼架構是一種電腦設計方式。核心：**程式和資料都放在同一個記憶體中**，通常也**共用同一組匯流排**，CPU 依照順序一個一個讀取指令並執行。

- **計算機系統基本組成**：輸入單元、輸出單元、運算器（ALU）、控制器（CU）、記憶體。
- **匯流排**：電腦內部傳輸資料的通道（可想成馬路）。CPU、記憶體、輸入輸出設備之間靠匯流排傳送資料。

### 特色
1. **程式內儲概念（Stored-Program Concept）**：程式與資料皆存放於記憶體中，CPU 可從記憶體依序讀取指令並執行。
2. **循序執行**：CPU 依「**取指令 → 解碼 → 執行**」的步驟循序處理記憶體中的指令；除非遇到**跳躍指令或中斷事件**，才會改變原本的執行順序。

### 與哈佛架構的差異
| | 馮紐曼架構 | 哈佛架構 |
| --- | --- | --- |
| 記憶體 | 程式與資料**共用**記憶體與匯流排 | 程式記憶體與資料記憶體**分離** |
| 取指令／取資料 | 可能互相**競爭**傳輸通道 → 瓶頸 | 可**同時**取指令與取資料 |
| 設計 | 簡單 | 較複雜 |
| 效能 | 較易受瓶頸限制 | 較佳 |

### 馮紐曼瓶頸（Von Neumann Bottleneck）
**定義**：CPU 與記憶體之間的資料傳輸速度有限，當 CPU 需頻繁讀取指令與資料時，會因等待記憶體傳輸而降低整體效能。

**改善方法**（共同目標：減少 CPU 等待記憶體的時間、提高資料供應速度）：
1. **快取 Cache**：速度快、容量小的記憶體，放在 CPU 附近或內部，存放最近常用或可能再用的資料。
2. **預取（Prefetch）**：預先猜測 CPU 接下來可能需要的指令／資料，先拿到較快的位置。
3. **增加匯流排寬度**：提高一次可傳送多少位元資料。
4. **記憶體頻寬**：提升單位時間內記憶體可傳輸的資料量。
5. **管線化（Pipeline）**：把一個工作切成多階段，讓不同指令重疊執行。
6. **平行處理**：同時處理多個工作。
7. **記憶體階層**：把不同速度、容量、成本的記憶體安排成層級（暫存器 → 快取 → 主記憶體 RAM → SSD／硬碟）。

## 2. 圖靈機與圖靈測試

### 一、圖靈機

**圖靈機是什麼**
圖靈機是一種**抽象的計算模型**，不是實體電腦。用來描述「計算」最核心的過程，並研究哪些問題可以被明確的計算程序解決。它不討論硬體細節（CPU、記憶體、OS），只保留計算最基本的元素：
1. 資料如何被儲存。
2. 資料如何被讀取。
3. 每一步如何根據規則改變資料。
4. 什麼情況下計算會結束。

因此圖靈機是一種**理論上的簡化模型**，用來回答：電腦到底能不能解決某個問題？

**圖靈機的主要組成**（三部分）
1. **無限長紙帶**：儲存輸入、輸出與計算過程中的中間結果。
2. **讀寫頭**：讀取目前格子的符號，也可寫入符號，並向左或向右移動。
3. **有限控制器**：根據目前狀態與讀到的符號，決定下一步要做什麼。

**圖靈機如何運作**（每一步）
1. 讀取目前格子的符號。
2. 根據目前狀態與讀到的符號查詢規則。
3. 在目前格子寫入新符號，或保留原符號。
4. 讀寫頭向左或向右移動。
5. 進入下一個狀態。

→ 不斷重複「**讀取、判斷、寫入、移動、換狀態**」，直到符合停止條件。

**可計算是什麼**
指某問題可被一套明確的計算程序解決。以圖靈機角度：若存在一套規則，能讓圖靈機在**有限步驟**內完成計算並得到答案，這問題通常就可稱為可計算。重點：
1. **問題**：具明確輸入與輸出的任務。
2. **明確程序**：可一步步執行的規則。
3. **有限步驟**：計算過程會在某個時間點結束，不會永遠執行。

→ 可計算關心的不是「算得快不快」，而是理論上是否存在明確方法、能在有限步驟內算出答案。

### 二、圖靈測試
**圖靈測試**是用來判斷機器是否展現出類似人類智慧的測試。

基本想法：若一位審問者只透過**文字對話**與兩個對象互動（一個是人、一個是機器），而審問者**無法可靠分辨**哪一個是機器，就可認為該機器通過圖靈測試。

→ 它重視機器在對話中的**外在表現**，而非內部是否真的像人類思考。比較像檢驗「機器能不能表現得像人類」，而不是證明「機器是否真正具有意識」。

### 三、圖靈機 vs 圖靈測試
| 項目 | 圖靈機 | 圖靈測試 |
| --- | --- | --- |
| 核心問題 | 什麼問題可以被計算？ | 機器能否表現得像人類？ |
| 關注重點 | 計算程序與可計算性 | 對話表現與智慧判斷 |
| 性質 | 理論計算模型 | 人工智慧測試方法 |
| 常見用途 | 研究演算法、計算能力與計算極限 | 討論機器智慧與人機互動 |

> 總結：**圖靈機**關心「計算是否可能」，**圖靈測試**關心「機器是否能展現類似人類的智慧表現」。
