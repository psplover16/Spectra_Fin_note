## 6. 匯流排（Bus）

### 三種匯流排
- **位址匯流排（Address Bus）**：找位置。傳送記憶體或 I/O 位址。
- **資料匯流排（Data Bus）**：送內容。傳送資料。
- **控制匯流排（Control Bus）**：管動作。傳送讀寫、中斷、時脈、確認等控制訊號。

### 基本計算
- n bits 位址匯流排可產生 **2^n 個位址**。
- 若每個位址代表 1 byte，則可定址空間為 **2^n bytes**。
- n bits 資料匯流排一次可傳送 n bits 的資料。

> **最大陷阱：可定址空間看「位址匯流排」，不是資料匯流排。**

### 手把手例題　【練流程】
**題**：某 CPU 位址匯流排 20 bits、資料匯流排 8 bits。可定址空間多大？一次能傳多少資料？
```text
可定址空間 = 2^20 = 1,048,576 個位址 = 1 MB（每位址 1 byte）
一次可傳   = 8 bits = 1 byte
```
> 再練一題：位址匯流排 16 bits → 2^16 = 65,536 = 64 KB。

### 傳輸方向
- 位址匯流排：通常 CPU → 記憶體或 I/O，**單向**為主。
- 資料匯流排：**雙向**。
- 控制匯流排：依訊號而定，常見為雙向或多方向。

### 讀與寫
**讀取**（CPU 給位址 + 說要讀 → 記憶體回資料）
1. 位址匯流排：CPU 送出位址。
2. 控制匯流排：CPU 送出「讀取」訊號。
3. 資料匯流排：記憶體把資料放上來，CPU 接收。

**寫入**（CPU 給位址 + 給資料 + 說要寫 → 記憶體覆蓋成新資料）
1. 位址匯流排：要寫到這個位置。
2. 資料匯流排：要寫入的內容。
3. 控制匯流排：送出寫入訊號。

### 補充
- **暫存器 register**：在 CPU 內部，通常不當作外部匯流排連接的記憶體來考。
- **快取 cache**：常在 CPU 和主記憶體之間，實作上可能有內部匯流排或專用通道，但基本計概題通常不把它當 Bus 題的「記憶體」主角。
- **RAM**：國考講 CPU 透過位址匯流排讀寫記憶體時，通常就是指 RAM。

## 13. USB 速度

### USB 常見速度表（必背）
| 版本或名稱 | 常見名稱 | 理論速度 |
| --- | --- | --- |
| USB 1.0 / 1.1 | Low Speed | 1.5 Mbps |
| USB 1.0 / 1.1 | Full Speed | 12 Mbps |
| **USB 2.0** | **High Speed** | **480 Mbps** ★ |
| **USB 3.0 / 3.1 Gen 1 / 3.2 Gen 1x1** | **SuperSpeed** | **5 Gbps** ★ |
| **USB 3.1 Gen 2 / 3.2 Gen 2x1** | **SuperSpeed+** | **10 Gbps** ★ |
| **USB 3.2 Gen 2x2** | SuperSpeed USB 20Gbps | **20 Gbps** ★ |
| USB4 Gen 2x2 | USB4 20Gbps | 20 Gbps |
| **USB4 Gen 3x2** | USB4 40Gbps | **40 Gbps** ★ |
| **USB4 Version 2.0 / USB 80Gbps** | USB4 80Gbps | **80 Gbps** ★ |

> ★ ＝ 最常考優先背（原筆記標紅的幾行）。純 Markdown 無法上色，這裡用 **粗體＋★** 代替；若貼回你的網站且渲染器支援 HTML，可改用 `<span style="color:red">…</span>`。
>
> 優先背：**USB 2.0 = 480 Mbps、USB 3.0 = 5 Gbps、USB 3.1 Gen 2 = 10 Gbps、USB 3.2 Gen 2x2 = 20 Gbps、USB4 常見 40 Gbps、USB4 Version 2.0 = 80 Gbps**。

### Mbps 與 MB/s 不一樣
1. USB 規格常寫 Mbps / Gbps，小寫 `b` 是 **bit（位元）**。
2. 1 Byte = 8 bits。
3. MB/s ≈ Mbps ÷ 8；GB/s ≈ Gbps ÷ 8。

### 備註
1. 實際速度會受線材、控制器、協定開銷與裝置限制影響。
2. **Type-C 是接頭形狀，不保證一定是高速 USB。**

## 加強練習　【練流程】
**練習 1**：要對 4 GB 記憶體（byte 定址），需幾條位址線？
> 解：4 GB = 2³² bytes → **32 條**

**練習 2**：24 條位址線可定址多少？
> 解：2²⁴ = **16 MB**
