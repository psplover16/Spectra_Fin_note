# 基本計概 08：進制轉換

> 數值與編碼（計算題）。本篇最長，但都是同類轉換，熟方法後讀很快。

## 14. 進制轉換

> 十進制逢 10 進 1、二進制逢 2 進 1、八進制逢 8 進 1、十六進制逢 16 進 1。

### 十六進制字母
| 十六進制 | 十進制 |
| --- | ---: |
| A | 10 |
| B | 11 |
| C | 12 |
| D | 13 |
| E | 14 |
| F | 15 |

### 轉換方法總表
| 題型 | 方法 | 讀取方向 |
| --- | --- | --- |
| 十進制整數轉 n 進制 | 連除 n，直到商為 0，記餘數 | 餘數**由下往上**讀 |
| 十進制小數轉 n 進制 | 連乘 n，直到小數變 0，取整數 | 整數部分**由上往下**讀 |
| n 進制轉十進制 | 位值展開 | 每位乘上基底次方後加總 |
| 二進制轉八進制 | 每 **3 bits** 一組<br>整數：從小數點往左分組<br>小數：從小數點往右分組 | 不足補 0 |
| 二進制轉十六進制 | 每 **4 bits** 一組<br>整數：從小數點往左分組<br>小數：從小數點往右分組 | 不足補 0 |

> 表示法：`(1011)₂` 右下角的 `₂` 表示二進制。

### 範例（含完整過程）

**1. `(450.153)₁₀` → 二進制**

整數 450（連除 2，餘數由下往上讀）：
```text
450 ÷2 = 225 … 0
225 ÷2 = 112 … 1
112 ÷2 =  56 … 0
 56 ÷2 =  28 … 0
 28 ÷2 =  14 … 0
 14 ÷2 =   7 … 0
  7 ÷2 =   3 … 1
  3 ÷2 =   1 … 1
  1 ÷2 =   0 … 1
→ 由下往上：111000010
驗算：256+128+64+2 = 450 ✓
```
小數 0.153（連乘 2，取整數，由上往下讀）：
```text
0.153 ×2 = 0.306 → 0
0.306 ×2 = 0.612 → 0
0.612 ×2 = 1.224 → 1（留 0.224）
0.224 ×2 = 0.448 → 0
0.448 ×2 = 0.896 → 0
0.896 ×2 = 1.792 → 1（留 0.792）
0.792 ×2 = 1.584 → 1（留 0.584）
0.584 ×2 = 1.168 → 1（留 0.168）…（不會終止）
→ 由上往下：0.00100111…
```
**答案**：`(450.153)₁₀ ≈ (111000010.00100111…)₂`（小數為循環、不終止，取近似）

---

**2. `(450.153)₁₀` → 十六進制**

整數 450（連除 16）：
```text
450 ÷16 = 28 … 2
 28 ÷16 =  1 … 12 (C)
  1 ÷16 =  0 … 1
→ 由下往上：1 C 2 = 1C2
驗算：1×256 + 12×16 + 2 = 450 ✓
```
小數 0.153（連乘 16）：
```text
0.153 ×16 = 2.448 → 2（留 0.448）
0.448 ×16 = 7.168 → 7（留 0.168）
0.168 ×16 = 2.688 → 2（留 0.688）
0.688 ×16 =11.008 → B（留 0.008）…（不會終止）
→ 0.272B…
```
**答案**：`(450.153)₁₀ ≈ (1C2.272B…)₁₆`（小數取近似）
> 也可由第 1 題的二進位 `111000010.00100111` 直接 4 位一組驗證：整數 `1 1100 0010` = 1C2、小數 `0010 0111` = 27…，一致。

---

**3. `(11010101.1011)₂` → 八進制**（每 3 bits 一組）

整數 `11010101`，從小數點往左每 3 bits：
```text
011 010 101  →  3 2 5
（最左不足補 0：11 → 011）
```
小數 `1011`，從小數點往右每 3 bits：
```text
101 100  →  5 4
（最右不足補 0：1 → 100）
```
**答案**：`(11010101.1011)₂ = (325.54)₈`
> 驗算：整數 213 = 325₈ ✓；小數 0.6875 = .54₈ ✓

---

**4. `(1011110010.101)₂` → 十六進制**

> 原題小數寫成 `.151`，含非法數字 **5**（二進位只有 0、1），研判為 `.101` 之誤，已直接更正。

整數 `1011110010`，每 4 bits 一組（從小數點往左）：
```text
0010 1111 0010  →  2 F 2
（最左不足補 0：10 → 0010）
```
小數 `.101`，每 4 bits 一組（從小數點往右，補 0）：
```text
1010  →  A
（不足補 0：101 → 1010）
```
**答案**：`(1011110010.101)₂ = (2F2.A)₁₆`
> 驗算：整數 754 = 2F2 ✓；小數 .101₂ = 0.625 = .A₁₆（A/16 = 10/16 = 0.625）✓

---

**5. `(653.5)₈` → 二進制**（每個八進位數字 → 3 bits）

```text
6 = 110
5 = 101
3 = 011      → 整數 110101011
.5 = 101     → 小數 .101
```
**答案**：`(653.5)₈ = (110101011.101)₂`
> 驗算：653₈ = 427 = 110101011₂ ✓；.5₈ = 0.625 = .101₂ ✓

---

**6. `(653.5)₈` → 十六進制**（先轉二進位，再 4 bits 一組）

由第 5 題：`110101011.101₂`
```text
整數：0001 1010 1011 → 1 A B = 1AB
（從小數點往左每 4 bits，最左補 0）
小數：1010 → A
（從小數點往右每 4 bits，補 0：101 → 1010）
```
**答案**：`(653.5)₈ = (1AB.A)₁₆`
> 驗算：427 = 1AB₁₆ ✓；.5₈ = 0.625 = .A₁₆ ✓

---

**7. `(2F2.C)₁₆` → 二進制**（每個十六進位數字 → 4 bits）

```text
2 = 0010
F = 1111
2 = 0010     → 整數 (0010 1111 0010) = 1011110010
.C = 1100    → 小數 .1100 = .11
```
**答案**：`(2F2.C)₁₆ = (1011110010.11)₂`
> 驗算：2F2₁₆ = 754 = 1011110010₂ ✓；.C₁₆ = 0.75 = .11₂ ✓

---

**8. `(2F2.C)₁₆` → 八進制**（先轉二進位，再 3 bits 一組）

由第 7 題：`1011110010.1100₂`
```text
整數：001 011 110 010 → 1 3 6 2 = 1362
（從小數點往左每 3 bits，最左補 0）
小數：110 → 6
（從小數點往右每 3 bits，補 0：110 → 110）
```
**答案**：`(2F2.C)₁₆ = (1362.6)₈`
> 驗算：754 = 1362₈ ✓；.C₁₆ = 0.75 = .6₈ ✓

---

## 加強練習　【練流程】
**練習 1**：`(1101.011)₂` → 十進制
> 解：整數 `1101` = 8+4+1 = 13；小數 `.011` = 1/4 + 1/8 = 0.375 → **13.375**

**練習 2**：`(172)₁₀` → 二進制、十六進制
> 解：172 = `10101100₂`（128+32+8+4）；每 4 bits 一組 `1010 1100` = **AC₁₆**

**練習 3**：`(3A.8)₁₆` → 二進制、八進制
> 解：3=0011、A=1010、.8=1000 → 二進制 **111010.1₂**；每 3 bits 一組 `111 010 . 100` = **72.4₈**
