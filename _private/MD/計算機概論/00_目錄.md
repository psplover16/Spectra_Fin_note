# 基本計概 — 分篇目錄

> 原本一份彙整檔，依「每篇閱讀 ≤ 10 分鐘」拆成 13 篇；每篇的計算題練習已併入該篇末。

| # | 篇名 | 內容 |
|---|---|---|
| 01 | 架構與計算理論 | 馮紐曼架構、圖靈機與圖靈測試 |
| 02 | 機器指令與指令週期 | Opcode/Operand、Fetch-Decode-Execute、PC/IR |
| 03 | Pipeline 與 Hazard | 管線化、加速比、三種 Hazard、RAW/WAR/WAW |
| 04 | 效能與 RISC／CISC | CPI/MIPS 公式與計算、RISC vs CISC |
| 05 | 匯流排與 USB | 位址/資料/控制匯流排、2ⁿ 定址、USB 速度 |
| 06 | 記憶體（一）階層與分類 | 階層、Locality、RAM/ROM、SRAM/DRAM |
| 07 | 記憶體（二）暫存器與 Cache | 各暫存器、Cache、AMAT |
| 08 | 進制轉換 | 二/八/十/十六進制互轉（8 題＋練習，本篇最長） |
| 09 | 補數轉換 | 符號大小、1 補數、2 補數 |
| 10 | 浮點數轉換 | IEEE 754 單/雙精度、編碼與反推 |
| 11 | 數碼與文字碼 | BCD、Gray、ASCII/Unicode/UTF-8 |
| 12 | 檢查碼（一）Parity 與 CRC | 同位檢查、CRC 模 2 除法 |
| 13 | 檢查碼（二）漢明碼與漢明距 | Hamming 編碼/解碼、漢明距 |

> 大區對應：**01** 架構｜**02–05** 指令與 CPU｜**06–07** 記憶體｜**08–13** 數值與編碼
