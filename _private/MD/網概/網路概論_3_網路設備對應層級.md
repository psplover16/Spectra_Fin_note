# 網路概論 3：網路設備對應層級

> 科目：網路概論
> 學習方式：屬【理解】＋【硬背】——「屬哪一層」雖要記，但**從設備功能就能推**（看 bit → L1、看 MAC → L2、看 IP → L3），懂功能就記得住。

---

## 一、七個網路設備總表（核心）　【理解】＋【硬背】

| 設備 | OSI 層 | 功能（做什麼） | 重點／場景 |
|---|---|---|---|
| **中繼器 Repeater** | **L1** 實體 | 把訊號放大／再生，延長傳輸距離 | 只處理 bit、不看位址；延長纜線 |
| **集線器 Hub** | **L1** 實體 | 多埠中繼器；收到訊號**廣播給所有埠** | 共享頻寬、會碰撞、已被 switch 取代 |
| **橋接器 Bridge** | **L2** 資料鏈結 | 依 **MAC** 連接／過濾兩網段；分割碰撞域 | 比 hub 智慧；switch 就是多埠 bridge |
| **L2 交換器 Switch** | **L2** 資料鏈結 | 多埠橋接器；依 **MAC** 只送給目標埠 | 每埠獨立碰撞域、全雙工；現代 LAN 核心 |
| **L3 交換器 L3 Switch** | **L3** 網路 | switch ＋ router：依 **IP** 跨 VLAN／子網路轉送（硬體路由，快） | 企業內跨 VLAN 路由 |
| **路由器 Router** | **L3** 網路 | 連接**不同網路**，依 **IP** 選路、轉送封包；分割廣播域 | 連 LAN 到 Internet、可做 NAT |
| **閘道器 Gateway** | **可到 L7** 應用 | 連接**不同協定**的網路，做協定轉換 | 異質網路／協定轉換 |

> 推理法（不用硬背）：**看 bit → L1（Hub/Repeater）；看 MAC → L2（Switch/Bridge）；看 IP → L3（Router/L3 Switch）；轉協定 → Gateway（可到 L7）。**

---

## 二、碰撞域 vs 廣播域（超常考）　【理解】

- **碰撞域 Collision Domain**：會互相「撞」在一起的範圍（同時傳會碰撞）。
- **廣播域 Broadcast Domain**：一個廣播封包能傳到的範圍。

| 設備 | 碰撞域 | 廣播域 |
|---|---|---|
| Hub／Repeater | 全部**同一個**（會互撞） | 同一個 |
| Switch／Bridge | **每埠切開**（各自獨立） | 同一個 |
| Router | 切開 | **每介面切開** |

> 一句話：**Switch 切「碰撞域」、Router 切「廣播域」。**（VLAN 也能在 switch 上切廣播域，見下。）

---

## 三、LAN vs VLAN　【理解】

| | LAN | VLAN（虛擬 LAN） |
|---|---|---|
| 怎麼分 | 實體連在一起 ＝ 一個廣播域 | 用**軟體**把交換器的埠**邏輯切成多個獨立廣播域** |
| 佈線 | 換網段要實體重新佈線 | **不用重新佈線**，軟體設定即可 |
| 隔離／安全 | 同網段廣播互通 | 不同 VLAN 預設**不能互通**（要靠 L3 路由），隔離廣播、較安全 |
| 分組依據 | 依實體位置 | 依**邏輯**（如部門），不受實體位置限制 |

> 記憶鉤子：**VLAN ＝ 用軟體把一台實體交換器「邏輯切成多個獨立 LAN／廣播域」。** 好處是免重新佈線、隔離廣播、較安全、依部門彈性分組。
