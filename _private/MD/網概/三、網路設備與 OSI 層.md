## 主題是什麼

網路設備與 OSI 層，是國家考試很常出現的基礎題。題目通常不會問得很花俏，而是要你判斷「某個設備在哪一層運作」、「它根據什麼資訊轉送資料」、「它能不能切割碰撞域或廣播域」。

開放式系統互連模型（Open Systems Interconnection Model, OSI Model）是一套用來理解網路通訊的分層模型。它把網路通訊拆成不同層次，讓我們可以用比較有系統的方式理解設備功能。例如：實體層（Physical Layer）重視訊號本身，資料鏈結層（Data Link Layer）重視同一區域網路內的資料框（Frame）與媒體存取控制位址（Media Access Control Address, MAC Address），網路層（Network Layer）則重視網際網路協定位址（Internet Protocol Address, IP Address）與路由選擇。

這個主題的核心想法很簡單：設備看得懂哪一層的資訊，就大多在哪一層運作。只會處理電氣或光學訊號的設備，通常在實體層；會看 MAC 位址的設備，通常在資料鏈結層；會看 IP 位址並選路的設備，通常在網路層。

## 先懂 OSI 分層的核心想法

在考網路設備前，先抓住三個最常考的層級：

1. 實體層（Physical Layer）
   實體層負責傳送原始位元訊號，例如電訊號、光訊號或無線訊號。這一層不理解 MAC 位址，也不理解 IP 位址，只管訊號能不能傳出去、傳得遠不遠、是否需要重新整理。

2. 資料鏈結層（Data Link Layer）
   資料鏈結層負責同一個區域網路內的資料傳輸，常見單位是資料框（Frame）。這一層常用媒體存取控制位址（Media Access Control Address, MAC Address）判斷資料要送到哪一台設備。

3. 網路層（Network Layer）
   網路層負責不同網路之間的傳送，常見單位是封包（Packet）。這一層會根據網際網路協定位址（Internet Protocol Address, IP Address）做路由選擇，也就是決定資料要往哪一條路走。

具體來說，如果題目說某設備「重生訊號」，通常想到實體層；如果題目說「根據 MAC 位址轉送 Frame」，通常想到資料鏈結層；如果題目說「根據 IP 位址選路」，通常想到網路層。

## 常見網路設備與 OSI 對應

### 中繼器（Repeater）

中繼器（Repeater）是運作在實體層（Physical Layer）的設備，主要功能是重生訊號。所謂重生訊號，是指訊號傳輸距離太遠而衰減時，中繼器把訊號重新整理、放大或再生，讓訊號可以繼續傳下去。

核心想法是：中繼器不會判斷資料要送給誰，也不會看 MAC 位址或 IP 位址。它只知道「訊號進來，就把訊號整理後送出去」。

具體範例：早期網路線距離太長，訊號變弱，可能在中間加入中繼器讓訊號延伸更遠。

國考考法常問：中繼器屬於 OSI 哪一層？答案是實體層。也可能問它是否能分割碰撞域或廣播域，答案是否定的。

### 集線器（Hub）

集線器（Hub）是運作在實體層（Physical Layer）的多埠中繼設備。它可以把多台電腦接在一起，但它的轉送方式很粗糙：某個埠收到訊號後，會把訊號送到其他埠。

核心想法是：集線器不會學習 MAC 位址，也不會判斷目的地，所以所有連接到集線器的設備會共享頻寬，而且容易發生碰撞。碰撞域（Collision Domain）是指同一時間傳輸時可能互相碰撞的範圍。集線器會讓碰撞域變大，這是國考很愛考的缺點。

具體範例：如果四台電腦接在同一台集線器上，其中一台送資料，集線器可能把訊號送給其他所有埠，其他電腦即使不是目的地也會收到訊號。

國考考法常問：集線器在哪一層？答案是實體層。它是否能依 MAC 位址轉送？不能。它是否讓每個埠獨立碰撞域？不能。

### 橋接器（Bridge）

橋接器（Bridge）是運作在資料鏈結層（Data Link Layer）的設備，主要根據媒體存取控制位址（Media Access Control Address, MAC Address）轉送資料框（Frame）。它可以把區域網路切成不同區段，藉此分割碰撞域。

核心想法是：橋接器比集線器聰明，因為它會看 MAC 位址，判斷資料框是否需要轉送到另一個網路區段。

具體範例：兩個早期區域網路區段用橋接器連起來，橋接器會依照 MAC 位址決定資料框是否要跨區段轉送。

國考考法常問：橋接器屬於哪一層？答案是資料鏈結層。它依據什麼位址？答案是 MAC 位址。它能不能分割碰撞域？可以。

### 第二層交換器（Layer 2 Switch, L2 Switch）

第二層交換器（Layer 2 Switch, L2 Switch）是運作在資料鏈結層（Data Link Layer）的交換器，主要依照 MAC 位址表（MAC Table）轉送資料框（Frame）。

核心想法是：L2 Switch 可以把每個埠視為獨立的碰撞域，效能比集線器好很多。但是預設情況下，它不會切割廣播域（Broadcast Domain）。廣播域是指廣播訊息可以到達的範圍，如果沒有使用其他機制切分，廣播仍可能在同一個交換網路中傳播。

具體範例：辦公室內多台電腦接到同一台 L2 Switch，每台電腦通常有自己的交換器埠，因此彼此不必像集線器那樣共享同一個碰撞範圍。

國考考法常問：L2 Switch 根據什麼轉送？答案是 MAC 位址。它處理的資料單位是什麼？常見答案是 Frame。它能不能分割碰撞域？可以。預設能不能分割廣播域？通常不能。

### 第三層交換器（Layer 3 Switch, L3 Switch）

第三層交換器（Layer 3 Switch, L3 Switch）是具備路由功能的交換器，通常運作在網路層（Network Layer）。它結合交換器的高速轉送能力與路由器的網路層選路能力。

核心想法是：L3 Switch 不只會做交換，也能做不同網段之間的路由，常見於企業網路中的核心層或匯聚層。

具體範例：公司把不同部門切成不同虛擬區域網路（Virtual Local Area Network, VLAN），若各 VLAN 之間需要互通，可以由 L3 Switch 執行 VLAN 間路由。

國考考法常問：L3 Switch 與 L2 Switch 差在哪裡？L2 Switch 主要依 MAC 位址轉送，L3 Switch 具備依 IP 位址做路由的能力。

### 路由器（Router）

路由器（Router）是運作在網路層（Network Layer）的設備，主要依據 IP 位址選擇路徑，把封包（Packet）送往不同網路。

核心想法是：路由器負責連接不同網段，也能分割廣播域。它不像 L2 Switch 主要處理同一區域網路內的 MAC 轉送，而是根據 IP 位址判斷下一站要往哪裡走。

具體範例：家中的網路要連上網際網路（Internet），通常會透過路由器把家中區域網路與外部網路連接起來。

國考考法常問：路由器依據什麼位址轉送？答案是 IP 位址。路由器是否能分割廣播域？可以。路由器屬於 OSI 哪一層？答案是網路層。

### 閘道器（Gateway）

閘道器（Gateway）是用來連接不同協定、不同格式或不同系統的設備或服務。它可能在較高層運作，實際層級要看轉換內容而定。

核心想法是：閘道器的重點不是單純轉送，而是「轉換」。如果兩邊系統使用不同協定、資料格式或應用方式，閘道器可以負責讓它們互通。

具體範例：某個舊系統使用特殊通訊協定，新系統使用另一種協定，中間可透過閘道器做協定或格式轉換。

國考考法常問：閘道器是否一定只在某一固定層？不一定，需看情境。若題目強調跨不同協定或應用層轉換，通常要想到 Gateway。

### 防火牆（Firewall）

防火牆（Firewall）是用來做存取控制與安全防護的設備或系統。它常見於網路層（Network Layer）、傳輸層（Transport Layer）或應用層（Application Layer），實際運作層級會依防火牆型態而不同。

核心想法是：防火牆不是單純負責連線，而是判斷哪些流量可以通過、哪些流量應該被阻擋。它可以依 IP 位址、連接埠、通訊協定或應用內容做控管。

具體範例：企業在內部網路與外部網路之間放置防火牆，用來限制外部連線進入內部系統，也可以把公開服務放在非軍事區（Demilitarized Zone, DMZ）中降低風險。

國考考法常問：防火牆是否只屬於單一 OSI 層？不一定。常見考點是防火牆可依型態出現在網路層、傳輸層或應用層。

## 設備功能、優缺點與適合場景

| 設備 | 主要 OSI 層 | 功能 | 優點 | 缺點 | 適合場景 |
| --- | --- | --- | --- | --- | --- |
| 中繼器（Repeater） | 實體層（Physical Layer） | 重生訊號、延長距離 | 簡單、成本低 | 不分割碰撞域與廣播域 | 早期或特殊長距離實體連線 |
| 集線器（Hub） | 實體層（Physical Layer） | 多埠訊號轉發 | 成本低 | 所有埠共享頻寬，碰撞多 | 現代少用，常作歷史觀念題 |
| 橋接器（Bridge） | 資料鏈結層（Data Link Layer） | 依 MAC 位址轉送 Frame | 可分割碰撞域 | 埠數少、效能有限 | 早期 LAN 區段連接 |
| 第二層交換器（Layer 2 Switch, L2 Switch） | 資料鏈結層（Data Link Layer） | 依 MAC Table 交換 Frame | 效能好，每埠獨立碰撞域 | 預設不切廣播域 | 一般區域網路存取層 |
| 第三層交換器（Layer 3 Switch, L3 Switch） | 網路層（Network Layer） | 交換加路由 | VLAN 間路由速度快 | 成本較高，功能依設備而定 | 企業核心層或匯聚層 |
| 路由器（Router） | 網路層（Network Layer） | 依 IP 位址路由 | 可分割廣播域，連接不同網路 | 處理延遲通常比交換高 | 連接不同網段、廣域網路與 Internet |
| 閘道器（Gateway） | 依情境而定，常見於高層 | 協定或格式轉換 | 可跨異質系統 | 設定與維護較複雜 | 舊系統整合、應用層代理 |
| 防火牆（Firewall） | 網路層、傳輸層或應用層 | 存取控制與防護 | 提升安全，可記錄與控管 | 規則錯誤會阻擋服務或放行風險 | 網路邊界、DMZ、內部分段 |

## LAN 與 VLAN 易混淆整理

區域網路（Local Area Network, LAN）是指在有限範圍內形成的網路，例如辦公室、教室或家中網路。LAN 可以是實體上的網路，也可以是邏輯上的區域網路概念。

虛擬區域網路（Virtual Local Area Network, VLAN）是在交換器上切分出來的邏輯網段。它的重點是不用完全依賴實體位置，也可以把不同設備分到不同邏輯群組，藉此隔離廣播域並提高管理彈性。

| 比較項目 | 區域網路（LAN） | 虛擬區域網路（VLAN） |
| --- | --- | --- |
| 基本意義 | 一個區域範圍內的網路 | 在交換器上切出的邏輯網段 |
| 切分方式 | 可依實體連線或網路規劃形成 | 主要依交換器設定形成 |
| 管理彈性 | 較受實體位置影響 | 可跨實體位置做邏輯分組 |
| 廣播域 | 視網路設計而定 | 可用來隔離廣播域 |
| 國考關鍵字 | 區域、內部網路 | 邏輯切分、隔離廣播域、交換器設定 |

具體範例：同一間公司有業務部與會計部，即使兩個部門的電腦都接在同一台交換器上，也可以透過 VLAN 把它們分成不同邏輯網段，讓廣播流量不互相干擾。

## 國考常見考法

國考最常用「設備加功能」來考你對 OSI 層的判斷。

1. 看到「重生訊號」：想到中繼器（Repeater）與實體層（Physical Layer）。
2. 看到「多埠中繼、共享頻寬、碰撞多」：想到集線器（Hub）與實體層。
3. 看到「依 MAC 位址轉送 Frame」：想到橋接器（Bridge）或第二層交換器（Layer 2 Switch, L2 Switch）。
4. 看到「依 IP 位址選路」：想到路由器（Router）或第三層交換器（Layer 3 Switch, L3 Switch）。
5. 看到「協定轉換、異質系統整合」：想到閘道器（Gateway）。
6. 看到「存取控制、封包過濾、應用層控管」：想到防火牆（Firewall）。
7. 看到「邏輯切分廣播域」：想到虛擬區域網路（Virtual Local Area Network, VLAN）。

## 國考必背整理

- 中繼器（Repeater）：實體層（Physical Layer），重生訊號。
- 集線器（Hub）：實體層（Physical Layer），多埠中繼，碰撞域大。
- 橋接器（Bridge）：資料鏈結層（Data Link Layer），依 MAC 位址分隔碰撞域。
- 第二層交換器（Layer 2 Switch, L2 Switch）：資料鏈結層，依 MAC 位址轉送資料框（Frame）。
- 第三層交換器（Layer 3 Switch, L3 Switch）：網路層（Network Layer），具路由功能。
- 路由器（Router）：網路層，依 IP 位址選路。
- 閘道器（Gateway）：可跨不同協定或做高層轉換，層級依情境而定。
- 防火牆（Firewall）：可出現在網路層、傳輸層或應用層，依型態而定。
- 虛擬區域網路（Virtual Local Area Network, VLAN）：在交換器上切分邏輯網段，可隔離廣播域。

## 容易考的判斷題

1. 中繼器（Repeater）會依 IP 位址選路。
   錯。中繼器只處理實體層訊號，不看 IP 位址。

2. 集線器（Hub）可以讓每個埠成為獨立碰撞域。
   錯。集線器所有埠通常共享同一個碰撞範圍。

3. 橋接器（Bridge）可依 MAC 位址轉送資料框。
   對。橋接器屬於資料鏈結層設備。

4. 第二層交換器（Layer 2 Switch, L2 Switch）預設會切割廣播域。
   錯。L2 Switch 通常可分割碰撞域，但預設不切割廣播域。

5. 路由器（Router）可以連接不同網段。
   對。路由器依 IP 位址做路由，常用來連接不同網路。

6. 第三層交換器（Layer 3 Switch, L3 Switch）具備路由功能。
   對。它可用於 VLAN 間路由等場景。

7. 閘道器（Gateway）一定只運作在實體層。
   錯。閘道器重點在協定或格式轉換，常視情境在較高層運作。

8. 防火牆（Firewall）一定只屬於網路層。
   錯。防火牆可依型態在網路層、傳輸層或應用層運作。

9. 虛擬區域網路（Virtual Local Area Network, VLAN）可以提高網路管理彈性。
   對。VLAN 可用邏輯方式分組，不必完全依賴實體位置。

## 考前速記小抄

實體層看訊號：中繼器（Repeater）、集線器（Hub）。

資料鏈結層看 MAC：橋接器（Bridge）、第二層交換器（Layer 2 Switch, L2 Switch）。

網路層看 IP：路由器（Router）、第三層交換器（Layer 3 Switch, L3 Switch）。

需要轉換協定或格式：閘道器（Gateway）。

需要存取控制與安全防護：防火牆（Firewall）。

要把交換器上的網路做邏輯切分、隔離廣播域：虛擬區域網路（Virtual Local Area Network, VLAN）。

最短記法可以背成：訊號找 Repeater/Hub，MAC 找 Bridge/L2 Switch，IP 找 Router/L3 Switch，轉換找 Gateway，安全控管找 Firewall。
