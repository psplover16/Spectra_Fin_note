## 資料鏈結層是什麼

資料鏈結層（Data Link Layer）是開放式系統互連模型（Open Systems Interconnection Model, OSI Model）的第 2 層，主要負責「同一段網路或同一個區域網路內」的資料傳送。換句話說，它關心的是：資料從這台電腦送到同一個區域網路中的下一台設備時，要怎麼包裝、怎麼辨識對方、怎麼檢查有沒有出錯。

新手可以把網路傳輸想成寄包裹。實體層（Physical Layer）像道路和電線，只負責讓 0 與 1 可以在媒介上流動；資料鏈結層則像包裹外箱與地址標籤，會把一串位元整理成可辨識的單位，並標出要送給哪個網路卡。

國考常考的核心觀念是：資料鏈結層處理的是「框架（Frame）」和「媒體存取控制位址（Media Access Control Address, MAC Address）」，不是網際網路協定位址（Internet Protocol Address, IP Address）。IP Address 主要屬於網路層（Network Layer）的概念，MAC Address 則是資料鏈結層常見考點。

## 訊框化、框架與基本功能

訊框化（Framing）是指資料鏈結層將位元串流（Bit Stream）切割並包裝成框架（Frame）的過程。框架（Frame）是資料鏈結層傳送資料的基本單位，通常會包含目的位址、來源位址、控制資訊、資料內容，以及錯誤偵測欄位。

資料鏈結層的三個基本功能很常出現在選擇題：

1. 訊框化（Framing）：把連續的 bit stream 分成一個一個 frame，讓接收端知道資料從哪裡開始、到哪裡結束。
2. 錯誤偵測（Error Detection）：檢查傳輸過程中資料是否可能發生錯誤，常見方法是循環冗餘檢查（Cyclic Redundancy Check, CRC）。
3. 流量控制（Flow Control）：控制傳送端送資料的速度，避免接收端來不及處理。

舉例來說，當電腦透過乙太網路（Ethernet）送資料給同一個區域網路中的另一台電腦時，資料不是毫無結構地直接丟出去，而是會被包成 Ethernet frame。接收端收到 frame 後，會檢查目的 MAC Address 是否與自己有關，也會透過 CRC 判斷資料是否可能損壞。

國考考法通常會問：「哪一層負責 framing？」答案是資料鏈結層（Data Link Layer）。若題目問「哪一層處理 frame？」也要想到第 2 層。

## MAC 位址、橋接器與交換器

媒體存取控制位址（Media Access Control Address, MAC Address）是網路介面卡在資料鏈結層使用的硬體位址，常用來在同一個區域網路中識別傳送端與接收端。它不像 IP Address 那樣主要用於跨網路路由，而是偏向區域網路內的資料轉送。

橋接器（Bridge）是早期用來連接區域網路區段（Local Area Network Segment, LAN Segment）的資料鏈結層設備。它會學習 MAC Address，並依據目的 MAC Address 決定是否要把 frame 轉送到另一個網段。

第二層交換器（Layer 2 Switch, L2 Switch）可以理解成多埠的 Bridge。它會建立 MAC 位址表（MAC Address Table），記錄「哪個 MAC Address 在哪個連接埠」。當 Switch 收到 frame 時，會查表決定要從哪個 port 轉送出去，而不是每次都廣播給所有連接埠。

第三層交換器（Layer 3 Switch, L3 Switch）則多了路由（Routing）能力，除了能做 L2 交換，也能在虛擬區域網路（Virtual Local Area Network, VLAN）之間進行轉送。國考若問「哪種交換器具備 routing 功能」，通常要選 L3 Switch。

具體例子是：同一間辦公室裡有多台電腦接在同一台 L2 Switch 上，Switch 會根據 MAC Address Table 轉送 frame。如果公司把財務部與資訊部切成不同 VLAN，並且要讓兩個 VLAN 彼此通訊，可能就需要具備 routing 功能的 L3 Switch 或 Router。

## 錯誤偵測、流量控制與 ARQ

錯誤偵測（Error Detection）是接收端判斷資料在傳輸中是否可能出錯的機制。循環冗餘檢查（Cyclic Redundancy Check, CRC）是資料鏈結層常見的錯誤偵測方法，它會根據傳送資料計算出檢查值，接收端再重新計算並比對。

要注意，錯誤偵測不等於錯誤更正。CRC 主要用來發現錯誤，不是直接把錯誤內容修好。國考很喜歡用這點設陷阱：看到 CRC，優先想到 error detection。

流量控制（Flow Control）是控制傳送速度的機制。若傳送端送太快，接收端緩衝區可能滿掉，導致資料遺失。資料鏈結層可以透過控制傳送節奏，讓雙方速度比較匹配。

自動重送請求（Automatic Repeat reQuest, ARQ）是當資料傳送失敗或確認訊息異常時，透過重送來提高可靠性的機制。常見 ARQ 類型有三種：

1. 停止等待 ARQ（Stop-and-Wait ARQ）：送出一個 frame 後先等待確認，收到確認才送下一個。概念簡單，但效率較低。
2. 回退 N ARQ（Go-Back-N ARQ）：可以連續送多個 frame，但若中間某個 frame 出錯，會從出錯處開始回退重送後續 frame。
3. 選擇重送 ARQ（Selective Repeat ARQ）：只重送出錯或遺失的 frame，效率通常比 Go-Back-N ARQ 好，但實作較複雜。

國考常問 ARQ 的比較。簡單記法是：Stop-and-Wait 最保守，Go-Back-N 會回退重送一串，Selective Repeat 只挑錯的重送。

## 傳輸方向與多重存取

單工（Simplex）是指資料只能單向傳輸。例如某些單向廣播情境，只能從傳送端到接收端。

半雙工（Half-duplex）是指雙方都可以傳，但不能同時傳。像對講機常被拿來當例子：一方講話時，另一方通常要等。

全雙工（Full-duplex）是指雙方可以同時傳送與接收。現代交換式乙太網路常見全雙工模式，因為傳送與接收可以同時進行，碰撞問題也大幅降低。

多重存取（Multiple Access）是在多個設備共用同一傳輸媒介時，決定誰可以使用媒介的機制。它可以分成無競爭與競爭兩大類。

無競爭多重存取（Contention-free Multiple Access）會用某種安排方式決定誰可以傳，常見例子包括權杖傳遞（Token Passing）與輪詢（Polling）。這類方法的特色是秩序明確，比較不會發生大家同時搶著傳的情況。

競爭多重存取（Contention-based Multiple Access）則是讓設備競爭媒介使用權，常見例子包括 ALOHA、載波感測多重存取（Carrier Sense Multiple Access, CSMA）、具碰撞偵測的載波感測多重存取（Carrier Sense Multiple Access with Collision Detection, CSMA/CD），以及具碰撞避免的載波感測多重存取（Carrier Sense Multiple Access with Collision Avoidance, CSMA/CA）。

CSMA 的核心想法是「先聽再傳」：設備傳送前先感測媒介是否空閒。CSMA/CD 會在傳送時偵測碰撞，若碰撞發生就停止傳送並退避，傳統乙太網路常見這個概念。CSMA/CA 則偏向事先避免碰撞，常見於無線網路（Wireless Fidelity, Wi-Fi），因為無線環境不容易像有線網路那樣邊傳邊可靠地偵測碰撞。

## HDLC 與 PPP

高階資料鏈結控制（High-Level Data Link Control, HDLC）是一種位元導向（Bit-oriented）的資料鏈結層協定。位元導向的意思是它以位元為基礎處理資料框架，而不是以字元為主要單位。

點對點協定（Point-to-Point Protocol, PPP）是常見於點對點連線的資料鏈結層協定，過去常見於撥接網路，也常與乙太網路上的點對點協定（Point-to-Point Protocol over Ethernet, PPPoE）一起出現在考題中。PPP 的特色之一是可支援認證，例如密碼驗證協定（Password Authentication Protocol, PAP）或挑戰握手驗證協定（Challenge Handshake Authentication Protocol, CHAP）。

國考若問「常見於撥接、PPPoE，且可支援認證的是哪個協定？」通常答案是 PPP。若問「位元導向資料鏈結協定」則常指 HDLC。

## 5-4-3 規則

5-4-3 規則（5-4-3 Rule）是傳統乙太網路中繼器（Repeater）環境下的歷史規則。它的內容是：最多 5 個區段（Segment）、4 個中繼器（Repeater），其中最多 3 個區段可以接有主機，也就是 populated segment。

這個規則在現代交換式網路中比較少直接使用，因為 Switch 已經取代許多早期共享媒介與 repeater 的情境。不過國考仍可能把它當作網路歷史觀念題考出來。

記憶方式很直接：5 個 segment、4 個 repeater、3 個 populated segment。題目若出現傳統 Ethernet、repeater、segment，就要想到 5-4-3 Rule。

## 國考常見考法

資料鏈結層常見考法不是要你背很深的協定細節，而是要能辨認「哪個名詞屬於哪一層」以及「幾個相似名詞差在哪裡」。

1. 問 OSI 第 2 層負責什麼：要答 framing、MAC Address、error detection、flow control。
2. 問資料單位：資料鏈結層是 frame，不是 packet、segment 或 bit。
3. 問 CRC 功能：CRC 是 error detection，重點是偵測錯誤。
4. 問 CSMA/CD 與 CSMA/CA：CSMA/CD 常連到傳統 Ethernet，CSMA/CA 常連到 Wi-Fi。
5. 問 Bridge 與 Switch：Bridge 較早期，L2 Switch 可視為多埠 Bridge，L3 Switch 具 routing 功能。
6. 問 PPP：常見於撥接、PPPoE，可支援認證。
7. 問 5-4-3 Rule：傳統 Ethernet repeater 規則，現代較少直接使用。

## 國考必背整理

1. 資料鏈結層（Data Link Layer）是 OSI 第 2 層。
2. 資料鏈結層的資料單位是框架（Frame）。
3. 訊框化（Framing）是把 bit stream 切成 frame。
4. 循環冗餘檢查（Cyclic Redundancy Check, CRC）常用於錯誤偵測（Error Detection）。
5. 流量控制（Flow Control）用來控制傳送速率，避免接收端來不及處理。
6. 媒體存取控制位址（Media Access Control Address, MAC Address）屬於資料鏈結層常見位址概念。
7. CSMA/CD 常與傳統乙太網路連在一起。
8. CSMA/CA 常與 Wi-Fi 連在一起。
9. PPP 常見於撥接、PPPoE，且可支援認證。
10. 5-4-3 Rule 是傳統 Ethernet repeater 規則：5 個 segment、4 個 repeater、最多 3 個 populated segment。

## 容易考的判斷題

1. 資料鏈結層負責將 bit stream 包裝成 frame。  
   答：對。這就是訊框化（Framing）。

2. CRC 主要用來進行路由選擇。  
   答：錯。CRC 主要用於錯誤偵測（Error Detection），路由選擇主要是網路層工作。

3. CSMA/CD 常見於 Wi-Fi，CSMA/CA 常見於傳統乙太網路。  
   答：錯。通常是 CSMA/CD 對傳統 Ethernet，CSMA/CA 對 Wi-Fi。

4. L2 Switch 會依據 MAC Address Table 轉送 frame。  
   答：對。這是第二層交換器的重要功能。

5. L3 Switch 只能做第二層交換，不能做 routing。  
   答：錯。L3 Switch 具備 routing 功能。

6. Stop-and-Wait ARQ 是送出一個 frame 後等待確認，收到確認才繼續送下一個。  
   答：對。它簡單但效率較低。

7. Selective Repeat ARQ 會把錯誤 frame 後面的所有 frame 全部重送。  
   答：錯。Selective Repeat ARQ 是選擇性重送；Go-Back-N ARQ 才容易出現回退重送一串的概念。

8. 5-4-3 Rule 在現代交換式網路中仍是每天設定 Switch 的必要規則。  
   答：錯。它主要是傳統 Ethernet repeater 的歷史觀念，但仍可能考。

- 第 2 層：資料鏈結層（Data Link Layer）。
- 第 2 層資料單位：框架（Frame）。
- Framing：bit stream 切成 frame。
- CRC：錯誤偵測，不是 routing。
- Flow Control：控制傳送速度。
- MAC Address：資料鏈結層位址概念。
- Bridge：早期連接 LAN segment。
- L2 Switch：多埠 Bridge，看 MAC Address Table。
- L3 Switch：多了 routing，可做 VLAN 間轉送。
- Simplex：單向。
- Half-duplex：雙向但不能同時。
- Full-duplex：雙向可同時。
- CSMA：先聽再傳。

- CSMA/CA：避免碰撞，Wi-Fi。
- ARQ 三種：Stop-and-Wait、Go-Back-N、Selective Repeat。
- HDLC：位元導向資料鏈結協定。
- PPP：撥接、PPPoE、可認證。
- 5-4-3 Rule：5 segments、4 repeaters、3 populated segments。
