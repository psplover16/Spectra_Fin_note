## 資料庫這科在準備什麼

資料庫（Database）是用來有系統地儲存、管理與查詢資料的集合。考試中的資料庫不是只考「資料放在哪裡」，而是會考你是否理解資料如何被設計、查詢、更新、保護，以及如何避免資料重複與不一致。

資料庫管理系統（Database Management System, DBMS）是管理資料庫的軟體，例如 MySQL、Microsoft SQL Server、PostgreSQL、Oracle Database。你可以把資料庫想成資料本身，把資料庫管理系統（DBMS）想成負責開門、查詢、修改、控管權限與維持安全的管理員。

國家考試準備資料庫時，最重要的方向通常有兩條：

1. 理論要會看：例如資料模型、關聯式資料庫、正規化、交易、索引、完整性限制。
2. SQL 要會寫：尤其是查詢、篩選、分組、排序、連接、子查詢與資料異動。

其中 SQL 幾乎是一定要反覆練的部分，因為它很容易以選擇題、申論題、改錯題或手寫查詢題出現。

## SQL 為什麼一定要熟

SQL（Structured Query Language，結構化查詢語言）是操作關聯式資料庫（Relational Database）的主要語言。關聯式資料庫是把資料放在一張張資料表（Table）中，資料表由資料列（Row）與資料欄（Column）組成。

SQL 的核心想法很直接：你不是一步一步告訴電腦怎麼找資料，而是描述「我要什麼資料」。例如你可以要求系統找出所有成績大於 80 分的學生，或統計每個部門的人數。

常見 SQL 類型可以先這樣理解：

| 類型 | 英文 | 功能 | 常見語法 |
|---|---|---|---|
| 資料查詢語言 | Data Query Language, DQL | 查資料 | `SELECT` |
| 資料定義語言 | Data Definition Language, DDL | 建立或修改資料庫結構 | `CREATE`、`ALTER`、`DROP` |
| 資料操作語言 | Data Manipulation Language, DML | 新增、修改、刪除資料 | `INSERT`、`UPDATE`、`DELETE` |
| 資料控制語言 | Data Control Language, DCL | 控制權限 | `GRANT`、`REVOKE` |
| 交易控制語言 | Transaction Control Language, TCL | 控制交易結果 | `COMMIT`、`ROLLBACK` |

### 具體範例

假設有一張學生資料表 `Student`，欄位包含 `student_id`、`name`、`score`。如果要查詢分數大於等於 60 分的學生，可以寫：

```sql
SELECT student_id, name, score
FROM Student
WHERE score >= 60;
```

這題看起來簡單，但國考可能會進一步問：

1. `SELECT *` 與指定欄位有什麼差異。
2. `WHERE` 是在分組前還是分組後篩選。
3. 如果要統計各班平均分數，要用哪個聚合函數（Aggregate Function）。
4. 如果要篩選平均分數大於 80 的班級，應該用 `WHERE` 還是 `HAVING`。

所以練 SQL 不能只背語法，而要知道每個子句在查詢流程中的角色。

## 練習 SQL 時要注意的資料庫系統差異

標準 SQL（Standard SQL）是 SQL 語言的共同規範，但不同資料庫管理系統（DBMS）會有自己的語法擴充與函數。這也是準備時很容易踩到的地方：網路上的練習題可能使用 MySQL，考題或教材可能偏標準 SQL，實務範例又可能使用 T-SQL 或 PostgreSQL。

MySQL（My Structured Query Language）是一種常見的開源資料庫管理系統。T-SQL（Transact-SQL）是 Microsoft SQL Server 使用的 SQL 擴充語言。PostgreSQL 是一種重視標準與擴充性的開源資料庫管理系統。

核心想法是：基本查詢語法大多相通，但日期函數、字串函數、分頁語法、型別轉換、空值處理等細節可能不同。

### 常見差異舉例

| 主題 | 標準概念 | 不同 DBMS 可能差異 |
|---|---|---|
| 取目前日期 | 取得系統日期或時間 | 可能使用 `CURRENT_DATE`、`GETDATE()`、`NOW()` |
| 字串連接 | 把兩段文字接起來 | 可能使用 `||`、`+`、`CONCAT()` |
| 限制筆數 | 只取前幾筆資料 | 可能使用 `FETCH FIRST`、`LIMIT`、`TOP` |
| 空值處理 | 處理 `NULL` | 可能使用 `COALESCE()`、`ISNULL()`、`IFNULL()` |

練題時要先確認題目使用的是哪一種 SQL。國考若沒有特別指定產品，答題時通常以標準 SQL 與通用觀念為主，避免寫太偏某一套系統的專屬語法。

## 國考常見考法

國考考資料庫時，SQL 常見考法不是單純問「這個指令是什麼」，而是把語法放進資料表情境中，要求你判斷結果或寫出查詢。

常見題型包含：

1. 寫出查詢語句  
   例如查詢某科成績最高的學生、列出沒有選課的學生、統計每個部門平均薪資。

2. 判斷查詢結果  
   題目給資料表與 SQL，要求判斷輸出幾列、哪些資料會出現。

3. 比較 `WHERE` 與 `HAVING`  
   `WHERE` 是分組前篩選資料列，`HAVING` 是分組後篩選群組。

4. 比較不同連接（Join）  
   內部連接（Inner Join）只保留符合連接條件的資料；外部連接（Outer Join）會保留某一邊或兩邊未配對的資料。

5. 考空值 `NULL`  
   空值（NULL）代表未知、缺漏或不適用，不等於 0，也不等於空字串。判斷空值要用 `IS NULL`，不是用 `= NULL`。

6. 考不同 DBMS 語法陷阱  
   題目可能出現某些系統才支援的函數，要求考生辨識是否屬於標準 SQL 或特定資料庫語法。

## 易混淆整理

| 易混淆項目 | 正確理解 | 常見錯誤 |
|---|---|---|
| 資料庫（Database）與 DBMS | 資料庫是資料集合，DBMS 是管理資料庫的軟體 | 把資料本身和管理軟體混為一談 |
| SQL 與 DBMS | SQL 是語言，DBMS 是執行與管理資料庫的系統 | 以為 SQL 本身就是一套資料庫軟體 |
| 標準 SQL 與產品 SQL | 標準 SQL 是共同規範，產品 SQL 可能有擴充 | 直接把 MySQL 函數當成所有系統都能用 |
| `WHERE` 與 `HAVING` | `WHERE` 篩選資料列，`HAVING` 篩選分組後結果 | 在聚合函數條件中誤用 `WHERE` |
| `NULL` 與 0 | `NULL` 是未知或無值，0 是明確數值 | 用 `= NULL` 判斷空值 |
| `DELETE` 與 `DROP` | `DELETE` 刪資料列，`DROP` 刪資料表或物件 | 把刪資料與刪結構混在一起 |

## 國考必背整理

1. SQL（Structured Query Language）是操作關聯式資料庫的主要語言。
2. 資料庫（Database）是資料集合；資料庫管理系統（DBMS）是管理資料庫的軟體。
3. 練 SQL 時要分清楚標準 SQL 與特定 DBMS 語法。
4. 基本查詢順序要熟：`SELECT`、`FROM`、`WHERE`、`GROUP BY`、`HAVING`、`ORDER BY`。
5. `WHERE` 用在分組前，`HAVING` 用在分組後。
6. `NULL` 不能用一般等號判斷，要用 `IS NULL` 或 `IS NOT NULL`。
7. 聚合函數（Aggregate Function）例如 `COUNT()`、`SUM()`、`AVG()`、`MAX()`、`MIN()`，常搭配 `GROUP BY`。
8. 不同 DBMS 的函數可能不同，看到日期、字串、分頁、空值函數時要特別小心。

## 容易考的判斷題

1. SQL 是一種資料庫管理系統。  
   錯。SQL 是語言，資料庫管理系統（DBMS）才是軟體系統。

2. MySQL、T-SQL、PostgreSQL 的所有函數都完全相同。  
   錯。基本 SQL 概念相通，但函數與語法細節可能不同。

3. 如果題目沒有指定特定 DBMS，答題應優先使用通用 SQL 概念。  
   對。國考通常重視標準觀念，不宜依賴太偏產品專屬的寫法。

4. `WHERE` 可以直接篩選 `AVG(score) > 80` 的分組結果。  
   錯。聚合後的分組條件通常應使用 `HAVING`。

5. `NULL` 可以用 `= NULL` 判斷。  
   錯。判斷空值要使用 `IS NULL`。

## 考前速記小抄

資料庫這科不要只看定義，SQL 一定要動手寫。最基本的 `SELECT` 查詢、`WHERE` 篩選、`GROUP BY` 分組、`HAVING` 分組後篩選、`ORDER BY` 排序，要練到看到題目就能判斷該用哪個子句。

練歷屆試題時，要特別標記每題使用的是標準 SQL、MySQL、T-SQL 還是 PostgreSQL。只要題目出現日期函數、字串函數、限制筆數、空值處理，就要提醒自己：這可能是不同資料庫管理系統（DBMS）的語法差異。

最後記住一句話：國考重點不是背最多函數，而是能看懂資料表、寫出正確查詢，並知道哪些語法是通用觀念，哪些是特定系統的寫法。
