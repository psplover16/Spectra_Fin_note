# 基本計概 10：浮點數轉換（傳統表示法 + IEEE 754）

> 數值與編碼（計算題）。

## 16. 浮點數轉換

> 浮點數是電腦用來表示小數或很大、很小數字的方法。

> 🎯 **這篇怎麼用**：兩種表示法（傳統、IEEE 754）的轉換規則**不要硬背**——把下面的手把手例題親手算過幾遍，建立肌肉記憶，看到題目就會做。核心路徑只有一條：**轉二進位 → 正規化 → 算指數 → 填欄位**。

### 傳統（一般）浮點表示法　【理解】

最早的浮點數，就是把一個數拆成三塊存起來：

> **± 尾數（mantissa）× 2^指數（exponent）**

存成三個欄位：**符號 S｜指數（用超額碼 excess）｜尾數**。

**和 IEEE 754 比，差在三點（這就是考點）：**

| | 傳統（一般） | IEEE 754 |
|---|---|---|
| 最高位的 1 | **完整存進尾數**（不隱藏） | **隱藏**，只存小數部分（多賺 1 位精度） |
| 指數編碼 | 超額碼 excess（數值看教材） | bias：單精度 **127**、雙精度 **1023** |
| 特殊值 | 通常沒有 | 有 0／非正規／∞／NaN 的保留編碼 |

**同一個數、兩種存法（以 `10.25` 為例）**：
- 正規化（兩種一樣）：`10.25 = 1010.01₂ = 1.01001 × 2³`。
- **傳統**：尾數**完整存** `1.01001`（連最高位的 1 一起）；指數一樣用偏移碼，但**偏移值依格式而定**（8 位指數常見 excess-128 或 127，見下方說明）。
- **IEEE 754**：尾數**隱藏**最高位 1、只存 `01001`，指數用 bias（`3 + 127 = 130`）。

> ⚠ 各家教材對「傳統表示法」的欄位寬度、正規化形式（`1.xxx` 或 `0.1xxx`）、超額值定義略有不同。上面抓的是**通用觀念 + 三大差異**；若你的教材有指定格式，貼給我，我用你那版的規則重算例題。

> 💡 **偏移值（bias／excess）怎麼來、為什麼 IEEE 用 127？** k 位指數欄的偏移值常見兩種：**2^(k−1)**（8 位 → 128）或 **2^(k−1) − 1**（8 位 → **127**；11 位 → 1023）。**IEEE 754 故意取「少 1」的版本（127／1023）**，是為了把「指數全 0」和「指數全 1」兩個編碼**保留給特殊值**（0／非正規數、∞／NaN）。所以**偏移值不是傳統 vs IEEE 的鐵則差異**（兩邊都可能用不同值）——**真正穩定的差異是「隱藏位元」**（表格第一列）。

下面主力練 **IEEE 754**（最常考、規則最明確）。

### IEEE 754 欄位
| 類型 | 總位元 | Sign | Exponent | Fraction | bias |
| --- | ---: | ---: | ---: | ---: | ---: |
| 單精度 | 32 bits | 1 bit | 8 bits | 23 bits | 127 |
| 雙精度 | 64 bits | 1 bit | 11 bits | 52 bits | 1023 |

公式：
```text
(-1)^S × 1.F × 2^(E − bias)
```

| 欄位 | 中文 | 白話 |
| --- | --- | --- |
| S | 符號位 | 0 正、1 負 |
| E | 指數欄位 | 存的是「實際指數 + bias」 |
| F | Fraction / 尾數欄位 | 只存小數點右邊，不存最前面的 1 |

### 完整流程（發送端：算出要傳什麼）
1. 判斷正負數：正數 S = 0；負數 S = 1。
2. 計算數值的二進位。
3. 正規化成 `1.xxxxx × 2^n`。
4. 算 `E = n + bias`。
5. 把 `(n + bias)₁₀` 轉成二進位（記為 Y）。
6. 把 `1.xxxxx` 去掉最高位的 1（記為 Z）。
7. 把 S、Y、Z 組合，注意 Fraction 的 bits 數。

### 正規化
把二進位數寫成 `1.xxxxx × 2^n`：
```text
1101.101(2) = 1.101101(2) × 2^3   （小數點往左移 3 位 → 指數 +3）
0.0101(2)   = 1.01(2)    × 2^-2   （小數點往右移 2 位 → 指數 −2）
```

### 十進位小數轉二進位
- 整數部分：除以 2，記餘數，最後**倒著讀**。
- 小數部分：乘以 2，取整數，最後**順著讀**。

例：`13.625(10)`
```text
13    = 1101
0.625 = 0.101
→ 13.625(10) = 1101.101(2) = 1.101101(2) × 2^3
```

### 範例：`10.25(10)` 轉 IEEE 754 單精度
1. 符號：10.25 是正數 → **S = 0**。
2. 轉二進位：`10 = 1010`、`0.25 = 0.01` → `10.25 = 1010.01(2)`。
3. 正規化：`1010.01 = 1.01001 × 2^3` → n = 3。
4. Exponent：`E = n + bias = 3 + 127 = 130 = 10000010(2)`。
5. Fraction：`1.01001` 取小數點右邊 `01001`，補滿 23 bits → `01001000000000000000000`。

**答案**：
```text
0 10000010 01001000000000000000000   →   0x41240000
```

### 範例：IEEE 754 反推
```text
1 10000001 10000000000000000000000
```
拆欄位：
```text
S = 1
E = 10000001(2) = 129
F = 1000000000000000000000
n = E − bias = 129 − 127 = 2
1.F = 1.1(2) = 1.5(10)
→ (-1)^1 × 1.5 × 2^2 = −1 × 1.5 × 4 = −6
```
**答案**：`−6`

### 為什麼 0.1 可能不精確？
```text
0.1(10) = 0.0001100110011…(2)   （循環小數）
```
電腦欄位有限，不能存無限位，只能存近似值 → **不是所有十進位小數都能被二進位浮點數精確表示**。

### 易錯陷阱
| 容易錯的地方 | 正確觀念 |
| --- | --- |
| Exponent 直接存實際指數 n | 錯，存的是 `n + bias` |
| Fraction 把最前面的 1 也存進去 | 錯，正規化的最前面 1 是隱含位元 |
| 小於 1 的數正規化後指數寫正數 | 通常錯，小數點往右移時指數是負數 |
| 十進位小數轉二進位用除以 2 | 錯，小數部分用乘以 2 |
| 負浮點數用二補數表示 | 錯，IEEE 754 用 Sign bit 表示正負 |

### 國考答題句
1. IEEE 754 正規化數的公式為 `(-1)^S × 1.F × 2^(E − bias)`。
2. 單精度共 32 bits：Sign 1、Exponent 8、Fraction 23，bias = 127。
3. 雙精度共 64 bits：Sign 1、Exponent 11、Fraction 52，bias = 1023。
4. Exponent 欄位存的是「實際指數 + bias」，不是直接存實際指數。
5. Fraction 只存正規化後小數點右側的位元，最前面的 1 為隱含位元。
6. 十進位小數轉二進位小數時，使用乘以 2 取整數的方法。
7. 有些十進位小數轉成二進位會循環，因此浮點數可能只能近似表示。
8. IEEE 754 與傳統浮點表示法最大差異：IEEE 754 **隱藏正規化後最高位的 1**（hidden bit）、只存小數部分；傳統則**完整儲存尾數**。

### 考前速記
```text
單精度：1 / 8 / 23，bias = 127
雙精度：1 / 11 / 52，bias = 1023

轉換流程：
1. 看正負號，決定 S。
2. 把絕對值轉成二進位。
3. 正規化成 1.F × 2^n。
4. 算 E = n + bias。
5. Fraction 填 F，不填隱含的 1。
6. 合併 S、Exponent、Fraction。

反推流程：
1. 拆 S、E、F。
2. 算 n = E − bias。
3. Fraction 前面補回隱含的 1。
4. 套 (-1)^S × 1.F × 2^n。
```

## 加強練習　【練流程】
**練習 1**：`−0.75` → IEEE 754 單精度
> 解：S=1；0.75 = `0.11₂` = `1.1 × 2⁻¹` → n = −1，E = −1+127 = 126 = `01111110`，F = `1000…`
> → `1 01111110 10000000000000000000000` = **0xBF400000**

**練習 2**：反推 `0 10000000 10000000000000000000000`（單精度）
> 解：E = 128 → n = 1；1.F = 1.1 = 1.5 → `+1.5 × 2¹` = **3**

**練習 3**：`6.5` → IEEE 754 單精度
> 解：6.5 = `110.1₂` = `1.101 × 2²` → n = 2，E = 2+127 = 129 = `10000001`，F = `101…`
> → `0 10000001 10100000000000000000000` = **0x40D00000**

**練習 4**：`−0.0625` → IEEE 754 單精度（負指數）
> 解：0.0625 = 1/16 = `0.0001₂` = `1.0 × 2⁻⁴` → n = −4，E = −4+127 = 123 = `01111011`，F = 全 0
> → `1 01111011 00000000000000000000000` = **0xBD800000**

**練習 5**：反推 `0 01111101 00000000000000000000000`（單精度）
> 解：E = `01111101₂` = 125 → n = 125−127 = −2；1.F = 1.0 → `+1.0 × 2⁻²` = **0.25**

**練習 6（兩種表示法對照）**：把 `−3.5` 正規化，分別寫出 IEEE 754 與「傳統（不隱藏）」的尾數。
> 解：3.5 = `11.1₂` = `1.11 × 2¹`，S = 1，n = 1。
> - **IEEE 754**：隱藏最高位 → 尾數欄 `11000…`；E = 1+127 = 128 = `10000000` → `1 10000000 11000000000000000000000`。
> - **傳統（不隱藏）**：尾數完整存 `1.11`（即 `111…`，連開頭的 1 一起）。
