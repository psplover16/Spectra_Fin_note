# 基本計概 12：檢查碼（一）Parity 與 CRC

> 數值與編碼（計算題）。

### Parity Check（同位元檢查）
加一個檢查位元，讓 1 的總數符合規則；檢查位元位置由發送方與接收方協調好即可。
| 類型 | 規則 |
| --- | --- |
| 偶同位（Even Parity） | 加上檢查位後，1 的總數為偶數 |
| 奇同位（Odd Parity） | 加上檢查位後，1 的總數為奇數 |

> 奇同位、偶同位，也可譯成奇校驗、偶校驗。

### CRC
1. **CRC（Cyclic Redundancy Check，循環冗餘檢查）** 常用在網路傳輸與儲存裝置，主要用來**偵測**錯誤，不是用來更正。
2. 傳送資料前，先依資料算出一串「檢查位元」附加在資料後面一起傳送；接收端再重算一次，看結果是否正確。
3. 算法：
   1. 看生成多項式長度（ex. `1011`）。
   2. CRC 位數 = 生成多項式長度 − 1。
   3. 原資料後面補相同數量的 0。
   4. 用生成多項式做**模 2 除法**（不進位、不借位，減法等於 XOR）。
   5. 最後餘數就是 CRC。
   6. 原資料 + CRC = 實際傳送資料。
   7. 接收端再除一次，餘數為 0 表示通過。

**手把手例題**　【練流程】
**題**：資料 `1101011011`，生成多項式 `10011`（5 bits → CRC 4 bits）。求 CRC 與傳送資料。
```text
資料後補 4 個 0 → D = 11010110110000，除數 G = 10011
（每次把 G 對齊「目前最左的 1」做 XOR）

11010110110000
10011
──────────────
01001110110000     11010 ⊕ 10011 = 01001
 10011
──────────────
00000010110000     10011 ⊕ 10011 = 00000
      10011
──────────────
00000000101000     10110 ⊕ 10011 = 00101
        10011
──────────────
00000000001110     10100 ⊕ 10011 = 00111
                   （剩 1110 不足 5 位 → 停）

餘數 = CRC = 1110
傳送資料 = 1101011011 + 1110 = 11010110111110
接收端：11010110111110 ÷ 10011 → 餘數 0 → 無錯
```

## 加強練習　【練流程】
**練習**：資料 `1010`，生成多項式 `1011`（CRC 3 bits）。求 CRC 與傳送資料。
> 解：補 3 個 0 → `1010000`，÷ `1011`：
> ```text
> 1010000
> 1011
> ────
> 0001000     1010 ⊕ 1011 = 0001
>    1011
> ────
> 0000011     1000 ⊕ 1011 = 0011 → 餘 011
> ```
> CRC = **011**，傳送 = `1010 011` = **1010011**（接收端再除餘 0）
