程式

一、準備方向

[原文提醒]
- 基本語法要會寫：if-else、switch、迴圈、物件導向、常用字串函式。
- 常考語言：C、C++、Java、Python。
- 語言獨有特性要記：
  - C / C++：指標。
  - Java：GC / G1GC 等垃圾回收觀念。
  - Python：List、Tuple、Dictionary、Set。

二、基礎

[比較] Assembler vs Compiler vs Interpreter
- Assembler：組合語言轉機器碼。
- Compiler：將高階語言整體或大段編譯成目標碼。
- Interpreter：逐行或逐步解讀執行。

[必背]
- 變數：儲存資料的命名空間，注意型別與作用域。
- 函式：封裝可重用邏輯。
- 陣列：同型別連續資料集合。
- 迴圈：for、while、do-while。
- 條件：if-else、switch。
- 例外處理：try、catch、finally、throw。

[比較] 參數傳遞
- Call by Value：傳值，函式內修改不影響原值。
- Call by Address：傳位址，常見於 C 指標。
- Call by Reference：傳參考，可影響原物件或變數。
- Call by Name：延遲求值概念，較少見但可能考名詞。

[必背] static
- C/C++ 區域 static 變數：生命週期延長至程式結束，但作用域仍在區塊內。
- C/C++ 檔案層級 static：限制 linkage。
- Java static：屬於 class，不屬於特定 object。

三、中階

[必背] 指標
- 指標存放位址。
- & 取址，* 解參考。
- 指標與陣列關係常考。
- 注意 null pointer、dangling pointer、memory leak。

[必背] 字串相關函式
- C：strlen、strcpy、strncpy、strcmp、strcat。
- C++：std::string 常用 length、substr、find。
- Java：String length、substring、equals、charAt。
- Python：len、split、join、find、replace。

[必背] OOP 三大特性
- Encapsulation：封裝資料與操作。
- Inheritance：繼承既有類別特性。
- Polymorphism：多型，同一介面可有不同實作。

[補充] OOP 常見延伸
- Overloading：多載，同名函式參數不同。
- Overriding：覆寫，子類別改寫父類別方法。
- Abstract Class vs Interface：抽象類別可含狀態與部分實作；介面偏規格契約。

[必背] Recursion
- 遞迴需有 base case 與 recursive case。
- 常見題型：階乘、費氏數列、河內塔、樹走訪、DFS。
- 注意 stack overflow 與重複計算，可用 memoization。

四、Python 特殊資料型別

[比較]
- List：有序、可變、可重複。
- Tuple：有序、不可變、可重複。
- Dictionary：key-value，key 不可重複。
- Set：無序、不重複。

五、C / C++ / Java 補充重點

[補充]
- C：指標、struct、malloc/free、陣列與字串結尾 '\0'。
- C++：class、constructor/destructor、RAII、reference、STL。
- Java：JVM、bytecode、GC、class、interface、exception、collection framework。
