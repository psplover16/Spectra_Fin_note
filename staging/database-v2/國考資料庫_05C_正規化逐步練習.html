正規化逐步練習

10 張設計不良的表，一步一步走 1NF → 2NF → 3NF
怎麼用這份文件：每題上方橘框＝題目（永遠顯示），下方藍框＝逐步解答。 按右上「默寫模式」會把解答全部藏起來、只留題目，你先在紙上自己正規化，再點該題標題展開、對照核對。
默寫模式：解答已隱藏。請依題目自己拆解到 3NF，再點該題標題顯示解答核對。

📋 正規化解題 SOP（每題都照這五步走）

  1. 寫出主鍵與所有功能相依。
  2. 1NF：每格是否單一值？有多值或重複群組 → 拆成多列／另立表。
  3. 2NF：有無「非主屬性只靠複合主鍵的一部分」（部分相依）？有 → 把那部分連同它決定的屬性抽出另立表。
  4. 3NF：有無「非主屬性靠另一個非主屬性決定」（遞移相依）？有 → 把它抽出另立表。
  5. 寫出最終各表（標主鍵 底線、外來鍵 FK）。

1多值欄位（1NF）

題目

表：學生社團（學號, 姓名, 社團），主鍵 = {學號}。

學號姓名社團
S01王小明籃球社、熱舞社
S02李小華吉他社

任務：正規化到 3NF。

解答

① 主鍵與相依：主鍵 {學號}；學號 → 姓名。社團一格塞了多個值。

② 1NF：「社團」非單一值 → 違反。把社團拆成單一值、另立一張表。

③ 2NF／④ 3NF：拆完後沒有部分相依、也沒有遞移相依 → 通過。

⑤ 最終結果：

  • 學生（學號, 姓名）
  • 學生社團（學號 FK, 社團）　主鍵 = {學號, 社團}

2重複群組（1NF）

題目

表：訂單（訂單號, 客戶, 商品1, 商品2, 商品3），主鍵 = {訂單號}。用三個欄位塞多項商品。

訂單號客戶商品1商品2商品3
O01陳大同滑鼠鍵盤螢幕
O02林志成耳機——

任務：正規化到 3NF。

解答

① 主鍵與相依：主鍵 {訂單號}；訂單號 → 客戶。商品散在三個重複欄位。

② 1NF：重複群組（商品1～3）違反「不可有重複欄位」→ 把商品改成多列、另立明細表。

③ 2NF／④ 3NF：無部分相依、無遞移相依 → 通過。

⑤ 最終結果：

  • 訂單（訂單號, 客戶）
  • 訂單商品（訂單號 FK, 商品）　主鍵 = {訂單號, 商品}

3部分相依（2NF）

題目

表：選課（學號, 課號, 成績, 課名），主鍵 = {學號, 課號}。

已知：{學號,課號} → 成績、課號 → 課名。

任務：正規化到 3NF。

解答

① 相依：複合主鍵 {學號,課號}；成績靠整把鑰匙，課名只靠課號。

② 1NF：皆單一值 → 通過。

③ 2NF：課名只靠「課號」（主鍵的一部分）→ 部分相依。把 {課號, 課名} 抽出另立表。

④ 3NF：剩下無遞移相依 → 通過。

⑤ 最終結果：

  • 選課（學號, 課號, 成績）　課號 FK → 課程
  • 課程（課號, 課名）

4多個部分相依（2NF）

題目

表：訂單明細（訂單號, 商品號, 數量, 商品名, 單價, 訂單日期），主鍵 = {訂單號, 商品號}。

已知：{訂單號,商品號} → 數量、商品號 → 商品名, 單價、訂單號 → 訂單日期。

任務：正規化到 3NF。

解答

① 相依：數量靠整把鑰匙；商品名/單價只靠商品號；訂單日期只靠訂單號。

② 1NF：通過。

③ 2NF：兩組部分相依——商品名、單價靠「商品號」；訂單日期靠「訂單號」。各自抽出另立表。

④ 3NF：三表皆無遞移相依 → 通過。

⑤ 最終結果：

  • 訂單明細（訂單號, 商品號, 數量）
  • 商品（商品號, 商品名, 單價）
  • 訂單（訂單號, 訂單日期）

5遞移相依（3NF）

題目

表：員工（員工號, 姓名, 部門號, 部門名），主鍵 = {員工號}。

已知：員工號 → 姓名, 部門號、部門號 → 部門名。

任務：正規化到 3NF。

解答

① 相依：員工號決定姓名、部門號；部門號又決定部門名。

② 1NF：通過。③ 2NF：主鍵是單一屬性，不可能有部分相依 → 通過。

④ 3NF：部門名靠「部門號」（非主屬性）→ 遞移相依（員工號 → 部門號 → 部門名）。把 {部門號, 部門名} 抽出。

⑤ 最終結果：

  • 員工（員工號, 姓名, 部門號 FK）
  • 部門（部門號, 部門名）

6遞移相依（3NF）

題目

表：書籍（ISBN, 書名, 出版社, 出版社地址），主鍵 = {ISBN}。

已知：ISBN → 書名, 出版社、出版社 → 出版社地址。

任務：正規化到 3NF。

解答

① 相依：ISBN 決定書名、出版社；出版社決定其地址。

② 1NF／③ 2NF：單一主鍵，皆通過。

④ 3NF：出版社地址靠「出版社」（非主屬性）→ 遞移相依。把 {出版社, 出版社地址} 抽出。

⑤ 最終結果：

  • 書籍（ISBN, 書名, 出版社 FK）
  • 出版社（出版社, 出版社地址）

7部分相依綜合（1NF＋2NF）

題目

表：成績單（學號, 姓名, 課號, 課名, 學分, 成績），主鍵 = {學號, 課號}。

已知：學號 → 姓名、課號 → 課名, 學分、{學號,課號} → 成績。

任務：正規化到 3NF。

解答

① 相依：姓名只靠學號；課名、學分只靠課號；成績靠整把鑰匙。

② 1NF：皆單一值 → 通過。

③ 2NF：兩組部分相依——姓名靠「學號」、課名/學分靠「課號」。各抽出。

④ 3NF：三表皆無遞移相依 → 通過。

⑤ 最終結果：

  • 學生（學號, 姓名）
  • 課程（課號, 課名, 學分）
  • 成績（學號, 課號, 成績）

8全餐：多值＋部分（1NF＋2NF）

題目

表：租借（會員號, 會員名, 會員電話, 影片號, 影片名, 類型, 租借日），主鍵 = {會員號, 影片號}；會員電話可有多筆。

已知：會員號 → 會員名、影片號 → 影片名, 類型、{會員號,影片號} → 租借日，會員號可對多個電話。

任務：正規化到 3NF。

解答

① 相依：會員名只靠會員號；影片名、類型只靠影片號；租借日靠整把鑰匙；電話為多值。

② 1NF：會員電話多值 → 另立電話表（每列一支）。

③ 2NF：部分相依——會員名靠「會員號」、影片名/類型靠「影片號」。各抽出。

④ 3NF：各表皆無遞移相依 → 通過。

⑤ 最終結果：

  • 會員（會員號, 會員名）
  • 會員電話（會員號 FK, 電話）
  • 影片（影片號, 影片名, 類型）
  • 租借（會員號, 影片號, 租借日）

9遞移相依：地址（3NF）

題目

表：員工（員工號, 姓名, 郵遞區號, 縣市, 區），主鍵 = {員工號}。

已知：員工號 → 姓名, 郵遞區號、郵遞區號 → 縣市, 區。

任務：正規化到 3NF。

解答

① 相依：員工號決定姓名、郵遞區號；郵遞區號決定縣市、區。

② 1NF／③ 2NF：單一主鍵，皆通過。

④ 3NF：縣市、區靠「郵遞區號」（非主屬性）→ 遞移相依。把 {郵遞區號, 縣市, 區} 抽出。

⑤ 最終結果：

  • 員工（員工號, 姓名, 郵遞區號 FK）
  • 郵遞區（郵遞區號, 縣市, 區）

10期末大魔王：部分＋遞移（2NF＋3NF）

題目

表：發票（發票號, 日期, 客戶號, 客戶名, 客戶地址, 商品號, 商品名, 單價, 數量），主鍵 = {發票號, 商品號}。

已知：發票號 → 日期, 客戶號、客戶號 → 客戶名, 客戶地址、商品號 → 商品名, 單價、{發票號,商品號} → 數量。

任務：正規化到 3NF。

解答

① 相依：發票號決定日期、客戶號（客戶號再帶出客戶名/地址）；商品號決定商品名、單價；數量靠整把鑰匙。

② 1NF：皆單一值 → 通過。

③ 2NF（除部分相依）：

  • 日期、客戶號（連同客戶名、客戶地址）只靠「發票號」→ 抽到發票表。
  • 商品名、單價只靠「商品號」→ 抽到商品表。
  • 得：發票（發票號, 日期, 客戶號, 客戶名, 客戶地址）、商品（商品號, 商品名, 單價）、明細（發票號, 商品號, 數量）。

④ 3NF（除遞移相依）：發票表裡 客戶名、客戶地址 靠「客戶號」（非主屬性）→ 遞移相依。把客戶資料抽出客戶表。

⑤ 最終結果（4 張表）：

  • 發票（發票號, 日期, 客戶號 FK）
  • 客戶（客戶號, 客戶名, 客戶地址）
  • 商品（商品號, 商品名, 單價）
  • 發票明細（發票號, 商品號, 數量）
💡 大魔王心法欄位一多就照順序問兩件事：先問「有沒有只靠半把複合鍵的」（2NF），再問「有沒有非主屬性互相決定的」（3NF）。每發現一組，就抽一張新表。
