Expression Notation

運算式表示法

同一個運算式依運算子擺放的位置,可寫成中序(Infix)、前序(Prefix)、後序(Postfix)三種形式,並與運算式樹的走訪一一對應。

運算式表示法(中序 / 前序 / 後序)

同一個運算式有三種寫法,差別在運算子擺哪裡:

  • 中序 Infix:A + B(運算子在中間,一般數學式,人類看的)。
  • 前序 Prefix:+ A B(運算子在前,又叫波蘭表示法)。
  • 後序 Postfix:A B +(運算子在後,又叫逆波蘭 RPN,電腦最好算)。

和樹走訪的漂亮連結:把運算式畫成「運算式樹」,那麼——前序走訪 = 前序式、中序走訪 = 中序式、後序走訪 = 後序式。

例:(A + B) * C 的運算式樹:

        *
       / \
      +   C
     / \
    A   B
  • 前序(prefix):* + A B C
  • 中序(infix):A + B * C(注意:中序會丟失括號,需靠優先權或括號還原)
  • 後序(postfix):A B + C *

電腦用堆疊 (Stack) 來做「中序轉後序」與「後序求值」。

用三題實戰前中後序

下面三題各打一個考點,建議先自己算,再對詳解。

題目一(考點:中序 → 後序 + 前序)

把下面這個中序運算式,分別轉成後序和前序:

A × B + C × ( D − E )

詳解:先認優先權 —— × 高於 +,而括號 ( ) 最先算。把式子拆成「一定要先算」的小塊,再依序合併。

轉後序(運算子放到兩個運算元「後面」):

  1. A × B → A B ×
  2. D − E(括號先算)→ D E −
  3. C × (D−E) → C 接上一步結果,再放 × → C D E − ×
  4. 最後的 + 把「①的結果 A B ×」和「③的結果 C D E − ×」串起來,+ 放最後 → 完成。

後序答案:A B × C D E − × +

轉前序(運算子放到兩個運算元「前面」):

  1. A × B → × A B
  2. D − E → − D E
  3. C × (D−E) → × C − D E
  4. 最後的 + 把「①的結果 × A B」和「③的結果 × C − D E」串起來,+ 放最前 → 完成。

前序答案:+ × A B × C − D E

其實兩者就是同一棵運算式樹的後序 / 前序走訪(根是最後才做的 +):

          +
        /   \
       ×     ×
      / \   / \
     A   B C   −
              / \
             D   E

題目二(考點:後序用堆疊求值)

用堆疊算出下面這個後序運算式的值,並寫出每一步的堆疊狀態:

6 2 3 + × 8 4 / −

詳解:規則很簡單 —— 遇到數字就 push;遇到運算子就 pop 兩個出來算,先 pop 的當右運算元、後 pop 的當左運算元,算完把結果 push 回去。

讀到動作堆疊(左→右,右端為頂)
6push 66
2push 26, 2
3push 36, 2, 3
+pop 3、pop 2 → 2 + 3 = 5,push 56, 5
×pop 5、pop 6 → 6 × 5 = 30,push 3030
8push 830, 8
4push 430, 8, 4
/pop 4、pop 8 → 8 / 4 = 2,push 230, 2
−pop 2、pop 30 → 30 − 2 = 28,push 2828

答案 = 28。特別注意 − 和 / 這種不可交換的運算:是「後 pop − 先 pop」(左 − 右、左 / 右),千萬別算反成 2 − 30。

題目三(考點:運算式樹 → 三種走訪)

寫出下面這棵運算式樹的前序、中序(記得該加括號)、後序:

        ×
       / \
      +   −
     / \ / \
    A  B C  D

詳解:三種走訪只差在「根(節點自己)什麼時候輸出」——前序=根→左→右;中序=左→根→右;後序=左→右→根。這棵樹的根是 ×,左子樹是 A + B,右子樹是 C − D:

  1. 前序(根先):× →(+ A B)→(− C D)= × + A B − C D
  2. 中序(根在中):(A + B)→ × →(C − D)。因為 × 優先權比 +、− 高,不加括號會變成 A + B × C − D、意思整個跑掉,所以左右都要括起來。
  3. 後序(根最後):(A B +)→(C D −)→ × = A B + C D − ×

答案:
前序 × + A B − C D
中序 (A + B) × (C − D)(必須加括號)
後序 A B + C D − ×

★ 常考重點:前/中/後序 = 運算子在前/中/後;對應運算式樹的前/中/後序走訪。轉換與求值用堆疊。
