紅黑樹_刪除

紅黑樹刪除的完整 SOP,加上走遍每一條修復分支的 16 道實戰題與詳解。

記號:(B) 黑、(R) 紅、x = 雙黑節點、w = x 的兄弟、P = 父親

刪除 SOP(照著跑)　→　附錄:為什麼(可跳過)　→　16 題(走遍每一條分支)　→　覆蓋矩陣

題目裡的「情況 1 / 2 / 3 / 4」= SOP 裡的 Case 1 / 2 / 3 / 4。

刪除 SOP

前置作業:刪除與判斷

1. 照常刪除

D(你要刪的節點)有幾個小孩做什麼
0 個直接砍掉
1 個那個小孩頂替它的位置
2 個找「右子樹最小值」當替身,把替身的 key 抄進來,然後刪除那個替身

兩個代號(後面 16 題都用它們)

意思
y真正被刪掉或移走的節點(是 D,或是替身)
x頂替 y 位置的節點(可能是 NIL)

y 永遠只有 0 或 1 個小孩(替身是「一路往左到底」找到的,不可能有左小孩)。

2. 看顏色

條件動作
出口①y 是紅色SOP 結束,不用做事
出口②y 黑,但 x 是紅色把 x 塗黑,SOP 結束
—y 黑,x 也黑(含 NIL)產生「雙黑」,進入下方修復 SOP

「雙黑」= x 多背一個黑。

x 本來是紅 → 紅 + 黑 = 黑 → 直接塗黑就還清了(出口②)。

x 本來是黑 → 黑 + 黑 = 雙黑 → 賴帳,要進四大情境。

y 只有三種長相(所以不用擔心漏掉組合)

y 的顏色y 的小孩數x走哪
紅必定 0 個(葉)NIL出口①
黑1 個(必定是紅葉)那個紅葉出口②
黑0 個NIL雙黑 → 四大情境

性質 5 鎖死了組合:紅節點不可能只有一個小孩;黑節點若只有一個小孩,那個小孩必定是紅葉。

必背 SOP:雙黑修復四大情境

前提假設:雙黑節點在「左邊」。(如果在右邊,把口訣裡的左 / 右互換即可)

觀察重點:只看「兄弟」和「姪子(兄弟的小孩)」的顏色。

附錄|(可跳過)為什麼

這一節不用背。 但看懂之後,四個 Case 就不需要背了。

一、換個看法:紅色 = 餘額,黑色 = 本金

黑節點 = 本金(計入黑高)

紅節點 = 餘額(不計入黑高,是「額外的」)

性質翻譯
性質 5(黑高處處相同)每條路徑的本金必須一樣多
性質 4(不能紅接紅)餘額不能疊

紅色就是可動用的錢。看到紅色,就是看到錢。

二、刪除的每一條規則,都是同一句話

規則用「餘額 / 本金」翻譯
y 是紅 → 什麼都不用做你拿走的是餘額,本金沒動
x 是紅 → 塗黑就結束x 自己有餘額 → 轉成本金,補上缺口
雙黑這條路的本金少一塊,而且身邊沒餘額可以轉
Case 2 之後爸爸是紅 → 塗黑結束爸爸有餘額 → 直接拿來抵
推到根 → 結束全樹本金一起少一塊,誰都沒吃虧

三、四個 Case,只是在問「錢在哪」

先問:兄弟家有錢嗎?

看兩個姪子。有紅的 = 兄弟家有餘額。

因為紅小孩不佔黑高 —— 它就是掛在兄弟身上的額外資產。

兄弟姪子意思
黑有紅的有餘額,借得到 → Case 3 / 4
黑兩個都黑兄弟身上只有自己那塊本金,借了它自己就垮 → 借不到 → Case 2

Case 2|兄弟家也窮 → 兩家一起減,虧空上報

沒錢可借,那就大家一起少一塊本金(兄弟塗紅 = 本金變餘額)。

兩邊一樣窮 → 對爸爸來說公平 → 把「少一塊」的帳報給爸爸。

爸爸結果
紅(有餘額)拿來抵 → 結清
黑爸爸成了新的雙黑 → 繼續往上報
是根全樹一起少一塊,誰都沒吃虧 → 結清

只有 Case 2 會往上傳:合併之後虧空還在,只是換人扛。

Case 4|錢在遠端 → 直接借,收工

旋轉時,兄弟 w 會從遠姪子頭上走掉 → 遠姪子那條路少一塊本金。

只有遠姪子本身是紅的(有餘額),才能把它塗黑補回來。
它本來就是黑的話,塗了等於沒塗。

那近姪子呢? 旋轉時它換邊搬到爸爸底下,而爸爸剛好塗黑 —— 一進一出打平,幫不上忙。

Case 3|錢在近端 → 先挪到遠端

近端的紅色是有錢,但位置不對,遞不過來。

先對兄弟轉一次,把紅色挪到遠端 → 變成 Case 4 → 借。

Case 1|你認錯人了

這是最容易誤解的一個。它根本不是解法。

      P(B)                     x 的「binary 兄弟」是 w
     /    \                    但 w 是紅的 ——
   x(BB)   w(R)                它其實跟 P 是「同一個節點」的一部分
          /    \
        wl(B)  wr(B)           ⇒ x 真正的兄弟是 wl,不是 w

Case 1 旋轉之後:

      w(B)
     /    \
   P(R)   wr(B)                x 的兄弟終於變成 wl 了
   /  \
  x(BB) wl(B)

Case 1 只是把畫法翻了一面,好讓 x 的「真兄弟」站到兄弟的位置上。
雙黑一點都沒解決 —— 但你現在看得到真正的兄弟了。

(為什麼 w 跟 P 是「同一個節點」?看第四節。)

四、再深一層:紅黑樹其實是 2-3-4 樹

對應規則

一個黑節點,加上它的紅小孩,合起來是 B 樹裡的「同一個節點」。

黑節點的紅小孩數合起來是幾個 key
02-node1
13-node2
24-node3

紅色不是顏色,是一根「我跟我爸是同一個節點」的標記。

四個 Case 的 B 樹意義

CaseRB 動作在 2-3-4 樹裡旋轉
1兄弟紅 → 旋轉換色換畫法。B 樹一點都沒變,只是把 x 的真兄弟叫出來1
2兩姪子黑 → 兄弟塗紅,往上推兄弟是 2-node,沒有多的 key 可借 → 合併 → 爸爸下溢 → 往上0
3近姪子紅 → 旋轉換色換畫法。B 樹沒變,只是把要借的 key 挪到能借的位置1
4遠姪子紅 → 旋轉換色兄弟是 3-node / 4-node,有多的 key → 借一個 key → 結束1

只有 Case 2(合併)和 Case 4(借)在做真正的事。

Case 1 和 Case 3 都只是「換畫法」。

「兄弟家有沒有紅姪子」= 「兄弟這個 B 樹節點是不是 2-node」。
2-node 借不出去(借了自己就垮)→ 只能合併。這跟 B 樹刪除的邏輯一字不差。

這樣「旋轉 ≤ 3」就是廢話了

換畫法(Case 1)  1 轉
換畫法(Case 3)  1 轉
借  (Case 4)    1 轉
合併(Case 2)    0 轉 —— 只是記帳,不動樹
                ─────
                最多 3 轉

Case 1 不可能出現兩次(換完畫法,真兄弟就站好了)。
Case 3 不可能出現兩次(挪完錢,直接就借)。

五、記憶結構:只有三個問題

① 兄弟是紅的?    → 你認錯人了,先把真兄弟叫出來      (Case 1)
② 遠端有紅?      → 借,收工                          (Case 4)
③ 近端有紅?      → 先把錢挪到遠端,再借              (Case 3 → 4)
   都沒有         → 兩家一起窮,虧空報給爸爸          (Case 2)

六、順帶把插入也解釋了

RB 插入在 2-3-4 樹裡旋轉
父親是黑 → 結束key 塞進 2-node → 變 3-node0
情況三(叔叔黑,直線)key 塞進 3-node → 變 4-node1
情況二(叔叔黑,折線)換畫法1
情況一(叔叔紅)節點是 4-node,塞不下了 → 分裂,中間的 key 往上推 → 爸爸可能又溢位 → 往上0

插入旋轉 ≤ 2 = 換畫法(1)+ 完成(1)。分裂不旋轉。

新節點為什麼一律塗紅?

紅是餘額,不動本金 → 黑高不變 → 性質 5 永遠安全。
塗黑就是憑空多印一塊本金 → 全樹的帳立刻對不上。

先放餘額,不動本金。這是紅黑樹所有操作的第一原則。
