AVL樹_刪除

這份是 AVL 樹刪除的實戰筆記:先背刪除 SOP,再用兩個雙旋連鎖範例(LR / RL)與兩題練習詳解把流程練熟。

高度約定:h(null) = 0、h(葉) = 1、h(x) = 1 + max(h(左), h(右))
平衡因子:BF(x) = h(左) − h(右)
★ = 失衡點　◆ = 較高子

刪除 SOP(先背這個)

從上往下走;把被移除節點的父親當起點,一路往上修到根。

顏色的意思

灰前置 / 計算(化簡、重算高度與 BF)
琥珀判斷(是否平衡、查表分型)
藍單旋(LL 右旋 / RR 左旋)　速查↗
紫雙旋(LR / RL,先橋直再轉)　速查↗
珊瑚往上一層 → 迴圈回 ①
青處理完根 → 結束

四型旋轉速查

+2 / 較高子 +1 或 0右旋(LL,單旋)
+2 / 較高子 −1LR:先對左小孩左旋,再對這個節點右旋
−2 / 較高子 −1 或 0左旋(RR,單旋)
−2 / 較高子 +1RL:先對右小孩右旋,再對這個節點左旋

旋轉怎麼畫

右旋 P　L = P.left;b = L.right 搬到 P.left

   P                L
  / \              / \
 L   c    ──►     a   P
/ \                  / \
a   b               b   c

左旋 P　R = P.right;b = R.left 搬到 P.right

   P                R
  / \              / \
 a   R    ──►     P   c
    / \          / \
   b   c        a   b

檢查:唸一次中序,順序沒變就對了。

(選配)提早停手

不做也不會錯,只是多算幾層。考卷問「連鎖到哪一層」時才需要:

這一層發生了什麼子樹高度可以停?
沒失衡,h 沒變不變停
沒失衡,h 少 1矮 1往上
單旋,較高子 BF = ±1矮 1往上
單旋,較高子 BF = 0不變停
雙旋(LR / RL)矮 1往上

範例 A｜二 → 零　＋　LR 雙旋　＋　連鎖

特徵:後繼是葉節點、第一次是雙旋、旋轉後矮 1 層 → 連鎖到根。
