紅黑樹

紅黑樹是一種以節點紅黑著色搭配五大性質、把樹高鎖在 O(log n) 的自平衡二元搜尋樹,這份速記卡只收考卷會出的定義、五大性質、插入、刪除與時間複雜度。

① 定義【硬背】

紅黑樹 = BST + 每個節點多帶一個顏色(紅 / 黑)

  • 所有空指標都視為一個黑色的 NIL 哨兵。
  • NIL 就是紅黑樹的「葉節點」;有 key 的叫內部節點。
  • 畫圖時 NIL 通常省略,但算黑高時一定要算進去。

黑高 bh(x)

bh(x) = 從 x 往下,到任一 NIL 的路徑上,黑節點的個數

不含 x 自己,但含最底下那個 NIL。

例bh
單獨一個黑根節點1(只有 NIL)
20(B) 底下掛 10(B)、30(B)bh(20) = 2、bh(10) = 1

⚠️ 算成 0 就是定義記錯。

② 五大性質【硬背】

  1. 每個節點不是紅就是黑。
  2. 根是黑。
  3. 每個葉節點(NIL)是黑。
  4. 紅節點的兩個小孩都是黑(⇔ 不能「紅接紅」)。
  5. 從任一節點到其下方每一個 NIL,經過的黑節點數目相同。

兩條在幹嘛?【理解】

管什麼效果
性質 4不能太紅任一路徑上,紅色最多佔一半
性質 5黑色要均勻每條路徑黑數一樣多

合起來 → 最長路徑 ≤ 最短路徑的 2 倍 → 樹高被鎖死。

檢查合法性:必做三件事

① 根是黑?
② 有沒有紅接紅?
③ 逐條路徑數黑色 —— 每條都一樣多嗎?

⚠️ 第三件最容易漏。 有些樹根黑、沒紅接紅,但黑色不均勻,一樣是死。

      20(B)        20→10(R)→NIL = 1 黑
     /    \        20→30(B)→NIL = 2 黑   ✗ 違反性質 5
   10(R)  30(B)

由性質推出來的結論

結論說明
黑高 b → 節點數2^b − 1 ~ 2^(2b) − 1
樹高 h(層數)b ≤ h ≤ 2b
含 NIL 時黑比紅多✓(n 個內部節點 → 恰 n+1 個 NIL,全黑)
只算內部節點時黑比紅多✗(紅最多可達黑的 2 倍)

③ 插入

鐵則:新節點一律塗紅【理解】

塗什麼後果
塗黑那條路徑黑數 +1 → 一定違反性質 5(全域問題,難修)
塗紅黑高不變 → 性質 5 永遠安全;頂多紅接紅(局部問題,好修)

紅色是免費的,它不佔黑高。 寧可製造好修的局部問題。

四個角色

z(新節點)、P(父)、G(祖父)、U(叔叔 = P 的兄弟,NIL 也算)

SOP

新節點塗紅
   ↓
父 P 是黑? ──是──► 結束(連叔叔都不用看)
   ↓ 否
看叔叔 U 的顏色
   ├─ U 紅  ──► 情況一:P、U 塗黑,G 塗紅,問題上移到 G(回到開頭)
   └─ U 黑/NIL
        ├─ z 在內側(折線) ──► 情況二:對 P 旋轉橋直 → 進情況三
        └─ z 在外側(直線) ──► 情況三:對 G 反向旋轉 + 交換 P、G 顏色 → 結束

SOP(圖解流程)

起點永遠是「父 P 是不是黑」;父黑直接收工。只有情況一會往上迴圈,情況二、三各轉一次就結束。

顏色的意思

灰前置(BST 插入、新節點塗紅)
琥珀判斷(父黑?、叔叔顏色、z 位置)
藍情況一:三方變色(不旋轉)
紫旋轉(情況二橋直 / 情況三收尾)
珊瑚問題上移到 G → 迴圈回開頭
青結束(免修或修完)

三情況速查

父 P 黑不用修(0 轉)
情況一 · U 紅P、U 塗黑,G 塗紅,上移到 G(0 轉,會迴圈)
情況二 · U 黑內側對 P 旋轉橋直 → 進情況三(1 轉)
情況三 · U 黑外側對 G 反向旋轉 + P、G 換色 → 結束(1 轉)
只有情況一會往上迴圈(可重複 O(log n) 次,但一次都不轉);一旦進到情況二 / 三,最多再轉 2 次就結束 → 插入旋轉 ≤ 2 次。

父 P叔叔 Uz 位置情況動作旋轉
黑——無違反不用修0
紅紅任意一P、U 塗黑,G 塗紅,問題上移到 G0

紅黑/NIL外側(直線)三對 G 反向旋轉 + 交換 P、G 顏色1

情況一「黑高沒變」的理由:原本「G 黑 + P/U 紅」= 1 黑;改完「G 紅 + P/U 黑」= 1 黑。只是把紅往上推一層。

G 若變成根 → 塗回黑。

為什麼旋轉 ≤ 2 次?【理解】

情況旋轉出口
一0上移兩層,繼續迴圈(可重複 O(log n) 次)
二1必定進情況三
三1P 變黑 → 紅接紅消失 → 結束

最壞路徑:情況一 × 很多次(0 轉) → 情況二(1 轉) → 情況三(1 轉) → ≤ 2 次

④ 刪除

第一步|化簡:找出「真正要移除的節點 y」

設 D = 你要刪的節點。

D 的小孩數動作y 是誰
0 / 1直接移除 / 用那個小孩頂替y = D
2找 S = D.right 一路往左到底;把 S 的 key 抄進 D;改成去刪 Sy = S

S 是最左者 → 絕對沒有左小孩 → y 永遠只有 0 或 1 個小孩。

只搬 key,節點沒搬(D 留在原位換名牌)。

x = 頂替 y 位置的那個節點(可能是 NIL)。

第二步|看顏色,決定要不要修

y 是紅色? ──是──► 結束(黑高不變,0 旋轉)
   ↓ 否(y 是黑)
x 是紅色? ──是──► 把 x 染黑,結束(0 旋轉)
   ↓ 否(x 是黑,含 NIL)
x 背上「雙黑」→ 跑下面的四情況 fixup

兩個提早結束的出口,先檢查它們,別急著套四情況。

第三步|雙黑 fixup(x 為左小孩版;右小孩鏡像)

角色:x(雙黑)、w(x 的兄弟)、P(父親)
近 / 遠:相對於 x。x 在左 → w.left 是近、w.right 是遠。

w 是紅? ──是──► 情況 1:對 P 左旋;w→黑、P→紅          (進 2/3/4)
   ↓ 否
w 兩個小孩都黑? ──是──► 情況 2:w→紅;x 上移到 P
   ↓ 否                    (P 若紅 → 染黑結束;否則回到開頭)
w 的「遠」小孩是黑(近的紅)? ──是──► 情況 3:對 w 右旋;w↔近小孩換色 (進 4)
   ↓ 否
情況 4:對 P 左旋;w 接手 P 的顏色;P→黑;遠小孩→黑  ──► 結束

判斷表【硬背】

情況條件動作旋轉出口
1w 是紅對 P 左旋;w→黑、P→紅1必進 2/3/4
2w 黑,兩小孩都黑w→紅;x 上移到 P0P 紅 → 染黑結束;否則迴圈
3w 黑,近紅、遠黑對 w 右旋;w ↔ 近小孩換色1必進 4
4w 黑,遠小孩紅對 P 左旋;w 接手 P 的顏色;P→黑;遠小孩→黑1結束

【理解】記憶線索

  • 1:兄弟太紅 → 先把它壓成黑(轉化用)
  • 2:兩邊一起少一個黑 → 公平 → 往上推。唯一會迴圈的情況
  • 3:紅色長在近端不好用 → 甩到遠端
  • 4:遠端有紅可以借 → 一刀結束

為什麼旋轉 ≤ 3 次?【理解】

情況旋轉迴圈?
11不迴圈,必進 2/3/4
20會迴圈,但一次都不轉
31不迴圈,必進 4
41直接結束

關鍵觀察:情況 1 執行後 P 被染紅 → 之後若進情況 2,x 上移到紅色的 P,迴圈立刻終止。

所以最壞路徑:

情況 2 × k 次(0 轉) → 情況 1(1 轉) → 情況 3(1 轉) → 情況 4(1 轉) → 結束

≤ 3 次

⑤ 時間複雜度【硬背】

樹高

h ≤ 2 log₂(n + 1)　　(n = 內部節點數)

推導主線:

①「黑色至少佔一半」    →  bh ≥ h / 2
②「黑高決定節點數下界」→  n ≥ 2^bh − 1
                       ⇒  h ≤ 2 log₂(n+1)

⚠️ 這是上界,不保證達得到。AVL 的 N(h) 表給的才是精確最大值。

三種操作

操作複雜度拆解
搜尋O(log n)就是走樹高
插入O(log n)BST 插入 O(log n) + 變色 O(log n) + 旋轉 ≤ 2 次
刪除O(log n)BST 刪除 O(log n) + 變色 O(log n) + 旋轉 ≤ 3 次

旋轉次數是常數,變色次數是 O(log n)。

旋轉要搬指標、動記憶體;變色只改 1 個 bit。這個交換就是紅黑樹存在的理由。

一句話選用:查詢為主 → AVL;改動頻繁 → 紅黑樹。

標準函式庫全選紅黑樹,因為 map 的真實負載是混合的。

⑥ 六大陷阱【硬背】

#陷阱正解
1檢查合法性只做兩件事必做三件,第三件是逐條路徑數黑色
2黑高忘記算 NILbh(單一黑根) = 1,不是 0
3插入時搞錯判斷起點起點永遠是「新節點的父親是不是紅的」。父黑 → 直接結束
4刪除急著套四情況先看兩個出口:y 是紅 → 結束;x 是紅 → 染黑結束
5把「上界」講成「最大值」2 log₂(n+1) 是上界,不保證可達
6「算不算 NIL」沒問清楚黑高一定算 NIL;「黑比紅多嗎」則要先問

高頻是非題

敘述答案理由
黑節點的兩個小孩必須是紅色✗性質 4 只管紅節點的小孩
紅黑樹是高度最小的 BST✗只保證 h ≤ 2log₂(n+1),AVL 才逼近最矮
全部節點塗黑一定合法✗合法 ⟺ 完美二元樹
插入一定要旋轉✗父黑就不用修;情況一只變色
刪除一定要旋轉✗y 紅或 x 紅都直接結束
紅黑樹的旋轉次數是 O(log n)✗旋轉是常數(插入 ≤2、刪除 ≤3);變色才是 O(log n)
新節點可以塗黑✗一定破壞性質 5(全域問題)

⑦ 考場最後 60 秒

檢查一棵樹合不合法

根黑 → 無紅接紅 → 逐條路徑數黑色(含 NIL)

插入

塗紅 → 父黑就結束 → 看叔叔:紅→變色上移;黑→折線先橋直、直線就旋轉換色

刪除

兩個小孩 → 換後繼的 key,改刪後繼
y 紅 → 結束 │ x 紅 → 染黑結束 │ 都黑 → 雙黑,跑四情況

數字

h ≤ 2log₂(n+1)　│　三種操作都 O(log n)
插入旋轉 ≤ 2　│　刪除旋轉 ≤ 3　│　變色 O(log n)　│　每節點 1 bit
