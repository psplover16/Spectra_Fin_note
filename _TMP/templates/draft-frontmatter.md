# _TMP 草稿 frontmatter 模板

```yaml
---
topic_id: ""
subject: ""
source_files: []
status: draft
generated_at: ""
verified_by: ""
---
```

## status

`status` 只允許：

- `draft`
- `verified`
- `blocked`

只有 `verified` 可由主代理匯入正式 app data。

## 草稿內容骨架

```md
# <topic title>

## source mapping

- source files:
- source sections:
- source summary:

## exam outline

## memory points

## understanding notes

## teaching content

## exam focus

## Java examples

## complexity and stability

## pitfalls

## technical terms

## verifier result

- final status:
- issue list:
- fix summary:
- verifier identity:
```
