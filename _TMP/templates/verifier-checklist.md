# verifier checklist

每份 `_TMP` 草稿通過前，verifier 至少檢查：

- 來源對應
- 考試大綱
- 記憶重點
- 理解重點
- 事實正確性
- Java 語意
- 時間複雜度
- 空間複雜度
- 穩定性
- 中英專有名詞
- 新手可讀性
- 考官可見註解

## verifier result format

```md
## verifier result

- source mapping:
- issue list:
- fix summary:
- final status:
- verifier identity:
```

`final status` 只能是 `verified` 或 `blocked`。
