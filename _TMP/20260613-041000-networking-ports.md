# 常見連接埠(Port Number)

## 來源摘要

來源「四、常見 Port Number」列出常見服務、port number 與 TCP/UDP 對應。

## 教學內容

- 連接埠(Port) 是同一台主機內用來分辨服務的號碼。
- TCP(Transmission Control Protocol) 重可靠連線；UDP(User Datagram Protocol) 重低延遲與低開銷。
- HTTP 是 80/TCP，HTTPS 是 443/TCP，DNS 是 53/UDP 與 53/TCP。
